线性回归

Lesson 0006（重写·深度版）· 第二阶段开始 · 预计 40-50 分钟

🔁 衔接

回归是量化最常用的统计工具——因子检验、收益归因、预测都用它。但金融数据违反回归几乎所有经典假设。这节讲清：OLS 的假设是什么、金融数据怎么违反每一个、违反后标准误差和 t 检验怎么失效、怎么修（Newey-West HAC、Fama-MacBeth）。不搞清这些，你的因子检验 p 值全是错的。

一、OLS 回顾与它的假设

线性回归模型：

$$y_t = \alpha + \beta_1 x_{1,t} + \cdots + \beta_k x_{k,t} + \varepsilon_t$$

OLS 找 $\beta$ 最小化残差平方和。在经典假设下（残差独立同分布、同方差、与 x 无关、正态），OLS 系数是最优线性无偏估计（BLUE），t 检验、F 检验、置信区间都有效。

⚠️ 金融数据违反几乎每一条

  • 残差自相关：金融残差有时间序列相关（0004），不独立
  • 异方差：残差方差随时间变（波动率聚集，0003），不同方差
  • 肥尾：残差非正态（0003、0005），t 检验基于正态
  • 多重共线性：因子之间高度相关（动量和短期反转、价值和质量）
  • 伪回归：非平稳序列回归（对价格回归）
  • 内生性：x 和 ε 相关（遗漏变量、测量误差、反向因果）

二、违反的后果——为什么你的 p 值是错的

2.1 残差自相关 + 异方差 → 标准误差错

OLS 标准误差公式假设残差独立同方差。违反时，标准误差有偏，t 检验和置信区间都错。典型后果：你算出某因子 t=3（"显著"），实际修正后 t=1（不显著）。大量"发现"的因子是标准误差算错导致的幻觉。

2.2 多重共线性 → 系数不稳定

两个因子高度相关时，回归分不清谁的贡献是谁的——系数方差爆炸，对样本微小变化极敏感。例：把"6 月动量"和"12 月动量"同时放回归，两者相关 0.9+，系数可能一个正一个负且都不显著，但合起来显著。解决：正交化（0012）、PCA、或干脆只放一个。

2.3 伪回归 Spurious Regression

两个独立非平稳序列回归，会得到显著系数和高 R²——纯假象。Granger-Newbold 1974 经典：两个独立随机游走回归，R² 常达 0.7+，t 检验"显著"。对价格回归价格就是伪回归。解决：对平稳序列回归（收益、差分、或协整组合）。

2.4 肥尾 → t 检验失效

t 检验基于正态残差。肥尾下，极端样本主导系数估计，t 统计量分布不再是 t——你算的 p 值偏小（过度拒绝原假设）。解决：稳健标准误差（heteroskedasticity-robust）、bootstrap、或直接用 t 分布残差。

三、修正方法

Newey-West HAC 标准误差

同时修正异方差和自相关的稳健标准误差（Heteroskedasticity and Autocorrelation Consistent）：

$$\hat{\Sigma}_{NW} = \hat{\Sigma}_0 + \sum_{l=1}^{L} w_l (\hat{\Sigma}_l + \hat{\Sigma}_l')$$

对滞后协方差加权求和（权重 $w_l$ 如 Bartlett 核衰减）。$L$ 是最大滞后——选太大方差大、选太小修正不足。实务用 $L \approx T^{1/3}$。金融回归几乎必用 Newey-West，否则 t 检验不可信。

Fama-MacBeth 回归——横截面因子检验的标准

检验因子横截面定价的两步法：

  1. 每个时点 $t$，横截面回归 $r_{i,t} = \alpha_t + \beta_t \cdot f_{i,t} + \varepsilon_{i,t}$，得 $\hat\beta_t$
  2. 对时间序列 $\{\hat\beta_t\}$ 算均值和 t 统计量（用 Newey-West 修自相关）

这处理了"横截面相关 + 时间序列相关"的双重问题，是因子检验（0009-0012）的标准工具。

正交化与 PCA

多重共线性的解决：把相关因子正交化（0012 详讲）——保留信息、消除共线性、系数可解释。PCA 更彻底但失去经济含义。

四、回归在量化里的三种用法

用法做什么关键陷阱
因子检验回归未来收益对因子值，看系数显著标准误差必须 Newey-West；多重检验（0008）
收益归因把策略收益回归到因子，分解 alpha 和 beta遗漏因子→ alpha 虚高（"alpha 是没识别的 beta"）
预测用因子预测未来收益R² 极低（金融可预测性弱）；过拟合

⚡ 金融回归的 R² 通常极低

横截面因子回归 R² 典型 0.01-0.05（解释 1-5% 收益变异）。这不是模型烂——是金融本来就难预测。低 R² + 显著系数 = 好因子（信号弱但真）。新手误区：追求高 R² → 加一堆因子过拟合 → 样本外崩。因子检验看的是系数显著性和经济逻辑，不是 R²。

🔗 币圈回归的特殊问题

  • 样本短：BTC 2009 至今，多数币更短。回归样本量小，标准误差大，更难显著。
  • 结构性断裂：每周期市场结构变，一个全样本回归可能平均掉不同体制的相反关系。用滚动回归或体制切换。
  • 幸存者偏差：只对还活着的币回归，死币（归零的）被排除 → 因子表现虚高（0008）。
  • 横截面小且变：每时期可交易的币数量变化大（2017 几十、2024 几千），横截面回归规模不一致。

测验

1. 金融数据为什么让 OLS 假设失效？

数据量不够 残差自相关（时间序列）、异方差（波动率聚集）、肥尾（非正态）、共线性（因子相关）、非平稳（伪回归） 数据不准 市场无效

2. 不修正直接用 OLS 标准 t 检验，后果？

没影响 标准误差有偏，p 值错——大量"显著"因子是标准误差算错的幻觉 系数错 只影响 R²

3. Newey-West HAC 标准误差解决什么？

多重共线性 同时修正异方差和残差自相关——金融回归几乎必用 伪回归 肥尾

4. 两个独立随机游走回归得到高 R² 显著系数，这是？

真有关系 伪回归——非平稳序列回归的假象，应对平稳序列（收益/差分/协整组合）回归 数据巧合 模型太好

5. 横截面因子回归 R² 只有 0.03，说明？

因子没用，删掉 正常——金融本来就难预测；看系数显著性（Newey-West）和经济逻辑，不是 R² 模型错了 要加更多因子提 R²
