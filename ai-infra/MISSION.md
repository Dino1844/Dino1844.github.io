# Mission: AI Infra

## Why
准备 AI Infra / LLM Infra 工程师面试(字节、阿里、OpenAI 量级),6 个月内从"有 ML 基础、工程/系统/CUDA 弱"打到能拿 offer。拿到 offer 后能在工作中独立落地推理服务、训练集群。

## Success looks like
- 白板讲清 LLM 推理/训练全链路关键机制(PagedAttention / 3D 并行 / ZeRO / NCCL)
- 手撕核心代码片段(Attention kernel / batching 调度 / 通信 overlap)
- 回答"为什么这么设计、瓶颈在哪、怎么优化"类系统设计题
- 有 2 个可讲的项目:改 vLLM + 跑 Megatron-LM 并行训练
- 通过模拟面试(高级 tier)

## Constraints
- 6 个月,每周 ~12h
- 有 ML 基础,工程/系统/CUDA 弱
- CUDA 半吊子状态:懂概念、不会写 → 用写代码兑现概念,不从概念讲起
- 学习偏好:先概念后代码,概念扎实再动手
- 方向:推理 Infra + 训练 Infra + CUDA/Kernel + 系统/调度(全要)

## Out of scope
- 模型架构/算法创新(已有 ML 基础,不在本 mission)
- 前端/产品层
- 非 LLM 的传统 ML infra(如推荐系统 serving)
