常见因子（下）+ 币圈特有因子

Lesson 0011（重写·深度版）· 预计 40-50 分钟

🔁 衔接

上节讲了三个传统因子。这节先补两个传统因子（低波动、质量），然后重点展开币圈特有因子——这是你做币圈量化最有 edge 的地方。传统因子在币圈要么不适用、要么已被充分定价，但链上数据、资金费率信号、稳定币流、清算带这些币圈因子很多还没被研究透，alpha 衰减更慢。

一、低波动因子 Low Volatility / Bet Against Beta (BAB)

1.1 现象

按波动率（或 β）排序，做多低波动组、做空高波动组，长期风险调整后跑赢。这直接违反 CAPM——CAPM 预测 β 与收益线性正相关，实证却发现低 β 资产收益高于线性预测，高 β 资产低于。

Frazzini-Pedersen (2014) BAB 构造

关键技巧：不能简单按 β 排序等权做多空——因为低 β 资产波动小，等权下风险贡献太小。BAB 按 β 的倒数定仓位：

$$w_i \propto \frac{1}{\beta_i} \quad (\text{低 } \beta \text{ 多配，高 } \beta \text{ 空配})$$

且做多端和做空端各自波动率归一化，使两端风险贡献相等。这样构造的组合才是"赌低 β 跑赢高 β"，而不是被高波动端主导。

1.2 为什么有效——两个机制

机制 A：杠杆约束 Leverage Constraint

很多机构（养老金、共同基金）不能或不愿加杠杆。为了达到目标收益，它们只能买高 β 资产（β>1 的股票，自带"杠杆"效果）→ 高 β 资产被推贵 → 未来收益降低。低 β 资产被冷落 → 便宜 → 未来收益高。这是 BAB 的核心解释——杠杆约束导致高 β 被高估。

机制 B：彩票偏好 Lottery Preference

散户偏好右偏的"彩票型"资产（高波动、可能暴涨）→ 高波动资产被推贵 → 收益降低。这和 BAB 互补——一个讲机构杠杆约束，一个讲散户彩票偏好，都把高波动资产推贵。

1.3 实证与失败模式

BAB 在美股 1929-2020 夏普 ~0.7，跨 24 国市场都成立。但有两个陷阱：

⚠️ 陷阱 1：低波动 = 低流动性？

低波动资产往往流动性差（没人交易才波动小）。回测买入"低波动山寨币"看起来稳——但实盘里你的单子本身就把价格打飞，回测的波动率是没有你参与时的波动率。必须配流动性过滤：只选日均成交额 > 阈值的标的。

⚠️ 陷阱 2：低波动在牛市跑输

低波动资产在单边牛市跑输（高 β 资产涨更多）。2017-2021 低波动因子连续跑输。它有体制性——在震荡/熊市有效，在狂暴牛市失效。

🔗 币圈低波动

币圈低波动因子陷阱更严重：币圈低波动币往往是死币（没流动性、没叙事），不是"稳健"。且币圈整体波动高，"低波动"的币年化也有 30-50%，仍远高于传统资产。币圈慎用低波动因子，要用必须严格过滤流动性和"项目还活着"。

二、质量因子 Quality

2.1 构造

质量 = 基本面"好"。Novy-Marx (2013) 用毛利率（Gross Profitability = (收入-成本)/资产）作为质量度量，发现它预测收益。Fama-French 五因子的 RMW（盈利强减弱）也是质量类。

指标含义
ROE / ROA净资产/资产收益率——越高越好
毛利率盈利能力稳定性
负债率越低越稳健
盈利波动越低越稳定
Piotroski F-score9 个基本面信号的合成评分

2.2 为什么有效

Novy-Marx 解释：高质量公司盈利能力可持续，市场低估了这种持续性，所以高质量股被低估。也有风险补偿视角：质量股在衰退期更抗跌，但平时被低估作为补偿。

2.3 核心用途：过滤价值陷阱

⚡ 价值 + 质量是经典组合

上节讲价值因子最大的坑是价值陷阱——"便宜但烂"。质量因子专门识别"烂不烂"。组合起来：在便宜股里挑质量好的 = 便宜且好，过滤掉便宜且烂。Asness et al. (2019) "Quality Minus Junk" 证明价值+质量组合夏普比单价值高 50%+。这是 Warren Buffett "以合理价格买好公司" 的量化版。

🔗 币圈质量

币圈"质量"度量（没有财报，用链上/项目数据）：

指标含义数据源
GitHub 开发活跃度commits/PR/贡献者数——项目还活着Glassnode, Santiment
TVL 稳定性DeFi 锁仓量是否在流失DefiLlama
持币集中度前 10 地址占比——越分散越健康链上
审计与 multisig是否经审计、金库是否多签DefiSafety 等
上线交易所数越多 = 越被认可CoinGecko

逻辑相同——筛掉"便宜但烂"的项目。币圈质量因子数据噪声大（GitHub 可刷、TVL 可刷），需多指标交叉验证。

三、币圈特有因子 ⭐（重点）

以下因子在传统市场不存在或不可观测，是币圈量化的独特 edge。每个讲清楚怎么算、为什么有效、怎么用、陷阱。

3.1 资金费率方向信号 Funding Rate Signal

上节讲了费率套利（carry，对冲掉方向赚费率）。费率还能做方向信号——不对冲，赌反转。

机制

费率极端值 = 单边过度拥挤。费率 +0.15%/8h 意味着多头愿意付年化 ~164% 维持多头头寸——这种拥挤度不可持续，反转临近。逻辑链：

费率极高 → 多头过度杠杆 → 价格稍有下跌 → 多头被清算 → 强制卖出 → 价格继续跌 → 更多清算 → 反转

这是杠杆清算的正反馈，币圈独有（传统市场没有如此透明的杠杆/清算数据）。

构造

信号 = 费率的 z-score（相对历史均值的标准化）：

$$\text{sig}_t = -\frac{f_t - \mu_f}{\sigma_f}$$

负号：费率极高（z 大正）→ 信号负 → 做空。费率极负 → 信号正 → 做多。只在 |z| 超过阈值（如 2）时开仓——常态费率无信号。

⚠️ 陷阱

费率极端可以持续很久——牛市里费率 0.1% 可以维持数周（多头一直在付钱且一直在赚，费率没回归）。过早反向开仓会被趋势打爆。必须配趋势过滤：只在动量信号也转负时才用费率反转信号。或等费率开始回落（二阶导转负）再进——确认反转已开始。

3.2 链上活跃度因子 On-Chain Activity

核心指标与算法

指标怎么算信号
活跃地址数当日发起/接收交易的去重地址数上升→使用增加→基本面改善
新增地址当日首次出现的地址数加速→新用户涌入→可能顶部（散户 FOMO）
交易所净流入流入交易所地址的币量 − 流出大量流入→准备抛售→看跌
SOPRSpent Output Profit Ratio = Σ(支出价值)/Σ(获取价值)>1 持有者整体盈利，<1 亏损
MVRV市值 / 已实现市值（按链上最后移动价计的总成本）极高→顶部，极低→底部

MVRV 详解（最重要的链上指标之一）

已实现市值（Realized Cap）= 每个币按它最后一次链上移动时的价格计价，全网络求和。可理解为"全网持仓成本基础"。

$$\text{MVRV} = \frac{\text{Market Cap}}{\text{Realized Cap}} = \frac{\text{当前价}}{\text{全网平均持仓成本}}$$

MVRV = 2 → 当前价是全网平均成本的 2 倍 → 持有者整体浮盈 100% → 抛售压力大。MVRV < 1 → 整体亏损，抛售动力弱（亏着不卖）。

历史：BTC MVRV > 3.5 是顶部区域（2013、2017、2021 顶部都触过），< 1 是底部区域（2015、2018、2022 底部）。这是币圈少数有清晰历史阈值的指标。

⚠️ 陷阱

链上指标有滞后和噪声：地址可刷（交易所内部地址、刷量团队）、UTXO 模型 vs 账户模型算法不同、隐私链/二层网络活动看不到。且 MVRV 阈值每周期都在变——2017 顶部 MVRV 4，2021 顶部只到 3.5，市场在进化。不能机械套历史阈值。

3.3 稳定币流量因子 Stablecoin Flows

机制

稳定币（USDT/USDC）是币圈弹药。USDT 大量流入交易所 = 资金准备买币 = 看涨。流出 = 资金撤离 = 看跌。这个因子在牛市初期尤其有效——往往先有稳定币涌入，后有币价上涨（领先信号）。

构造：监测稳定币在交易所余额的变化率。余额周环比 +5% → 看涨信号。

⚠️ 陷阱

稳定币流入也可能是准备卖币换稳定币（不确定方向）。要区分：流入 + 后续 BTC 流出交易所（提到冷钱包）= 真买；流入 + BTC 留在交易所 = 可能要卖。需结合币的流向一起看。且稳定币本身有发行/赎回（USDT 增发）干扰——要剔除稳定币市值变化。

3.4 清算带 / 持仓结构因子 Liquidation Clusters

机制

开放合约持仓量（OI）+ 杠杆分布 → 推算清算价格带。价格穿越某杠杆密集区时，触发连环清算 → 可预测的剧烈波动。

例：BTC 在 $60k，大量 10x 多单的清算价在 $54k。价格跌到 $54k → 这些多单被强平 → 强制卖出 → 价格跌到 $52k → 触发更多清算 → 雪崩。这是币圈"闪崩"的主因。

构造

从交易所 API 拿 OI 分布（或用 Coinglass 等聚合数据），估算各杠杆档位的清算价。清算密度高的价格带 = 磁吸区（价格倾向被吸过去触发清算）也是反弹区（清算完后卖压消失）。

信号：价格接近下方清算密集带 → 做空（赌清算雪崩）；清算已发生 → 做多（赌反弹）。

🔗 这是币圈独有的微观结构 alpha

传统市场没有如此透明的杠杆/清算数据。币圈交易所公开 OI、费率、有时清算数据。这个因子币圈特有、逻辑清晰、衰减较快（套利者也在用）。适合中高频，需实时数据。

3.5 跨交易所价差因子 Cross-Exchange Basis

同一币在币安、Coinbase、Kraken 上价格短暂偏离。价差超过阈值 → 在贵的卖、便宜的买 → 等价差回归。这是极短尺度均值回归，半衰期秒-分钟。

陷阱：需要低延迟执行 + 跨所资金调拨 + 提币时间（链上确认）风险。散户难做（拼不过机构的延迟和费用），但理解它有助于理解流动性和滑点。

⚡ 选因子的原则

对你（币圈、概念驱动、AI 写代码）：优先选逻辑清晰、衰减慢、数据可得的因子——动量、费率套利、费率方向信号、MVRV。这些有明确经济逻辑（不是数据挖掘），衰减慢（alpha 还在），且数据从 Glassnode/币安 API 容易拿。清算带和跨所价差虽有效但需低延迟基础设施，不适合现阶段。价值/低波动在币圈证据弱，慎用。

测验

1. BAB（Bet Against Beta）为什么有效？

低 β 资产收益更高 杠杆约束迫使不能加杠杆的机构买高 β 资产推贵它，低 β 被冷落而便宜——未来低 β 跑赢 低 β 没有风险 CAPM 预测的

2. 质量因子最核心的用途是？

单独做策略 和价值因子组合，过滤"便宜但烂"的价值陷阱 替代动量 替代低波动

3. MVRV = 2 意味着什么？

市值是 2 倍 当前价是全网平均持仓成本的 2 倍，持有者整体浮盈 100%，抛售压力大 要涨 2 倍 无意义

4. 资金费率方向信号（极端费率反向开仓）的最大陷阱是？

费率不能算 费率极端可维持很久（牛市多头一直付钱一直赚），过早反向会被趋势打爆——需配趋势过滤 费率总是均值回归 费率信号无效

5. 清算带因子的信号逻辑是？

清算带无法预测 价格接近杠杆密集清算带→触发连环清算→可预测剧烈波动；清算后卖压消失→反弹 清算带和价格无关 只在牛市有效
