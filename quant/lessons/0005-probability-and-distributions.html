概率与分布

Lesson 0005（重写·深度版）· 第一阶段收官 · 预计 45-55 分钟

🔁 衔接

0003 讲了金融数据肥尾、0004 讲了时间序列。这节把"肥尾"正式化：用什么分布建模金融收益。从正态出发，一步步放松假设——对数正态、Student-t、极值理论——每步说清"为什么要换、新分布解决什么、还剩什么问题"。这是风险度量（VaR、ES）和期权定价（BS 假设对数正态）的数学基础。

一、正态分布 Normal——起点和它为什么不够

$$f(x) = \frac{1}{\sigma\sqrt{2\pi}} e^{-\frac{(x-\mu)^2}{2\sigma^2}}$$

正态是起点因为CLT：大量独立小冲击的和趋向正态。如果收益是很多独立信息冲击的累加，正态合理。它只有两个参数（$\mu, \sigma$），完全由均值方差决定，数学上极方便。

⚠️ 正态在金融里的三宗罪

  • 无肥尾：尾部 $e^{-x^2}$ 衰减太快，4σ 事件概率 0.003%，实际金融几年一次。低估尾部风险。
  • 对称：左右尾相同。金融收益负偏——崩盘比暴涨剧烈（左尾更肥）。
  • 无界：支持整个实数轴。简单收益有下界 -100%（价格非负），正态给正概率于 < -100%。

二、对数正态 Log-normal——解决下界

如果 $r = \ln(P_t/P_{t-1})$ 正态，则价格比 $P_t/P_{t-1} = e^r$ 对数正态。价格自动 ≥ 0，解决下界问题。这是 Black-Scholes 的假设（第十三课）。

$$P_T = P_0 \cdot e^{(\mu - \sigma^2/2)T + \sigma\sqrt{T} Z}, \quad Z \sim N(0,1)$$

注意 $-\sigma^2/2$ 修正项：$E[P_T] = P_0 e^{\mu T}$，但中位数 $= P_0 e^{(\mu-\sigma^2/2)T}$——对数正态右偏，均值被少数大涨拉高，中位数低于均值。

⚠️ 对数正态仍无肥尾

对数正态只解决了下界，没解决肥尾——它的尾部仍是 $e^{-(\ln x)^2}$，比正态稍肥但远不够。BS 用对数正态假设，所以定价低估尾部——市场用波动率微笑修正（第十三课）。

三、Student-t 分布——正式引入肥尾

$$f(x) \propto \left(1 + \frac{x^2}{\nu}\right)^{-(\nu+1)/2}$$

$\nu$ 是自由度（尾指数相关）。$\nu$ 越小尾越肥：

  • $\nu \to \infty$：退化为正态
  • $\nu = 1$：柯西分布，连均值都不存在
  • 金融收益 $\nu$ 实测约 3-7

关键：$\nu < 4$ 时四阶矩不存在（峰度无穷），$\nu < 2$ 时方差都不存在。这解释了为什么金融数据的样本峰度极不稳定——真实峰度可能无穷，你用有限样本估永远在变。

为什么 t 分布拟合金融收益好

t 分布可理解为"正态 + 随机方差"——方差本身随机的正态混合。这正好对应波动率聚集：每个时点条件正态，但方差随时间变（随机），无条件分布就肥尾。t 分布是波动率聚集在分布层面的表现。

四、偏态 Skewness——左右不对称

$$\text{Skew} = \frac{E[(r-\mu)^3]}{\sigma^3}$$

股票收益负偏（左尾更肥）——崩盘比暴涨多。典型值 -0.5 到 -1。原因：去杠杆/恐慌是正反馈（跌→强平→更跌），上涨相对渐进。

🔗 币圈的偏态

币圈偏态更复杂：整体负偏（崩盘如 2020-03、2022-06），但牛市单币正偏极强——山寨币暴涨 10x、100x，右尾也肥。所以币圈是双尾肥，比股票的"左肥右瘦"更对称。这解释了为什么币圈期权波动率微笑比股票对称（第十三课）。做空山寨币（赌右尾不出现）极其危险——右尾肥意味着"涨 10x"概率不可忽略。

五、极值理论 Extreme Value Theory, EVT——专门建模尾部

前面分布拟合整个分布，但风险管理只关心尾部。EVT 直接建模极端值的分布。广义极值分布 GEV：

$$P(X \leq x) \approx \exp\left[-\left(1 + \xi \frac{x-u}{\sigma}\right)^{-1/\xi}\right]$$

$\xi$ 是形状参数：$\xi > 0$ 就是肥尾（Fréchet，幂律尾部），$\xi = 0$ 正态尾部（Gumbel），$\xi < 0$ 有上界（Weibull）。

EVT 的实务价值

用 EVT 估尾部不需要假设整个分布——只拟合最极端的样本（如最大 5% 损失），外推到 99.9% VaR。比"假设正态算 VaR"靠谱得多，因为不假设全分布形状。BitMEX、币安等清算引擎的风险模型用 EVT 估极端损失概率。VaR 和 Expected Shortfall：

$$\text{VaR}_\alpha = -\inf\{x : P(r \leq x) > 1-\alpha\}, \quad \text{ES}_\alpha = -E[r \mid r \leq -\text{VaR}_\alpha]$$

VaR 是 α 分位点损失，ES 是超过 VaR 之后的平均损失。ES 比 VaR 好——VaR 只告诉你"99% 不会亏超过 X"，但那 1% 里亏多少不管；ES 给条件期望，是一致性风险度量（coherent risk measure），数学性质更好。Basel III 已从 VaR 转向 ES。

六、分布选择对照

分布尾部偏态用在哪缺陷
正态瘦无Sharpe、初学、CLT 近似低估尾部、对称、无下界
对数正态稍肥正偏BS 期权定价仍不够肥、固定偏态方向
Student-t肥（幂律）无（对称版）收益建模、VaR对称（要 skewed-t 补偏态）
skewed-t / Johnson SU肥任意币圈收益、风险管理参数多、估计难
EVT (GEV/GPD)专门尾部含极端风险、清算引擎只管尾部，不管中心

测验

1. 正态分布建模金融收益的主要问题？

计算太复杂 无肥尾（低估极端事件）、对称（金融负偏）、无下界（给 < -100% 正概率） 参数太多 不支持负数

2. Student-t 分布比正态好在哪？

更简单 有肥尾（幂律衰减，$\nu$ 控制尾肥程度），可理解为"方差随机的正态"=波动率聚集在分布层面的表现 永远对称 无尾部

3. 为什么 Expected Shortfall 比 VaR 好？

算起来简单 VaR 只给分位点不管那 1% 里亏多少，ES 给超过 VaR 后的平均损失，是一致性风险度量 VaR 是错的 数值更小

4. 币圈收益偏态的特点？

强负偏，和股票一样 整体负偏（崩盘），但牛市山寨币右尾极肥（暴涨 10x+）——双尾肥，比股票对称 完全对称 强正偏

5. EVT（极值理论）为什么适合风险管理？

拟合整个分布最准 只拟合极端样本外推尾部，不假设全分布形状——风险只关心尾部，避免全分布误设 计算最快 监管要求
