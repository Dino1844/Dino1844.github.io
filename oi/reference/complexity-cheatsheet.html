大 O 定义

T(n) = O(f(n)) ⇔ ∃C, n₀ > 0 使得对所有 n ≥ n₀，T(n) ≤ C·f(n)。
直觉：描述增长趋势的上界，忽略常数和低阶项。

分析四步法

  1. 确定变量 — 谁是 n？
  2. 找最内层操作 — 执行最多次的语句
  3. 计算执行次数 — 用 n 表示
  4. 忽略常数和低阶 — O(n²+n) → O(n²)

一句秒记

C++ 每秒约 10⁷~10⁸ 次简单运算。n=10⁵ → 必须 ≤ O(n log n)；n=10³ → O(n²) 可行。
