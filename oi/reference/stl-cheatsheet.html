容器选择决策树

需要按键快速查找？
├── 是 → 需要有序？ → 是 → map / set (O(log n))
│                   → 否 → unordered_map / unordered_set (O(1))
└── 否 → 需要头尾操作？
         ├── 只需尾部 → vector (O(1) amortized)
         ├── 需要头部 → deque (O(1))
         └── 需要中间 → 考虑 list (但遍历 O(n))

unordered_map<K,V> / unordered_set<T>

操作代码复杂度
插入/更新mp[key] = val;均摊 O(1) ⚠️ key 不存在会插入
存在性检查mp.count(key) 或 mp.find(key) != mp.end()均摊 O(1)
删除mp.erase(key);均摊 O(1)
遍历for (auto& [k, v] : mp)O(n)
⚠️ 关键区别：mp[key] 在 key 不存在时会插入 {key, V()}。
若只想检查存在性，必须用 mp.find(key) 或 mp.count(key)。

stack / queue / deque

容器pushpoptop/front典型场景
stack<T>push(x) O(1)pop() O(1)top() O(1)DFS 非递归、单调栈、括号匹配
queue<T>push(x) O(1)pop() O(1)front() O(1)BFS、层序遍历
deque<T>头尾 push/pop 均 O(1)头尾 O(1)滑动窗口最值、单调队列

priority_queue<T>（堆）

// 默认大顶堆
priority_queue<int> pq;        // top() 返回最大值

// 小顶堆（三种写法）
priority_queue<int, vector<int>, greater<int>> pq;

// 自定义比较（lambda + decltype）
auto cmp = [](int a, int b) { return a > b; };
priority_queue<int, vector<int>, decltype(cmp)> pq(cmp);
操作代码复杂度
插入pq.push(x);O(log n)
取堆顶pq.top();O(1)
弹出堆顶pq.pop();O(log n)

<algorithm> 常用算法

算法代码复杂度
排序sort(v.begin(), v.end());O(n log n)
降序排序sort(v.begin(), v.end(), greater<int>());O(n log n)
自定义排序sort(v.begin(), v.end(), [](auto& a, auto& b) { return ...; });O(n log n)
二分查找binary_search(v.begin(), v.end(), x);O(log n)
下界（≥x）auto it = lower_bound(v.begin(), v.end(), x);O(log n)
上界（>x）auto it = upper_bound(v.begin(), v.end(), x);O(log n)
反转reverse(v.begin(), v.end());O(n)
最大值auto it = max_element(v.begin(), v.end());O(n)
全排列next_permutation(v.begin(), v.end());O(n)
第 k 小nth_element(v.begin(), v.begin()+k, v.end());O(n) 平均
去重auto it = unique(v.begin(), v.end()); v.erase(it, v.end());O(n)
