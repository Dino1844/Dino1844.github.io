核心职责

在不可靠的 IP 层之上，提供可靠、有序、去重的字节流传输。附带流量控制和拥塞控制。

标志位 (Flags)

标志含义出现于
SYN同步序列号，建立连接三次握手
ACK确认号字段有效握手后几乎所有包
FIN发送方数据发完，请求关闭四次挥手
RST强制重置连接异常终止
PSH催促接收方立即上交应用层交互式应用
URG紧急数据（极少使用）—

拥塞控制核心算法

阶段cwnd 增长触发离开的条件
慢启动每 RTT 翻倍（指数）cwnd ≥ ssthresh 或丢包
拥塞避免每 RTT +1 MSS（线性）丢包
快速恢复每收到重复 ACK，cwnd +1收到新 ACK → 回到拥塞避免
丢包响应：
超时 (RTO) → ssthresh = cwnd/2, cwnd = 1, 重新慢启动
3 个重复 ACK → ssthresh = cwnd/2, cwnd = cwnd/2, 快速重传 + 快速恢复

三次握手

Client → Server: SYN, seq=x
Client ← Server: SYN+ACK, seq=y, ack=x+1
Client → Server: ACK, seq=x+1, ack=y+1

四次挥手

主动方 → 被动方: FIN, seq=u
主动方 ← 被动方: ACK, ack=u+1
主动方 ← 被动方: FIN, seq=v
主动方 → 被动方: ACK, ack=v+1  →  进入 TIME_WAIT (2MSL)

常见 CLI 调试

命令作用
ss -t state time-wait查看 TIME_WAIT 连接数
ss -t state established查看已建立的 TCP 连接
tcpdump -i eth0 tcp port 443抓取 TCP 包
sysctl net.ipv4.tcp_congestion_control查看当前拥塞控制算法
