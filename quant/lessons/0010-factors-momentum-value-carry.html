常见因子（上）：动量、价值、Carry

Lesson 0010（重写·深度版）· 预计 40-50 分钟

🔁 衔接

上节建立了因子模型框架：收益 = Σβ·因子 + α。但"因子"还是抽象的——到底哪些因子真实存在、怎么构造、为什么有溢价、什么时候失效？这节展开三个最稳健、跨市场验证过、有清晰经济逻辑的因子。每个因子按同一结构讲：构造 → 为什么有效 → 实证 → 失败模式 → 币圈。

一、动量因子 Momentum

1.1 构造

两类构造（上节已区分，这里给精确公式）：

时间序列动量（TSMOM）

对每个资产 $i$，信号 = 过去 $k$ 期的对数收益：

$$\text{sig}_{i,t} = \sum_{s=1}^{k} r_{i,t-s} = \ln(P_{t-1}/P_{t-k-1})$$

仓位方向 = sign(sig)：正就做多，负就做空，零空仓。仓位大小常按波动率反比缩放（$w_i \propto \text{sig}_i / \sigma_i$）——这是波动率目标，让每个资产风险贡献相等。

横截面动量（XSMOM）

在每个时点 $t$，对所有资产按过去 $k$ 期收益排序，分 $N$ 组（如十组）。做多最高组、做空最低组：

$$\text{XSMOM}_t = R^{\text{top}}_t - R^{\text{bottom}}_t$$

多空金额相等 → 市场中性。学术标准：$k=12$ 个月（剔除最近 1 个月，Carhart UMD），持有 1 个月，每月再平衡。

1.2 为什么有效——三个解释

学术界争论 30 年，没有单一解释。三个机制都有证据：

解释 A：信息扩散缓慢（underreaction）

重大消息（盈利超预期、监管落地、技术升级）不是瞬间被所有人消化。Hong-Stein (1999) 的模型：信息缓慢扩散到投资者群体，早期反应者买入 → 价格部分上涨 → 后知后觉者陆续跟进 → 持续上涨。这解释了动量形成。

解释 B：行为偏差（disposition effect + extrapolation）

两个行为偏差共同维持动量：

  • 处置效应：投资者赢家卖得太早、输家拿得太久。这压抑了价格对新信息的充分调整——赢家本该涨更多但被提前卖出压制，输家本该跌更多但被死扛支撑。趋势因此被拉长。
  • 外推偏差：投资者把近期趋势外推到未来（"这币一直在涨，还会涨"），在趋势后期推高价格。

外推解释了动量后期反转——外推过度导致价格越过基本面，然后崩。

解释 C：风险补偿

趋势跟踪在震荡市持续小亏、在趋势市大赚。这种收益结构类似做空波动率——平时收小钱，偶尔大亏（动量崩溃）。动量溢价可能是对"承受震荡期痛苦 + 崩溃尾部风险"的补偿。这个解释能说明为什么动量没被套利消除——大多数人承受不了震荡期回撤，不会无限涌入。

动量是学术界发现的最稳健因子——跨资产、跨市场、跨时间尺度都成立。Asness et al. (2013) "Value and Momentum Everywhere" 在八个市场都找到它。

1.4 失败模式：动量崩溃 Momentum Crash

⚠️ 2009 年 3 月的教训

2008 金融危机中，动量策略大量做空"过去一年跌惨的"金融股。2009 年 3 月市场急速反弹，这些空头单边爆亏——动量策略在一个月内亏掉过去几年的累计收益。Daniel-Moskowitz (2016) 量化：动量崩溃是条件偏度现象——市场反弹时动量收益分布的左尾突然变肥。

根本原因：动量策略在反弹时持有大量空头，空头在反弹中亏钱。这是结构性的，不是偶然。

缓解动量崩溃的方法

  • 波动率目标（最有效）：市场波动飙升时自动降仓。2009 年 3 月波动飙升 → 仓位自动缩小 → 崩溃损失被限制。Moskowitz-Ooi-Pedersen 加了 vol scaling 后，2009 年回撤从 -70% 降到 -25%。
  • 动量信号波动过滤：信号本身的波动大时降仓。
  • 加反转因子对冲：短期反转和长期动量组合，部分对冲崩溃。
  • 识别体制：在"急速反转"体制（如 VIX 飙升后）暂停动量。

🔗 币圈动量

为什么更强：散户占比高（行为偏差大）、信息不对称严重（叙事传播慢）、杠杆正反馈循环（涨→空头被清算→强制买入→继续涨）。这三个机制都比传统市场更剧烈。

参数：BTC/ETH 用周-月级动量（12-26 周）较稳；日内动量噪声大。山寨币动量衰减更快（叙事周期短），用更短窗口（2-4 周）。

崩溃：币圈动量崩溃更猛——Luna (2022.5) 一周从 $80 归零，FTX (2022.11) 一天 -30%。任何币圈动量策略必须配波动率目标，否则活不过一个完整周期。

横截面山寨轮动：牛市中段资金从一个币轮到下一个，按相对强弱排序能捕捉。但熊市失效（一起跌，无相对强弱）且幸存者偏差严重——回测必须包含已归零的币。

二、价值因子 Value

2.1 构造

价值 = 便宜。度量"便宜"用价格相对某个基本面指标的比率：

指标公式含义
账面市值比B/P = 账面价值 / 市值Fama-French HML 用的
盈利收益率E/P = 盈利 / 市值1/PE，高=便宜
股息率D/P = 股息 / 市值高=便宜且付现
EV/EBITDA企业价值 / 息税折旧前利润剔除资本结构差异

构造：按价值指标排序，做多便宜组（高 B/P、高 E/P），做空贵组。Fama-French HML 就是这么做的。

2.2 为什么有效

解释 A：过度反应与均值回归

De Bondt-Thaler (1985)：投资者对坏消息过度反应，把困境公司股价砸得过低。后续现实没那么糟，价格回弹 → 便宜股跑赢。这是行为解释，和价值因子的长期反转性质一致（价值本质是 3-5 年均值回归）。

解释 B：风险补偿（distress risk）

便宜股往往是陷入困境的公司——高 B/P 常因为价格跌了（市场在担心）。价值溢价是对承担困境风险的补偿：便宜股在经济衰退时更容易破产，需要溢价补偿。这个解释说价值不是免费午餐。

解释 C：错配久期（duration mismatch）

成长股的现金流在远期，价值股在近期。利率上升时远期现金流折现更多 → 成长股跌更多 → 价值股相对跑赢。近年价值因子表现和利率变动高度相关——2022 年加息周期价值大爆发。

2.3 实证

美股 1927-2020，HML 年化溢价 ~4-5%，夏普 ~0.4。但价值有长失效期：1998-2000 互联网泡沫连续 5 年跑输，2018-2020 又连续 3 年跑输（直到 2022 加息回来）。长期有效 ≠ 一直有效。

2.4 失败模式：价值陷阱 + 长失效期

⚠️ 价值陷阱 Value Trap

便宜可能有原因：基本面在恶化，"便宜"会变更便宜。例：某山寨币 TVL 在流失但市值还没跌完，看起来"便宜"（市值/TVL 低）——其实是 TVL 还会继续掉，市值会跟着跌。区分"便宜且好"和"便宜且烂"是价值因子的核心难点。质量因子（下节）就是用来过滤价值陷阱的——价值 + 质量组合夏普比单价值高得多。

⚠️ 长失效期

价值能连续跑输 5 年。单做价值的策略，多数人扛不住 5 年回撤就退出了——这恰恰是价值溢价能存在的原因（解释 C 的风险补偿）。但对你意味着：价值因子不能单用，必须和动量等组合（0012）。

🔗 币圈的"价值"

币圈没有 P/E、P/B，但有类比——价格相对链上基本面的比率：

指标含义
市值 / 日活地址 (NVT 类)价格相对使用量
市值 / TVL（DeFi）价格相对锁仓量
市值 / 开发者活跃度价格相对开发投入
市值 / 已实现市值（MVRV）价格相对链上成本基础

问题：币圈"基本面"噪声大、易操纵（TVL 刷量、地址刷量）、项目生命周期短。价值因子在币圈远不如股票市场稳健——Asness 等人的"Value Everywhere"在币圈证据最弱。慎用，且必须配质量过滤。

三、Carry 因子 Carry

3.1 构造

Carry = 持有某资产的即时现金流收益率（假设价格不变）。构造：做多高 carry 资产、做空低 carry 资产，赚利差。

$$\text{carry}_i = \frac{F_i(t, t+h) - S_i(t)}{h \cdot S_i(t)} \quad (\text{近似})$$

$F$ 是 $h$ 期后的远期价格，$S$ 是现价。carry = 远期相对现货的折溢价率。Koijen et al. (2018) 证明这个统一公式跨资产都适用：

市场carry 来源机制
外汇利率差 $r_{\text{高}} - r_{\text{低}}$借低利率币买高利率币
债券到期收益率 − 短端利率期限溢价
商品期现价差backwardation（近>远）为正 carry
币圈永续资金费率做空高费率收钱

3.2 为什么有效

风险补偿视角

carry 本质是对承担某种风险的即期补偿。外汇 carry：高利率币常有贬值风险（汇率崩盘），carry 溢价补偿贬值风险。商品 backwardation：补偿生产者的对冲需求（生产者卖远期保值，压低远期价格）。币圈费率：补偿做空者承担的逼空风险。

关键：carry 不是无风险——它有"carry unwinding"尾部风险：平时收小钱，危机时标的暴涨（你做空）暴亏。

3.3 实证

Koijen et al. (2018) 在外汇、债券、商品、指数四个市场都找到 carry 溢价，组合夏普 ~0.8-1.0。币圈费率套利实证夏普更高（~1.5-2.5），但样本短、可能含幸存者偏差（没经历极端挤兑）。

3.4 失败模式：carry unwinding

⚠️ 危机时一起爆

2008 金融危机：高利率货币（澳元、新西兰元）暴跌，外汇 carry 策略集体 unwinding，一个月亏掉数年累计收益。1998 LTCM：利差套利在俄罗斯违约时爆。

币圈版：FTX (2022.11) 崩盘时，费率套利者现货在 FTX、合约头寸在别处——交易所挤兑导致对冲失效，现货拿不回来，合约端还在亏。费率套利的尾部风险是对手方风险，不是市场风险。

🔗 币圈 carry = 资金费率套利（详解）

费率机制（第一课已铺垫，这里给公式）：永续合约价格 $F$ 偏离现货 $S$ 时，每 8 小时多空间转移费率：

$$\text{funding rate} \approx \frac{F - S}{S} \cdot \frac{1}{\text{周期}} \quad (\text{clamp 到 } \pm 0.75\%)$$

$F > S$（多头狂热）→ 费率正 → 多头付空头 → 做多成本增 → 平多 → $F$ 压回 $S$。

套利：费率 0.1%/8h（年化 ~100%）时，现货买 1 BTC + 永续做空 1 BTC。价格风险对冲掉，每 8 小时稳收 0.1%。这是币圈少数有明确经济逻辑、不是数据挖掘的因子——费率存在是因为投机者愿意付钱维持杠杆，套利者赚这个溢价。

容量限制：套利者涌入 → 合约卖压 → $F$ 压回 $S$ → 费率回落。费率套利的容量有限，资金多了溢价就消失。这是 carry 因子普遍的拥挤效应。

尾部风险：交易所挤兑（FTX）、现货和合约在不同所的跨所风险、极端行情下现货和合约价差拉大导致保证金不足被强平。不要把全部资金放一个所做费率套利。

⚡ 动量和价值负相关——组合的基石

Asness et al. (2013) 关键发现：动量和价值在所有市场都负相关（约 -0.4 到 -0.7）。这反直觉但合理：动量买"涨的"（往往贵），价值买"便宜的"（往往跌的）——天然对立。负相关意味着组合起来夏普比单用高得多，且动量崩溃时价值往往表现好（2009 年 3 月动量崩、价值反弹）。这是 0012 多因子组合的理论基础。

测验

1. 动量崩溃（如 2009 年 3 月）的结构性原因是什么？

数据错误 策略持有大量"过去跌惨的"空头，市场急速反弹时空头单边爆亏 过拟合 手续费

2. 缓解动量崩溃最有效的方法是？

缩短回看窗口 波动率目标——市场波动飙升时自动降仓，限制崩溃损失 只做多 增加杠杆

3. 价值陷阱是什么？怎么过滤？

价值因子过拟合，用回测验证 便宜是因为基本面在恶化（会变更便宜），用质量因子过滤"便宜且烂"的 价值因子不存在 价值因子只适用股票

4. 资金费率套利的尾部风险主要是什么？

BTC 价格暴跌 对手方风险——交易所挤兑导致现货和合约头寸分离，对冲失效（如 FTX） 费率永远为负 手续费太高

5. 动量和价值为什么负相关？为什么这是好事？

它们用同一数据，所以负相关 动量买涨的（贵）、价值买便宜的（跌的）天然对立；负相关→组合夏普更高，且一方崩溃时另一方往往救场 负相关意味着不能组合 它们其实正相关
