# Resources

## 书籍

### 金融基础
- **《投资学》(Investments)** — Bodie, Kane & Marcus
  - 金融学科最权威的入门教材，覆盖市场、工具、资产定价、组合理论
  - 适合：系统建立金融知识体系
  - 状态：待获取

- **《期权、期货及其他衍生品》(Options, Futures, and Other Derivatives)** — John C. Hull
  - 衍生品定价的圣经，量化金融必读
  - 适合：有一定基础后深入衍生品
  - 状态：待获取

### 量化专项
- **《量化金融》(Paul Wilmott on Quantitative Finance)** — Paul Wilmott
  - 量化金融百科全书式著作
  - 适合：进阶参考
  - 状态：待获取

- **《金融统计与数据分析》(Statistics and Data Analysis for Financial Engineering)** — David Ruppert
  - 用 R 讲金融数据分析，统计方法扎实
  - 适合：学习金融数据建模
  - 状态：待获取

- **《Python 金融数据分析》(Python for Finance)** — Yves Hilpisch
  - 用 Python 做量化金融的实操书
  - 适合：动手实践
  - 状态：待获取

## 在线资源

### 平台
- **QuantConnect** (quantconnect.com) — 在线量化策略开发与回测平台
- **JoinQuant / 聚宽** (joinquant.com) — 国内最大的量化平台之一，有丰富的中文文档和社区

### 数据源
- **Yahoo Finance** — 免费的历史行情数据
- **Tushare** — 国内开源金融数据接口
- **AKShare** — 国产开源金融数据 Python 库

### 币圈资源
- **Binance Research** (research.binance.com) — 币安研究院，高质量报告
- **Glassnode** (glassnode.com) — 链上数据分析平台
- **CoinGecko** (coingecko.com) — 加密货币行情和数据 API
- **Messari** (messari.io) — 加密研究机构，深度报告

### 社区
- **Quantitative Finance Stack Exchange** (quant.stackexchange.com) — 量化金融问答社区
- **r/quant** (reddit.com/r/quant) — Reddit 量化社区
- **知乎量化金融话题** — 中文讨论
