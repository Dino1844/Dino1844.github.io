0020 的 DP 可以精确求解已知模型的 MDP。但在现实里，智能体不知道 $\mathcal{P}$ 和 $\mathcal{R}$—— 它只能通过与环境交互获得采样数据 $(s,a,r,s')$。本课把整条链推广到未知模型： 用采样期望替代精确期望，用自举（bootstrapping）替代全扫描。

激活已有知识

  1. Bellman 期望方程：$V^\pi(s) = \sum_a\pi\sum_{s'}\mathcal{P}[\mathcal{R}+\gamma V^\pi(s')]$
  2. Bellman 最优方程：$V^*(s)=\max_a\sum_{s'}\mathcal{P}[\mathcal{R}+\gamma V^*(s')]$
  3. 0020 的 GPI 范式：策略评估 + 策略改进交替
  4. 0012 的偏差-方差分解：$\mathbb{E}[(y-\hat{f})^2]=\text{Bias}^2+\text{Var}+\sigma^2$

1. 问题：DP 的两个致命假设

DP（策略迭代 + 值迭代）有效但有两个前提——现实中常不成立：

  1. 需要已知 $\mathcal{P}$ 和 $\mathcal{R}$。DP 的 Bellman 更新里直接用了转移概率和奖励函数。如果不知道——你就没法算期望。
  2. 需要全扫描。DP 每次更新遍历所有 $s\in\mathcal{S}$。状态空间大时不可行。

Model-free RL 的回答：(1) 用环境交互采样替代已知模型——从 $(s,a,r,s')$ 元组里学；(2) 用函数逼近替代全扫描（0022）。本课聚焦在表格型 model-free 方法——状态和动作有限，但 $\mathcal{P},\mathcal{R}$ 未知。

2. 蒙特卡洛（MC）：采样完整轨迹，平均回报

RL 范式

蒙特卡洛方法 · Monte Carlo

数学本质：用完整轨迹的采样回报来估计价值函数。$V^\pi(s) = \mathbb{E}_\pi[G_t|S_t=s]$ → 实际走完一条轨迹，记录从 $s$ 出发的实际回报 $G_t$，多做几次取平均。

核心公式（增量更新）

$$V(s) \leftarrow V(s) + \alpha\big[G_t - V(s)\big]$$

$\alpha$ = 学习率。$G_t$ = 真实回报（从 $s$ 出发走到终点拿到的全部奖励）。

→ 需要完整轨迹（episodic）→ 无偏但高方差

MC 不依赖 $\mathcal{P}$ 也不自举（bootstrapping）——它等轨迹结束，用实际拿到的回报当目标。优点：无偏估计（$\mathbb{E}[G_t]=V^\pi(s)$）。缺点：方差大——每条轨迹的回报受后续所有随机转移和动作影响，波动剧烈。

MC 策略评估（First-Visit）

对每个状态 $s$，维护 $V(s)$ 和计数 $N(s)$
走一轨迹 $s_0,a_0,r_1,s_1,a_1,r_2,\ldots,s_T$。对轨迹中第一次出现的每个状态 $s$，算 $G_t$。First-visit MC 保证每个状态 $s$ 的回报独立——消除轨迹内的相关。
$V(s) \leftarrow V(s) + \frac{1}{N(s)}(G_t - V(s))$递增平均 = 向目标 $G_t$ 移一小步

3. 时序差分（TD）：一步采样 + 自举

RL 范式 #23

时序差分学习 · TD(0)

数学本质：不等轨迹结束——每走一步就用 Bellman 方程做一步自举：用当前的 $V(s')$ 做 $r+\gamma V(s')$ 作为"更好的估计"，更新 $V(s)$。

核心公式（TD 更新）

$$\boxed{\;V(s) \leftarrow V(s) + \alpha\big[\underbrace{r + \gamma V(s')}_{\text{TD 目标}} - V(s)\big]\;}$$

$\delta_t = r + \gamma V(s') - V(s)$ = TD 误差（TD error）——"我以为这个状态值 $V(s)$，但实际拿到 $r$ 后到了值 $V(s')$ 的状态，预测偏了多少"。

→ 不需要完整轨迹→ 有偏但低方差→ 在线学习
TD 的"自举"是什么意思？TD 目标 $r+\gamma V(s')$ 里用到了当前的 $V(s')$——这是"用自己的估计去更新自己"。DP 也自举（用 $V_k$ 算 $V_{k+1}$）。MC 不自举——只用真实回报 $G_t$。自举 = 偏差的代价换方差的降低，这是 TD 与 MC 的核心 tradeoff。

TD 学习不需要环境模型，也不需要完整轨迹——每走一步 $(s,a,r,s')$ 就能做一次更新。这使得 TD 可以在线学习，适用于 continuing（无限长）任务。

MC vs TD：MC 走完整轨迹后回溯更新所有经过的状态；TD 每走一步就更新——用 V(s') 的当前估计做 bootstrapping。

4. MC vs TD：偏差-方差权衡

MCTD(0)
更新目标$G_t$（完整轨迹的真实回报）$r+\gamma V(s')$（一步采样 + 自举）
偏差无偏（$\mathbb{E}[G_t]=V^\pi$）有偏（$V(s')$ 初始不准 → 目标不准）
方差高（$G_t$ 含后续所有随机性）低（只有一步的随机性）
需要 episodic?是（等轨迹结束）否（每步都能更新）
收敛慢但稳通常更快（尤其 $\alpha$ 合适时）
这和 ML 的偏差-方差分解是同构的。MC 像 KNN——用原始数据点（轨迹），无偏但高变。TD 像回归——用模型假设（Bellman 方程的结构）约束估计，引入偏差但压低方差。哪个更好取决于样本量：数据少时 TD 的结构优势更大，数据多时 MC 的无偏性更可靠。

5. On-policy 控制：SARSA

预测（评估 $V^\pi$）只是第一步。RL 的终极目标是学最优策略。用 GPI 范式：TD 做策略评估 + $\varepsilon$-greedy 做策略改进 → SARSA。

SARSA 更新

从状态 $s$，用当前策略（$\varepsilon$-greedy）选动作 $a$，环境返回 $r,s'$。
在 $s'$，再次用同一策略选动作 $a'$。"SARSA" 的名字就是 $(s,a,r,s',a')$——五个字母对应五元组。
$Q(s,a) \leftarrow Q(s,a) + \alpha\big[r + \gamma Q(s',a') - Q(s,a)\big]$用实际执行的 $a'$ 做 TD 目标——on-policy
$$\boxed{\;Q(s,a) \leftarrow Q(s,a) + \alpha\big[r + \gamma Q(s',a') - Q(s,a)\big]\;}$$

On-policy：SARSA 学习的是自己正在执行的策略的 $Q$ 值。行为策略（选 $a$ 和 $a'$ 的策略）= 目标策略（被优化的策略）。这有一个后果——为了探索，行为策略必须随机（$\varepsilon$-greedy），所以 SARSA 学的是"带探索的最优策略"——它在乎探索的代价，会更"保守"。

6. Off-policy 控制：Q-learning

RL 范式 #24

Q-learning · Off-Policy TD Control

核心洞察：行为策略和目标策略可以不同——用任意策略（如随机探索）采样数据，但更新时假设最优策略（取 $\max$）。这是 Q-learning 和 SARSA 的本质区别。

核心公式

$$\boxed{\;Q(s,a) \leftarrow Q(s,a) + \alpha\big[r + \gamma \max_{a'} Q(s',a') - Q(s,a)\big]\;}$$

和 SARSA 的唯一区别：TD 目标用 $\max_{a'}Q(s',a')$（最优动作的 $Q$ 值）而不是实际执行的 $a'$ 的 $Q$ 值。

→ 0022 DQN: Q-learning + 神经网络
SARSA (on-policy)Q-learning (off-policy)
TD 目标$r + \gamma Q(s',a')$$r + \gamma \max_{a'} Q(s',a')$
$a'$ 的选择按行为策略（含探索）取 $\arg\max Q$（纯贪心）
学到的是"带探索的最优策略""纯最优策略"（独立于探索）
危险对探索代价敏感（保守）可能高估 $Q$ 值（max 偏差）
SARSA 在悬崖边更安全，Q-learning 更快但可能摔死。经典例子：Cliff Walking——SARSA 走远路绕过悬崖（因为探索步可能掉下去），Q-learning 走悬崖边（因为最优策略就是贴着走）。当场上的"探索步"有真实代价时（如交易亏损），SARSA 更安全。

7. 探索：$\varepsilon$-greedy 与 softmax

Model-free RL 的核心两难：探索（试没试过的动作，可能发现更好的）vs 利用（用已知最好的，稳拿奖励）。

$\varepsilon$-greedy：以 $1-\varepsilon$ 概率选 $\arg\max_a Q(s,a)$（利用），以 $\varepsilon$ 概率随机选（探索）。简单有效，但探索时所有非最优动作等概率——有些明显差的动作也会被"浪费"探索。

Softmax/Boltzmann 探索：$\pi(a\mid s) = \frac{\exp(Q(s,a)/\tau)}{\sum_{a'}\exp(Q(s,a')/\tau)}$。温度 $\tau$ 控制随机程度：$\tau\to 0$ → 贪婪；$\tau\to\infty$ → 均匀随机。$Q$ 值高的动作被选的概率更高——"聪明地探索"。

范式 #25 · 探索-利用权衡

这是 RL 独有的困难——监督学习没有"选哪个数据点去标注"的问题。多臂老虎机（bandit）是纯探索-利用问题（没有状态转移），MDP 是 bandit + 状态转移。解决思路：(1) $\varepsilon$ 随时间衰减（先多探索，后多利用）；(2) 用置信区间（UCB）；(3) Thompson 采样（贝叶斯版）。

8. 推导与自测

L1 · MC vs TD 的偏差-方差 L1
一个 MDP 有两个状态 A→B（奖励 0），B→终止（奖励 1）。$\gamma=1$。已有 8 条轨迹的数据：6 条 A→B→1，2 条 B→1。分别用 MC（first-visit，对 A 采样回报）和 TD(0) 估算 $V(A)$。TD 的 $V(B)$ 已收敛到 1。比较 MC 和 TD 的估计值，解释差异来源。
展开推导
MC 对 A：所有经过 A 的轨迹里 $G_t=1$（A→B→1），所以 $V_{\text{MC}}(A)=1$。MC 只看实际拿到的回报——6 条 A→B→1 全是 1。
TD 对 A：$V(A)=0+\gamma V(B)=1$。$V(B)$ 已收敛到 1。在这个简单例子里 MC 和 TD 给出相同答案——因为转移是确定性的。
但如果有随机转移——比如 A $\xrightarrow{0.5}$ B1（奖励 1），A $\xrightarrow{0.5}$ B2（奖励 0）——MC 每条轨迹的 $G_t$ 要么是 1 要么是 0，方差大。TD 用 $V(B)$ 的平均值做 bootstrapping，方差小。TD 利用 Markov 结构压缩方差。
L2 · Q-learning 的 max 偏差 L2
Q-learning 用 $\max_{a'}Q(s',a')$ 做 TD 目标。假设某状态 $s'$ 有三个动作，真实 $Q^*(s',a)=1$ 对所有 $a$，但估计值 $Q(s',a)$ 因采样噪声分别在 1 附近波动：（0.8, 1.3, 0.9）。解释为什么 $\max$ 操作会导致系统性高估 $Q(s',\cdot)$，并说明 Double Q-learning 如何解决。
展开推导
$\max_a Q(s',a) = 1.3 > 1.0$（真实最大值）。$\max$ 选的是估计值里最高的——这个"最高"部分来自运气（正噪声）。这是选择偏差（selection bias）：在噪声里挑最大的 → 高估。
Double Q-learning：维护两套 $Q_1,Q_2$。用 $Q_1$ 选动作（$\arg\max$），用 $Q_2$ 评价值。更新 $Q_1$ 时：$Q_1(s,a) \leftarrow Q_1(s,a) + \alpha[r+\gamma Q_2(s',\arg\max_{a'}Q_1(s',a')) - Q_1(s,a)]$。选和评用不同的 $Q$——去相关 → 消除正偏差。
上例：$Q_1$ 选动作 2（值 1.3），$Q_2$ 对该动作的估值可能是 0.95（无正噪声偏置）→ TD 目标约 0.95，不偏高。DQN 的 target network 也是同一思路——用延迟更新的网络做评估。
L3 · SARSA vs Q-learning 的最优策略差异 L3
证明：在有随机奖励和 $\varepsilon>0$ 的 MDP 中，SARSA 收敛到的策略可能不是纯最优策略 $\pi^*$，而是"最优带探索"策略。给出一个简单反例：探索步有代价时 SARSA 会绕路，而 Q-learning 抄近路。
展开推导
SARSA 评估的 $Q$ 是行为策略（含 $\varepsilon$-greedy 探索）的期望回报。$\varepsilon$-greedy 的行为策略有 $\varepsilon/|A|$ 的概率选非最优动作。SARSA 的 TD 目标 $r+\gamma Q(s',a')$ 里 $a'$ 是实际执行的——如果实际执行了探索步，这个 $a'$ 对应的 $Q$ 值会被"拉低"。
Cliff Walking 例子：最优策略贴悬崖走（路径短），但 $\varepsilon$-greedy 探索时可能掉下悬崖（大负奖励）。SARSA 学到：悬崖边的 $Q$ 值被"探索步掉下去"的负奖励压低 → 策略趋向于走安全远路。Q-learning 学到：$\max Q$ 假设不掉下去 → 贴悬崖。SARSA 的 on-policy 性质让它对探索步的代价"负责"；Q-learning 的 off-policy 性质让它无视探索步的代价。
结论：当探索步在真实部署中不存在时（训练完 $\varepsilon=0$），Q-learning 给的才是真正的最优策略。当探索/训练过程本身有代价时（如在线交易），SARSA 更安全。没有哪个"更好"——取决于"训练时的代价"是否算在优化目标里。
关键带回：MC = 完整采样 → 无偏高方差；TD = 一步自举 → 有偏低方差。MC 像 KNN，TD 像回归。SARSA = on-policy TD 控制（在乎探索代价）；Q-learning = off-policy TD 控制（只在乎最优策略）。Q-learning 的 $\max$ 导致高估，Double Q-learning 和 target network（0022 DQN）都是为解决这个。
