PTE · 页表项

Page Table Entry · 64-bit (x86-64)
一个PTE把一个虚拟页映射到一个物理帧——每个bit控制硬件行为。
Bit名称语义课
0P (Present)0→缺页·1→页在内存0003,0004
1R/W0→只读·1→可写·COW用此bit0003,0004
2U/S0→仅内核可访·1→用户可访0003
5A (Accessed)硬件自动置1—页替换判断热度0004
6D (Dirty)被写过—换出须写回磁盘0004
8G (Global)CR3写时不刷TLB—内核页用0003
63XD (NX)禁止执行—DEP的硬件基础0003,0009
主要课次：0003, 0004, 0009
