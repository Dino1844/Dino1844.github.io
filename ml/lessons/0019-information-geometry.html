1. 梯度方向取决于你怎么写参数

1.1 回顾：L0018 的终点是这节课的起点

在 L0018 中，score matching 损失里出现了 $\operatorname{tr}(\nabla_{\mathbf{x}} \mathbf{s}_\theta)$——score 网络对数据 $\mathbf{x}$ 的 Jacobian 的迹。那是数据空间的信息。

这节课把镜头转向参数空间。当我们用梯度下降优化一个概率模型时，我们在参数空间中移动——但参数空间的「几何」是什么？它是一个平直欧氏空间，还是一个弯曲的流形？

核心问题：如果我们改变了模型的参数化方式（比如把 $\sigma$ 换成 $\log\sigma$），梯度下降的方向会改变吗？如果会——哪个才是「正确」的？还是说「最陡方向」本身只是一个依赖于写法的人为概念？

1.2 一个简单的实验：Bernoulli 分布的两种写法

🌰 让我不舒服的第一步

硬币正面概率 $\theta\in(0,1)$。Bernoulli 分布：$p(x|\theta)=\theta^x(1-\theta)^{1-x}$，$x\in\{0,1\}$。

观测一次正面 ($x=1$)，负对数似然损失：$\mathcal{L}(\theta)=-\log p(x=1|\theta)=-\log\theta$。

梯度：$\frac{d\mathcal{L}}{d\theta}=-\frac{1}{\theta}$。在 $\theta=0.5$ 处，梯度 = $-2$。学习率 $\eta=0.1$：$\theta\leftarrow 0.5-0.1\times(-2)=0.7$。

现在换 logit 参数化：$\phi=\log\frac{\theta}{1-\theta}$，$\theta=\sigma(\phi)=\frac{1}{1+e^{-\phi}}$。

同样数据、同样损失：$\mathcal{L}(\phi)=-\log\sigma(\phi)=\log(1+e^{-\phi})$。

梯度：$\frac{d\mathcal{L}}{d\phi}=\sigma(\phi)-1=\theta-1$。在 $\theta=0.5$（$\phi=0$）处，梯度 = $-0.5$。$\eta=0.1$：$\phi\leftarrow 0-0.1\times(-0.5)=0.05$，对应 $\theta=\sigma(0.05)\approx 0.512$。

参数化$\theta=0.5$ 处的梯度一步后的 $\theta$
$\theta$（直接概率）$-2$$0.7$
$\phi$（logit）$-0.5$$\approx 0.512$
同一个模型、同一个数据、同一个学习率——走到了不同的地方。 在 $\theta$ 参数化下走了一步到 0.7；在 $\phi$ 参数化下只到了 0.512。这不是 bug——这是欧氏梯度下降的属性：它对参数化的选择不不变。「最陡下降方向」中的「最陡」是相对于参数坐标的欧氏距离定义的——而欧氏距离本身取决于你怎么写参数。

1.3 我们需要什么

需要一个不依赖于参数化方式的「最陡方向」定义。这个定义只应该依赖于概率分布本身的结构—— 两个参数 $\theta_1$ 和 $\theta_2$ 之间的「距离」不应该由它们在参数坐标中的欧氏距离来定义， 而应该由它们代表的概率分布 $p_{\theta_1}$ 和 $p_{\theta_2}$ 之间的差异来定义。

📍 停下来想一想：如果你说「$\theta=0.5$ 和 $\theta=0.7$ 差了 0.2」——这个 0.2 意味着什么？ 在概率意义上，$\theta=0.5$ 的硬币和 $\theta=0.7$ 的硬币「有多不一样」？ 我们需要用这个概率意义上的距离来定义梯度，而不是坐标意义上的。

2. Fisher 信息矩阵

核心概念

Fisher 信息矩阵 · Fisher Information Matrix

概率空间的黎曼度量
数学本质：$\mathbf{F}(\theta) = \mathbb{E}_{p_\theta}[\nabla_\theta\log p \cdot \nabla_\theta\log p^\top] = -\mathbb{E}_{p_\theta}[\nabla_\theta^2\log p]$。它衡量"参数的一个微小变化对概率分布的影响有多大"——信息越大 = 分布越尖锐 = 参数越确定。

为什么 Fisher 是"度量"

KL 散度的二阶展开：$\mathrm{KL}(p_\theta\|p_{\theta+d\theta}) \approx \frac{1}{2}d\theta^\top\mathbf{F}(\theta)d\theta$

Fisher 定义了参数空间中"真正"的距离——不是欧氏距离，是分布之间的差异。这就是为什么梯度下降需要在 Fisher 度量下做。

→ 0004(指数族): $a''(\eta)$ = Fisher → 0009(逻辑回归): Hessian = $\Phi^\top S\Phi$ = Fisher → 0018: 参数 score $\nabla_\theta\log p$

2.1 参数 Score——L0018 的镜像

在 L0018 中定义了对数据的 score：$\nabla_{\mathbf{x}}\log p(\mathbf{x})$。现在定义对参数的 score：

$$\boxed{\nabla_{\boldsymbol{\theta}}\log p(\mathbf{x}|\boldsymbol{\theta})}$$

这是一个向量，长度等于参数个数。衡量：参数 $\boldsymbol{\theta}$ 的微小变化会让观测到 $\mathbf{x}$ 的对数概率变化多少？ 如果某个参数方向的 score 很大，说明数据对这个参数「很敏感」——参数的一点点变化就会让观测概率大幅改变。

🌰 Bernoulli 的参数 score

$p(x|\theta)=\theta^x(1-\theta)^{1-x}$。取对数：$\log p(x|\theta)=x\log\theta+(1-x)\log(1-\theta)$。

$\frac{d}{d\theta}\log p(x|\theta)=\frac{x}{\theta}-\frac{1-x}{1-\theta}$

$x=1$：score = $1/\theta$。在 $\theta\approx 0$ 时 → 巨大。

$x=0$：score = $-1/(1-\theta)$。在 $\theta\approx 1$ 时 → 巨大。

score = 「这个观测有多意外」。几乎确定的硬币（$\theta\approx 1$）出现反面 —— score 极大。

2.2 Fisher 信息矩阵的定义

$$\boxed{\mathbf{F}(\boldsymbol{\theta}) = \mathbb{E}_{p(\mathbf{x}|\boldsymbol{\theta})}\big[\nabla_{\boldsymbol{\theta}}\log p \cdot \nabla_{\boldsymbol{\theta}}\log p^\top\big]}$$

逐条拆解：

  1. $\nabla_{\boldsymbol{\theta}}\log p$ 是参数 score 列向量（$P$ 维）
  2. $\nabla\log p \cdot \nabla\log p^\top$ 是外积——$P\times P$ 矩阵，第 $(i,j)$ 元 = $\frac{\partial\log p}{\partial\theta_i}\cdot\frac{\partial\log p}{\partial\theta_j}$
  3. $\mathbb{E}_{p(\mathbf{x}|\boldsymbol{\theta})}$ 是在模型自己的分布下取期望——用当前参数下的「预期数据」来评估这些参数对数据的影响力敏感度
  4. 结果 $\mathbf{F}$ 是 $P\times P$ 半正定矩阵
直觉：$\mathbf{F}_{ij}$ 衡量 $\theta_i$ 和 $\theta_j$ 在影响数据分布时的「重叠程度」。 如果它很大，改变 $\theta_i$ 和改变 $\theta_j$ 对数据分布的影响高度相似——在概率空间里，这两个参数方向是「几乎平行」的。 Fisher 矩阵是参数 score 的协方差矩阵——它告诉你每个参数方向上的「信息量」有多大。
Fisher 来自 Ronald Fisher (1890–1962)。他最初用它给出最大似然估计的渐近方差下界（Cramér-Rao bound）：任何无偏估计量方差 ≥ $\mathbf{F}^{-1}$。这里用的是它的几何含义——Amari (1980s) 发现它是概率分布空间的黎曼度量。

2.3 手算：$\mathcal{N}(\mu,\sigma)$ 的 Fisher 矩阵

🌰 一维高斯，$\boldsymbol{\theta}=(\mu,\sigma)$

Step 1：对数密度
$\log p(x|\mu,\sigma)=-\frac12\log(2\pi)-\log\sigma-\frac{(x-\mu)^2}{2\sigma^2}$
Step 2：参数 score
$\frac{\partial\log p}{\partial\mu}=\frac{x-\mu}{\sigma^2}$// 对 $\mu$ 求导
$\frac{\partial\log p}{\partial\sigma}=-\frac{1}{\sigma}+\frac{(x-\mu)^2}{\sigma^3}$// 对 $\sigma$ 求导
Step 3：取 $p$ 下的期望（记住 $\mathbb{E}[(x-\mu)^2]=\sigma^2$，$\mathbb{E}[(x-\mu)^4]=3\sigma^4$）
$\mathbf{F}_{\mu\mu}=\mathbb{E}[(\frac{x-\mu}{\sigma^2})^2]=\frac{\sigma^2}{\sigma^4}=\frac{1}{\sigma^2}$
$\mathbf{F}_{\mu\sigma}=\mathbb{E}[\frac{x-\mu}{\sigma^2}\cdot(-\frac1\sigma+\frac{(x-\mu)^2}{\sigma^3})]=0$// 奇函数期望为零（高斯对称）
$\mathbf{F}_{\sigma\sigma}=\mathbb{E}[(-\frac1\sigma+\frac{(x-\mu)^2}{\sigma^3})^2]=\frac{2}{\sigma^2}$// 利用峰度 $\mathbb{E}[(x-\mu)^4]=3\sigma^4$
$$\mathbf{F}(\mu,\sigma)=\begin{pmatrix}1/\sigma^2 & 0 \\ 0 & 2/\sigma^2\end{pmatrix}$$

观察：

  • $\mu$ 方向的信息量 = $1/\sigma^2$。$\sigma$ 大时，单个数据点关于 $\mu$ 的信息很少（分布宽，数据含混）
  • $\sigma$ 方向的信息量 = $2/\sigma^2$，是 $\mu$ 方向的两倍——改变 $\sigma$ 比改变 $\mu$ 对分布影响大得多
  • 非对角元为零——$\mu$ 和 $\sigma$ 在「影响数据分布」方面是正交的

2.4 Fisher 的三个关键性质

  1. 半正定：$\mathbf{v}^\top\mathbf{F}\mathbf{v}=\mathbb{E}[(\mathbf{v}^\top\nabla\log p)^2]\ge 0$——任何参数方向上的「信息量」都是非负的。
  2. 等于负期望 Hessian：$\mathbf{F}(\boldsymbol{\theta})=-\mathbb{E}_p[\nabla_{\boldsymbol{\theta}}^2\log p]$——Fisher 是 log 似然曲面在期望意义上的曲率。
  3. 重参数化不变性：如果换一套参数 $\boldsymbol{\phi}=g(\boldsymbol{\theta})$，Fisher 矩阵按 Jacobian 变换：$\mathbf{F}(\boldsymbol{\phi})=\mathbf{J}^{-\top}\mathbf{F}(\boldsymbol{\theta})\mathbf{J}^{-1}$——几何结构独立于参数表达。

3. KL 散度和 Fisher：几何的由来（度规矩阵 = 域翻译器）

3.1 先看地球：为什么度规矩阵是「域翻译器」

北京飞纽约。在地球表面，最短路径是大圆航线（穿过北极圈）。

但把这条最短路径画在墨卡托投影地图上（经线平行、纬线平行）——它是一条弯弯曲曲的弧线。而地图上的「直线」（等纬线）反而是绕远的。

地图坐标 ≠ 真实距离。度规矩阵 = 把「坐标差」翻译成「真实距离」的转换函数。

地球表面，用经纬度 $(\theta,\phi)$ 坐标：

$$ds^2 = \underbrace{R^2}_{\text{纬度系数恒定}} d\theta^2 + \underbrace{R^2\sin^2\theta}_{\text{经度系数随 } \theta \text{ 变化！}} d\phi^2$$
  • 纬度差 $1^\circ$ ≈ 111 km（全球一样）
  • 经度差 $1^\circ$：赤道 ≈ 111 km；北京（40°N）≈ 85 km；北极 ≈ 0 km

这就是 $R^2\sin^2\theta$ 的作用：同一个坐标变化 $d\phi$，在赤道和北极对应的实际地面距离完全不同。

$$\underbrace{d\boldsymbol{\theta}}_{\text{坐标域}} \;\xrightarrow{\;ds^2 = d\boldsymbol{\theta}^\top\mathbf{G}\,d\boldsymbol{\theta}\;}\; \underbrace{ds^2}_{\text{实际距离域}}$$

3.2 KL 散度的二阶展开 = Fisher 度量

现在把这个逻辑搬到概率分布空间。KL 散度是「两个分布之间的真实差异」：

$D_{\text{KL}}(p_{\boldsymbol{\theta}}\|p_{\boldsymbol{\theta}+d\boldsymbol{\theta}}) = \mathbb{E}_{p_{\boldsymbol{\theta}}}\big[\log\frac{p_{\boldsymbol{\theta}}}{p_{\boldsymbol{\theta}+d\boldsymbol{\theta}}}\big]$
$= -\mathbb{E}_{p_{\boldsymbol{\theta}}}\big[\log p_{\boldsymbol{\theta}+d\boldsymbol{\theta}} - \log p_{\boldsymbol{\theta}}\big]$
泰勒展开 $\log p_{\boldsymbol{\theta}+d\boldsymbol{\theta}}$：
$\log p_{\boldsymbol{\theta}+d\boldsymbol{\theta}} \approx \log p_{\boldsymbol{\theta}} + \nabla_{\boldsymbol{\theta}}\log p_{\boldsymbol{\theta}}^\top d\boldsymbol{\theta} + \frac12 d\boldsymbol{\theta}^\top(\nabla_{\boldsymbol{\theta}}^2\log p_{\boldsymbol{\theta}})d\boldsymbol{\theta}$
代入取期望：
$D_{\text{KL}} \approx -\underbrace{\mathbb{E}[\nabla\log p]^\top d\boldsymbol{\theta}}_{=\mathbf{0}} - \frac12 d\boldsymbol{\theta}^\top\underbrace{\mathbb{E}[\nabla^2\log p]}_{=-\mathbf{F}}d\boldsymbol{\theta}$
一阶项消失：score 在自身分布下的期望恒为零——$\mathbb{E}_p[\nabla\log p]=\int p\cdot\frac{\nabla p}{p}=\nabla\int p=\nabla 1=\mathbf{0}$。// 概率质量守恒——总概率永远是 1
$$\boxed{D_{\text{KL}}(p_{\boldsymbol{\theta}}\|p_{\boldsymbol{\theta}+d\boldsymbol{\theta}}) \approx \frac12\,d\boldsymbol{\theta}^\top\mathbf{F}(\boldsymbol{\theta})\,d\boldsymbol{\theta}}$$
核心几何事实：Fisher 矩阵是 KL 散度诱导的黎曼度量。 参数空间中的坐标差 $d\boldsymbol{\theta}$ 是「地图坐标」，$d\boldsymbol{\theta}^\top\mathbf{F} d\boldsymbol{\theta}$ 是这些坐标差对应的「真实概率距离」（= 2×KL 的二阶近似）。

一阶项消失是最关键的一步——它保证了距离的 leading order 是二次型，这正是黎曼度量需要的性质（距离应该是二次型，不是线性的）。Score 期望为零不是巧合——是概率密度归一化条件的必然推论。
📍 停下来想一想：参数空间中的 $d\boldsymbol{\theta}$ 是地图坐标。$\mathbf{F}$ 把地图坐标翻译成真实概率距离。 $\mathbf{F}$ 的各分量依赖于你在参数空间的位置——就像 $R^2\sin^2\theta$ 依赖于纬度。 在 $\sigma=3$ 处调 $\mu$，和在 $\sigma=0.5$ 处调 $\mu$，「同样的一步坐标变化」引起的分布变化完全不同。

4. 自然梯度

优化范式

自然梯度 · Natural Gradient

参数化不变的梯度下降
数学本质：$\Delta\theta = -\eta\mathbf{F}^{-1}\nabla_\theta\mathcal{L}$。普通梯度下降在欧氏空间找最陡方向——但这个方向取决于你怎么写参数。自然梯度在Fisher 度量下找最陡方向——不依赖参数化方式。

一句话直觉

$\mathbf{F}^{-1}$ 做了两件事：(1) 在分布变化剧烈的方向缩小步长（因为一步就改变很多）；(2) 在分布变化平缓的方向放大步长。结果是每一步在概率意义上走相同的距离。

→ 0001 §3: 正规方程 = 线性回归的自然梯度 → 0014: Adam ≈ 对角 Fisher 近似 → KFAC: 分块 Fisher 近似

4.1 重新定义「最陡」

普通 GD 等价于解带欧氏范数约束的优化问题：

$$\min_{d\boldsymbol{\theta}}\mathcal{L}(\boldsymbol{\theta}+d\boldsymbol{\theta})\ \text{s.t.}\ \|d\boldsymbol{\theta}\|_{\mathbf{I}}^2 \le \varepsilon^2$$

约束 $\|d\boldsymbol{\theta}\|^2 = d\boldsymbol{\theta}^\top\mathbf{I}\,d\boldsymbol{\theta}$ 假设所有参数坐标的刻度相同——但这不是真的。

自然梯度把约束换成 Fisher 范数：

$$\boxed{\min_{d\boldsymbol{\theta}}\mathcal{L}(\boldsymbol{\theta}+d\boldsymbol{\theta})\ \text{s.t.}\ d\boldsymbol{\theta}^\top\mathbf{F}(\boldsymbol{\theta})\,d\boldsymbol{\theta} \le \varepsilon^2}$$

约束含义：每一步最多改变分布一个「KL 距离」$\varepsilon^2/2$——不依赖于参数化方式。

4.2 拉格朗日乘子法推导

一阶近似 $\mathcal{L}(\boldsymbol{\theta}+d\boldsymbol{\theta})\approx\mathcal{L}(\boldsymbol{\theta})+\nabla\mathcal{L}^\top d\boldsymbol{\theta}$：

$\mathcal{L}(d\boldsymbol{\theta},\lambda)=\nabla\mathcal{L}^\top d\boldsymbol{\theta}+\lambda(d\boldsymbol{\theta}^\top\mathbf{F}d\boldsymbol{\theta}-\varepsilon^2)$
对 $d\boldsymbol{\theta}$ 求导为零：
$\nabla\mathcal{L}+2\lambda\mathbf{F}d\boldsymbol{\theta}=\mathbf{0}$// $\frac{\partial}{\partial d\boldsymbol{\theta}}(a^\top d\boldsymbol{\theta})=a$；$\frac{\partial}{\partial d\boldsymbol{\theta}}(d\boldsymbol{\theta}^\top\mathbf{F}d\boldsymbol{\theta})=2\mathbf{F}d\boldsymbol{\theta}$
$d\boldsymbol{\theta}=-\frac{1}{2\lambda}\mathbf{F}^{-1}\nabla\mathcal{L}$// 吸收 $\frac{1}{2\lambda}$ 到 $\eta$ 中
$$\boxed{\boldsymbol{\theta}_{t+1} = \boldsymbol{\theta}_t - \eta\,\mathbf{F}(\boldsymbol{\theta}_t)^{-1}\,\nabla_{\boldsymbol{\theta}}\mathcal{L}(\boldsymbol{\theta}_t)}$$
自然梯度 = 普通梯度 × Fisher 逆矩阵。$\mathbf{F}^{-1}$ 的作用是「除以每个方向的 sensitivity」。如果某方向的 Fisher 值大（参数对分布影响大），$\mathbf{F}^{-1}$ 在这个方向就小——走一小步就够了。影响小的方向被放大。

本质：先把弯曲的统计流形拉平（乘以 $\mathbf{F}^{-1}$），在这个平直空间里走普通梯度步，再把坐标映射回去。

4.3 手算验证：Bernoulli 的自然梯度

🌰 回到 1.2 节的例子

Fisher 信息（一维标量）：$\mathbf{F}(\theta)=\mathbb{E}[(\frac{d}{d\theta}\log p)^2]=\frac{1}{\theta(1-\theta)}$。

自然梯度：$\tilde{\nabla}\mathcal{L}=\mathbf{F}^{-1}\cdot\nabla\mathcal{L}=\theta(1-\theta)\cdot(-\frac1\theta)=\theta-1$。

在 $\theta=0.5$ 处：$\tilde{\nabla}\mathcal{L}=-0.5$。更新 $\theta\leftarrow 0.5-\eta(-0.5)=0.5+0.5\eta$。

用 logit 参数化 $\phi$ 再算：

$\mathbf{F}(\phi)=\mathbf{F}(\theta)\cdot(\frac{d\theta}{d\phi})^2=\frac{1}{\theta(1-\theta)}\cdot[\theta(1-\theta)]^2=\theta(1-\theta)$。

自然梯度：$\tilde{\nabla}_\phi\mathcal{L}=(\theta-1)/(\theta(1-\theta))$。更新 $\phi\leftarrow 0-\eta\cdot\frac{-0.5}{0.25}=2\eta$，对应 $\theta=\frac{1}{1+e^{-2\eta}}\approx 0.5+0.5\eta$（$\eta$ 小时）。

两套参数化给出相同的分布更新路径。$\theta(0.5+0.5\eta)$ 不管用 $\theta$ 还是 $\phi$ 都一样。 这就是重参数化不变性——换一套参数，概率分布的变化轨迹不变。

4.4 高斯分布的自然梯度——一个漂亮的解耦

🌰 $\mathcal{N}(\mu,\sigma)$ 拟合目标 $\mathcal{N}(0,1)$，KL 损失

KL 的梯度：$\frac{\partial\text{KL}}{\partial\mu}=\frac{\mu}{\sigma^2}$，$\frac{\partial\text{KL}}{\partial\sigma}=\frac{\sigma^2-1-\mu^2}{\sigma^3}$。

Fisher 逆矩阵：$\mathbf{F}^{-1}=\operatorname{diag}(\sigma^2,\sigma^2/2)$。

自然梯度更新：

$$\mu_{t+1} = \mu_t - \eta\cdot\sigma^2\cdot\frac{\mu_t}{\sigma^2} = \mu_t(1-\eta)$$

$\mu$ 的更新和 $\sigma$ 完全解耦——简单的指数衰减，不管 $\sigma$ 多大！

而普通 GD 的 $\mu$ 更新是 $\mu_{t+1}=\mu_t(1-\eta/\sigma^2)$——当 $\sigma$ 很大时 $\mu$ 几乎不动。

5. 可视化：为什么自然梯度好

高斯 $\mathcal{N}(\mu,\sigma)$ 拟合目标 $\mathcal{N}(0,1)$。损失函数是 KL 散度 $D_{\text{KL}}(p_{\text{target}}\|p_{\text{model}})$。

6. 实战：回到深度学习

6.1 和牛顿法的关系

牛顿法：$\Delta\boldsymbol{\theta}=-\eta\mathbf{H}^{-1}\nabla\mathcal{L}$，$\mathbf{H}=\nabla_{\boldsymbol{\theta}}^2\mathcal{L}$ 是即时 Hessian。

当 $\mathcal{L}=-\log p$（对数似然损失）：$\mathbf{F}=-\mathbb{E}_p[\nabla^2\log p]$ 是期望 Hessian。

牛顿法自然梯度
用的矩阵即时 Hessian $\mathbf{H}$期望 Hessian（= Fisher）
正定性可以不半正定（某点曲率为负 → 牛顿步可能走错方向）总是半正定
计算需要二阶导数只需一阶导数的外积期望

对于对数似然损失，自然梯度 ≈ 对 Hessian 做了平滑——数值上更稳定。

6.2 维数灾难

$\mathbf{F}$ 是 $P\times P$ 矩阵。$P$= 百万到千亿 → 存储和求逆需要 $O(P^2)\sim O(P^3)$ —— 不现实。

实际近似：

  • KFAC (Martens & Grosse, 2015)：将 Fisher 近似为 Kronecker 积——逐块对角 + 每块可逆。$O(P)$ 复杂度。中等规模网络有效。
  • Adam：逐坐标的梯度平方移动平均——相当于对 Fisher 对角线的粗略近似（假设参数间无耦合）。解释了为什么 Adam 通常比 SGD 快——它至少考虑到了不同参数的敏感度差异。

8. 核心 takeaway

  1. 普通梯度下降的「最陡」依赖于参数化方式——换一个写法就走到了不同的地方。
  2. 我们需要一个只依赖概率分布本身的距离定义。KL 散度就是这个「概率意义上的距离」。
  3. KL 的二阶泰勒展开给出 $\frac12 d\boldsymbol{\theta}^\top\mathbf{F}d\boldsymbol{\theta}$——Fisher 矩阵 = KL 诱导的黎曼度量 = 参数空间中的「域翻译器」。
  4. 把梯度下降的约束从欧氏范数换成 Fisher 范数 → 自然梯度 = $\mathbf{F}^{-1}\nabla\mathcal{L}$。
  5. 自然梯度有重参数化不变性——$\theta$ 或 logit，分布的变化路径一样。
  6. 高维中 $\mathbf{F}^{-1}$ 不可算 → KFAC、Adam 的对角近似是实用的折衷。
📌 下节课方向：KL 散度只是众多「分布间距离」的一种。 GAN 用 JS 散度 → 梯度消失。WGAN 用 Wasserstein 距离 → 就稳定了。 Score matching 用 Fisher divergence。下节课：散度家族与最优传输——理解为什么不同的散度导致不同的算法行为和几何。
