SVM 是你"理解但不熟推导"的部分——本课的目标就是把每一步代数走通，让你能从"最大间隔"四个字一路推到对偶问题的标准形， 并说清每一步为什么这么做。SVM 的推导是 ML 里拉格朗日对偶最经典的实例，掌握它等于掌握了一整类"带约束的凸优化"套路。

故事的逻辑链：几何上想最大化决策边界到最近点的距离（间隔）→ 写成带约束的优化问题 → 约束碍事，用拉格朗日乘子吸进目标 → 对原始变量求偏导令零，消去它们，得到只含乘子的对偶问题 → KKT 互补松弛条件揭示只有"边界上的点"（支持向量）的乘子非零 → 强对偶性由凸性 + Slater 保证，对偶解 = 原始解 → 对偶里数据只以内积出现，套核技巧即升维。 每一步都不是技巧堆砌，而是前一步的必然展开。

  2. 二分类标签 $y_n\in\{-1,+1\}$（注意 SVM 用 $\pm1$，不是逻辑回归的 $\{0,1\}$）。正确分类即 $y_n(\mathbf{w}^\top\mathbf{x}_n+b)>0$。
  3. 带等式约束的拉格朗日法：$\min f$ s.t. $g=0$ → $\mathcal{L}=f-\lambda g$，对 $x$ 和 $\lambda$ 求驻点。不等式约束要加 KKT。

1. 几何直觉：间隔最大化推出约束优化

最大间隔分类器。实线 = 决策边界，虚线 = 间隔边界。圈出来的点 = 支持向量（决定边界位置）。

线性可分的二分类数据 $\{(\mathbf{x}_n,y_n)\}_{n=1}^N$，$y_n\in\{-1,+1\}$。决策边界是超平面 $\mathbf{w}^\top\mathbf{x}+b=0$。 间隔（margin）定义为所有样本到决策边界的最小距离：

$$\text{margin} = \min_n \frac{y_n(\mathbf{w}^\top\mathbf{x}_n+b)}{\|\mathbf{w}\|}$$

这里用 $y_n(\mathbf{w}^\top\mathbf{x}_n+b)$ 而非 $|\mathbf{w}^\top\mathbf{x}_n+b|$ 是因为正确分类时 $y_n$ 与 $\mathbf{w}^\top\mathbf{x}_n+b$ 同号，乘积为正，正好给出带符号的距离。SVM 的目标：在所有正确分类的超平面里，选间隔最大的那个。

$$\max_{\mathbf{w},b}\;\min_n \frac{y_n(\mathbf{w}^\top\mathbf{x}_n+b)}{\|\mathbf{w}\|} \qquad\text{s.t.}\quad y_n(\mathbf{w}^\top\mathbf{x}_n+b)>0,\;\forall n$$
为什么最大化间隔？ 几何上，间隔越大，决策边界对样本位置的扰动越不敏感——泛化越好。 这是一种结构风险最小化：不直接最小化训练误差（线性可分时本来就是 0），而是最小化一个与容量相关的量（间隔的倒数）。 这与 基石 0001 的正则化视角 的"正则化 = 罚复杂度"是同一哲学的不同面孔——下一课（0008）会把这点讲透：硬间隔 SVM 等价于 hinge 损失 + $\ell_2$ 正则。

2. 标准化约束：把间隔固定为 1，问题变干净

上面的 $\max\min$ 形式不好处理。关键观察：$(\mathbf{w},b)$ 可以整体放缩而不改变超平面—— $\mathbf{w}^\top\mathbf{x}+b=0$ 与 $(c\mathbf{w})^\top\mathbf{x}+cb=0$ 是同一个超平面。利用这个自由度，把最近点的函数间隔固定为 1：

$$y_n(\mathbf{w}^\top\mathbf{x}_n+b)\geq 1,\quad\forall n \qquad\text{（最近的点取等号）}$$

在这个归一化下，间隔 $=\min_n \frac{y_n(\mathbf{w}^\top\mathbf{x}_n+b)}{\|\mathbf{w}\|}=\frac{1}{\|\mathbf{w}\|}$。 最大化间隔 $\frac{1}{\|\mathbf{w}\|}$ 等价于最小化 $\|\mathbf{w}\|$，等价于最小化 $\frac12\|\mathbf{w}\|^2$（平方是为了求导干净，且凸）。

$$\boxed{\;\min_{\mathbf{w},b}\;\frac12\|\mathbf{w}\|^2 \qquad\text{s.t.}\quad y_n(\mathbf{w}^\top\mathbf{x}_n+b)\geq 1,\;\forall n\;}$$

这是 SVM 的原始问题（primal）。目标 $\frac12\|\mathbf{w}\|^2$ 是凸二次，约束是线性的——所以这是一个凸二次规划（convex QP），有唯一全局解。

归一化的合法性：设最优超平面最近点函数间隔为 $m>0$。令 $\tilde{\mathbf{w}}=\mathbf{w}/m,\tilde b=b/m$，则最近点函数间隔变 1，超平面不变，$\|\tilde{\mathbf{w}}\|=\|\mathbf{w}\|/m$。所以"固定间隔为 1 再最小化 $\|\mathbf{w}\|^2$"与"直接最大化 $1/\|\mathbf{w}\|$"给出同一个超平面。这不是近似，是精确等价。

3. 拉格朗日法：把约束吸进目标函数

优化范式

拉格朗日对偶 · Lagrange Duality

约束优化 → 无约束鞍点问题
数学本质：约束优化 $\min f(\mathbf{w})$ s.t. $g_i(\mathbf{w})\leq 0$ → 无约束极小极大：$\min_{\mathbf{w}}\max_{\boldsymbol{\alpha}\geq 0} \mathcal{L}(\mathbf{w},\boldsymbol{\alpha})$。乘子 $\alpha_i$ 是约束的"价格"。

拉格朗日函数

$$\mathcal{L}(\mathbf{w},\boldsymbol{\alpha}) = f(\mathbf{w}) + \sum_i \alpha_i g_i(\mathbf{w}), \quad \alpha_i \geq 0$$

KKT 条件在最优点成立：$\alpha_i g_i(\mathbf{w}^*) = 0$（互补松弛——要么约束活跃，要么乘子为零）。

→ 0007: SVM 对偶推导 → 0008: 软间隔加松弛变量 → 0015: VI 约束优化视角

原始问题有 $N$ 个不等式约束 $y_n(\mathbf{w}^\top\mathbf{x}_n+b)-1\geq 0$。引入拉格朗日乘子 $\alpha_n\geq 0$（每个约束一个），构造拉格朗日函数：

$$\mathcal{L}(\mathbf{w},b,\boldsymbol{\alpha}) = \frac12\|\mathbf{w}\|^2 - \sum_{n=1}^N \alpha_n\big[y_n(\mathbf{w}^\top\mathbf{x}_n+b)-1\big]$$

减号是约定：约束写成 $g_n\geq0$，乘子 $\alpha_n\geq0$，$\mathcal{L}=f-\sum\alpha_n g_n$。这样对偶函数 $\theta(\boldsymbol{\alpha})=\inf_{\mathbf{w},b}\mathcal{L}$ 始终是原始最优值的下界（弱对偶）。

🔗 推导范式 #8 · 拉格朗日对偶——"约束变乘子，原始变量求导消去"

任何 $\min f$ s.t. $g_n\geq0$ 的凸问题都能走这套：(1) $\mathcal{L}=f-\sum\alpha_n g_n$，$\alpha_n\geq0$；(2) 对原始变量求驻点（偏导令零），解出原始变量关于 $\boldsymbol\alpha$ 的表达式；(3) 代回 $\mathcal{L}$ 消去原始变量，得对偶 $\max_\boldsymbol\alpha\theta(\boldsymbol\alpha)$；(4) KKT 补充互补松弛定解。 本课 SVM、0008 软间隔、0010 EM（EM 是对偶的远亲：下界最大化）、0015 变分推断——全是"造下界再最大化"这一招。 对偶的价值：变量数从 $D$（特征维）变 $N$（样本数），且只出现内积——为核化铺路。

4. 求对偶：先对 $\mathbf{w},b$ 求偏导令零

对偶函数 $\theta(\boldsymbol{\alpha})=\inf_{\mathbf{w},b}\mathcal{L}(\mathbf{w},b,\boldsymbol{\alpha})$。对 $\mathbf{w}$ 和 $b$ 求偏导令零：

对 $\mathbf{w}$ 求驻点

$\displaystyle \nabla_{\mathbf{w}}\mathcal{L} = \mathbf{w} - \sum_{n=1}^N \alpha_n y_n \mathbf{x}_n = \mathbf{0}$ $\frac{\partial}{\partial\mathbf{w}}\|\mathbf{w}\|^2=\mathbf{w}$（带 $\frac12$），$\frac{\partial}{\partial\mathbf{w}}\mathbf{w}^\top\mathbf{x}_n=\mathbf{x}_n$
$\displaystyle \Rightarrow\quad \mathbf{w} = \sum_{n=1}^N \alpha_n y_n \mathbf{x}_n$ 这是 SVM 的第一个关键等式——$\mathbf{w}$ 是数据的线性组合

对 $b$ 求驻点

$\displaystyle \frac{\partial\mathcal{L}}{\partial b} = -\sum_{n=1}^N \alpha_n y_n = 0$ $b$ 只在 $\alpha_n y_n b$ 里出现，求导得 $-\sum\alpha_n y_n$
$\displaystyle \Rightarrow\quad \sum_{n=1}^N \alpha_n y_n = 0$ 对偶问题的一个等式约束
$\mathbf{w}=\sum\alpha_n y_n\mathbf{x}_n$ 就是 0006 表示定理的 SVM 版本！ 最优 $\mathbf{w}$ 落在数据张成的子空间里。这不是巧合——它是"目标含 $\|\mathbf{w}\|^2$ 正则 + 损失只通过 $\mathbf{w}^\top\mathbf{x}_n$ 依赖 $\mathbf{w}$"的必然结果。 SVM 的对偶推导其实是表示定理的"约束优化版证明"。

现在把 $\mathbf{w}=\sum\alpha_n y_n\mathbf{x}_n$ 和 $\sum\alpha_n y_n=0$ 代回 $\mathcal{L}$ 消去 $\mathbf{w},b$：

代回化简

$\displaystyle \mathcal{L} = \frac12\|\mathbf{w}\|^2 - \sum_n\alpha_n y_n\mathbf{w}^\top\mathbf{x}_n - b\sum_n\alpha_n y_n + \sum_n\alpha_n$
$\displaystyle = \frac12\|\mathbf{w}\|^2 - \mathbf{w}^\top\!\sum_n\alpha_n y_n\mathbf{x}_n - b\cdot 0 + \sum_n\alpha_n$ 用 $\sum\alpha_n y_n=0$ 消去 $b$ 项
$\displaystyle = \frac12\|\mathbf{w}\|^2 - \mathbf{w}^\top\mathbf{w} + \sum_n\alpha_n = -\frac12\|\mathbf{w}\|^2 + \sum_n\alpha_n$ 用 $\mathbf{w}=\sum\alpha_n y_n\mathbf{x}_n$，所以 $\sum\alpha_n y_n\mathbf{x}_n=\mathbf{w}$
$\displaystyle = \sum_{n=1}^N\alpha_n - \frac12\sum_{n=1}^N\sum_{m=1}^N \alpha_n\alpha_m y_n y_m\,\mathbf{x}_n^\top\mathbf{x}_m$ 把 $\|\mathbf{w}\|^2=\mathbf{w}^\top\mathbf{w}$ 用 $\mathbf{w}=\sum\alpha_n y_n\mathbf{x}_n$ 展开

对偶问题是最大化这个（在 $\alpha_n\geq0$、$\sum\alpha_n y_n=0$ 约束下）：

$$\boxed{\;\max_{\boldsymbol{\alpha}}\;\sum_{n=1}^N\alpha_n - \frac12\sum_{n,m}\alpha_n\alpha_m y_n y_m\,\mathbf{x}_n^\top\mathbf{x}_m \qquad\text{s.t.}\quad \alpha_n\geq0,\;\sum_n\alpha_n y_n=0\;}$$

注意三件事：(1) 变量是 $\boldsymbol\alpha\in\mathbb{R}^N$，与特征维 $D$ 无关——这是高维核化的关键；(2) 数据只通过内积 $\mathbf{x}_n^\top\mathbf{x}_m$ 出现——这是核技巧的入口；(3) 仍是凸 QP（目标关于 $\boldsymbol\alpha$ 是凹二次，最大化凹 = 凸优化）。

5. KKT 条件：互补松弛推出"支持向量"

原始问题凸、约束仿射，所以 KKT 条件是充要的。四个条件：

$$\begin{aligned} &\text{(1) 稳定性:}\quad \nabla_{\mathbf{w}}\mathcal{L}=\mathbf{0},\;\partial_b\mathcal{L}=0 \;\Rightarrow\; \mathbf{w}=\sum\alpha_n y_n\mathbf{x}_n,\;\sum\alpha_n y_n=0\\ &\text{(2) 原始可行:}\quad y_n(\mathbf{w}^\top\mathbf{x}_n+b)\geq 1\\ &\text{(3) 对偶可行:}\quad \alpha_n\geq 0\\ &\text{(4) 互补松弛:}\quad \alpha_n\big[y_n(\mathbf{w}^\top\mathbf{x}_n+b)-1\big]=0 \end{aligned}$$

互补松弛是 SVM 全部直觉的来源。它说：每个样本 $n$，要么 $\alpha_n=0$，要么 $y_n(\mathbf{w}^\top\mathbf{x}_n+b)=1$（恰好在间隔边界上）。

  • $\alpha_n=0$ 的样本：对 $\mathbf{w}=\sum\alpha_m y_m\mathbf{x}_m$ 无贡献——它不在边界上，挪动它不影响解。
  • $\alpha_n>0$ 的样本：必须 $y_n(\mathbf{w}^\top\mathbf{x}_n+b)=1$，即恰好在间隔边界（函数间隔恰为 1）。这些点叫支持向量（support vectors）。
支持向量是"刚好卡住间隔"的点。 解 $\mathbf{w}=\sum_{n\in SV}\alpha_n y_n\mathbf{x}_n$ 只由支持向量决定——其余样本就算删掉，解不变。 这就是 SVM 的稀疏性：决策函数 $f(\mathbf{x})=\mathbf{w}^\top\mathbf{x}+b=\sum_{n\in SV}\alpha_n y_n\mathbf{x}_n^\top\mathbf{x}+b$ 只需对支持向量求和。 对比逻辑回归：那里每个样本都进梯度，没有稀疏性。这是 SVM 的结构性优势。

求出 $\boldsymbol\alpha$ 后，$\mathbf{w}$ 由 $\sum\alpha_n y_n\mathbf{x}_n$ 给出。偏置 $b$ 用任一支持向量（其 $y_n(\mathbf{w}^\top\mathbf{x}_n+b)=1$）解出： $b=y_n-\mathbf{w}^\top\mathbf{x}_n$（对任意 $n$ 满足 $\alpha_n>0$）。实践中对所有支持向量取平均以稳定数值。

6. 强对偶成立：Slater 条件与凸性

弱对偶说对偶最优 $\leq$ 原始最优。强对偶（等号成立）需要条件。这里：目标 $\frac12\|\mathbf{w}\|^2$ 凸，约束仿射（线性），且线性可分时 Slater 条件成立（存在严格可行点 $y_n(\mathbf{w}^\top\mathbf{x}_n+b)>1$）。 所以强对偶成立，对偶解 $\boldsymbol\alpha^\star$ 代回 KKT 给出原始解 $(\mathbf{w}^\star,b^\star)$。

🔗 推导范式 #9 · 凸 + Slater → 强对偶 → KKT 充要

对凸优化 $\min f$ s.t. $g_n\leq0$（$f,g_n$ 凸），只要存在严格可行点（Slater），强对偶成立且 KKT 是充要条件。 这意味着：解对偶 = 解原始，且对偶通常更好算（变量少、结构好）。 SVM、0008 软间隔、凸优化里的内点法、0015 平均场变分的强对偶——都靠这一条。 反例：非凸问题（如带 sigmoid 的某些神经网络训练）强对偶可能不成立，对偶只是下界——这是变分推断（0015）只能给 ELBO 下界、不保证紧的根本原因。

7. 核化：对偶里只有内积，换核即升维

对偶问题里数据只以 $\mathbf{x}_n^\top\mathbf{x}_m$ 出现，决策函数也只以 $\mathbf{x}_n^\top\mathbf{x}$ 出现。把内积换成核 $k(\mathbf{x}_n,\mathbf{x}_m)=\boldsymbol\phi(\mathbf{x}_n)^\top\boldsymbol\phi(\mathbf{x}_m)$（0006），就把线性 SVM 升到特征空间 $\boldsymbol\phi$ 里的非线性 SVM，而推导一行不改：

$$\max_{\boldsymbol{\alpha}}\;\sum_n\alpha_n - \frac12\sum_{n,m}\alpha_n\alpha_m y_n y_m\,k(\mathbf{x}_n,\mathbf{x}_m),\quad \alpha_n\geq0,\;\sum_n\alpha_n y_n=0$$ $$f(\mathbf{x})=\sum_{n\in SV}\alpha_n y_n\,k(\mathbf{x}_n,\mathbf{x})+b$$

这是 0006 表示定理的回报：解在数据张成的子空间，所以只需 $N\times N$ 核矩阵，无穷维特征空间永不显式出现。RBF 核 $k(\mathbf{x},\mathbf{z})=\exp(-\gamma\|\mathbf{x}-\mathbf{z}\|^2)$ 对应无穷维特征空间——SVM + RBF 能拟合任意复杂的边界，却仍受间隔正则控制，不易过拟合。

硬间隔的局限：要求线性可分（在特征空间里）。真实数据常有噪声或重叠，硬间隔要么无解要么被 outlier 拉歪。下一课 0008 引入松弛变量 $\xi_n$ 允许违反间隔，把"必须分对"换成"违反要罚"，得到软间隔 SVM——并揭示它就是 hinge 损失 + $\ell_2$ 正则，回接基石 0001 §2 损失视角。

8. 推导与演算

下面 6 道题，难度递增。先自己做，做不出再看提示，做完再对解答。SVM 的推导就这些，全走通就真懂了。

题 1 · 从间隔最大化到标准原始问题 L1 · 基础
从 $\max_{\mathbf{w},b}\min_n\frac{y_n(\mathbf{w}^\top\mathbf{x}_n+b)}{\|\mathbf{w}\|}$ 出发，利用 $(\mathbf{w},b)$ 的放缩自由度，推出标准原始问题 $\min\frac12\|\mathbf{w}\|^2$ s.t. $y_n(\mathbf{w}^\top\mathbf{x}_n+b)\geq1$。说清"固定间隔为 1"为什么不失一般性。
提示
设最优解最近点函数间隔为 $m$。令 $\tilde{\mathbf{w}}=\mathbf{w}/m,\tilde b=b/m$。验证约束变 $y_n(\tilde{\mathbf{w}}^\top\mathbf{x}_n+\tilde b)\geq1$，目标变 $\frac{1}{2}\|\tilde{\mathbf{w}}\|^2=\frac{1}{2m^2}\|\mathbf{w}\|^2$。最大化 $1/\|\mathbf{w}\|$ 等价于最小化 $\|\mathbf{w}\|^2$。
解答
设某超平面正确分类所有点，最近点函数间隔 $m=\min_n y_n(\mathbf{w}^\top\mathbf{x}_n+b)>0$。几何间隔 $=m/\|\mathbf{w}\|$。
放缩 $\tilde{\mathbf{w}}=\mathbf{w}/m,\tilde b=b/m$：超平面方程 $\tilde{\mathbf{w}}^\top\mathbf{x}+\tilde b=0$ 与原相同（同乘 $m$），所以分类不变。新函数间隔 $\min_n y_n(\tilde{\mathbf{w}}^\top\mathbf{x}_n+\tilde b)=m/m=1$。
新几何间隔 $=1/\|\tilde{\mathbf{w}}\|=m/\|\mathbf{w}\|$——与放缩前相同（放缩不改几何间隔，本应如此）。
所以"在所有正确分类的超平面里最大化几何间隔"等价于"在满足 $y_n(\mathbf{w}^\top\mathbf{x}_n+b)\geq1$ 的超平面里最大化 $1/\|\mathbf{w}\|$"，即最小化 $\|\mathbf{w}\|$，即最小化 $\frac12\|\mathbf{w}\|^2$（平方为了凸 + 求导干净）。$\square$
不失一般性：放缩自由度意味着函数间隔的绝对值无意义（可任意调），只有几何间隔（除以 $\|\mathbf{w}\|$ 后）有意义。固定函数间隔为 1 只是选了一个方便的归一化代表。
题 2 · 对 $\mathbf{w},b$ 求驻点 L1 · 基础
对拉格朗日 $\mathcal{L}=\frac12\|\mathbf{w}\|^2-\sum_n\alpha_n[y_n(\mathbf{w}^\top\mathbf{x}_n+b)-1]$，求 $\nabla_{\mathbf{w}}\mathcal{L}=0$ 和 $\partial\mathcal{L}/\partial b=0$，推出 $\mathbf{w}=\sum\alpha_n y_n\mathbf{x}_n$ 和 $\sum\alpha_n y_n=0$。
提示
$\nabla_{\mathbf{w}}\frac12\|\mathbf{w}\|^2=\mathbf{w}$，$\nabla_{\mathbf{w}}(\mathbf{w}^\top\mathbf{x}_n)=\mathbf{x}_n$。$b$ 是标量，$\partial(\alpha_n y_n b)/\partial b=\alpha_n y_n$。
解答
$\nabla_{\mathbf{w}}\mathcal{L}=\mathbf{w}-\sum_n\alpha_n y_n\mathbf{x}_n=0\Rightarrow\mathbf{w}=\sum_n\alpha_n y_n\mathbf{x}_n$。
$\frac{\partial\mathcal{L}}{\partial b}=-\sum_n\alpha_n y_n=0\Rightarrow\sum_n\alpha_n y_n=0$。$\square$
第一条是表示定理的 SVM 实例；第二条是对偶的等式约束，代回时消去 $b$ 项。
题 3 · 代回化简得到对偶目标 L2 · 理解
把题 2 的两个结果代回 $\mathcal{L}$，证明 $\mathcal{L}$ 化为 $\sum_n\alpha_n-\frac12\sum_{n,m}\alpha_n\alpha_m y_n y_m\mathbf{x}_n^\top\mathbf{x}_m$。说清 $b$ 项为什么消失。
提示
展开 $\mathcal{L}=\frac12\|\mathbf{w}\|^2-\sum\alpha_n y_n\mathbf{w}^\top\mathbf{x}_n-b\sum\alpha_n y_n+\sum\alpha_n$。$b$ 项系数是 $-\sum\alpha_n y_n=0$。再用 $\mathbf{w}=\sum\alpha_n y_n\mathbf{x}_n$ 把 $\sum\alpha_n y_n\mathbf{w}^\top\mathbf{x}_n=\mathbf{w}^\top\mathbf{w}=\|\mathbf{w}\|^2$。
解答
$\mathcal{L}=\frac12\|\mathbf{w}\|^2-\sum_n\alpha_n y_n\mathbf{w}^\top\mathbf{x}_n-b\sum_n\alpha_n y_n+\sum_n\alpha_n$。
$b$ 项：$-b\sum_n\alpha_n y_n=-b\cdot0=0$（用题 2 第二条）。这就是 $b$ 消失的原因——对 $b$ 求驻点产生的等式约束正好消掉 $b$。
中间项：$\sum_n\alpha_n y_n\mathbf{w}^\top\mathbf{x}_n=\mathbf{w}^\top\sum_n\alpha_n y_n\mathbf{x}_n=\mathbf{w}^\top\mathbf{w}=\|\mathbf{w}\|^2$（用题 2 第一条 $\sum\alpha_n y_n\mathbf{x}_n=\mathbf{w}$）。
所以 $\mathcal{L}=\frac12\|\mathbf{w}\|^2-\|\mathbf{w}\|^2+\sum\alpha_n=-\frac12\|\mathbf{w}\|^2+\sum\alpha_n$。
展开 $\|\mathbf{w}\|^2=\mathbf{w}^\top\mathbf{w}=\big(\sum_n\alpha_n y_n\mathbf{x}_n\big)^\top\big(\sum_m\alpha_m y_m\mathbf{x}_m\big)=\sum_{n,m}\alpha_n\alpha_m y_n y_m\mathbf{x}_n^\top\mathbf{x}_m$。
得 $\mathcal{L}=\sum_n\alpha_n-\frac12\sum_{n,m}\alpha_n\alpha_m y_n y_m\mathbf{x}_n^\top\mathbf{x}_m$。$\square$
题 4 · 互补松弛与支持向量的稀疏性 L2 · 理解
(a) 写出 SVM 的四个 KKT 条件。
(b) 用互补松弛 $\alpha_n[y_n(\mathbf{w}^\top\mathbf{x}_n+b)-1]=0$ 证明：$\alpha_n>0$ 当且仅当 $\mathbf{x}_n$ 在间隔边界上（$y_n(\mathbf{w}^\top\mathbf{x}_n+b)=1$）。
(c) 证明决策函数 $f(\mathbf{x})=\sum_n\alpha_n y_n\mathbf{x}_n^\top\mathbf{x}+b$ 只需对 $\alpha_n>0$ 的样本求和。
提示
(b) 互补松弛说乘积为 0，所以 $\alpha_n>0$ 时另一个因子必为 0。反之若 $\alpha_n=0$，另一个因子可任意（只要 $\geq0$，即原始可行）。(c) $\alpha_n=0$ 的项对 $\mathbf{w}$ 和 $f$ 都无贡献。
解答
(a) (1) $\mathbf{w}=\sum\alpha_n y_n\mathbf{x}_n$，$\sum\alpha_n y_n=0$；(2) $y_n(\mathbf{w}^\top\mathbf{x}_n+b)\geq1$；(3) $\alpha_n\geq0$；(4) $\alpha_n[y_n(\mathbf{w}^\top\mathbf{x}_n+b)-1]=0$。
(b) ($\Rightarrow$) $\alpha_n>0$ 时由 (4) $y_n(\mathbf{w}^\top\mathbf{x}_n+b)-1=0$，即在间隔边界。($\Leftarrow$) 在间隔边界 $y_n(\mathbf{w}^\top\mathbf{x}_n+b)=1$ 时 (4) 自动满足，$\alpha_n$ 可 $>0$（具体值由对偶解定）。严格在间隔外（$>1$）时 (4) 强制 $\alpha_n=0$。
(c) $f(\mathbf{x})=\mathbf{w}^\top\mathbf{x}+b=\big(\sum_n\alpha_n y_n\mathbf{x}_n\big)^\top\mathbf{x}+b=\sum_n\alpha_n y_n\mathbf{x}_n^\top\mathbf{x}+b$。$\alpha_n=0$ 的项贡献 0，所以 $f(\mathbf{x})=\sum_{n\in SV}\alpha_n y_n\mathbf{x}_n^\top\mathbf{x}+b$，$SV=\{n:\alpha_n>0\}$。$\square$
这就是 SVM 的稀疏性：非支持向量对预测无贡献。删掉它们，解不变。
题 5 · 对偶是凹二次规划 L3 · 进阶
把对偶目标写成矩阵形式 $\mathbf{1}^\top\boldsymbol\alpha-\frac12\boldsymbol\alpha^\top\mathbf{Q}\boldsymbol\alpha$，其中 $Q_{nm}=y_n y_m\mathbf{x}_n^\top\mathbf{x}_m$。证明 $\mathbf{Q}$ 半正定，从而对偶是凹二次规划（最大化凹函数 = 凸优化），有唯一解（若 $\mathbf{Q}$ 正定）。
提示
$\mathbf{Q}=(\mathbf{Y}\mathbf{X})(\mathbf{Y}\mathbf{X})^\top$ 形式，其中 $\mathbf{Y}=\operatorname{diag}(y_n)$。对任意 $\mathbf{v}$，$\mathbf{v}^\top\mathbf{Q}\mathbf{v}=\|(\mathbf{Y}\mathbf{X})^\top\mathbf{v}\|^2\geq0$。
解答
令 $\mathbf{Y}=\operatorname{diag}(y_1,\dots,y_N)$，$\mathbf{X}\in\mathbb{R}^{N\times D}$ 行为 $\mathbf{x}_n^\top$。则 $Q_{nm}=y_n y_m\mathbf{x}_n^\top\mathbf{x}_m=(\mathbf{Y}\mathbf{X}\mathbf{X}^\top\mathbf{Y})_{nm}$，即 $\mathbf{Q}=\mathbf{Y}\mathbf{X}\mathbf{X}^\top\mathbf{Y}$。
$\mathbf{Q}=(\mathbf{Y}\mathbf{X})(\mathbf{Y}\mathbf{X})^\top$，形如 $\mathbf{A}\mathbf{A}^\top$，必半正定。
验证：$\mathbf{v}^\top\mathbf{Q}\mathbf{v}=\mathbf{v}^\top(\mathbf{Y}\mathbf{X})(\mathbf{Y}\mathbf{X})^\top\mathbf{v}=\|(\mathbf{Y}\mathbf{X})^\top\mathbf{v}\|^2\geq0$。
所以 $-\frac12\boldsymbol\alpha^\top\mathbf{Q}\boldsymbol\alpha$ 是凹函数（$\mathbf{Q}$ 半正定 $\Rightarrow$ $-\mathbf{Q}$ 半负定），加线性项 $\mathbf{1}^\top\boldsymbol\alpha$ 仍凹。最大化凹函数在凸约束（$\alpha_n\geq0$ 线性，$\sum\alpha_n y_n=0$ 线性）下是凸优化问题。
$\mathbf{Q}$ 正定（$\mathbf{Y}\mathbf{X}$ 行满秩，需 $N\leq D$ 且 $\mathbf{x}_n$ 线性无关）时目标严格凹，解唯一。否则解集是凸的，但 $\mathbf{w}^\star=\sum\alpha_n^\star y_n\mathbf{x}_n$ 仍唯一（不依赖具体 $\boldsymbol\alpha^\star$ 选择）。$\square$
题 6 · 把硬间隔 SVM 推到 1 维几何例子（范式迁移） L3 · 进阶
1 维输入：正类点 $x=+2,+3$，负类点 $x=-2,-3$。用 SVM 原始问题 $\min\frac12 w^2$ s.t. $y_n(wx_n+b)\geq1$ 求最优 $w,b$，并验证对偶解 $\boldsymbol\alpha$、支持向量、间隔。这题训练你把抽象推导用到具体数字上。
提示
对称性提示 $b=0$，决策边界 $x=0$。最近点是 $\pm2$，它们应是支持向量（$|wx|=\!1$ 在 $x=\pm2$ 给 $w=1/2$）。验证外层点 $\pm3$ 满足约束 $|w\cdot3|=1.5\geq1$。对偶：$\alpha_{+2}=\alpha_{-2}=?$，外层 $\alpha=0$，验 $\sum\alpha_n y_n=0$。
解答
数据对称 $\Rightarrow$ 解对称 $\Rightarrow b=0$，边界 $wx=0$ 即 $x=0$。约束 $y_n w x_n\geq1$：正类 $wx\geq1$（$x=2,3$），负类 $wx\leq-1$ 即 $w(-x)\geq1$（$-x=2,3$）。
最紧约束来自最近点 $|x|=2$：$w\cdot2\geq1\Rightarrow w\geq1/2$。目标 $\min\frac12 w^2$ 单调增（$w>0$），取最小 $w=1/2$。
验证外层 $|x|=3$：$w\cdot3=1.5\geq1$ ✓。所以 $w^\star=1/2,b^\star=0$，间隔 $=1/|w|=2$。
支持向量：$|x|=2$ 的点（$\pm2$），它们约束取等。$|x|=3$ 的点约束严格 $>1$，$\alpha=0$。
对偶：$\mathbf{w}=\sum\alpha_n y_n x_n=\alpha_{+2}\cdot1\cdot2+\alpha_{-2}\cdot(-1)\cdot(-2)=2(\alpha_{+2}+\alpha_{-2})=1/2$，所以 $\alpha_{+2}+\alpha_{-2}=1/4$。等式约束 $\sum\alpha_n y_n=\alpha_{+2}-\alpha_{-2}=0$（对称）$\Rightarrow\alpha_{+2}=\alpha_{-2}=1/8$。
验证对偶目标：$\sum\alpha_n-\frac12\sum_{n,m}\alpha_n\alpha_m y_n y_m x_n x_m$。只有 $\pm2$ 贡献：$\sum\alpha=1/4$，$\frac12[2\cdot(1/8)^2\cdot1\cdot4+2\cdot(1/8)(1/8)\cdot(-1)\cdot(-4)]=\frac12[1/8+1/8]=1/8$（对角 + 交叉）。目标 $=1/4-1/8=1/8$。
原始目标 $\frac12 w^2=\frac12\cdot1/4=1/8$。对偶 = 原始 ✓ 强对偶验证通过。$\square$
范式迁移：这个"对称 → $b=0$ → 最紧约束定 $w$ → 验证其余"的套路，在 0008 软间隔里会再加一步"找违反约束的 outlier 定 $\xi_n$"。把抽象 KKT 落到具体数字，是检验真懂的标准。

9. 自测

Q1 · 为什么 SVM 用 $y\in\{-1,+1\}$ 而逻辑回归用 $y\in\{0,1\}$？
答案
$y\in\{-1,+1\}$ 让约束 $y_n(\mathbf{w}^\top\mathbf{x}_n+b)\geq1$ 用一个不等式统一两类：正类 $y=+1$ 时 $\mathbf{w}^\top\mathbf{x}+b\geq1$，负类 $y=-1$ 时 $-(\mathbf{w}^\top\mathbf{x}+b)\geq1$。乘 $y_n$ 把两类约束写成一个形式。逻辑回归用 $\{0,1\}$ 是因为 Bernoulli 似然 $\phi^y(1-\phi)^{1-y}$ 用 0/1 标签自然。标签选择服务于各自推导的简洁性。
Q2 · $\mathbf{w}=\sum\alpha_n y_n\mathbf{x}_n$ 与 0006 表示定理是什么关系？
答案
它是表示定理的 SVM 实例。表示定理说：目标含 $\|\mathbf{w}\|^2$ 正则 + 损失只通过 $\mathbf{w}^\top\mathbf{x}_n$ 依赖 $\mathbf{w}$，则最优 $\mathbf{w}=\sum\alpha_n\mathbf{x}_n$。SVM 的 $\frac12\|\mathbf{w}\|^2$ 目标 + 约束只通过 $\mathbf{w}^\top\mathbf{x}_n$ 依赖 $\mathbf{w}$，正好满足条件。SVM 对偶推导里对 $\mathbf{w}$ 求驻点得到 $\mathbf{w}=\sum\alpha_n y_n\mathbf{x}_n$，本质就是表示定理的证明。$y_n$ 只是乘进系数里。
Q3 · 强对偶为什么成立？如果数据线性不可分（硬间隔无解）会怎样？
答案
强对偶成立因为：目标 $\frac12\|\mathbf{w}\|^2$ 凸，约束 $y_n(\mathbf{w}^\top\mathbf{x}_n+b)-1\geq0$ 仿射（线性），线性可分时存在严格可行点（Slater 条件：取一个间隔 $>1$ 的超平面）。凸 + Slater → 强对偶 + KKT 充要。线性不可分时原始问题无可行点（约束 $y_n(\mathbf{w}^\top\mathbf{x}_n+b)\geq1$ 无解），Slater 不成立，硬间隔 SVM 无解。这时需软间隔（0008）引入松弛 $\xi_n$ 允许违反，或用核升维到可分。
Q4 · 为什么对偶问题比原始问题更适合核化？
答案
对偶问题里数据只通过内积 $\mathbf{x}_n^\top\mathbf{x}_m$ 出现，决策函数也只通过 $\mathbf{x}_n^\top\mathbf{x}$。换成核 $k(\mathbf{x}_n,\mathbf{x}_m)=\boldsymbol\phi(\mathbf{x}_n)^\top\boldsymbol\phi(\mathbf{x}_m)$ 就升维，推导不改。原始问题里 $\mathbf{w}$ 在特征空间 $\boldsymbol\phi$ 里是无穷维向量（如 RBF），无法显式表示。对偶变量是 $\boldsymbol\alpha\in\mathbb{R}^N$，与特征维无关，只依赖样本数。这就是"对偶为核化铺路"——表示定理保证解在 $N$ 维子空间，所以 $N\times N$ 核矩阵够用。
