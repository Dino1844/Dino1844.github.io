1. 一个让人不安的事实：梯度方向取决于你怎么写参数

1.1 回顾：L0001 的终点，本节的起点

在 L0001 中，score matching 损失里出现了 $\operatorname{tr}(\nabla_{\mathbf{x}} \mathbf{s}_\theta)$ —— score 网络对数据 $\mathbf{x}$ 的 Jacobian 的迹。那是数据空间中的「几何」信息。

这节课我们把镜头转向参数空间。当我们用梯度下降优化一个概率模型时， 我们在参数空间中移动——但参数空间的几何是什么？它是不是我们默认的欧氏空间？

核心问题：如果我们改变了模型的参数化方式（比如把 $\sigma$ 换成 $\log \sigma$）， 梯度下降的搜索方向会改变吗？如果会——那哪个方向才是「正确」的？还是说梯度下降的「最陡方向」 本身就是一个依赖于参数化选择的人为概念？

1.2 一个简单的实验：Bernoulli 分布的两种写法

🌰 让我不舒服的第一步

考虑一个最简单的概率模型：一枚硬币，正面概率为 $\theta \in (0, 1)$。Bernoulli 分布：

$p(x|\theta) = \theta^x (1-\theta)^{1-x}, \quad x \in \{0, 1\}$

假设我们观察到一次正面（$x=1$），损失函数是负对数似然：

$\mathcal{L}(\theta) = -\log p(x=1|\theta) = -\log \theta$

梯度：$\frac{d\mathcal{L}}{d\theta} = -\frac{1}{\theta}$。在 $\theta = 0.5$ 处，梯度是 $-2$。

现在换一种参数化。令 $\phi = \text{logit}(\theta) = \log\frac{\theta}{1-\theta}$（即 $\theta = \frac{1}{1+e^{-\phi}}$）。

同一个观测、同一个模型、同一个损失函数——只是用 $\phi$ 而不是 $\theta$ 来写：

$\mathcal{L}(\phi) = -\log\left(\frac{1}{1+e^{-\phi}}\right) = \log(1+e^{-\phi})$

梯度：$\frac{d\mathcal{L}}{d\phi} = -\frac{e^{-\phi}}{1+e^{-\phi}} = \theta - 1$。在 $\theta=0.5$ 处（对应 $\phi=0$），梯度是 $-0.5$。

比较：

参数化$\theta=0.5$ 处的梯度梯度下降的一步（$\eta=0.1$）
$\theta$$-2$$\theta \leftarrow 0.5 - 0.1 \times (-2) = 0.7$
$\phi$$-0.5$$\phi \leftarrow 0 - 0.1 \times (-0.5) = 0.05$，对应 $\theta \approx 0.512$
同一个模型，同一个数据，同一个学习率——但梯度下降走到了不同的地方！ 在 $\theta$ 参数化下走了一步到 0.7；在 $\phi$ 参数化下只到了 0.512。 这不是 bug——这是欧氏梯度下降的固有属性：它对参数化方式不不变。 「最陡下降方向」中的「最陡」是相对于参数空间的欧氏距离定义的，而这个距离本身取决于你怎么写参数。

1.3 我们需要什么？

我们需要一个不依赖于参数化方式的「最陡方向」定义。这个定义应该只依赖于概率分布本身的结构—— 两个参数 $\theta_1$ 和 $\theta_2$ 之间的「距离」不应该由它们在参数坐标中的欧氏距离来定义， 而应该由它们代表的概率分布 $p_{\theta_1}$ 和 $p_{\theta_2}$之间的差异来定义。

📍 停下来想一想：如果你说「$\theta = 0.5$ 和 $\theta = 0.7$ 差 0.2」——这个 0.2 意味着什么？ 在概率意义上，$\theta=0.5$ 的硬币和 $\theta=0.7$ 的硬币「有多不一样」？ 我们应该用这个「概率意义上的距离」来定义梯度，而不是参数坐标中的欧氏距离。

2. Fisher 信息矩阵：概率空间的自带度量

2.1 Score 函数（参数版）

在 L0001 中我们定义了对数据的 score：$\nabla_{\mathbf{x}} \log p(\mathbf{x})$。现在定义对参数的 score：

$$\boxed{\nabla_{\boldsymbol{\theta}} \log p(\mathbf{x}|\boldsymbol{\theta})}$$

这是一个向量，长度等于参数个数。它衡量：参数 $\boldsymbol{\theta}$ 的微小变化会让观测到 $\mathbf{x}$ 的对数概率变化多少？ 如果某个参数方向的 score 很大，说明这个参数对数据的解释力很强——数据对这个参数「很敏感」。

🌰 Bernoulli 分布的参数 score

$p(x|\theta) = \theta^x(1-\theta)^{1-x}$。取对数：$\log p(x|\theta) = x\log\theta + (1-x)\log(1-\theta)$

对 $\theta$ 求导：$\frac{d}{d\theta}\log p(x|\theta) = \frac{x}{\theta} - \frac{1-x}{1-\theta}$

当 $x=1$：$\text{score} = \frac{1}{\theta}$；当 $x=0$：$\text{score} = -\frac{1}{1-\theta}$。

在 $\theta \approx 0$ 时观察到 $x=1$ → score 巨大（「这个结果太意外了，参数一定不对」）。这正是 score 的含义：数据对参数的「惊讶程度」。

2.2 Fisher 信息：Score 的协方差矩阵

定义 Fisher 信息矩阵（Fisher Information Matrix）：

$$\boxed{\mathbf{F}(\boldsymbol{\theta}) = \mathbb{E}_{p(\mathbf{x}|\boldsymbol{\theta})}\left[ \nabla_{\boldsymbol{\theta}} \log p \cdot \nabla_{\boldsymbol{\theta}} \log p^\top \right]}$$

逐条理解：

  1. $\nabla_{\boldsymbol{\theta}} \log p$ 是一个列向量（参数 score）
  2. 外积 $\nabla \log p \cdot \nabla \log p^\top$ 是一个矩阵——第 $(i,j)$ 个元素是两个参数偏导的乘积
  3. $\mathbb{E}_{p(\mathbf{x}|\boldsymbol{\theta})}$ 是在模型自己的分布下取期望——用当前参数下期望的数据来评估参数 sensitivity
  4. 结果 $\mathbf{F}(\boldsymbol{\theta})$ 是一个 $P \times P$ 的半正定矩阵（$P$ = 参数个数）
直觉：Fisher 矩阵的每个元素 $\mathbf{F}_{ij}$ 衡量参数 $\theta_i$ 和 $\theta_j$ 在影响数据分布时的「重叠程度」。 如果 $\mathbf{F}_{ij}$ 很大，说明改变 $\theta_i$ 和改变 $\theta_j$ 对数据分布的影响高度相似—— 在概率分布空间中，这两个参数方向是「几乎平行」的。

2.3 手算：一维高斯的 Fisher 矩阵

🌰 $\mathcal{N}(\mu, \sigma^2)$，参数 $\boldsymbol{\theta} = (\mu, \sigma)$

$\log p(x|\mu,\sigma) = -\frac{1}{2}\log(2\pi) - \log\sigma - \frac{(x-\mu)^2}{2\sigma^2}$ // 高斯对数密度
对 $\mu$ 的 score：
$\frac{\partial \log p}{\partial \mu} = \frac{x-\mu}{\sigma^2}$ // 对 $\mu$ 求导，$-\frac{(x-\mu)^2}{2\sigma^2} \to \frac{2(x-\mu)}{2\sigma^2}$
对 $\sigma$ 的 score：
$\frac{\partial \log p}{\partial \sigma} = -\frac{1}{\sigma} + \frac{(x-\mu)^2}{\sigma^3}$ // $-\log\sigma \to -1/\sigma$；$-(x-\mu)^2/(2\sigma^2) \to (x-\mu)^2/\sigma^3$
计算 Fisher 各分量：
$\mathbf{F}_{\mu\mu} = \mathbb{E}\left[\left(\frac{x-\mu}{\sigma^2}\right)^2\right] = \frac{\mathbb{E}[(x-\mu)^2]}{\sigma^4} = \frac{\sigma^2}{\sigma^4} = \frac{1}{\sigma^2}$ // $\mathbb{E}[(x-\mu)^2] = \sigma^2$ 是方差的定义
$\mathbf{F}_{\mu\sigma} = \mathbb{E}\left[\frac{x-\mu}{\sigma^2} \cdot \left(-\frac{1}{\sigma} + \frac{(x-\mu)^2}{\sigma^3}\right)\right] = 0$ // 奇函数期望为零（高斯是对称的）
$\mathbf{F}_{\sigma\sigma} = \mathbb{E}\left[\left(-\frac{1}{\sigma} + \frac{(x-\mu)^2}{\sigma^3}\right)^2\right] = \frac{2}{\sigma^2}$ // 利用 $\mathbb{E}[(x-\mu)^4] = 3\sigma^4$（高斯峰度）
$$\mathbf{F}(\mu, \sigma) = \begin{pmatrix} \frac{1}{\sigma^2} & 0 \\ 0 & \frac{2}{\sigma^2} \end{pmatrix}$$

观察：$\mu$ 方向的信息量是 $1/\sigma^2$，$\sigma$ 方向是 $2/\sigma^2$。 $\sigma$ 方向的「信息量」是 $\mu$ 方向的两倍——当你同时改变 $\mu$ 和 $\sigma$ 一个单位， 改变 $\sigma$ 对分布的影响更大。而且这个「信息量」和坐标刻度有关：$\sigma$ 越大， 信息越少（分布越宽，单个数据点包含的参数信息越少）。

2.4 Fisher 矩阵的关键性质

  1. 半正定：$\mathbf{v}^\top \mathbf{F} \mathbf{v} = \mathbb{E}[(\mathbf{v}^\top \nabla \log p)^2] \geq 0$。任何参数方向上的「信息量」都是非负的。
  2. 等于负 Hessian 的期望：$\mathbf{F}(\boldsymbol{\theta}) = -\mathbb{E}_{p}[\nabla_{\boldsymbol{\theta}}^2 \log p]$。Fisher 矩阵是 log 似然的 expected Hessian——它描述了期望意义上的曲率。
  3. 重参数化不变性：如果换一套参数 $\boldsymbol{\phi} = g(\boldsymbol{\theta})$，Fisher 矩阵会按 Jacobian 变换：$\mathbf{F}(\boldsymbol{\phi}) = \mathbf{J}^{-\top} \mathbf{F}(\boldsymbol{\theta}) \mathbf{J}^{-1}$。这意味着Fisher 矩阵定义的几何结构独立于参数化选择——它就是概率分布空间的内在度量。
Fisher 信息矩阵的名称来自统计学家 Ronald Fisher (1890–1962)，他奠定了现代统计学的数学基础。 Fisher 最初用它来给出最大似然估计的渐近方差下界（Cramér-Rao bound）：任何无偏估计量的方差不可能小于 $\mathbf{F}^{-1}$。 这里我们用的是它的几何含义——Amari (1980s) 的贡献。

3. KL 散度和 Fisher：几何的由来

3.1 为什么 Fisher 矩阵是一个「度量」

在微分几何中，一个黎曼度量（Riemannian metric）定义了流形上每点的「无穷小距离」。 如果流形的坐标是 $\boldsymbol{\theta}$，度规矩阵 $\mathbf{G}(\boldsymbol{\theta})$ 定义了坐标微元 $d\boldsymbol{\theta}$ 的长度：

$$ds^2 = d\boldsymbol{\theta}^\top \mathbf{G}(\boldsymbol{\theta})\, d\boldsymbol{\theta} = \sum_{i,j} G_{ij}(\boldsymbol{\theta})\, d\theta_i\, d\theta_j$$

在平直欧氏空间中，$\mathbf{G} = \mathbf{I}$——这就是我们通常用的距离 $(ds^2 = d\theta_1^2 + d\theta_2^2 + \cdots)$。但在概率分布空间中，自然的度量是 Fisher 矩阵 $\mathbf{G}(\boldsymbol{\theta}) = \mathbf{F}(\boldsymbol{\theta})$。为什么？

3.2 核心推导：KL 散度的二阶展开

KL 散度衡量两个分布的差异。把 $p_{\boldsymbol{\theta}+d\boldsymbol{\theta}}$ 在 $\boldsymbol{\theta}$ 处泰勒展开：

$D_{\text{KL}}(p_{\boldsymbol{\theta}} \| p_{\boldsymbol{\theta}+d\boldsymbol{\theta}}) = \mathbb{E}_{p_{\boldsymbol{\theta}}}\left[ \log \frac{p_{\boldsymbol{\theta}}}{p_{\boldsymbol{\theta}+d\boldsymbol{\theta}}} \right]$
$= \mathbb{E}_{p_{\boldsymbol{\theta}}}\left[ \log p_{\boldsymbol{\theta}} - \log p_{\boldsymbol{\theta}+d\boldsymbol{\theta}} \right]$
$= -\mathbb{E}_{p_{\boldsymbol{\theta}}}\left[ \log p_{\boldsymbol{\theta}+d\boldsymbol{\theta}} - \log p_{\boldsymbol{\theta}} \right]$

现在对 $\log p_{\boldsymbol{\theta}+d\boldsymbol{\theta}}$ 在 $\boldsymbol{\theta}$ 处做二阶泰勒展开：

$\log p_{\boldsymbol{\theta}+d\boldsymbol{\theta}} \approx \log p_{\boldsymbol{\theta}} + \nabla_{\boldsymbol{\theta}}\log p_{\boldsymbol{\theta}}^\top d\boldsymbol{\theta} + \frac{1}{2} d\boldsymbol{\theta}^\top (\nabla_{\boldsymbol{\theta}}^2 \log p_{\boldsymbol{\theta}})\, d\boldsymbol{\theta}$
代入并取期望：
$D_{\text{KL}}(p_{\boldsymbol{\theta}} \| p_{\boldsymbol{\theta}+d\boldsymbol{\theta}}) \approx -\underbrace{\mathbb{E}[\nabla \log p]^\top d\boldsymbol{\theta}}_{= \mathbf{0}\text{（score 的期望为零）}} - \frac{1}{2} d\boldsymbol{\theta}^\top \underbrace{\mathbb{E}[\nabla^2 \log p]}_{= -\mathbf{F}(\boldsymbol{\theta})}\, d\boldsymbol{\theta}$
$$\boxed{D_{\text{KL}}(p_{\boldsymbol{\theta}} \| p_{\boldsymbol{\theta}+d\boldsymbol{\theta}}) \approx \frac{1}{2} d\boldsymbol{\theta}^\top \mathbf{F}(\boldsymbol{\theta})\, d\boldsymbol{\theta}}$$
这就是核心几何事实：KL 散度在 $\boldsymbol{\theta}$ 附近的二阶近似恰好是 $\frac{1}{2}$ 倍的 Fisher 二次型。 换句话说，Fisher 矩阵定义了概率分布之间无穷小 KL 距离。 这不是我们「选择」用 Fisher 做度量——而是KL 散度本身就诱导出了 Fisher 度量。

$D_{\text{KL}}(p_{\boldsymbol{\theta}} \| p_{\boldsymbol{\theta}+d\boldsymbol{\theta}}) \approx \frac{1}{2} ds^2$，其中 $ds^2 = d\boldsymbol{\theta}^\top \mathbf{F}(\boldsymbol{\theta})\, d\boldsymbol{\theta}$。
📍 停下来想一想：「score 的期望为零」这一步是关键——$\mathbb{E}_{p}[\nabla_{\boldsymbol{\theta}} \log p] = \int p \cdot \frac{\nabla p}{p} = \nabla \int p = \nabla 1 = \mathbf{0}$。这一项消失使得一阶项不贡献距离，距离的 leading order 是二阶——这正是黎曼度量需要的性质（距离应该是二次型，不是线性的）。

4. 自然梯度下降：沿着真正的「最陡方向」走

4.1 重新定义「最陡方向」

传统梯度下降：$\boldsymbol{\theta}_{t+1} = \boldsymbol{\theta}_t - \eta \nabla_{\boldsymbol{\theta}} \mathcal{L}$。等价于解这个约束优化问题：

$$\argmin_{d\boldsymbol{\theta}} \; \mathcal{L}(\boldsymbol{\theta} + d\boldsymbol{\theta}) \quad \text{subject to} \quad \|d\boldsymbol{\theta}\| \leq \varepsilon$$

约束 $\|d\boldsymbol{\theta}\| \leq \varepsilon$ 用的是欧氏范数 $\|d\boldsymbol{\theta}\|^2 = d\boldsymbol{\theta}^\top \mathbf{I}\, d\boldsymbol{\theta}$。这就是问题所在——欧氏范数依赖于参数化的刻度。

自然梯度（Natural Gradient）把这个约束换成 Fisher 范数：

$$\argmin_{d\boldsymbol{\theta}} \; \mathcal{L}(\boldsymbol{\theta} + d\boldsymbol{\theta}) \quad \text{subject to} \quad d\boldsymbol{\theta}^\top \mathbf{F}(\boldsymbol{\theta})\, d\boldsymbol{\theta} \leq \varepsilon^2$$

约束的含义：每一步最多改变分布一个「KL 距离」$\varepsilon^2/2$——这个约束不依赖于参数化方式。

4.2 拉格朗日乘子法推导

一阶近似 $\mathcal{L}(\boldsymbol{\theta} + d\boldsymbol{\theta}) \approx \mathcal{L}(\boldsymbol{\theta}) + \nabla\mathcal{L}^\top d\boldsymbol{\theta}$。拉格朗日函数：

$\mathcal{L}(d\boldsymbol{\theta}, \lambda) = \nabla\mathcal{L}^\top d\boldsymbol{\theta} + \lambda\left(d\boldsymbol{\theta}^\top \mathbf{F} d\boldsymbol{\theta} - \varepsilon^2\right)$
对 $d\boldsymbol{\theta}$ 求导并等于零： // $\frac{\partial}{\partial d\boldsymbol{\theta}}(a^\top d\boldsymbol{\theta}) = a$；$\frac{\partial}{\partial d\boldsymbol{\theta}}(d\boldsymbol{\theta}^\top \mathbf{F} d\boldsymbol{\theta}) = 2\mathbf{F} d\boldsymbol{\theta}$
$\nabla\mathcal{L} + 2\lambda \mathbf{F} d\boldsymbol{\theta} = \mathbf{0} \quad\Rightarrow\quad d\boldsymbol{\theta} = -\frac{1}{2\lambda} \mathbf{F}^{-1} \nabla\mathcal{L}$
将步长因子吸收到学习率 $\eta$ 中：
$$\boxed{\boldsymbol{\theta}_{t+1} = \boldsymbol{\theta}_t - \eta\, \mathbf{F}(\boldsymbol{\theta}_t)^{-1}\, \nabla_{\boldsymbol{\theta}} \mathcal{L}(\boldsymbol{\theta}_t)}$$
自然梯度 = 普通梯度 × Fisher 逆矩阵。$\mathbf{F}^{-1}$ 的作用是「除以每个方向的 sensitivity」。 如果一个参数方向对分布影响很大（Fisher 对角元大），自然梯度在这一步会缩小这个方向的步长—— 因为在这个方向上走一小步就能引起很大的分布变化。反之，影响小的方向会被放大。

直观类比：在一个又窄又陡的山谷里，普通梯度会在两侧峭壁之间震荡。 自然梯度把山谷展平——它用 Fisher 度量重新拉伸了坐标，使得在「概率距离」的意义上， 每一步都朝着最优分布走了相等的距离。

4.3 手算验证：Bernoulli 问题回归

🌰 Bernoulli 分布的自然梯度

回到 1.2 节的 Bernoulli 例子。Fisher 信息量（一维标量）：

$\mathbf{F}(\theta) = \mathbb{E}\left[\left(\frac{d}{d\theta}\log p\right)^2\right] = \frac{1}{\theta(1-\theta)}$

自然梯度：$\tilde{\nabla}\mathcal{L} = \mathbf{F}^{-1} \cdot \nabla\mathcal{L} = \theta(1-\theta) \cdot \left(-\frac{1}{\theta}\right) = \theta - 1$

在 $\theta = 0.5$ 处，自然梯度 $= -0.5$。更新：$\theta \leftarrow 0.5 - \eta \times (-0.5) = 0.5 + 0.5\eta$。

现在用 logit 参数化 $\phi$ 的 Fisher 信息：

$\mathbf{F}(\phi) = \mathbf{F}(\theta)\left(\frac{d\theta}{d\phi}\right)^2 = \frac{1}{\theta(1-\theta)} \cdot [\theta(1-\theta)]^2 = \theta(1-\theta)$

自然梯度（在 $\phi$ 坐标中）：$\tilde{\nabla}_\phi\mathcal{L} = \mathbf{F}(\phi)^{-1} \cdot \nabla_\phi\mathcal{L} = \frac{\theta-1}{\theta(1-\theta)}$。

更新：$\phi \leftarrow 0 - \eta \times \frac{-0.5}{0.25} = 2\eta$，对应 $\theta = \frac{1}{1+e^{-2\eta}} \approx 0.5 + 0.5\eta$（当 $\eta$ 小时）。

两套参数化给出了相同的更新！$\theta \leftarrow 0.5 + 0.5\eta$ 不管用 $\theta$ 还是 $\phi$ 都是一样的。 这就是自然梯度的重参数化不变性——你可以用任何你喜欢的参数化，概率分布的变化路径是一样的。

6. 实战：回到深度学习

6.1 自然梯度和牛顿法的关系

牛顿法使用 Hessian 矩阵 $\mathbf{H} = \nabla_{\boldsymbol{\theta}}^2 \mathcal{L}$ 做 pre-conditioning： $\Delta\boldsymbol{\theta} = -\eta \mathbf{H}^{-1} \nabla\mathcal{L}$。当损失函数是负对数似然 $\mathcal{L} = -\log p$ 时：

$$\mathbf{H} = -\nabla_{\boldsymbol{\theta}}^2 \log p \quad \text{而} \quad \mathbf{F} = -\mathbb{E}_p[\nabla_{\boldsymbol{\theta}}^2 \log p]$$

Fisher 是期望 Hessian。牛顿法用单点的 Hessian（可能非正定），自然梯度用期望 Hessian（保证半正定）。对于对数似然损失，自然梯度 ≈ 对 Hessian 做了平滑——数值上更稳定。

6.2 为什么深度学习不用自然梯度？——维数灾难

现代神经网络有百万到千亿参数。$\mathbf{F}(\boldsymbol{\theta})$ 是 $P \times P$ 的矩阵， 存储和求逆都需要 $O(P^2) \sim O(P^3)$ 的复杂度——完全不现实。 实际使用的近似方法：

  • KFAC (Martens & Grosse, 2015)：将 Fisher 近似为 Kronecker 积（块对角 + 每块是外积），求逆变成逐块求逆——$O(P)$ 复杂度。在中等规模网络上有效。
  • Adam 的隐蔽几何：Adam 用 $\mathbf{v}_t$（梯度平方的指数移动平均）做逐坐标缩放。这可以看作对 Fisher 对角线的粗略近似——假设不同参数的 Fisher 信息互不相关。这解释了为什么 Adam 在大多数任务上比 SGD 快。但它仍然使用了欧氏空间中「每个参数独立」的假设——忽略了参数之间通过概率分布产生的耦合。

数据和参数是两面镜子。L0001 的数据 score 告诉我们「数据空间中概率如何变化」； 本节的参数 score 告诉我们「参数空间中概率如何变化」。Fisher 矩阵是两个视角的桥梁—— 它是参数 score 的二阶矩，定义了参数空间中的自然距离。

8. 核心 takeaway

  1. 普通梯度下降的「最陡方向」依赖于参数化的刻度——换一套参数就换一个方向。
  2. 我们需要一个只依赖于概率分布本身的距离定义。KL 散度就是这个「概率意义上的距离」。
  3. KL 散度的二阶泰勒展开给出 $\frac{1}{2}d\boldsymbol{\theta}^\top \mathbf{F}(\boldsymbol{\theta}) d\boldsymbol{\theta}$——Fisher 矩阵是 KL 散度诱导的黎曼度量。
  4. 将梯度下降的约束从欧氏范数换成 Fisher 范数 → 自然梯度 = $\mathbf{F}^{-1}\nabla\mathcal{L}$。
  5. 自然梯度有重参数化不变性——无论用 $\theta$ 还是 $\log\sigma$，参数更新对应的概率分布变化路径一样。
  6. Fisher 矩阵的逆在深度学习不可算 → 近似（KFAC、Adam 的对角假设）是实用的折衷。
