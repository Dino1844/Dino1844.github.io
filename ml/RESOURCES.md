# Resources

## 核心教材（已有）

- **PRML（模式识别与机器学习）** — Christopher Bishop
  机器学习领域最权威的教材之一，Bayesian 视角贯穿全书。覆盖：概率分布、线性模型、核方法、SVM、图模型、EM、采样、变分推断等。
  使用场景：**主教材**，课程主线将跟随 PRML 的结构展开。

- **MML（Mathematics for Machine Learning）** — Deisenroth, Faisal, Ong
  为 ML 量身定制的数学教材，覆盖线代、微积分、概率、优化。比 PRML 的数学附录更友好。
  使用场景：当 PRML 的数学推导不够清晰时，用 MML 作为补充参考。

## 补充资源

### 在线课程
- **CS229 (Stanford, Andrew Ng)** — 经典 ML 课程，数学推导扎实
  使用场景：补充 lecture notes 中的推导，特别是 GLM、SVM、学习理论部分
  链接：https://cs229.stanford.edu/syllabus-autumn2018.html

- **CS229: Machine Learning — Summer 2019 讲义** (Tengyu Ma 版本)
  更现代化、更数学化的讲义
  链接：https://cs229.stanford.edu/lectures-spring2022/main_notes.pdf

### 在线参考
- **StatQuest (YouTube)** — Josh Starmer
  用简单动画解释 ML 概念，适合建立直觉
  使用场景：遇到难懂的概念时，先看 StatQuest 建立直觉再啃推导

- **Distill.pub** — 视觉化 ML 期刊
  高质量交互式文章，适合深入理解特定主题
  链接：https://distill.pub/

### 社区
- **r/MachineLearning** (reddit.com/r/MachineLearning) — ML 研究和讨论
- **Cross Validated** (stats.stackexchange.com) — 统计/ML 问答社区，推导类问题质量很高
