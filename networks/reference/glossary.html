计算机网络术语表

参考文档 · ← 概念地图 · 持续更新中

本术语表是学习计算机网络的词汇基础。每条术语给出简洁定义和上下文。随着学习深入会不断扩充。

基础概念

协议 (Protocol)
通信双方约定的规则集合——定义消息的格式、顺序和响应方式。就像外交礼仪：握手用哪只手、先说什么后说什么。
参见：所有网络通信都基于某种协议
分层 (Layering)
将网络通信的复杂问题分解为多个独立层次，每层只解决一个子问题。下层为上层提供服务，上层不关心下层实现细节。
参见：OSI 模型、TCP/IP 模型
封装 (Encapsulation)
数据从上层传到下层时，每层在数据前面加上自己的头部信息（有时还有尾部）。就像信纸（数据）被放入信封（TCP 头），再装入邮袋（IP 头），再装上邮车（帧头）。
对应：解封装 (Decapsulation)
端到端原则 (End-to-End Principle)
网络核心应保持简单（尽力转发），复杂功能（如可靠性、安全）应放在端节点实现。这是互联网设计的哲学基石。
参见：Saltzer, Reed, Clark (1984)

应用层

DNS (Domain Name System)
将人类可读的域名（example.com）翻译为机器可读的 IP 地址（93.184.216.34）的分层命名系统。可类比为互联网的电话簿。
参见：A 记录、CNAME、递归查询、根域名服务器
HTTP (HyperText Transfer Protocol)
Web 的基石协议。客户端（浏览器）发送请求，服务器返回响应。无状态：每个请求独立，服务器不记得上次对话。
参见：HTTPS、HTTP/2、HTTP/3、REST
TLS (Transport Layer Security)
在 TCP 之上建立加密信道的协议。提供三个保证：机密性（别人看不到）、完整性（内容没被改）、身份验证（对方真的是它声称的那个）。
前身：SSL。最新：TLS 1.3
URL (Uniform Resource Locator)
统一资源定位符。格式：scheme://host:port/path?query#fragment。完整描述了「用什么协议、去哪台机器、取什么资源」。

传输层

TCP (Transmission Control Protocol)
面向连接的可靠传输协议。保证数据不丢、不乱、不重复。通过三次握手建立连接，四次挥手断开。提供拥塞控制和流量控制。
参见：UDP、三次握手、滑动窗口、拥塞控制
UDP (User Datagram Protocol)
无连接的「尽力而为」传输协议。不保证可靠，不保证顺序，不保证不重复。换来的是低延迟和低开销。
适用场景：视频通话、DNS 查询、在线游戏
端口 (Port)
16 位数字（0-65535），用于在同一个 IP 地址上区分不同的应用程序。IP 定位机器，端口定位进程。如 HTTP 默认 80，HTTPS 默认 443。
Socket = IP + Port
三次握手 (Three-Way Handshake)
TCP 建立连接的过程：① 客户端发 SYN ② 服务器回 SYN-ACK ③ 客户端回 ACK。目的是双方确认彼此的收发能力，并同步初始序列号。
为什么不是两次？——防止历史连接被错误建立
拥塞控制 (Congestion Control)
TCP 检测网络拥塞并自动降低发送速率的机制。核心算法：慢启动、拥塞避免、快速重传、快速恢复。
参见：AIMD、CUBIC、BBR

网络层

IP (Internet Protocol)
网络层的核心协议，负责将数据包从源主机路由到目的主机。提供「尽力而为」(best-effort) 服务——不保证送达、不保证顺序。
IPv4（32 位地址）→ IPv6（128 位地址）
IP 地址 (IP Address)
网络中每台设备的逻辑地址。IPv4 格式：192.168.1.1（4 字节）。IPv6 格式：2001:db8::1（16 字节）。
公网 IP vs 私有 IP、CIDR 表示法（192.168.1.0/24）
路由 (Routing)
确定数据包从源到目的地路径的过程。每个路由器查路由表，把包转发到「下一跳」(next hop)。
路由协议：BGP（域间）、OSPF/IS-IS（域内）
NAT (Network Address Translation)
网络地址转换。允许多台设备共享一个公网 IP。路由器将私有 IP 替换为公网 IP，并维护映射表。解决了 IPv4 地址不够用的燃眉之急。
副作用：破坏了端到端原则

链路层

MAC 地址 (Media Access Control Address)
48 位硬件地址，烧录在网卡中，用于同一局域网内的设备寻址。格式：00:1A:2B:3C:4D:5E。
IP 地址是「你在哪」，MAC 地址是「你是谁」
ARP (Address Resolution Protocol)
地址解析协议。在局域网中，通过 IP 地址查找对应的 MAC 地址。广播问「192.168.1.1 是谁？」，目标设备单播回答「是我，我的 MAC 是 XX」。
IPv6 中用 NDP (Neighbor Discovery Protocol) 替代
交换机 (Switch)
链路层设备，根据 MAC 地址转发帧。自学习：看到源 MAC 就记录在哪个端口，逐渐构建转发表。
vs 集线器（Hub）：广播到所有端口；vs 路由器（Router）：工作在网络层
帧 (Frame)
链路层的数据单元。以太网帧 = 目的 MAC + 源 MAC + 类型 + 数据 + CRC 校验。
MTU（最大传输单元）：通常 1500 字节
