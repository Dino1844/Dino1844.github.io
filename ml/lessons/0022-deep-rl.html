1. 死三角：RL + 函数逼近为什么会发散

范式 #26 · RL 的"死三角"（Deadly Triad）

自举（bootstrapping：用当前估计做更新目标）+ Off-policy 学习（行为策略 ≠ 目标策略）+ 函数逼近（神经网络替代表格）——三者取二可控，三者齐上随时发散。这是 Sutton & Barto §11.3 的命名，DQN 的经验回放和 target network 本质是给这三者各加了一道保险。

表格型 Q-learning 能收敛是因为 Bellman 算子 $\mathcal{T}^*$ 是压缩映射（$\gamma$-contraction）：$\|\mathcal{T}^*Q_1 - \mathcal{T}^*Q_2\|_\infty \leq \gamma\|Q_1-Q_2\|_\infty$。Banach 不动点定理保证迭代收敛到唯一 $Q^*$。

问题出在函数逼近破坏了压缩性。用神经网络 $Q_\theta$ 替代表格后，TD 更新变成了"Bellman 算子 → 梯度下降投影到网络参数空间 → 新的 $Q_\theta$"——两步的复合算子不再是压缩映射。Baird (1995) 反例：一个简单 7 状态 MDP，线性函数逼近 + off-policy TD → 参数发散到无穷。

为什么 Bellman 算子 + 函数逼近会发散

表格型：$Q_{k+1} = \mathcal{T}^*Q_k$。$\mathcal{T}^*$ 是 $\gamma$-contraction → $\|Q_{k+1}-Q^*\| \leq \gamma\|Q_k-Q^*\|$ → 几何收敛。压缩映射在 $\ell_\infty$ 范数下保证收敛。
函数逼近型：$Q_{k+1} = \Pi(\mathcal{T}^*Q_k)$，其中 $\Pi$ 是把结果投影回函数空间的投影算子（梯度下降一步 ≈ 投影）。$\Pi$ 在 $\ell_\infty$ 下可能扩大距离——投影到低维流形可能在 $\ell_\infty$ 中拉远。
$\Pi\circ\mathcal{T}^*$ 不一定是压缩——$\Pi$ 破坏了 $\mathcal{T}^*$ 的压缩性。这是 off-policy + 函数逼近发散的数学根源。On-policy（SARSA + 线性 FA）在特定条件下仍收敛（Tsitsiklis & Van Roy, 1997）。
DQN 的两个技巧从这个视角看：经验回放 → 把 off-policy 数据"伪装"成近似 on-policy（随机采样打破时序 → 行为策略 ≈ 过去策略的均匀混合 → 离当前策略不太远）。目标网络 → 把自举目标冻结 $\theta^-$，使 Bellman 算子在一段时间内不随参数移动，近似表格型更新（目标固定 → 纯监督回归 → 收敛）。

2. DQN：死三角的工程化解

深度 RL

DQN · Deep Q-Network

Mnih et al. 2015, Nature
数学本质：在死三角的三条边上各加一道约束——(1) 经验回放打破 off-policy 的时序相关（使训练数据"看起来"更像 on-policy）；(2) 目标网络冻结自举目标（使 TD 更新近似监督回归）；(3) 梯度裁剪/clip 限制单步参数变化（隐式限制 $\Pi$ 的扩张因子）。

损失函数

$$L(\theta) = \mathbb{E}_{(s,a,r,s')\sim\mathcal{D}}\Big[\big(r + \gamma\max_{a'} Q_{\theta^-}(s',a') - Q_\theta(s,a)\big)^2\Big]$$
→ 0021: Q-learning 的扩展→ 死三角: 三道保险

但这里有一个更深的矛盾：目标网络冻结参数 → 训练稳定了，但 $Q_{\theta^-}$ 是过时的——用它做的 TD 目标是错的。更新频率是 tradeoff：更新太快 → 不稳定（死三角再现）；更新太慢 → 目标偏差大 → 收敛慢。这本质上和偏差-方差权衡（0012）同构：目标网络延迟 = 用偏差（旧参数）换方差（训练稳定）。

$\max$ 操作为什么导致系统性高估？不是"噪声里有运气好的"这么简单。深层原因是 Jensen 不等式（0010 §4）：$f(\mathbb{E}[X]) \leq \mathbb{E}[f(X)]$ 对凸函数。$\max$ 是凸函数，所以 $\max(\mathbb{E}[Q]) \leq \mathbb{E}[\max(Q)]$——你应该比较"真实 $Q$ 的 $\max$"，但你实际上在比较"估计值 $Q$ 的 $\max$"，估计值含噪声 → $\max$ 放大正噪声、压缩负噪声 → 期望值偏高。这是凸函数对随机变量的系统性偏误——和 EM 的ELBO 下界是同一种 Jensen 效应，方向相反。

3. 策略梯度：为什么 $\nabla\log\pi$ 奇迹般出现

Q-learning 走的是间接路线：先求出 $Q^*$（一个标量场），再 $\arg\max$ 推出策略。策略梯度走直接路线：参数化 $\pi_\phi$，直接对期望回报求梯度。但"期望对参数的梯度"不能直接算——积分和求导交换需要条件。策略梯度定理用一个恒等式绕过了这个问题。

策略梯度定理的深层推导

目标：$J(\phi) = \mathbb{E}_{\tau\sim\pi_\phi}[G_0] = \int p_\phi(\tau)\,G(\tau)\,d\tau$，其中 $p_\phi(\tau) = p(s_0)\prod_t\pi_\phi(a_t|s_t)\mathcal{P}(s_{t+1}|s_t,a_t)$ 是轨迹概率。轨迹分布由策略和环境联合决定。
$\nabla_\phi J = \int \nabla_\phi p_\phi(\tau)\,G(\tau)\,d\tau$ 交换积分和求导——要求被积函数满足正则条件（RL 里通常满足）。
对数求导技巧（REINFORCE trick）：$\nabla_\phi p_\phi(\tau) = p_\phi(\tau)\,\nabla_\phi\log p_\phi(\tau)$。$\nabla\log f = \nabla f/f$ ⇔ $\nabla f = f\nabla\log f$——把"密度的梯度"变成"密度 × log-密度的梯度"。
$\nabla_\phi\log p_\phi(\tau) = \sum_t\nabla_\phi\log\pi_\phi(a_t|s_t)$ $\mathcal{P}$ 和 $\phi$ 无关——转移概率的梯度为零。不需要知道环境模型！
$\nabla_\phi J = \mathbb{E}_{\tau\sim\pi_\phi}\!\big[G(\tau)\sum_t\nabla_\phi\log\pi_\phi(a_t|s_t)\big]$ 这就是策略梯度定理。
$\nabla\log\pi$ 和 score function 是同族工具。0018 的 score function $\nabla_\mathbf{x}\log p(\mathbf{x})$ 衡量"数据方向怎么走能让概率增大"。 策略梯度的 $\nabla_\phi\log\pi_\phi(a|s)$ 衡量"参数怎么调能让这个动作的概率增大"。 同一个恒等式（$\nabla\log f = \nabla f/f$），两个完全不同的领域，两种完全不同的用法。

为什么要减 baseline？不是因为"方差大"——是因为控制变量法（control variate）。在蒙特卡洛估计 $\mathbb{E}[f(X)]$ 中，找一个已知期望为零的变量 $h(X)$，用 $f(X) - \beta h(X)$ 替代 $f(X)$——期望不变，方差可以大幅降。在策略梯度里，$b(s_t)$ 就是控制变量：$\mathbb{E}[\nabla\log\pi\cdot b(s)] = b(s)\nabla\sum\pi = 0$。最优 baseline 是 advantage $A^\pi(s,a) = Q^\pi(s,a) - V^\pi(s)$。

4. Actor-Critic：GPI 的神经网络版

RL 范式 #27

Actor-Critic 的深层结构

Actor-Critic 不是"两个网络互相帮助"——它是原始-对偶（primal-dual）优化的一个实例。Actor 在策略空间做梯度上升（原始问题），Critic 在值函数空间做 TD 学习（对偶——提供梯度方向的质量估计）。0020 的策略迭代（策略评估 + 策略改进）是这张图在表格空间的精确版；Actor-Critic 是它在函数空间的近似版。

TD 误差的双重角色

$\delta_t = r + \gamma V(s') - V(s)$ 同时做两件事：(1) 训练 Critic——$L = \delta_t^2$，最小化预测误差；(2) 训练 Actor——$\nabla_\phi J = \mathbb{E}[\nabla_\phi\log\pi_\phi(a|s)\,\delta_t]$，TD 误差本身就是 advantage 的无偏估计。一个标量同时驱动两个网络的更新——这是 Actor-Critic 最优雅的地方。

→ 0020: GPI 范式→ 0007: 原始-对偶→ 0010: TD 误差 = Bellman 残差
Actor-Critic 架构：Actor 输出动作，Critic 输出价值。环境返回 s', r → Critic 算 TD 误差 → TD 误差同时更新 Critic（缩小预测误差）和 Actor（策略梯度权重）。

5. PPO：Trust Region 与保守策略迭代

深度 RL 范式 #28

PPO 的数学机制

核心洞察：策略梯度的一步更新可以等价于在旧策略附近解一个带 KL 约束的优化问题。PPO 把 KL 约束近似为 clip——保留了约束的"精神"（不让策略变太远），但不需要算 KL 散度。

从 TRPO 到 PPO

TRPO（Trust Region Policy Optimization）精确求解：$\max_\phi \mathbb{E}[\frac{\pi_\phi}{\pi_{\text{old}}}A] \text{ s.t. } \mathrm{KL}(\pi_{\text{old}}\|\pi_\phi) \leq \delta$——用共轭梯度 + 线搜索保证约束成立。

PPO-Clip 的洞察：不需要精确计算 KL。$r_t = \pi_\phi/\pi_{\text{old}}$ 偏离 1 的程度就是 KL 的代理指标——当 $r_t\in[1-\epsilon,1+\epsilon]$ 时，KL 充分小。clip 操作等价于："如果这一步让策略变得太远，就别走了"。

→ 0001: KL 是概率空间的距离→ 0014: 梯度裁剪同构

PPO-Clip 为什么是"悲观下界"

无约束的策略梯度目标：$L^{\text{PG}} = r_t(\phi)\hat{A}_t$——如果 $A_t>0$，无限制增大 $\pi_\phi$ 就能无限降低 loss → 策略可能崩溃。
PPO 的 $\min$ 操作：当 $A_t>0$ 且 $r_t > 1+\epsilon$ 时，$\text{clip}(r_t, 1-\epsilon, 1+\epsilon) = 1+\epsilon < r_t$，所以 $\min(r_t A_t, (1+\epsilon)A_t) = (1+\epsilon)A_t$。clip 版本给出更保守（更大/更不激进）的 loss → 梯度为零 → 停止增大。
$L^{\text{CLIP}} \leq L^{\text{PG}}$（policy gradient 的 loss 永远小于等于 PPO 的）→ PPO 在做悲观优化：只在确信改进的方向上走，不确定时原地不动。这和悲观 MDP（robust MDP）以及 Thompson 采样里的不确定性惩罚同构。

5.5. 现代方法全景：SAC、TD3、以及统一的视角

深度 RL

SAC · Soft Actor-Critic

Haarnoja et al. 2018
数学本质：在 MDP 的奖励里加入策略熵：$\tilde{r} = r + \alpha H(\pi(\cdot|s))$。最大化"奖励 + 熵"等价于最小化 $\mathrm{KL}(\pi\|\pi_{\text{optimal}})$——熵正则化把贪心策略变成软策略。熵 = 探索的数学形式。最大熵 RL 和信息论（KL、熵）共享同一套数学。

三个组件

双 Q（取 $\min$ 防高估）+ 重参数化策略（$\mathbf{a}=f_\phi(\mathbf{s},\boldsymbol{\epsilon})$，让梯度能流过采样）+ 自动调节 $\alpha$（把熵系数当 Lagrangian 乘子，对偶上升求解——和 SVM 的约束优化同构）。

→ PPO: on-policy + clip→ SAC: off-policy + entropy→ 0010 EM: KL 驱动探索
深度 RL

TD3 · Twin Delayed DDPG

Fujimoto et al. 2018
数学本质：三个改进全部针对 Q 值高估的"选择偏差"——(1) 双 Q 取 min → 压缩正偏差（$\mathbb{E}[\min(Q_1,Q_2)] \leq \mathbb{E}[Q_i]$）；(2) 延迟策略更新 → Critic 先多走几步，Actor 再跟上，防止 Actor 在不准的 Critic 指导下走错方向；(3) 目标平滑 → 给目标动作加噪声 $\sim\text{clip}(\mathcal{N}(0,\sigma),-c,c)$，防止策略学会"利用"Q 函数的局部尖峰。
方法解决的核心问题数学工具与 ML 的联系
DQN死三角（off-policy + 自举 + FA）经验回放（打破时序）+ 目标网络（冻结目标）i.i.d. 假设（0016 反例）
Double DQN$\max$ 的 Jensen 高估选评分离（$Q_1$ 选动作，$Q_2$ 估值）选择偏差（0012 过拟合同构）
策略梯度高维连续动作的 $\arg\max$$\nabla\log\pi$（REINFORCE trick）Score function（0018）
Baseline (advantage)策略梯度的方差控制变量法（control variate）蒙特卡洛方差缩减
PPO策略更新步长的稳定性Clipped surrogate（KL 的代理）Trust region + 梯度裁剪（0014）
SAC探索不足 + 样本效率最大熵（奖励 + $H(\pi)$）KL 散度（0001 §6）· 对偶优化（0007）
TD3Q 高估 + 策略过拟合 Q双 Q min + 目标平滑正则化（防止过拟合 Q 函数）
所有现代 RL 方法都在做同一件事：管理估计的不确定性。 DQN 管理"数据分布的不确定性"（非 i.i.d.）；Double DQN/TD3 管理"估计值的不确定性"（Jensen 偏差）； PPO 管理"策略更新的不确定性"（trust region）；SAC 管理"动作选择的不确定性"（熵最大化）。 RL 的根本困难不是"怎么找到最优策略"——而是"在每一步信息都不完整的情况下，怎么安全地向最优策略移动"。 这和贝叶斯推断（0002/0003）里的"参数不确定时别过度自信"是同一种哲学。

6. 推导与自测

L1 · 经验回放为什么有效 L1
假设你在玩 Atari，连续 10 帧几乎一样（球在屏幕同一位置）。如果不做经验回放，用这 10 个连续样本训练——SGD 会有什么问题？经验回放池 $\mathcal{D}$ 有多大容量（存储多少条 $(s,a,r,s')$）为什么重要？
展开推导
连续样本高度相关 → 梯度方向几乎相同 → SGD 走的方向极度偏向"最近几帧的状态分布" → 参数更新有偏。SGD 假设 mini-batch 是 i.i.d. 的——连续样本违反复数假设。
经验回放从 $\mathcal{D}$ 随机采样 → 打破时序相关 → 近似 i.i.d.。$\mathcal{D}$ 越大 → 采样多样性越高 → 越接近 i.i.d.。但 $\mathcal{D}$ 太大 → 旧策略产生的数据占比高 → 数据"过时"——这是 off-policy 的根本张力。
这和 0016 的"金融数据不能 shuffle"形成对照：金融的时序结构是真实的信号（市场状态），shuffle 会破坏它；Atari 的时序相关是冗余（连续帧几乎一样），shuffle 消除冗余。
L2 · 策略梯度定理的直观证明 L2
策略梯度定理：$\nabla_\phi\mathbb{E}_{\tau\sim\pi_\phi}[G_0] = \mathbb{E}_\tau[\sum_t\nabla_\phi\log\pi_\phi(a_t|s_t)G_t]$。解释为什么 $\nabla\log\pi$ 出现了（提示：这和 0018 的 score function 同族），并说明为什么可以加任意 baseline $b(s_t)$ 而不改变梯度期望。
展开推导
$\nabla_\phi\pi_\phi(\tau) = \pi_\phi(\tau)\nabla_\phi\log\pi_\phi(\tau)$（对数求导技巧：$\nabla\log f = \nabla f/f$）。这和 $\nabla_\mathbf{x}\log p(\mathbf{x})$（0018 score function）是同一恒等式。
$\nabla_\phi\log\pi_\phi(\tau) = \sum_t\nabla_\phi\log\pi_\phi(a_t|s_t)$（轨迹 log-概率 = 各步 log-策略之和，与转移概率 $\mathcal{P}$ 无关——$\mathcal{P}$ 不含 $\phi$）。关键点：不需要知道环境模型也能算策略梯度！
加 baseline：$\mathbb{E}[\nabla\log\pi(a|s)b(s)] = b(s)\nabla\sum_a\pi(a|s) = b(s)\nabla 1 = 0$概率分布求和的梯度恒为零 → 加任意与 $a$ 无关的 baseline 不改变期望
$b(s)$ 降方差的直觉：如果 $G_t$ 总是正数 → 所有动作都被增强（只是程度不同）→ 相对差异被淹没。减去 $V(s)$ → 只有"比平均好"的动作被增强 → 信号更清晰。
L3 · PPO-Clip 的梯度行为 L3
设 $\epsilon=0.2$，$\pi_{\text{old}}(a|s)=0.1$，$\hat{A}_t>0$。分析当 $\pi_\phi(a|s)$ 从 0.1 增加到 0.15 时的 PPO 梯度和未约束策略梯度的差异。$\pi_\phi$ 超过多少时 PPO 的梯度会完全被 clip 置零？
展开推导
$r_t = \pi_\phi/\pi_{\text{old}} = 0.15/0.1 = 1.5$。$1+\epsilon = 1.2$，所以 $r_t > 1+\epsilon$ → 被 clip 到 1.2。当 $r_t > 1+\epsilon$ 且 $A_t>0$：未 clip 的 loss = $-1.5A_t$（更负），clip 后的 loss = $-1.2A_t$ → $\min$ 取 clip 后（-1.2 大于 -1.5）→ 梯度 = 0。
梯度为零的阈值：$\pi_\phi > (1+\epsilon)\pi_{\text{old}} = 1.2\times 0.1 = 0.12$。新策略比旧策略大超 20% 后，PPO 停止继续增大——"已经在变大了，别再变了"。
未约束策略梯度会继续增大 $\pi_\phi$——可能在新旧策略差异过大时导致训练崩溃（TRPO 论文里的 catastrophic degradation）。PPO 的 clip 给了 TRPO 级别的稳定性，但实现只有几行代码。
关键带回：RL + 神经网络的三条路——(1) DQN：值函数逼近，稳定靠经验回放+目标网络；(2) 策略梯度：直接优化 $\pi$，REINFORCE→Actor-Critic 把 $G_t$ 换成 advantage；(3) PPO：Actor-Critic + clipped surrogate，限制策略变化幅度。三条路共享一个数学内核：用 $\nabla\log\pi$（score function）把"期望对参数的梯度"变成"log-概率梯度的加权和"——这和 0018 的 score matching、0001 的 MLE 梯度是同族的工具。
