🗺️ 算法之间的数学关系

GAN

Generative Adversarial Network

Goodfellow et al., 2014
数学本质：用一个判别器的梯度来隐式地告诉生成器「真实分布在哪」——不建模 $p(\mathbf{x})$，不碰 $Z$。

核心公式

$$\min_G \max_D \; \mathbb{E}_{\mathbf{x} \sim p_{\text{data}}}[\log D(\mathbf{x})] + \mathbb{E}_{\mathbf{z} \sim p(\mathbf{z})}[\log(1 - D(G(\mathbf{z})))]$$

为什么绕开了 $Z$

GAN 从不显式写出 $p_{\text{model}}(\mathbf{x})$。生成器 $G$ 定义了一个隐式分布： 把简单噪声 $\mathbf{z}$ 推过神经网络，得到样本。这个分布的密度函数 $p_G(\mathbf{x})$ 根本没法写出来—— 但你也不需要写出来，因为判别器 $D$ 只比较「真假」，不计算概率密度。

关键洞察

  • 最优判别器 $D^*(\mathbf{x}) = \frac{p_{\text{data}}(\mathbf{x})}{p_{\text{data}}(\mathbf{x}) + p_G(\mathbf{x})}$ —— 它就是密度比
  • 当 $D^*$ 代入后，生成器的损失等价于最小化 $JS(p_{\text{data}} \| p_G)$
  • 所以 GAN 在做的其实是：通过对抗游戏，隐式地最小化分布之间的 divergence
  • 问题：$JS$ divergence 在高维空间中容易饱和（两分布支撑集几乎不交 → JS 恒为 $\log 2$）→ 梯度消失
→ WGAN: 用 Wasserstein 距离替代 JS → Score-Based: 显式学 score 而非隐式采样 → EBM: GAN 的判别器 $D$ 可以解释为能量函数
VAE

Variational Autoencoder

Kingma & Welling, 2014
数学本质：通过引入隐变量 $\mathbf{z}$，把对 $p(\mathbf{x})$ 的最大似然转化为优化一个可计算的下界 (ELBO)。

核心公式

$$\log p(\mathbf{x}) \geq \underbrace{\mathbb{E}_{q_\phi(\mathbf{z}|\mathbf{x})}[\log p_\theta(\mathbf{x}|\mathbf{z})]}_{\text{重建项}} - \underbrace{D_{\text{KL}}(q_\phi(\mathbf{z}|\mathbf{x}) \| p(\mathbf{z}))}_{\text{正则项}} = \text{ELBO}$$

为什么绕开了 $Z$

$\log p(\mathbf{x}) = \log \int p_\theta(\mathbf{x}, \mathbf{z})\, d\mathbf{z}$ —— 这个积分（配分函数在隐变量空间的对应物）不可计算。 VAE 的技巧是引入变分后验 $q_\phi(\mathbf{z}|\mathbf{x})$ 近似真实后验 $p(\mathbf{z}|\mathbf{x})$， 用 Jensen 不等式推出 ELBO 下界，优化这个下界就绕开了积分。

关键洞察

  • ELBO = $\log p(\mathbf{x}) - D_{\text{KL}}(q_\phi \| p_{\text{true}})$ —— 最大化 ELBO 就是同时最大化似然 + 逼近真实后验
  • 重参数化技巧 (reparameterization)：$\mathbf{z} = \mu_\phi + \sigma_\phi \odot \boldsymbol{\epsilon}$ 让梯度能流过采样
  • VAE 的生成质量不如 GAN 的原因：高斯假设 $p_\theta(\mathbf{x}|\mathbf{z})$ 导致模糊
  • 和 Diffusion 的联系：VAE 是一步生成，Diffusion 是 $T$ 步逐渐生成——可以把 Diffusion 看作层级 VAE
→ Diffusion: 多层 VAE，残差去噪 → VQ-VAE: 离散隐变量 → Normalizing Flow: 另一种绕积分的方式
EBM

Energy-Based Model

LeCun et al., 2006; 根在统计物理
数学本质：直接建模未归一化概率 $p(\mathbf{x}) \propto e^{-E_\theta(\mathbf{x})}$，接受 $Z$ 不可计算，用 MCMC 采样来绕开它。

核心公式

$$p_\theta(\mathbf{x}) = \frac{e^{-E_\theta(\mathbf{x})}}{Z(\theta)}, \quad Z(\theta) = \int e^{-E_\theta(\mathbf{x})}\, d\mathbf{x}$$

训练困境与解法

最大似然的梯度：$\nabla_\theta \log p_\theta(\mathbf{x}) = -\nabla_\theta E_\theta(\mathbf{x}) + \mathbb{E}_{p_\theta}[\nabla_\theta E_\theta(\mathbf{x})]$

第一项压低真实数据能量；第二项抬高模型采样处的能量。第二项需要从 $p_\theta$ 采样——这就是为什么 EBM 训练需要 MCMC（如 Langevin 动力学）。

关键洞察

  • Score function 就是负能量梯度：$\nabla_\mathbf{x} \log p(\mathbf{x}) = -\nabla_\mathbf{x} E(\mathbf{x})$
  • EBM 的 score 直接可算（不需要归一化），所以可以用 Score Matching 训练
  • $E(\mathbf{x})$ 低 → 概率高；$E(\mathbf{x})$ 高 → 概率低。能量函数是概率的「倒数对数」
  • 和物理的深层联系：Boltzmann 分布 $p \propto e^{-E/kT}$
→ Score-Based: Score Matching 训练 EBM → Diffusion: 退火 Langevin 动力学 → GAN: 判别器 ≈ 能量函数
Flow

Normalizing Flow

Rezende & Mohamed, 2015; Dinh et al., 2014
数学本质：唯一不绕开 $Z$ 的方法——用可逆变换强行让 $Z$ 可以解析计算（变量替换公式）。

核心公式

$$\mathbf{x} = f(\mathbf{z}), \quad p_X(\mathbf{x}) = p_Z(\mathbf{z}) \left|\det \frac{\partial f^{-1}}{\partial \mathbf{x}}\right| = p_Z(f^{-1}(\mathbf{x})) \left|\det \frac{\partial f}{\partial \mathbf{z}}\right|^{-1}$$

为什么不绕 $Z$

变量替换公式告诉你：如果你知道 $\mathbf{z}$ 的分布 $p_Z$（选简单的，如高斯），且 $f$ 可逆， 那么 $\mathbf{x}$ 的密度就可以精确计算——$Z$ 自动被 Jacobian 行列式处理了。 代价是 $f$ 必须可逆且 Jacobian 好算，这严重限制了模型结构。

关键洞察

  • 和 VAE 一样，Flow 也优化精确似然 $\log p(\mathbf{x})$——但不需要下界
  • Flow 是唯一能同时做到精确似然 + 精确采样的方法
  • 代价：维度必须保持不变，且 $f$ 可逆——严重限制了 expressivity
  • 连续化 Normalizing Flow → Neural ODE → 连续时间动力学
→ VAE: 同为似然方法 → Score-Based: Flow 的向量场和 score 场的关系 → Neural ODE: 连续化 Flow
Diff

Diffusion Model (DDPM)

Ho et al., 2020; Sohl-Dickstein et al., 2015
数学本质：在加噪的数据上做 Score Matching。DDPM 的 $\boldsymbol{\epsilon}$-预测损失就是去噪 score matching。

核心公式

$$\mathcal{L}_{\text{DDPM}} = \mathbb{E}_{t, \mathbf{x}_0, \boldsymbol{\epsilon}} \left[ \|\boldsymbol{\epsilon} - \boldsymbol{\epsilon}_\theta(\sqrt{\bar{\alpha}_t} \mathbf{x}_0 + \sqrt{1-\bar{\alpha}_t} \boldsymbol{\epsilon}, t)\|^2 \right]$$

为什么等于 Score Matching

定义 $\mathbf{x}_t = \sqrt{\bar{\alpha}_t} \mathbf{x}_0 + \sqrt{1-\bar{\alpha}_t} \boldsymbol{\epsilon}$，则 $$\nabla_{\mathbf{x}_t} \log q(\mathbf{x}_t | \mathbf{x}_0) = -\frac{\boldsymbol{\epsilon}}{\sqrt{1-\bar{\alpha}_t}}$$ 所以预测噪声 $\boldsymbol{\epsilon}$ 就是在估计 score。DDPM 的损失函数就是 denoising score matching (Vincent, 2011) 的加权版本。

关键洞察——为什么要加噪

  • 不加噪的问题：真实数据分布集中在低维流形上——score 在数据流形之外没有定义（概率为零，score 发散）
  • 加噪后：分布被「涂抹」到整个空间，score 处处有定义且光滑，可以用神经网络学习
  • 多尺度加噪 = 在不同「分辨率」上估计 score，从粗到细的 Langevin 采样 = 退火过程
  • 这就是为什么 DDPM 不是灵机一动——它是 Score Matching + 多尺度退火的自然实现
→ Score-Based: 本质相同（Song et al. 2021 统一） → VAE: Diffusion = 多层 VAE 的极限 → EBM: 都基于 score/能量
Score

Score-Based Generative Model

Song & Ermon, 2019; Song et al., 2021 (SDE 统一)
数学本质：显式地用神经网络学习 score function $\mathbf{s}_\theta(\mathbf{x}) \approx \nabla_\mathbf{x} \log p(\mathbf{x})$，然后用 Langevin 动力学采样。这是最直接绕开 $Z$ 的方法。

核心公式

$$\mathcal{L}_{\text{DSM}} = \mathbb{E}_{\mathbf{x} \sim p, \tilde{\mathbf{x}} \sim q_\sigma(\tilde{\mathbf{x}}|\mathbf{x})} \left[ \left\| \mathbf{s}_\theta(\tilde{\mathbf{x}}) - \nabla_{\tilde{\mathbf{x}}} \log q_\sigma(\tilde{\mathbf{x}} | \mathbf{x}) \right\|^2 \right]$$

SDE 统一视角 (Song et al., 2021)

正向过程（加噪）：$d\mathbf{x} = \mathbf{f}(\mathbf{x}, t)\, dt + g(t)\, d\mathbf{w}$
逆向过程（去噪/采样）：$d\mathbf{x} = [\mathbf{f}(\mathbf{x}, t) - g(t)^2 \nabla_\mathbf{x} \log p_t(\mathbf{x})]\, dt + g(t)\, d\bar{\mathbf{w}}$

逆向 SDE 的漂移项恰好需要 score $\nabla_\mathbf{x} \log p_t(\mathbf{x})$。 一旦你接受了「学 score → 用 SDE 逆向采样」这个框架，扩散模型和 score-based 模型就是同一个数学结构的两种实现。

关键洞察

  • Score-Based 模型是概念上最干净的绕 $Z$ 方法：只学 score，不碰密度
  • 和 EBM 的关系：$E(\mathbf{x}) = -\log p(\mathbf{x})$，所以 score = $-\nabla E$，是同一个东西
  • 和 Diffusion 的关系：噪声预测 = score 估计（在加噪分布上）
  • SDE 框架将离散的加噪/去噪推广为连续时间随机过程——这是真正的统一
↔ EBM: score = −∇E ↔ Diffusion: 噪声预测 ≡ score → SDE 统一: Song et al. 2021
