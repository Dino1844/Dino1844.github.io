1. 散度的公理：什么才算"距离"

数学上，"距离"需要满足三条公理：正定性 $d(p,q)\geq 0$ 且 $d(p,q)=0\Leftrightarrow p=q$，对称性 $d(p,q)=d(q,p)$，三角不等式 $d(p,q)+d(q,r)\geq d(p,r)$。KL 散度满足正定性（Gibbs 不等式）但不对称——它不是真正的距离。

范式 #29 · 散度 = 衡量分布差异的函数

散度（divergence）只要求正定性，不要求对称和三角不等式。这给了我们一个巨大的设计空间——可以根据任务选择不同几何性质的散度。VI 用反向 KL（mode-seeking），MLE 用前向 KL（mean-seeking），GAN 用 JS（对称），WGAN 用 Wasserstein（处处有梯度）。
散度对称?三角不等式?处处有梯度?典型用途
$D_{\text{KL}}(p\|q)$否否在 $q=0,p>0$ 处爆炸MLE、EM
$D_{\text{KL}}(q\|p)$否否在 $p=0,q>0$ 处爆炸变分推断 (VI)
JS 散度是否支撑不交时退化到常数原始 GAN
$W_1$ (Wasserstein-1)是是是（关键优势）WGAN

2. $f$-散度：一个公式，KL/JS/χ² 全在里面

范式 #30

$f$-散度 · $f$-Divergence

数学本质：$D_f(p\|q) = \mathbb{E}_q\!\big[f\!\big(\frac{p(x)}{q(x)}\big)\big] = \int q(x)\,f\!\big(\frac{p(x)}{q(x)}\big)\,dx$。其中 $f$ 是任意凸函数且 $f(1)=0$。换 $f$ = 换散度——这就像指数族里"换分布 = 换四个组件"的同构：一个统一形式覆盖一大类。

$f$ 函数对照表

$f(u)$散度公式
$u\log u$前向 KL$D_{\text{KL}}(p\|q)=\int p\log(p/q)$
$-\log u$反向 KL$D_{\text{KL}}(q\|p)=\int q\log(q/p)$
$-(u+1)\log\frac{u+1}{2}+u\log u$JS$D_{\text{JS}}=\frac12\mathrm{KL}(p\|m)+\frac12\mathrm{KL}(q\|m),\;m=\frac{p+q}{2}$
$(u-1)^2$Pearson $\chi^2$$\chi^2(p\|q)=\int\frac{(p-q)^2}{q}$
→ 指数族: 换组件 = 换分布→ $f$-散度: 换 $f$ = 换散度
凸函数 $f$ 决定了散度的全部几何性质。$f(u)=u\log u$：在 $u\to 0$ 时有界（$0\log 0\to 0$），所以前向 KL 对 $q=0$ 但 $p>0$ 的区域施重罚。$f(u)=-\log u$：在 $u\to\infty$ 时线性增长（$\log u$），所以反向 KL 对 $p=0$ 但 $q>0$ 的区域施软罚。这两个不对称性来自 $f$ 在 $u\to 0$ 和 $u\to\infty$ 的渐近行为——散度的全部"个性"都在 $f$ 的尾巴里。

3. 前向 KL vs 反向 KL：mean-seeking vs mode-seeking

范式 #31

前向 KL = mean-seeking · 反向 KL = mode-seeking

前向 KL $\mathrm{KL}(p\|q)$：$p$ 大处 $q$ 必须大，否则被 $\log(p/q)\to\infty$ 重罚 → $q$ 覆盖 $p$ 的所有模式（mean-seeking）。反向 KL $\mathrm{KL}(q\|p)$：$p$ 小处 $q$ 必须小，否则被 $q\log(q/p)$ 罚 → $q$ 缩在 $p$ 的一个模式里（mode-seeking）。

两种 KL 的选择决定了整个算法的行为

MLE/EM 用前向 KL（$\mathrm{KL}(\widehat{p}_{\text{data}}\|p_{\mathbf{w}})$）→ 模型必须覆盖数据的所有模式 → 不会漏模式，但可能把噪声当模式。

VI 用反向 KL（$\mathrm{KL}(q_\phi\|p_{\text{posterior}})$）→ $q$ 缩在真实后验的最高峰附近 → 若真后验多峰，只拟合一个峰。

→ 0001 §6: MLE = min 前向 KL→ 0015: VI = min 反向 KL→ 0010: EM = 前向 KL
多峰分布的悲剧：假设 $p_{\text{data}}$ 是双峰（两个 cluster）。前向 KL 训练的模型会生成两个峰（覆盖完整）。反向 KL 训练的模型（VI）可能只生成一个峰——它选择了"最安全"的那个模式，完全忽略了另一个。这就是为什么 VAE 生成的样本比 GAN "模糊"——反向 KL 的 mode-seeking 本性让 VAE 不敢覆盖全部模式。

4. Jensen-Shannon：对称且平滑

JS 散度取前向和后向 KL 的对称平均：$D_{\text{JS}}(p\|q) = \frac12\mathrm{KL}(p\|m) + \frac12\mathrm{KL}(q\|m)$，其中 $m=\frac{p+q}{2}$。它是对称的、有界的（$0\leq D_{\text{JS}}\leq\log 2$）。

为什么 GAN 用 JS？原始 GAN 的 minimax 目标：$\min_G\max_D\mathbb{E}_{p_{\text{data}}}[\log D]+\mathbb{E}_{p_G}[\log(1-D)]$。当 $D$ 达到最优 $D^*=\frac{p_{\text{data}}}{p_{\text{data}}+p_G}$ 时，生成器的损失 等价于 $2D_{\text{JS}}(p_{\text{data}}\|p_G)-\log 4$。

JS 的致命缺陷：梯度消失。在高维空间中，$p_{\text{data}}$ 和 $p_G$ 的支撑集（概率非零的区域）几乎不相交。当支撑不交时，$D_{\text{JS}}$ 恒定等于 $\log 2$——梯度完全为零。训练初期的生成器产生的是纯噪声，和数据分布支撑几乎无交集 → JS 散度停在 $\log 2$，梯度零 → GAN 不学了 → 训练崩溃。这是原始 GAN 不稳定的数学根源。

5. Wasserstein 距离：最优传输的几何直觉

范式 #32

Wasserstein 距离 · Earth Mover's Distance

直觉：把分布 $p$ 变成分布 $q$，最少需要把多少"概率质量"搬运多远的距离。不像 KL/JS 只比较同一位置的密度值，Wasserstein 考虑了空间的几何结构。

Wasserstein-1 (Kantorovich-Rubinstein 对偶)

$$W_1(p,q) = \sup_{\|f\|_L\leq 1} \mathbb{E}_{x\sim p}[f(x)] - \mathbb{E}_{x\sim q}[f(x)]$$

$f$ 是 1-Lipschitz 函数——变化不能太快。WGAN 的 Critic 就是在学这个最优的 $f$。

→ WGAN: Critic 近似 $f$→ 0019: 最优传输 = 概率空间几何

为什么 Wasserstein 解决了 JS 的梯度消失

JS 的问题：两分布支撑不交 → $D_{\text{JS}}=\log 2$（常数）→ $\nabla D_{\text{JS}}=0$ → 生成器得不到学习信号。
Wasserstein 的不同：$W_1(p,q)$ = 需要搬运的概率质量 × 搬运距离。即使两分布支撑不交，$W_1$ 仍然等于它们之间的空间距离 → 梯度不为零 → 生成器得到"往数据方向走"的信号。Wasserstein 连续依赖于分布的几何位置——JS 没有这个性质。
例如：$p=\delta_0$（Dirac at 0），$q_\theta=\delta_\theta$。$W_1(p,q_\theta)=|\theta|$（梯度 = $\pm 1$，处处非零）。$D_{\text{JS}}(p\|q_\theta)=\log 2$（$\theta\neq 0$ 时恒定，梯度 = 0）。这个一维例子完美展示了 Wasserstein 对生成模型的价值。

6. 为什么散度选择决定 GAN 的生与死

总结整个故事的逻辑链：

  1. 原始 GAN = min JS（等价性由最优判别器推导出）→ 高维支撑不交 → JS 常数 → 梯度消失 → 训练崩溃/模式坍塌。
  2. WGAN = min Wasserstein（用 Kantorovich-Rubinstein 对偶）→ 处处有梯度 → 训练稳定。代价：需要约束 Critic 是 1-Lipschitz（权重裁剪、梯度惩罚）。
  3. $f$-GAN：可以用任意 $f$-散度训练 GAN——用 Fenchel 对偶把 $\mathbb{E}_q[f(p/q)]$ 变成 $\sup_T[\mathbb{E}_p[T]-\mathbb{E}_q[f^*(T)]]$（$f^*$ = $f$ 的凸共轭）。$T$ 就是判别器。
Fenchel 对偶是 $f$-GAN 的数学核心。凸函数的对偶表示：$f(u) = \sup_{t\in\mathbb{R}}[tu - f^*(t)]$。代入 $u=p/q$： $D_f(p\|q) = \sup_T[\mathbb{E}_p[T(x)] - \mathbb{E}_q[f^*(T(x))]]$。 这就是 $f$-GAN 的统一框架——$T$ 是判别器，$f^*$ 是激活函数。换 $f$ = 换激活函数 = 换散度 = 换 GAN 的行为。这是"损失是噪声的影子"（0001 §2）在生成模型里的对应物："判别器的激活函数是散度的影子"。
$f$-散度$f^*(t)$ (凸共轭)判别器输出激活GAN 变体
KL$\exp(t-1)$无界（可能爆炸）—
JS$-\log(2-e^t)$Sigmoid原始 GAN
$\chi^2$$t+t^2/4$线性LSGAN
Wasserstein—（不是 $f$-散度）无激活（Critic）WGAN

7. 推导与自测

L1 · $f$-散度的非负性证明 L1
用 Jensen 不等式证明 $D_f(p\|q)\geq 0$。提示：$f$ 是凸函数，$f(1)=0$。
展开推导
$D_f(p\|q) = \mathbb{E}_q[f(p/q)] \geq f(\mathbb{E}_q[p/q])$Jensen 不等式：$f$ 是凸函数
$\mathbb{E}_q[p/q] = \int q\cdot(p/q)\,dx = \int p\,dx = 1$$p$ 是概率密度，积分为 1
$f(\mathbb{E}_q[p/q]) = f(1) = 0$$f(1)=0$ 是 $f$-散度的定义要求
因此 $D_f(p\|q) \geq 0$。等号成立当 $p/q$ 是常数（$p=q$ 几乎处处）。
L2 · JS 散度的有界性 L2
证明 $0\leq D_{\text{JS}}(p\|q)\leq\log 2$。提示：$D_{\text{JS}}=\frac12\mathrm{KL}(p\|m)+\frac12\mathrm{KL}(q\|m)$，其中 $m=(p+q)/2$。
展开推导
$\mathrm{KL}(p\|m) = \mathbb{E}_p[\log(p/m)] = \mathbb{E}_p[\log(2p/(p+q))] = \mathbb{E}_p[\log 2 + \log(p/(p+q))] \leq \mathbb{E}_p[\log 2] = \log 2$$p/(p+q)\leq 1$ → $\log\leq 0$ → 上界 $\log 2$
同理 $\mathrm{KL}(q\|m) \leq \log 2$。$D_{\text{JS}} = \frac12(\leq\log 2 + \leq\log 2) \leq \log 2$。这就是 JS 有界的原因——它比较的是 $p$ 和 $m=(p+q)/2$，不是直接比较 $p$ 和 $q$。
下界：非负性由 Jensen 保证。有界性是 JS 在高维失效的根源——支撑不交时直接饱和到上限 $\log 2$。
L3 · Wasserstein vs KL 的几何敏感性 L3
设 $p=\mathcal{N}(0,1)$，$q_\theta=\mathcal{N}(\theta,1)$。(1) 推导 $\mathrm{KL}(p\|q_\theta)$ 和 $W_2(p,q_\theta)$（Wasserstein-2）的表达式。(2) 分析它们作为 $\theta$ 的函数的梯度行为——哪个在 $\theta$ 大时梯度仍显著？(3) 解释这对生成模型训练的意义。
展开推导
(1) 两个高斯之间的 KL：$\mathrm{KL}(p\|q_\theta) = \frac12\big[\frac{\sigma_p^2}{\sigma_q^2} + \frac{(\mu_p-\mu_q)^2}{\sigma_q^2} - 1 + 2\log\frac{\sigma_q}{\sigma_p}\big]$。这里 $\mu_p=0,\mu_q=\theta,\sigma_p=\sigma_q=1$ → $\mathrm{KL}= \frac12\theta^2$。KL = 二次增长，梯度 $\theta$，随距离线性增长——看似不错。
两个高斯之间的 $W_2$：$W_2^2(p,q_\theta) = (\mu_p-\mu_q)^2 + (\sigma_p-\sigma_q)^2 = \theta^2 + 0$。$W_2 = |\theta|$，梯度 = $\text{sign}(\theta)$。Wasserstein-2 梯度是常数！无论两分布隔多远，梯度永远 $\pm 1$。
(2) KL 梯度 $=\theta$（小 $\theta$ 时梯度小 → 训练慢）；$W_2$ 梯度 $=\pm 1$（恒定 → 处处有效）。在这个例子里两者都好——但高维支撑不交时 KL 直接无穷大，$W$ 仍然有限。
(3) 生成模型意义：训练初期 $p_G$ 和 $p_{\text{data}}$ 几乎无交集。JS/KL 的梯度为零或无穷 → 生成器收不到信号。Wasserstein 的梯度仍反映两分布的几何距离 → 生成器始终知道"往哪走"。这就是 WGAN 比原始 GAN 稳定的数学根源。
关键带回：散度家族 = 一个统一框架（$f$-散度）生成 KL/JS/χ² + Wasserstein 作为"非 $f$ 的几何散度"。 前向 KL = 覆盖所有模式（MLE），反向 KL = 聚焦一个模式（VI），JS = 对称但高维失效（原始 GAN），Wasserstein = 处处有梯度（WGAN）。 "损失是噪声的影子"（0001）→ "判别器的激活函数是 $f$-散度的影子"（本课）→ "散度是生成模型行为的影子"。
