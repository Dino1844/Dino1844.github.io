# 课程路径设计

## 设计原则

1. **螺旋深化**：同一主题（如「合法性」「国家能力」「自由」）在不同阶段以不同深度重现
2. **每节课建立在前节之上**：概念有依赖关系，避免跳跃
3. **核心路径 + 可选扩展**：核心 ~25 节是主干；可选主题随时可插入
4. **每阶段以一个综合案例收尾**：把该阶段的概念在一个具体历史情境中整合练习

## 核心路径（25 节）

### Phase 1 · 思维脚手架（L1–L4）
- L1 ✅ 国家起源：四视角第一次交汇
- L2 合法性的面孔：韦伯三种权威 + 当代应用
- L3 制度如何变迁：路径依赖、关键节点、制度锁定
- L4 权力的三维：强制、交易、说服（综合：用四视角重审 L1）

### Phase 2 · 轴心时代（L5–L8）
- L5 轴心时代谜题：为什么全球同时哲学突破？
- L6 古希腊城邦：民主实验的成就与局限
- L7 战国百家：法家/儒家/道家的政治哲学分歧
- L8 柏拉图《理想国》vs 韩非子（综合：两种「好国家」）

### Phase 3 · 前现代系统（L9–L13）
- L9 罗马兴衰：共和国的帝国化与多因崩溃
- L10 中华帝国政治逻辑：郡县、科举、王朝周期律
- L11 封建制政治经济学：欧洲中世纪的特殊路径
- L12 宗教改革的经济后果：韦伯论及其批评
- L13 帝国比较：罗马 vs 中华 vs 蒙古（综合）

### Phase 4 · 大转型（L14–L18）
- L14 大分流：为什么是欧洲？
- L15 启蒙运动：理性、权利与革命的思想准备
- L16 法国大革命：启蒙哲学的实验室
- L17 工业革命：技术、资本、劳动的经济地震
- L18 资本主义的精神：马克思 vs 韦伯 vs 波兰尼（综合）

### Phase 5 · 20 世纪（L19–L22）
- L19 三种现代性方案：自由民主 vs 共产主义 vs 法西斯
- L20 大萧条与新政：资本主义的第一次自我修正
- L21 福利国家政治经济学：从俾斯麦到北欧
- L22 中国的革命与改革：从计划经济到国家资本主义（综合）

### Phase 6 · 当代综合（L23–L25）
- L23 全球化及其不满：贸易、移民、文化冲突
- L24 民主在衰落吗？民粹主义、极化、技术变革
- L25 气候危机 + AI 与权力：用整个框架理解今天（终章综合）

## 可选扩展（随时可插入）

- 比较视野：希腊城邦 vs 战国诸侯 vs 印度十六国
- 伊斯兰世界的政治哲学
- 蒙古帝国：没有官僚制的世界帝国
- 美国建国：洛克理论的第一个大规模实验
- 苏联实验：计划经济的可能性与失败
- 去殖民化：民族自决的梦想与现实
- 1978–2008：新自由主义的兴起与危机
- 中国的崛起：国家资本主义的政治经济学
- 不平等的道德与政治：皮凯蒂到社群主义

## 贯穿性主题（可在任何阶段插入）

- 「自由」在不同文明中的含义
- 革命比较：1688 · 1789 · 1917 · 1949
- 帝国的逻辑
- 货币与主权
- 战争与技术
