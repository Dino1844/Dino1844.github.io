上一课 0004 的逻辑回归直接建模 $p(y\mid\mathbf{x})$——它不管数据 $\mathbf{x}$ 是怎么来的，只关心分类边界。 这叫判别模型（discriminative model）。但还有另一条路：先建模 $\mathbf{x}$ 在每个类别下的分布 $p(\mathbf{x}\mid y)$， 再结合类别先验 $p(y)$，用贝叶斯定理算出 $p(y\mid\mathbf{x})$。这叫生成模型（generative model）。 两条路在分类问题上殊途同归，但哲学、假设、性能特征完全不同。 本课把它们放在一起对比，看清各自的骨架。

1. 根本区别：建模 $p(y\mid\mathbf{x})$ 还是 $p(\mathbf{x},y)$

给定数据 $\{(\mathbf{x}_n, y_n)\}_{n=1}^N$，$\mathbf{x}_n\in\mathbb{R}^D$，$y_n\in\{0,1\}$（先讨论二分类）。 分类的目标是预测 $y$ 给定 $\mathbf{x}$——即 $p(y\mid\mathbf{x})$。 但达到这个目标有两条截然不同的路径：

$$\text{判别:}\quad \text{直接建模 } p(y\mid\mathbf{x}) \qquad \text{生成:}\quad \text{建模 } p(\mathbf{x},y) = p(\mathbf{x}\mid y)\,p(y)$$

生成模型通过贝叶斯定理把 $p(\mathbf{x}\mid y)$ 和 $p(y)$ 转成 $p(y\mid\mathbf{x})$：

$$p(y\mid\mathbf{x}) = \frac{p(\mathbf{x}\mid y)\,p(y)}{p(\mathbf{x})} = \frac{p(\mathbf{x}\mid y)\,p(y)}{\sum_{y'} p(\mathbf{x}\mid y')\,p(y')}$$

分母 $p(\mathbf{x})$ 只是归一化常数，不影响分类决策。所以分类规则是：

$$\hat{y} = \arg\max_y\; p(\mathbf{x}\mid y)\,p(y)$$

这就是贝叶斯分类器（Bayes classifier）——在已知真实分布时它是最优的，错误率称为贝叶斯错误率（Bayes error rate）。实际中 $p(\mathbf{x}\mid y)$ 和 $p(y)$ 未知，我们需要从数据中估计它们——这就是生成模型做的事。

判别模型直接拟合 $p(y\mid\mathbf{x})$ 的决策边界，不关心 $\mathbf{x}$ 的分布。 生成模型先拟合 $\mathbf{x}$ 在每个类下的分布，再通过贝叶斯定理得到边界。 生成模型能做判别模型做不了的事：生成新样本、处理缺失特征、利用无标签数据。 代价是它必须对 $p(\mathbf{x}\mid y)$ 做假设——假设错了，分类性能可能更差。

逻辑回归（上一课 0004）是判别模型——它直接写 $p(C_1\mid\mathbf{x})=\sigma(\mathbf{w}^\top\mathbf{x}+w_0)$，用 MLE 或 IRLS 拟合 $\mathbf{w}$。而下面要讲的朴素贝叶斯和 LDA 是生成模型——它们先假设 $p(\mathbf{x}\mid C_k)$ 的形式，再推出后验。

2. 生成模型例 1：朴素贝叶斯

朴素贝叶斯（Naive Bayes）是生成模型最简单的例子。它的核心假设是条件独立（conditional independence）： 给定类别 $y$，特征 $\mathbf{x}=(x_1,\dots,x_D)$ 的各个维度相互独立。

$$p(\mathbf{x}\mid y) = \prod_{i=1}^D p(x_i\mid y)$$

这个假设"朴素"（naive）得几乎从不为真——特征之间几乎总有相关性。但出人意料的是， 即使假设被严重违反，朴素贝叶斯的分类性能往往还不错。原因在于：分类只关心 $\arg\max_y p(y)\prod_i p(x_i\mid y)$ 的排序正确， 不要求概率估计准确。只要各个类别的条件独立假设带来的偏误方向一致，决策边界就不会被破坏。

结合贝叶斯定理，分类规则变成：

$$\hat{y} = \arg\max_y\; p(y)\prod_{i=1}^D p(x_i\mid y)$$

取对数后：

$$\hat{y} = \arg\max_y\; \Big[\log p(y) + \sum_{i=1}^D \log p(x_i\mid y)\Big]$$

具体形式取决于 $x_i$ 的类型。如果 $x_i$ 是离散的（如文本分类中的词频），$p(x_i\mid y)$ 常用多项分布（multinomial）建模——这就是多项朴素贝叶斯（Multinomial Naive Bayes），文本分类的经典基准。如果 $x_i$ 是连续的，$p(x_i\mid y)$ 常用高斯建模——高斯朴素贝叶斯（Gaussian Naive Bayes），每个类下每个特征有自己的均值和方差。

示例：垃圾邮件分类

特征 $\mathbf{x}$ 是词袋向量——$x_i$ 表示第 $i$ 个词是否出现（0/1），用 Bernoulli 建模 $p(x_i\mid y)$。 先验 $p(y)$ 是垃圾邮件的比例。分类时计算： $\hat{y} = \arg\max_y \big[\log p(y) + \sum_i \log p(x_i\mid y)\big]$。 虽然"词的出现"显然不是条件独立的（"开会"和"通知"常一起出现），但朴素贝叶斯在垃圾邮件过滤中仍然表现优异。

朴素贝叶斯的"朴素"假设把 $D$ 维联合分布分解成 $D$ 个一维分布的乘积，参数从指数级降到线性级。 这是它样本效率高的根本原因——每个类只需估计 $D$ 个一维分布的参数，而不是一个 $D$ 维联合分布的参数。 但代价是条件独立假设几乎总是错的——当特征间强相关时，概率估计严重偏误。

3. 生成模型例 2：LDA——线性判别分析

线性判别分析（Linear Discriminant Analysis, LDA）是另一个经典的生成模型。 它假设每个类别的类条件分布是高斯，且所有类别共享同一个协方差矩阵：

$$p(\mathbf{x}\mid C_k) = \mathcal{N}(\mathbf{x}\mid\boldsymbol{\mu}_k,\boldsymbol{\Sigma}), \quad k=0,1$$ $$p(C_1) = \pi,\quad p(C_0) = 1-\pi$$

在这个假设下，后验概率 $p(C_1\mid\mathbf{x})$ 可以写成 sigmoid 形式，且决策边界是线性的。 这是生成模型推出线性边界的核心推导。我们来走一遍。

后验之比的对数（log-odds）：

$$a = \log\frac{p(C_1\mid\mathbf{x})}{p(C_0\mid\mathbf{x})} = \log\frac{p(\mathbf{x}\mid C_1)p(C_1)}{p(\mathbf{x}\mid C_0)p(C_0)} = \log\frac{p(\mathbf{x}\mid C_1)}{p(\mathbf{x}\mid C_0)} + \log\frac{\pi}{1-\pi}$$

代入高斯密度：

LDA 后验的推导

$\displaystyle \log\frac{p(\mathbf{x}\mid C_1)}{p(\mathbf{x}\mid C_0)} = -\frac{1}{2}(\mathbf{x}-\boldsymbol{\mu}_1)^\top\boldsymbol{\Sigma}^{-1}(\mathbf{x}-\boldsymbol{\mu}_1) +\frac{1}{2}(\mathbf{x}-\boldsymbol{\mu}_0)^\top\boldsymbol{\Sigma}^{-1}(\mathbf{x}-\boldsymbol{\mu}_0)$ 代入高斯密度，归一化常数 $\frac{1}{(2\pi)^{D/2}|\boldsymbol{\Sigma}|^{1/2}}$ 抵消
$\displaystyle = \mathbf{x}^\top\boldsymbol{\Sigma}^{-1}\boldsymbol{\mu}_1 - \frac{1}{2}\boldsymbol{\mu}_1^\top\boldsymbol{\Sigma}^{-1}\boldsymbol{\mu}_1 - \mathbf{x}^\top\boldsymbol{\Sigma}^{-1}\boldsymbol{\mu}_0 + \frac{1}{2}\boldsymbol{\mu}_0^\top\boldsymbol{\Sigma}^{-1}\boldsymbol{\mu}_0$ 展开二次型，$\mathbf{x}^\top\boldsymbol{\Sigma}^{-1}\boldsymbol{\mu} = \boldsymbol{\mu}^\top\boldsymbol{\Sigma}^{-1}\mathbf{x}$ 因 $\boldsymbol{\Sigma}$ 对称
$\displaystyle = \mathbf{x}^\top\boldsymbol{\Sigma}^{-1}(\boldsymbol{\mu}_1-\boldsymbol{\mu}_0) - \frac{1}{2}(\boldsymbol{\mu}_1+\boldsymbol{\mu}_0)^\top\boldsymbol{\Sigma}^{-1}(\boldsymbol{\mu}_1-\boldsymbol{\mu}_0)$ 合并同类项，用恒等式 $\boldsymbol{\mu}_1^\top\boldsymbol{\Sigma}^{-1}\boldsymbol{\mu}_1 - \boldsymbol{\mu}_0^\top\boldsymbol{\Sigma}^{-1}\boldsymbol{\mu}_0 = (\boldsymbol{\mu}_1+\boldsymbol{\mu}_0)^\top\boldsymbol{\Sigma}^{-1}(\boldsymbol{\mu}_1-\boldsymbol{\mu}_0)$

加上先验比的对数，得到：

$$a = \mathbf{w}^\top\mathbf{x} + w_0$$

其中：

$$\boxed{\;\mathbf{w} = \boldsymbol{\Sigma}^{-1}(\boldsymbol{\mu}_1 - \boldsymbol{\mu}_0)\;}$$ $$\boxed{\;w_0 = -\frac{1}{2}(\boldsymbol{\mu}_1+\boldsymbol{\mu}_0)^\top\boldsymbol{\Sigma}^{-1}(\boldsymbol{\mu}_1-\boldsymbol{\mu}_0) + \log\frac{\pi}{1-\pi}\;}$$

于是后验是：

$$p(C_1\mid\mathbf{x}) = \sigma(\mathbf{w}^\top\mathbf{x} + w_0)$$

注意：LDA 和逻辑回归得到了形式上完全相同的 sigmoid 后验和线性决策边界。 但它们的参数来源完全不同——LDA 的参数 $\mathbf{w},w_0$ 是 $\boldsymbol{\mu}_0,\boldsymbol{\mu}_1,\boldsymbol{\Sigma},\pi$ 的函数， 由类条件高斯和先验的 MLE 估计间接给出；而逻辑回归直接优化条件似然 $p(y\mid\mathbf{x})$。

LDA 的线性决策边界不是"设计"出来的，是"高斯共享协方差"假设的必然推论。 如果每个类有自己的协方差矩阵 $\boldsymbol{\Sigma}_k$，二次型展开后 $\mathbf{x}^\top\boldsymbol{\Sigma}_k^{-1}\mathbf{x}$ 项不会抵消， 决策边界变成二次的——那就是二次判别分析（QDA, Quadratic Discriminant Analysis）。 所以 LDA vs QDA 的选择，本质上就是"协方差是否共享"的假设选择。

参数估计也很直接。用 MLE：

$$\hat{\boldsymbol{\mu}}_k = \frac{1}{N_k}\sum_{n:y_n=k}\mathbf{x}_n, \quad \hat{\pi} = \frac{N_1}{N}$$ $$\hat{\boldsymbol{\Sigma}} = \frac{1}{N}\sum_{k}\sum_{n:y_n=k}(\mathbf{x}_n-\hat{\boldsymbol{\mu}}_k)(\mathbf{x}_n-\hat{\boldsymbol{\mu}}_k)^\top$$

注意 $\hat{\boldsymbol{\Sigma}}$ 是池化协方差（pooled covariance）——所有类共享，所以用所有样本围绕各自类均值的偏差来估计。这比每个类单独估计协方差要稳定得多，尤其在各类样本数少的时候。

🔗 推导范式 #6 · "log-likelihood 比 → 二次型抵消 → 线性边界"

生成模型推决策边界的通用招数：写 $\log p(\mathbf{x}\mid C_1)-\log p(\mathbf{x}\mid C_0)+\log\frac{\pi_1}{\pi_0}$，展开指数族的对数，看哪些项抵消。 高斯共享 $\boldsymbol{\Sigma}$ 时 $\mathbf{x}^\top\boldsymbol{\Sigma}^{-1}\mathbf{x}$ 两类相同抵消 → 线性；不共享 → 留下二次 → QDA。 0004 指数族、0010 GMM 的判别、0011 概率 PCA 的隐变量推断——都是"取对数 + 看抵消"这一招。 对数把指数族的乘积/商变成线性组合，抵消决定边界阶数。

4. LDA vs 逻辑回归：同一条边界，不同的假设

LDA 和逻辑回归都给出 $p(C_1\mid\mathbf{x})=\sigma(\mathbf{w}^\top\mathbf{x}+w_0)$ 的形式——决策边界都是线性的。 但它们的假设和估计方法完全不同：

维度LDA（生成）逻辑回归（判别）
建模对象 $p(\mathbf{x}\mid C_k)$ 和 $p(C_k)$ 直接 $p(C_k\mid\mathbf{x})$
核心假设 类条件高斯、共享协方差 log-odds 是 $\mathbf{x}$ 的线性函数
参数估计 类均值和协方差的 MLE 条件似然的 MLE（IRLS）
$\mathbf{w}$ 的表达式 $\boldsymbol{\Sigma}^{-1}(\boldsymbol{\mu}_1-\boldsymbol{\mu}_0)$ 闭式 数值优化，无闭式
对 $\mathbf{x}$ 分布敏感 是——假设错了影响大 否——只关心边界
样本效率 高（利用 $\mathbf{x}$ 全部信息） 相对低（只利用边界附近信息）

当数据确实来自两个共享协方差的高斯时，LDA 比逻辑回归更高效（更低的方差、更少的样本需求）；但当高斯假设不成立时（如数据来自非高斯分布），逻辑回归的决策边界仍然可以准确，而 LDA 会因模型错误而表现不佳。数据量足够大时，逻辑回归可以逼近任何线性决策边界，而 LDA 受限于高斯假设。

LDA 和逻辑回归的对比是"假设正确时的效率" vs "假设错误时的鲁棒性"的经典权衡。 数据少且类条件近似高斯共享协方差 → LDA 更好。 数据多或分布复杂 → 逻辑回归更鲁棒。 这个权衡是生成模型 vs 判别模型的缩影。

还有一个重要的联系：LDA 的 $\mathbf{w}$ 方向 $\boldsymbol{\Sigma}^{-1}(\boldsymbol{\mu}_1-\boldsymbol{\mu}_0)$ 恰好等于Fisher 线性判别（Fisher's Linear Discriminant）的方向。 Fisher 判别不假设高斯，而是直接寻找一个投影方向 $\mathbf{w}$，使投影后类间散度与类内散度之比最大。 当数据来自共享协方差的高斯时，Fisher 判别给出的方向与 LDA 的 $\mathbf{w}$ 方向完全一致。 所以 LDA 和 Fisher 判别在方向上等价，但 LDA 还给出了概率输出和决策阈值。

5. 何时用哪个：生成 vs 判别的权衡

前几节用朴素贝叶斯和 LDA 展示了生成模型，用逻辑回归展示了判别模型。 现在把权衡系统化：

生成模型的优势

  1. 样本效率更高。生成模型拟合 $p(\mathbf{x}\mid y)$ 利用了所有 $\mathbf{x}$ 的信息（包括无标签样本的结构），而判别模型只关心边界附近的信息。当类条件分布正确时，生成模型在少样本下方差更小。
  2. 能处理缺失特征。如果测试时 $\mathbf{x}$ 的某些维度缺失，生成模型可以对缺失维度积分（marginalize）：$p(y\mid\mathbf{x}_{\text{obs}})\propto p(y)\int p(\mathbf{x}_{\text{obs}},\mathbf{x}_{\text{miss}}\mid y)\,d\mathbf{x}_{\text{miss}}$。判别模型没有 $p(\mathbf{x})$，无法自然处理缺失——需要插补（imputation）或其他技巧。这个方向通向 0010 的 EM 算法。
  3. 能生成样本。从 $p(\mathbf{x}\mid y)$ 采样可以生成新数据，用于数据增强、异常检测、隐私保护等。
  4. 能利用无标签数据。半监督学习（如 self-training）中，生成模型可以自然地利用无标签数据来改进 $p(\mathbf{x})$ 的估计。

判别模型的优势

  1. 分类边界更准确。判别模型直接优化分类目标（条件似然），不浪费参数去拟合 $\mathbf{x}$ 的分布——而 $\mathbf{x}$ 的分布对分类可能完全无关。Vapnik 的著名论断："在解决一个分类问题时，不应该把资源浪费在解决一个更难的问题（建模 $p(\mathbf{x})$）上。"
  2. 对 $p(\mathbf{x}\mid y)$ 的假设鲁棒。生成模型必须假设 $p(\mathbf{x}\mid y)$ 的形式——如果假设错了，分类性能可能严重下降。判别模型不需要这个假设。
  3. 更灵活的特征工程。判别模型可以直接使用复杂的特征变换（如核方法、深度学习特征），而生成模型需要确保 $p(\mathbf{x}\mid y)$ 对这些变换可建模。
一个常见的误解："生成模型总是比判别模型差，因为 Vapnik 说过不要解更难的问题。" 实际上，当 $p(\mathbf{x}\mid y)$ 的假设正确时，生成模型在有限样本下可以显著优于判别模型（Ng & Jordan, 2002 的理论分析证明了这一点）。 选择哪种模型取决于：你对 $p(\mathbf{x}\mid y)$ 的假设有多自信？你的样本量有多大？你是否需要处理缺失值或生成样本？

还有一个更深的联系：当生成模型中有隐变量（如缺失特征、混合成分）时，可以用 EM 算法来最大化观测数据的似然——这是 0010 课的主题。 这是生成模型独有的能力——判别模型没有 $p(\mathbf{x})$ 的结构，无法自然地引入隐变量。 这会在后面的课程（EM 算法、混合模型）中展开。

题 1 · 朴素贝叶斯的分类规则 L1 · 基础
给定 $K$ 个类别，先验 $p(y=k)=\pi_k$，条件独立假设 $p(\mathbf{x}\mid y=k)=\prod_{i=1}^D p(x_i\mid y=k)$。 写出贝叶斯分类规则 $\hat{y}=\arg\max_k p(y=k\mid\mathbf{x})$，并取对数化简。 说明为什么取对数后计算更稳定。
提示
$p(y=k\mid\mathbf{x})\propto p(y=k)p(\mathbf{x}\mid y=k)$。取对数把乘积变求和，避免数值下溢。
解答
贝叶斯定理：$p(y=k\mid\mathbf{x}) = \dfrac{p(y=k)\,p(\mathbf{x}\mid y=k)}{p(\mathbf{x})}$。
分母 $p(\mathbf{x})$ 与 $k$ 无关，分类时只需比较分子：$\hat{y} = \arg\max_k\; \pi_k \prod_{i=1}^D p(x_i\mid y=k)$。
取对数：$\hat{y} = \arg\max_k\; \Big[\log\pi_k + \sum_{i=1}^D \log p(x_i\mid y=k)\Big]$。
为什么取对数更稳定：原始乘积 $\prod_i p(x_i\mid y=k)$ 当 $D$ 很大时数值极小，容易下溢为 0。取对数后求和不会下溢，且单调性不变——最大值对应的类别不变。
题 2 · 从贝叶斯定理推二分类后验的 sigmoid 形式 L1 · 基础
对二分类问题，证明后验可以写成 $p(C_1\mid\mathbf{x}) = \sigma(a)$ 的形式，其中 $a = \log\frac{p(\mathbf{x}\mid C_1)p(C_1)}{p(\mathbf{x}\mid C_0)p(C_0)}$。 写出 $\sigma(a)$ 的表达式，并说明 $a$ 的物理意义。
提示
$p(C_1\mid\mathbf{x}) = \frac{p(\mathbf{x}\mid C_1)p(C_1)}{p(\mathbf{x}\mid C_1)p(C_1)+p(\mathbf{x}\mid C_0)p(C_0)}$。分子分母同除以分子，得到 $\frac{1}{1+\exp(-a)}$ 的形式。
解答
$p(C_1\mid\mathbf{x}) = \dfrac{p(\mathbf{x}\mid C_1)p(C_1)}{p(\mathbf{x}\mid C_1)p(C_1)+p(\mathbf{x}\mid C_0)p(C_0)}$
分子分母同除以 $p(\mathbf{x}\mid C_1)p(C_1)$：$= \dfrac{1}{1+\dfrac{p(\mathbf{x}\mid C_0)p(C_0)}{p(\mathbf{x}\mid C_1)p(C_1)}}$
令 $a = \log\frac{p(\mathbf{x}\mid C_1)p(C_1)}{p(\mathbf{x}\mid C_0)p(C_0)}$，则 $\frac{p(\mathbf{x}\mid C_0)p(C_0)}{p(\mathbf{x}\mid C_1)p(C_1)} = e^{-a}$。
$\therefore p(C_1\mid\mathbf{x}) = \dfrac{1}{1+e^{-a}} = \sigma(a)$，其中 $\sigma(a)=\frac{1}{1+e^{-a}}$ 是 sigmoid 函数。
$a$ 的物理意义：$a = \log\frac{p(C_1\mid\mathbf{x})}{p(C_0\mid\mathbf{x})}$ 是后验 log-odds（对数几率）。$a>0$ 时 $p(C_1\mid\mathbf{x})>0.5$，预测为类别 1；$a<0$ 时预测为类别 0。决策边界在 $a=0$ 处。
题 3 · LDA 的后验推导 L2 · 理解
LDA 假设 $p(\mathbf{x}\mid C_k)=\mathcal{N}(\mathbf{x}\mid\boldsymbol{\mu}_k,\boldsymbol{\Sigma})$，$k=0,1$。从题 2 的 $a$ 出发，证明 $a = \mathbf{w}^\top\mathbf{x}+w_0$，并写出 $\mathbf{w}$ 和 $w_0$ 的表达式。
提示
代入高斯密度 $\mathcal{N}(\mathbf{x}\mid\boldsymbol{\mu},\boldsymbol{\Sigma}) = \frac{1}{(2\pi)^{D/2}|\boldsymbol{\Sigma}|^{1/2}}\exp\big(-\frac{1}{2}(\mathbf{x}-\boldsymbol{\mu})^\top\boldsymbol{\Sigma}^{-1}(\mathbf{x}-\boldsymbol{\mu})\big)$。归一化常数抵消。展开二次型时注意 $\mathbf{x}^\top\boldsymbol{\Sigma}^{-1}\boldsymbol{\mu} = \boldsymbol{\mu}^\top\boldsymbol{\Sigma}^{-1}\mathbf{x}$。
解答
$a = \log\frac{p(\mathbf{x}\mid C_1)}{p(\mathbf{x}\mid C_0)} + \log\frac{\pi}{1-\pi}$
代入高斯密度，归一化常数 $(2\pi)^{-D/2}|\boldsymbol{\Sigma}|^{-1/2}$ 在比中抵消：
$\log\frac{p(\mathbf{x}\mid C_1)}{p(\mathbf{x}\mid C_0)} = -\frac{1}{2}(\mathbf{x}-\boldsymbol{\mu}_1)^\top\boldsymbol{\Sigma}^{-1}(\mathbf{x}-\boldsymbol{\mu}_1) + \frac{1}{2}(\mathbf{x}-\boldsymbol{\mu}_0)^\top\boldsymbol{\Sigma}^{-1}(\mathbf{x}-\boldsymbol{\mu}_0)$
展开：$= -\frac{1}{2}(\mathbf{x}^\top\boldsymbol{\Sigma}^{-1}\mathbf{x} - 2\boldsymbol{\mu}_1^\top\boldsymbol{\Sigma}^{-1}\mathbf{x} + \boldsymbol{\mu}_1^\top\boldsymbol{\Sigma}^{-1}\boldsymbol{\mu}_1) + \frac{1}{2}(\mathbf{x}^\top\boldsymbol{\Sigma}^{-1}\mathbf{x} - 2\boldsymbol{\mu}_0^\top\boldsymbol{\Sigma}^{-1}\mathbf{x} + \boldsymbol{\mu}_0^\top\boldsymbol{\Sigma}^{-1}\boldsymbol{\mu}_0)$
$\mathbf{x}^\top\boldsymbol{\Sigma}^{-1}\mathbf{x}$ 项抵消：$= \boldsymbol{\mu}_1^\top\boldsymbol{\Sigma}^{-1}\mathbf{x} - \boldsymbol{\mu}_0^\top\boldsymbol{\Sigma}^{-1}\mathbf{x} - \frac{1}{2}\boldsymbol{\mu}_1^\top\boldsymbol{\Sigma}^{-1}\boldsymbol{\mu}_1 + \frac{1}{2}\boldsymbol{\mu}_0^\top\boldsymbol{\Sigma}^{-1}\boldsymbol{\mu}_0$
$= \mathbf{x}^\top\boldsymbol{\Sigma}^{-1}(\boldsymbol{\mu}_1-\boldsymbol{\mu}_0) - \frac{1}{2}(\boldsymbol{\mu}_1+\boldsymbol{\mu}_0)^\top\boldsymbol{\Sigma}^{-1}(\boldsymbol{\mu}_1-\boldsymbol{\mu}_0)$
加上先验比：$a = \underbrace{\boldsymbol{\Sigma}^{-1}(\boldsymbol{\mu}_1-\boldsymbol{\mu}_0)}_{\mathbf{w}}^\top\mathbf{x} \;+\; \underbrace{-\frac{1}{2}(\boldsymbol{\mu}_1+\boldsymbol{\mu}_0)^\top\boldsymbol{\Sigma}^{-1}(\boldsymbol{\mu}_1-\boldsymbol{\mu}_0) + \log\frac{\pi}{1-\pi}}_{w_0}$
所以 $\mathbf{w} = \boldsymbol{\Sigma}^{-1}(\boldsymbol{\mu}_1-\boldsymbol{\mu}_0)$，$w_0 = -\frac{1}{2}(\boldsymbol{\mu}_1+\boldsymbol{\mu}_0)^\top\boldsymbol{\Sigma}^{-1}(\boldsymbol{\mu}_1-\boldsymbol{\mu}_0) + \log\frac{\pi}{1-\pi}$。
题 4 · 协方差不共享时决策边界变成二次 L2 · 理解
如果每个类有自己的协方差矩阵 $p(\mathbf{x}\mid C_k)=\mathcal{N}(\mathbf{x}\mid\boldsymbol{\mu}_k,\boldsymbol{\Sigma}_k)$，证明后验 log-odds $a$ 包含 $\mathbf{x}$ 的二次项，即决策边界是二次的。写出 $\mathbf{x}^\top\mathbf{A}\mathbf{x}$ 项中 $\mathbf{A}$ 的表达式。
提示
展开 $\log p(\mathbf{x}\mid C_1) - \log p(\mathbf{x}\mid C_0)$，$\mathbf{x}^\top\boldsymbol{\Sigma}_1^{-1}\mathbf{x}$ 和 $\mathbf{x}^\top\boldsymbol{\Sigma}_0^{-1}\mathbf{x}$ 不会抵消，除非 $\boldsymbol{\Sigma}_1=\boldsymbol{\Sigma}_0$。
解答
$\log p(\mathbf{x}\mid C_k) = -\frac{1}{2}(\mathbf{x}-\boldsymbol{\mu}_k)^\top\boldsymbol{\Sigma}_k^{-1}(\mathbf{x}-\boldsymbol{\mu}_k) - \frac{1}{2}\log|\boldsymbol{\Sigma}_k| + \text{const}$
展开二次型：$(\mathbf{x}-\boldsymbol{\mu}_k)^\top\boldsymbol{\Sigma}_k^{-1}(\mathbf{x}-\boldsymbol{\mu}_k) = \mathbf{x}^\top\boldsymbol{\Sigma}_k^{-1}\mathbf{x} - 2\boldsymbol{\mu}_k^\top\boldsymbol{\Sigma}_k^{-1}\mathbf{x} + \boldsymbol{\mu}_k^\top\boldsymbol{\Sigma}_k^{-1}\boldsymbol{\mu}_k$
$a = \log\frac{p(\mathbf{x}\mid C_1)}{p(\mathbf{x}\mid C_0)} + \log\frac{\pi}{1-\pi}$
$= -\frac{1}{2}\mathbf{x}^\top(\boldsymbol{\Sigma}_1^{-1}-\boldsymbol{\Sigma}_0^{-1})\mathbf{x} + \mathbf{x}^\top(\boldsymbol{\Sigma}_1^{-1}\boldsymbol{\mu}_1-\boldsymbol{\Sigma}_0^{-1}\boldsymbol{\mu}_0) + \text{常数项}$
其中二次项系数矩阵 $\mathbf{A} = -\frac{1}{2}(\boldsymbol{\Sigma}_1^{-1}-\boldsymbol{\Sigma}_0^{-1})$。
当 $\boldsymbol{\Sigma}_1 \neq \boldsymbol{\Sigma}_0$ 时 $\mathbf{A}\neq\mathbf{0}$，决策边界 $a=0$ 是 $\mathbf{x}$ 的二次方程——即二次判别分析（QDA）。
当 $\boldsymbol{\Sigma}_1=\boldsymbol{\Sigma}_0=\boldsymbol{\Sigma}$ 时 $\mathbf{A}=\mathbf{0}$，二次项消失，退化为 LDA 的线性边界。
所以 LDA vs QDA 的选择 = 协方差是否共享的假设。共享协方差时参数更少（$O(D^2)$ vs $O(KD^2)$），方差更小但可能有偏。
题 5 · LDA 的 $\mathbf{w}$ 方向与 Fisher 判别方向 L3 · 进阶
Fisher 线性判别寻找投影方向 $\mathbf{w}$ 最大化 $\dfrac{(\mathbf{w}^\top(\boldsymbol{\mu}_1-\boldsymbol{\mu}_0))^2}{\mathbf{w}^\top\mathbf{S}_W\mathbf{w}}$，其中 $\mathbf{S}_W$ 是类内散度矩阵（within-class scatter matrix）。 证明：当数据来自共享协方差的高斯时，Fisher 判别的最优方向 $\mathbf{w}^*$ 与 LDA 的 $\mathbf{w}$ 方向相同（差一个标量因子）。
提示
对 Fisher 目标函数 $J(\mathbf{w}) = \frac{(\mathbf{w}^\top\mathbf{S}_B\mathbf{w})}{(\mathbf{w}^\top\mathbf{S}_W\mathbf{w})}$ 求导令为零，其中 $\mathbf{S}_B = (\boldsymbol{\mu}_1-\boldsymbol{\mu}_0)(\boldsymbol{\mu}_1-\boldsymbol{\mu}_0)^\top$。对共享协方差的高斯，$\mathbf{S}_W \propto \boldsymbol{\Sigma}$。
解答
Fisher 目标：$J(\mathbf{w}) = \dfrac{\mathbf{w}^\top\mathbf{S}_B\mathbf{w}}{\mathbf{w}^\top\mathbf{S}_W\mathbf{w}}$，其中 $\mathbf{S}_B = (\boldsymbol{\mu}_1-\boldsymbol{\mu}_0)(\boldsymbol{\mu}_1-\boldsymbol{\mu}_0)^\top$，$\mathbf{S}_W = \sum_{k}\sum_{n\in C_k}(\mathbf{x}_n-\boldsymbol{\mu}_k)(\mathbf{x}_n-\boldsymbol{\mu}_k)^\top$。
对 $\mathbf{w}$ 求导令为零：$\nabla J = \frac{2\mathbf{S}_B\mathbf{w}}{\mathbf{w}^\top\mathbf{S}_W\mathbf{w}} - \frac{2(\mathbf{w}^\top\mathbf{S}_B\mathbf{w})\mathbf{S}_W\mathbf{w}}{(\mathbf{w}^\top\mathbf{S}_W\mathbf{w})^2} = \mathbf{0}$。
两边同乘 $\mathbf{w}^\top\mathbf{S}_W\mathbf{w}$：$\mathbf{S}_B\mathbf{w} - \frac{\mathbf{w}^\top\mathbf{S}_B\mathbf{w}}{\mathbf{w}^\top\mathbf{S}_W\mathbf{w}}\mathbf{S}_W\mathbf{w} = \mathbf{0}$。
记 $\lambda = \frac{\mathbf{w}^\top\mathbf{S}_B\mathbf{w}}{\mathbf{w}^\top\mathbf{S}_W\mathbf{w}}$（即 $J(\mathbf{w})$ 本身），得 $\mathbf{S}_B\mathbf{w} = \lambda\mathbf{S}_W\mathbf{w}$——广义特征值问题。
代入 $\mathbf{S}_B = (\boldsymbol{\mu}_1-\boldsymbol{\mu}_0)(\boldsymbol{\mu}_1-\boldsymbol{\mu}_0)^\top$：$(\boldsymbol{\mu}_1-\boldsymbol{\mu}_0)(\boldsymbol{\mu}_1-\boldsymbol{\mu}_0)^\top\mathbf{w} = \lambda\mathbf{S}_W\mathbf{w}$。
左边 $(\boldsymbol{\mu}_1-\boldsymbol{\mu}_0)^\top\mathbf{w}$ 是标量，记作 $c$，则 $c(\boldsymbol{\mu}_1-\boldsymbol{\mu}_0) = \lambda\mathbf{S}_W\mathbf{w}$。
$\therefore \mathbf{w} \propto \mathbf{S}_W^{-1}(\boldsymbol{\mu}_1-\boldsymbol{\mu}_0)$。
当数据来自共享协方差的高斯时，$\mathbf{S}_W \propto \boldsymbol{\Sigma}$（类内散度矩阵正比于协方差矩阵），所以 $\mathbf{w} \propto \boldsymbol{\Sigma}^{-1}(\boldsymbol{\mu}_1-\boldsymbol{\mu}_0)$——正是 LDA 的 $\mathbf{w}$ 方向。
结论：LDA 和 Fisher 判别在投影方向上等价。区别在于 LDA 还给出了概率输出（sigmoid 后验）和决策阈值，而 Fisher 判别只给出投影方向。
题 6 · 样本效率的直觉论证 L3 · 进阶
生成模型拟合 $p(\mathbf{x}\mid y)$ 用了全部 $\mathbf{x}$ 的信息（包括类内结构），判别模型只拟合 $p(y\mid\mathbf{x})$（只关心边界附近的信息）。 直觉上，数据少时生成模型的方差更小。请：
  1. 给出一个简单的实验设计来验证这个论断（用什么数据、什么模型、什么度量）。
  2. 用方差分解的直觉解释为什么生成模型在少样本下方差更小。
  3. 说明什么时候这个优势会消失甚至反转。
提示
考虑 Ng & Jordan (2002) 的实验：在 UCI 数据集上比较朴素贝叶斯和逻辑回归，画学习曲线（error vs 训练集大小）。生成模型的方差来自 $p(\mathbf{x}\mid y)$ 和 $p(y)$ 的估计误差；判别模型的方差来自条件似然的估计误差——后者在边界附近样本稀疏时更大。
解答
(1) 实验设计：
数据：从两个共享协方差的高斯分布采样（LDA 假设正确），$D=2$，$\boldsymbol{\mu}_1=[1,1]^\top$，$\boldsymbol{\mu}_0=[-1,-1]^\top$，$\boldsymbol{\Sigma}=\mathbf{I}$。
模型：LDA（生成）vs 逻辑回归（判别）。
度量：在大量测试集上的分类错误率。对不同的训练集大小 $N=\{10,20,50,100,200,500\}$，每个 $N$ 重复 100 次随机实验，画平均错误率 $\pm 1$ 标准差的学习曲线。
预期：$N$ 小时 LDA 的错误率更低且方差更小；$N$ 大时两者趋近相同错误率（贝叶斯错误率）。
(2) 方差分解直觉：
生成模型估计的参数是 $\boldsymbol{\mu}_0,\boldsymbol{\mu}_1,\boldsymbol{\Sigma},\pi$——每个参数利用了所有样本的信息（$\boldsymbol{\mu}_k$ 用 $N_k$ 个样本，$\boldsymbol{\Sigma}$ 用全部 $N$ 个样本）。
判别模型（逻辑回归）估计 $\mathbf{w}$——它只通过条件似然间接利用样本信息，且主要受边界附近的样本影响。远离边界的样本对 $\mathbf{w}$ 的贡献很小（sigmoid 饱和区梯度接近 0）。
所以对同样数量的样本，生成模型等效地用了更多"有效信息"来估计决策边界——参数估计的方差更小。
(3) 优势消失/反转的条件：
当生成模型的假设（如高斯共享协方差）被严重违反时，它的偏误（bias）会很大——此时即使方差小，总误差也可能大于判别模型。例如数据来自多模态分布时高斯假设错误，LDA 的决策边界可能严重偏离最优边界，而逻辑回归（只要边界仍是线性的）不受影响。
数据量很大时，判别模型的方差也变小，而生成模型的偏误固定——所以大样本下判别模型通常更好。
总结：少样本 + 假设正确 → 生成模型胜；多样本或假设错误 → 判别模型胜。

7. 自测

Q1 · 生成模型和判别模型的根本区别是什么？

根本区别在于建模的对象：生成模型建模联合分布 $p(\mathbf{x},y)$（或等价地 $p(\mathbf{x}\mid y)$ 和 $p(y)$），判别模型直接建模条件分布 $p(y\mid\mathbf{x})$。生成模型通过贝叶斯定理得到后验，判别模型直接拟合后验。

Q2 · 朴素贝叶斯的"朴素"假设是什么？

朴素贝叶斯的假设是条件独立：$p(\mathbf{x}\mid y)=\prod_{i=1}^D p(x_i\mid y)$。这个假设几乎从不为真，但分类性能往往不错——因为分类只关心 $\arg\max$ 的排序正确，不要求概率估计准确。

Q3 · LDA 假设类条件分布为高斯且共享协方差，由此推出的决策边界是什么形状？

共享协方差时，二次型展开中 $\mathbf{x}^\top\boldsymbol{\Sigma}^{-1}\mathbf{x}$ 项在两类间抵消，只剩线性项 $\mathbf{x}^\top\boldsymbol{\Sigma}^{-1}(\boldsymbol{\mu}_1-\boldsymbol{\mu}_0)$。所以后验 log-odds 是 $\mathbf{x}$ 的线性函数，决策边界 $a=0$ 是超平面。如果协方差不共享，二次项保留，决策边界变成二次的（QDA）。

Q4 · 以下哪个是生成模型相对于判别模型的优势？

生成模型有 $p(\mathbf{x})$ 的结构，可以对缺失特征积分（marginalize）来自然处理缺失值。判别模型没有 $p(\mathbf{x})$，需要额外插补。A 和 B 是判别模型的优势。D 是错的——生成模型正是通过贝叶斯定理把 $p(\mathbf{x}\mid y)p(y)$ 转成 $p(y\mid\mathbf{x})$。
