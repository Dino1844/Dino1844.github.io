# 计算机网络 Resources

## Knowledge

- [Book: _Computer Networking: A Top-Down Approach_ (8th Edition) — Kurose & Ross](https://gaia.cs.umass.edu/kurose_ross/index.html)
  计算机网络领域的经典教材。自顶向下的叙事方式（应用层→传输层→网络层→链路层）天然适合问题驱动的学习路线。作者在网站上提供了配套的 lecture videos、Wireshark labs 和互动练习。Use for: 构建主干知识体系，所有核心概念的第一参考源。

- [Book: _TCP/IP Illustrated, Volume 1: The Protocols_ (2nd Edition) — Kevin Fall & Richard Stevens](https://www.informit.com/store/tcp-ip-illustrated-volume-1-the-protocols-9780321336316)
  TCP/IP 协议族的权威参考，深入到包格式和工作机制。Use for: 需要精确理解协议行为时查阅，不适合初学时通读。

- [Online: _Beej's Guide to Network Programming_ — Brian "Beej" Hall](https://beej.us/guide/bgnet/)
  用 C 语言讲解 socket 编程，但前几章对 TCP/UDP 概念的讲解非常清晰易懂。Use for: 通过代码视角理解传输层协议的行为。

- [Online: _High Performance Browser Networking_ — Ilya Grigorik](https://hpbn.co/)
  从浏览器和 Web 性能的角度讲网络，涵盖 TCP、TLS、HTTP/2、WebRTC 等。免费在线版。Use for: 理解网络协议对应用性能的影响，连接理论与工程实践。

## Wisdom (Communities)

- [r/networking](https://reddit.com/r/networking)
  企业网络从业者社区，信号质量较高。Use for: 实际网络架构问题、协议行为讨论。

- [Network Engineering Stack Exchange](https://networkengineering.stackexchange.com/)
  网络工程的 Stack Exchange 站点。Use for: 具体技术问题的解答，比 Reddit 更严谨。
