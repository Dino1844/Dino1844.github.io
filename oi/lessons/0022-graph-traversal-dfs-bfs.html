1. 图的表示：邻接矩阵 vs 邻接表

在做任何图算法之前，先决定「图怎么存」。两种标准方案：

邻接矩阵邻接表
存储vector<vector<int>> g(n, vector<int>(n))vector<vector<int>> g(n)
查边 O(1)✅ g[u][v]❌ 需遍历 g[u]
空间O(V²) — 稀疏图完全浪费O(V+E) — 稀疏图优选
遍历邻居O(V) — 必须扫全行O(deg(u)) — 只扫连出去的
适用稠密图（如 Floyd 算法）95% 的面试题
面试默认选择：邻接表。大多数 Hot 100 图题的图是稀疏图（V ~ 10⁴, E ~ 10⁴–10⁵），邻接矩阵的 O(V²) 空间直接爆内存。
C++ 模板：vector<vector<int>> g(n); 然后 g[u].push_back(v);

2. DFS 模板：递归地深入探索

DFS（Depth-First Search）的核心是「一条路走到黑，走不动了再回头」。用递归站（系统调用栈）天然匹配。

// 通用 DFS 模板（无向图，防重复访问）
int n;
vector<vector<int>> g;    // 邻接表
vector<bool> vis;            // visited 标记

void dfs(int u) {
    vis[u] = true;
    // 处理节点 u
    for (int v : g[u]) {
        if (!vis[v]) dfs(v);
    }
}

// 全图遍历——处理不连通图
for (int i = 0; i < n; i++)
    if (!vis[i]) dfs(i);  // 每个连通分量触发一次 dfs
关键教训：DFS 的「递归深度」= 图的最长路径长度。如果 V=10⁵ 且图是一条链，递归深度 10⁵ → 栈溢出。
面试中如果图很大，有两种选择：(1) 显式用 stack 模拟递归（手写栈），(2) 换 BFS（队列天然无递归风险）。

3. BFS 模板：队列的层序扩散

BFS（Breadth-First Search）的核心是「按层推进，先看到的先处理」。天然用队列实现，第一次到达某节点 = 从起点到该节点的最短路径（无权图）。

// 通用 BFS 模板（从 start 出发）
int bfs(int start, int target) {
    queue<int> q;
    vector<int> dist(n, -1);   // -1 = 未访问

    dist[start] = 0;
    q.push(start);

    while (!q.empty()) {
        int u = q.front(); q.pop();
        if (u == target) return dist[u];
        for (int v : g[u]) {
            if (dist[v] == -1) {
                dist[v] = dist[u] + 1;
                q.push(v);
            }
        }
    }
    return -1;  // 不可达
}

✅ BFS 的正确性证明（三段式）

① 不变式（Invariant）：队列中的节点按 dist 从小到大排列，且同一层的节点连续出队。

② 初始化：队列只有 start，dist[start]=0，不变式成立。

③ 保持：从 u 出队，它的邻居 v 第一次入队时 dist[v] = dist[u]+1。由于 dist[u] 是队列当前最小且队列有序，dist[v] 一定 ≥ 所有已在队列中的 dist——入队后队列仍然有序。
⟹ 第一次遇到 target 时 dist[target] 一定是最短距离。

4. 连通分量问题：DFS 染色法

连通分量 = 图中「彼此可达」的最大节点集合。核心操作：DFS/BFS 遍历一次就给一个连通分量「染色」（标记为同一 id）。

// 连通分量计数（染色法）
vector<int> color(n, -1);
int comp_cnt = 0;

for (int i = 0; i < n; i++) {
    if (color[i] == -1) {
        dfs(i, comp_cnt);   // 给整个连通分量染上 comp_cnt
        comp_cnt++;
    }
}
// comp_cnt = 连通分量个数
// color[u] = u 所属的连通分量编号

染色法就是「岛屿数量」这类问题的理论基础——网格图中的相邻关系就是隐性图，DFS/BFS 扫一遍数出连通块数量。

5. 题 1：岛屿数量 — 网格图的 DFS/BFS

LeetCode 200 · 难度：🟡 中等

'1'（陆地）和 '0'（水）组成的网格，求岛屿数量（上下左右相连的 1 算一个岛屿）。这不是传统邻接表图——但每个格子可以想象成节点，上下左右四个方向是它的边。

// DFS 解法（网格图，用方向数组）
const int dirs[4][2] = {{-1,0},{1,0},{0,-1},{0,1}};

void dfs(vector<vector<char>>& g, int r, int c) {
    int m = g.size(), n = g[0].size();
    g[r][c] = '0';   // 沉没——原地标记
    for (auto& d : dirs) {
        int nr = r + d[0], nc = c + d[1];
        if (nr >= 0 && nr < m && nc >= 0 && nc < n
            && g[nr][nc] == '1')
            dfs(g, nr, nc);
    }
}

int numIslands(vector<vector<char>>& g) {
    int cnt = 0;
    for (int r = 0; r < g.size(); r++)
        for (int c = 0; c < g[0].size(); c++)
            if (g[r][c] == '1') { cnt++; dfs(g, r, c); }
    return cnt;
}
技巧「沉没法」：DFS 访问过的 '1' 直接改成 '0'，省掉了 visited 数组。但修改了原输入——如果面试官不允许，就用 visited 二维数组替代。

6. 题 2：被围绕的区域 — 边界连通性

LeetCode 130 · 难度：🟡 中等

给定矩阵，把被 'X' 包围的 'O' 全变成 'X'。关键洞察：边界上的 'O' 永远不会被包围，和边界连通的 'O' 也是。

逆向思维：不直接找「被包围的 'O'」——不好找。改为找「没被包围的 'O'」（边界连通），剩下的就是被包围的。 
void solve(vector<vector<char>>& board) {
    int m = board.size(), n = board[0].size();
    auto dfs = [&](auto&& self, int r, int c) -> void {
        if (r < 0 || r >= m || c < 0 || c >= n || board[r][c] != 'O')
            return;
        board[r][c] = '#';  // 标记为「边界连通」
        for (auto& d : dirs)
            self(self, r + d[0], c + d[1]);
    };
    // 从四条边的 'O' 开始 DFS
    for (int i = 0; i < m; i++) {
        dfs(dfs, i, 0);
        dfs(dfs, i, n-1);
    }
    for (int j = 0; j < n; j++) {
        dfs(dfs, 0, j);
        dfs(dfs, m-1, j);
    }
    // 最后遍历：'#' → 'O',  'O' → 'X'
    for (int i = 0; i < m; i++)
        for (int j = 0; j < n; j++)
            board[i][j] = (board[i][j] == '#') ? 'O' : 'X';
}
「逆向思维」是图连通性问题的核心技巧。正着找「被包围的」很难，反着找「没被包围的」容易。
同模式题目：太平洋大西洋水流问题（LeetCode 417）——从四条边界分别 DFS，取交集。

7. 题 3：克隆图 — 图的深拷贝

LeetCode 133 · 难度：🟡 中等

给定一个无向连通图的引用，返回它的深拷贝（全新节点，边和原图相同）。

// DFS + 哈希映射：old_node → new_node
unordered_map<Node*, Node*> visited;

Node* cloneGraph(Node* node) {
    if (!node) return nullptr;
    if (visited.count(node))
        return visited[node];   // 已经复制过了，直接返回
    Node* clone = new Node(node->val);
    visited[node] = clone;
    for (Node* neighbor : node->neighbors)
        clone->neighbors.push_back(cloneGraph(neighbor));
    return clone;
}
为什么不用 BFS？DFS 和 BFS 都可以。DFS 更简洁——天然递归地处理每个邻居的复制。BFS 需要手动管理队列，语义上没优势。但是无向图要注意：不要在 visited 检查前递归，否则死循环（又回到自己）。

8. Trie（前缀树）：字符串高效查找

Trie 不是图，但它本质上是一棵多叉树，遍历思路和 DFS 完全一致。Trie 的核心优势：在 O(L) 时间内完成前缀匹配（L = 字符串长度），不受数据集大小影响。

struct TrieNode {
    TrieNode* next[26];   // 26 个小写字母
    bool isEnd;            // 到此是否是一个完整单词
    TrieNode() : isEnd(false) {
        fill(next, next + 26, nullptr);
    }
};

class Trie {
    TrieNode* root;
public:
    Trie() { root = new TrieNode(); }

    void insert(string word) {
        TrieNode* p = root;
        for (char c : word) {
            int i = c - 'a';
            if (!p->next[i]) p->next[i] = new TrieNode();
            p = p->next[i];
        }
        p->isEnd = true;
    }

    bool search(string word) {       // 精确查找
        TrieNode* p = root;
        for (char c : word) {
            p = p->next[c - 'a'];
            if (!p) return false;
        }
        return p->isEnd;
    }

    bool startsWith(string prefix) {  // 前缀查询
        TrieNode* p = root;
        for (char c : prefix) {
            p = p->next[c - 'a'];
            if (!p) return false;
        }
        return true;
    }
};
操作Trie哈希表
精确查找O(L)O(L) 平均
前缀查询O(L)❌ 必须遍历全部 key
空间可能有大量节点（26×深度）紧凑

Trie 的最大优势是前缀查询——哈希表做不到。而 0023 的「单词搜索 II」用 Trie 剪枝，正是利用了这个性质。

9. 题 4：单词搜索 II — Trie + 回溯剪枝

LeetCode 212 · 难度：🔴 困难

在字母矩阵中找所有出现的单词（相邻格连接）。如果每个单词都独立 DFS 一次——超时。用 Trie 存储单词列表，在 DFS 过程中同步遍历 Trie——当前缀不在 Trie 中时立刻剪枝。

// Trie + DFS 回溯的经典组合
vector<string> findWords(vector<vector<char>>& board,
                           vector<string>& words) {
    Trie trie;
    for (auto& w : words) trie.insert(w);

    int m = board.size(), n = board[0].size();
    vector<string> res;
    string cur;

    function<void(int,int,TrieNode*)> dfs =
        [&](int r, int c, TrieNode* p) {
        if (!p) return;
        if (p->isEnd) {
            res.push_back(cur);
            p->isEnd = false;  // 去重
        }
        if (r < 0 || r >= m || c < 0 || c >= n) return;
        char ch = board[r][c];
        if (ch == '#') return;

        TrieNode* nxt = p->next[ch - 'a'];
        if (!nxt) return;   // ⚡ 剪枝：前缀都不存在，不用继续

        board[r][c] = '#';  // 标记访问
        cur.push_back(ch);
        dfs(r-1,c, nxt); dfs(r+1,c, nxt);
        dfs(r,c-1, nxt); dfs(r,c+1, nxt);
        cur.pop_back();
        board[r][c] = ch;
    };

    for (int r = 0; r < m; r++)
        for (int c = 0; c < n; c++)
            dfs(r, c, trie.getRoot());
    return res;
}
复杂度分析：如果没有 Trie 剪枝，每个单词独立 DFS = O(K × 3ᴸ)。用了 Trie 后，一次 DFS 同时检查所有单词，在矩阵上只走一遍，最坏 O(M×N×3ᴸ) 但剪枝后远小于此。
空间：Trie O(总字符数)，递归栈 O(L)。

10. DFS vs BFS 选择决策

场景选 DFS选 BFS
求连通分量个数✅ 代码最简洁也可，代码略长
求最短路径（无权图）❌ 需要遍历全部路径✅ 第一次遇到即最短
拓扑排序✅ 后序遍历 + 逆序✅ Kahn 算法（BFS 版）
图很大（V > 10⁴ 且链状）❌ 栈溢出风险✅ 队列安全
回溯/排列组合（0022 先行课）✅ 天然匹配❌ 状态不好保存
按层输出（如层序遍历）❌ 需要额外 depth 参数✅ 天然按层
面试中通用的选择铁律：
• 只问「是否连通」→ DFS（代码最短）
• 问「最短距离/最少步数」→ BFS（第一次遇到即最优）
• 问「所有路径/具体路径」→ DFS/回溯（需要枚举时不能用 BFS，因为 BFS 的状态空间爆炸）
