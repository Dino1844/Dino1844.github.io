## 课程路线图（2026-06-19 确立）

骨架跟随 OSTEP（虚拟化·并发·持久化三卷），xv6 补实现视角，CSAPP 补系统编程视角。
每课仍是"一条逻辑链"——讲因果，不堆引用。
闭环设计：旧概念在新语境复现（0003 页表回接 0001 间接层，0009 系统调用追踪串起全部概念）。

### 0001 · OS 作为虚拟机器（Hub，公理集）
三条幻象（CPU/内存/I/O 虚拟化）、机制/策略分离、保护模型（用户态/内核态）、并发挑战、六大设计范式预览。
**本课是全书基石，后续每课从本课的不同公理展开。**

### 0002 · 进程与 CPU 调度
PCB → 进程状态机 → 上下文切换 → 调度指标 → 调度算法演进链（FIFO → SJF → STCF → RR → MLFQ → CFS）

### 0003 · 虚拟内存（上）：地址翻译与分页
基址-界限 → 分段 → 分页（页表、PTE 每 bit、TLB、多级页表、大页）

### 0004 · 虚拟内存（下）：页替换与完整系统
缺页中断 → 页替换算法（最优/FIFO/LRU/时钟）→ Belady 异常 → 抖动/工作集 → 按需调页 → COW → swap → mmap

### 0005 · 并发（上）：线程·锁·信号量
线程 vs 进程 → 竞态条件 → 临界区 → 互斥 → 锁实现链（关中断 → TAS → 自旋锁 → mutex）→ CAS → 信号量 → PV 问题

### 0006 · 并发（下）：管程·死锁·无锁
管程 + 条件变量 → Mesa/Hoare 语义 → 死锁四条件 → 预防/避免/检测/恢复 → 银行家算法 → 活锁/饥饿 → 无锁（CAS 栈）→ RCU

### 0007 · 文件系统：inode → 日志 → COW
inode（身份证）→ 多级索引 → 目录 = 名字到 inode 的映射 → 硬链接/软链接 → FFS → 崩溃一致性问题 → 日志（journaling）→ 写时复制（ZFS/Btrfs）

### 0008 · I/O 子系统与存储层次
中断 vs 轮询 vs DMA → 设备驱动模型 → I/O 调度 → 存储层次速度递降 → RAID 0/1/4/5/6 → RAID 5 write hole

### 0009 · 虚拟机·容器·安全·Linux 深潜
Hypervisor（type-1/2）→ trap-and-emulate → 硬件辅助虚拟化 → 容器 = namespaces + cgroups → 微内核 vs 宏内核 → OS 安全攻防链 → `task_struct`/`mm_struct`/VFS 全景 → 一次 `read()` 完整追踪 → xv6 速览
