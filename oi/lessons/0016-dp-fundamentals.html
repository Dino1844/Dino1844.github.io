1. DP 是什么：把大问题拆成子问题，并记住答案

回忆 Lesson 0000 中的斐波那契：朴素递归 O(2ⁿ) → 记忆化 O(n)。那次优化的核心是同一个子问题被重复求解。DP（动态规划）就是这个思想的系统化。

DP 的本质定义：一个问题能用 DP 求解，当且仅当它具有两个性质：
① 最优子结构（Optimal Substructure）：原问题的最优解可以由子问题的最优解组合而成。
② 重叠子问题（Overlapping Subproblems）：不同的递归路径会反复求解相同的子问题。

对比分治：分治也用「拆分→合并」，但分治的子问题不重叠（如归并排序的左右两半互不相交），所以不需要记忆化。DP 的精髓在于识别重叠并存储。

一个直觉例子

从 (0,0) 走到 (m,n) 的路径数。从 (i,j) 出发，可以向下或向右走一步：

paths(i, j) = paths(i+1, j) + paths(i, j+1)

注意 paths(2, 3) 会被 paths(1,3) 和 paths(2,2) 同时调用——重叠了。朴素递归会重复算，DP 把它存起来。

2. DP 的三要素：状态、转移、边界

任何 DP 题都可以拆成三个部分。面试中按这个顺序思考，能避免 80% 的卡壳。

要素含义思考方式
状态 dp[...]子问题的参数化描述「问题的哪些维度会变化？」通常对应：位置 i、容量 j、阶段 k、选/不选
转移从已知子问题计算当前问题「最后一步做了什么决策？」枚举所有可能的最后一步
边界最小子问题的直接答案「问题退化到最小时答案是什么？」dp[0]=? dp[1]=?
🧠 状态定义的黄金法则：状态要满足两个条件——
1. 无后效性：未来的决策只依赖当前状态，不依赖「怎么到达当前状态的」
2. 完备性：所有可能的最优解都能被某个状态表示
如果发现状态不够用（无法表达关键信息），就需要增加维度。这是 DP 调试的核心思路。

3. 从递归到 DP：四步思维阶梯

1
暴力递归
直接翻译问题，先不管复杂度
2
记忆化搜索
加 memo 数组，自顶向下
3
自底向上递推
改写成循环，按依赖顺序填表
4
空间优化
滚动数组 / 滚动变量

面试中从第 1 步开始，逐步优化。这样即使最后写不出最优解，至少能拿到暴力分。下面用爬楼梯完整演示这四步。

4. 题 1：爬楼梯 — 最简单的 1D DP

LeetCode 70. Climbing Stairs（Hot 100）
你在爬 n 阶楼梯，每次可以爬 1 或 2 阶。有多少种不同的方法爬到顶？

4.1 第 1 步：暴力递归

状态定义：设 f(n) = 爬 n 阶楼梯的方法数。
转移：最后一步要么爬 1 阶（来自 f(n-1)），要么爬 2 阶（来自 f(n-2)）。
边界：f(0)=1（在地面，1 种「不动」的方法），f(1)=1。

int climbStairs(int n) {
    if (n <= 1) return 1;
    return climbStairs(n - 1) + climbStairs(n - 2);
}
// 复杂度：O(2ⁿ) — n=45 就跑不出来

4.2 第 2 步：记忆化搜索

int memo[46];  // 初始化为 -1
int climbStairs(int n) {
    if (n <= 1) return 1;
    if (memo[n] != -1) return memo[n];  // 已算过，直接返回
    return memo[n] = climbStairs(n - 1) + climbStairs(n - 2);
}
// 复杂度：O(n) 时间，O(n) 空间

4.3 第 3 步：自底向上递推

记忆化是「自顶向下」（从 f(n) 出发，按需计算子问题）。递推是「自底向上」（从 f(0) 开始，依次填表）。

int climbStairs(int n) {
    if (n <= 1) return 1;
    vector<int> dp(n + 1);
    dp[0] = 1; dp[1] = 1;          // 边界
    for (int i = 2; i <= n; i++)
        dp[i] = dp[i - 1] + dp[i - 2];  // 转移
    return dp[n];
}

4.4 第 4 步：空间优化

观察转移：dp[i] 只依赖 dp[i-1] 和 dp[i-2]。不需要整个数组，两个变量就够。

int climbStairs(int n) {
    if (n <= 1) return 1;
    int prev2 = 1, prev1 = 1;  // dp[0], dp[1]
    for (int i = 2; i <= n; i++) {
        int cur = prev1 + prev2;
        prev2 = prev1; prev1 = cur;
    }
    return prev1;
}
// 复杂度：O(n) 时间，O(1) 空间 ✅
四步法的价值：面试时即使紧张忘了最优解，按「暴力→记忆化→递推→优化」走，至少能拿到 O(n) 的解。这个思维链在所有 DP 题通用。

5. 题 2：打家劫舍 — 状态引入「选/不选」

LeetCode 198. House Robber（Hot 100）
沿街排列的房屋，每间有金额 nums[i]。不能偷相邻的两间。求能偷到的最大金额。
例：nums = [2,7,9,3,1] → 答案 12（偷第 0,2,4 间）

5.1 状态定义（关键一步）

爬楼梯的状态只有「位置 i」一个维度。打家劫舍需要表达「在位置 i，偷或不偷」这个决策。两种定义方式：

方式 A（一维，推荐）：dp[i] = 考虑前 i 间房能偷到的最大金额。
方式 B（二维，更通用）：dp[i][0/1] = 考虑前 i 间房，第 i 间偷(1)/不偷(0) 的最大金额。

5.2 方式 A：一维 DP

转移：对于第 i 间房，两种选择：
- 不偷：dp[i] = dp[i-1]（沿用前 i-1 间的最优）
- 偷：dp[i] = dp[i-2] + nums[i]（不能偷第 i-1 间，所以来自 i-2）

int rob(vector<int>& nums) {
    int n = nums.size();
    if (n == 1) return nums[0];
    vector<int> dp(n);
    dp[0] = nums[0];
    dp[1] = max(nums[0], nums[1]);
    for (int i = 2; i < n; i++)
        dp[i] = max(dp[i-1], dp[i-2] + nums[i]);
    return dp[n-1];
}

5.3 方式 B：二维 DP（更清晰的「选/不选」）

// dp[i][0] = 不偷第 i 间，前 i 间最大金额
// dp[i][1] = 偷第 i 间，前 i 间最大金额
int n = nums.size();
vector<array<int,2>> dp(n);
dp[0][0] = 0;        // 不偷第 0 间
dp[0][1] = nums[0];   // 偷第 0 间
for (int i = 1; i < n; i++) {
    dp[i][0] = max(dp[i-1][0], dp[i-1][1]);  // 不偷 i，i-1 随意
    dp[i][1] = dp[i-1][0] + nums[i];            // 偷 i，i-1 必须不偷
}
return max(dp[n-1][0], dp[n-1][1]);
🧠 何时用二维「选/不选」：当相邻元素有互斥约束（不能同时选）时，二维状态能清晰表达约束。打家劫舍 II（环形）、股票含冷冻期、股票含手续费都用这个模式。Lesson 0019 会深入。

5.4 正确性论证

📐 打家劫舍的最优子结构证明

设 OPT(i) 为前 i 间房的最优解。考虑第 i 间房在最优解中的状态：

  • 若最优解不偷第 i 间：则 OPT(i) = OPT(i-1)。因为前 i-1 间的选择不受影响，且必须是 OPT(i-1)（否则替换后更优）。
  • 若最优解偷第 i 间：则第 i-1 间必不偷，OPT(i) = OPT(i-2) + nums[i]。OPT(i-2) 必须是前 i-2 间的最优（同样的替换论证）。

因此 OPT(i) = max(OPT(i-1), OPT(i-2) + nums[i])。这就是转移方程的来源。

6. 题 3：不同路径 — 2D 网格 DP

LeetCode 62. Unique Paths（Hot 100）
m×n 网格，从左上角到右下角，每次只能向下或向右走一步。有多少条不同路径？

6.1 状态与转移

状态：dp[i][j] = 从 (0,0) 到 (i,j) 的路径数。
转移：到达 (i,j) 的最后一步要么从 (i-1,j) 向下，要么从 (i,j-1) 向右。
    dp[i][j] = dp[i-1][j] + dp[i][j-1]
边界：第一行和第一列都只有 1 条路径（一直向右 / 一直向下）。

int uniquePaths(int m, int n) {
    vector<vector<int>> dp(m, vector<int>(n, 1));  // 边界：第一行/列=1
    for (int i = 1; i < m; i++)
        for (int j = 1; j < n; j++)
            dp[i][j] = dp[i-1][j] + dp[i][j-1];
    return dp[m-1][n-1];
}

复杂度：O(mn) 时间和空间。空间可优化到 O(n)（滚动数组，见 §8）。

6.2 为什么这是 DP 而不是 BFS/DFS

这题也可以 DFS 枚举所有路径，但那是 O(2m+n) 指数级。DP 之所以 O(mn)，是因为路径数有递推结构——每个格子的路径数只依赖左、上两个格子，且这些子问题被反复使用（重叠）。这是 DP 与暴力搜索的根本区别。

7. 题 4：最小路径和 — DP 值不只是计数

LeetCode 64. Minimum Path Sum（Hot 100）
m×n 网格每格有非负数 grid[i][j]，从左上到右下，每次向下或向右，使路径上数字之和最小。

7.1 与 Unique Paths 的对比

结构完全一样（2D 网格、向右/向下转移），唯一区别：dp 值从「路径计数」变成「路径最小和」，转移从「相加」变成「取 min 后相加」。

int minPathSum(vector<vector<int>>& grid) {
    int m = grid.size(), n = grid[0].size();
    vector<vector<int>> dp(m, vector<int>(n));
    dp[0][0] = grid[0][0];
    for (int i = 1; i < m; i++) dp[i][0] = dp[i-1][0] + grid[i][0];  // 第一列
    for (int j = 1; j < n; j++) dp[0][j] = dp[0][j-1] + grid[0][j];  // 第一行
    for (int i = 1; i < m; i++)
        for (int j = 1; j < n; j++)
            dp[i][j] = min(dp[i-1][j], dp[i][j-1]) + grid[i][j];
    return dp[m-1][n-1];
}
DP 的统一视角：计数问题用 +，最优化问题用 min/max。本质都是对所有「最后一步」的选择做聚合。
- 计数：dp[i] = Σ dp[子问题]
- 最小化：dp[i] = min(dp[子问题] + cost)
- 最大化：dp[i] = max(dp[子问题] + cost)
- 存在性：dp[i] = ∃ dp[子问题]（用 bool 或位运算）

8. 空间优化：滚动数组

观察 2D DP 的转移：dp[i][j] 只依赖 dp[i-1][...] 和 dp[i][...]。也就是说，算第 i 行只需要第 i-1 行。整个二维表可以压成一维。

// 原始 2D：
dp[i][j] = dp[i-1][j] + dp[i][j-1];

// 滚动数组：用一维 dp[j] 表示「当前行的第 j 列」
// dp[j] 在更新前还存着上一行的值（即 dp[i-1][j]）
vector<int> dp(n, 1);
for (int i = 1; i < m; i++)
    for (int j = 1; j < n; j++)
        dp[j] = dp[j] + dp[j-1];  // dp[j](旧)=上, dp[j-1](新)=左
return dp[n-1];
// 空间：O(mn) → O(n) ✅
⚠️ 滚动数组的陷阱：必须保证更新 dp[j] 时，dp[j-1] 已经是本行的新值（即左邻居），而 dp[j] 还是上一行的旧值（即上邻居）。所以列循环必须从左到右。如果转移依赖右邻居，就要从右到左。方向搞错就全盘皆输。

9. DP 设计的常见陷阱

陷阱症状解法
状态维度不足转移写不出，或写出来不对增加维度（如打家劫舍加「选/不选」）
边界处理遗漏n=0 或 n=1 时崩溃/返回错值单独处理小规模，或显式初始化 dp[0]
循环顺序错误用到还没算的值按依赖关系拓扑序填表（被依赖的先算）
滚动数组方向错结果完全不对画图确认每个 dp[j] 更新时左右邻居的「新旧」
初始值用错（0 vs 1 vs ∞）计数少 1 / 最优化取到错值计数：空方案=1；最优化：不可达=∞，可达=实际值
🎯 面试 DP 题的 5 分钟思考流程：
1. 识别 DP：求最值/计数/存在性，且子问题重叠
2. 定义状态：哪些维度变化？先写一维，不够再加
3. 写转移：枚举「最后一步」的所有选择
4. 定边界：最小子问题直接给值
5. 确定循环顺序：按依赖拓扑序
然后再考虑空间优化。
