# Teaching Notes

## User Preferences
- 中文为主要教学语言
- 混合式学习：书籍阅读 + 大问题驱动 + 历史年表推进，灵活切换
- 弹性时间节奏，课程需支持暂停/恢复
- 偏好跨学科整合，不希望按单一学科线性推进

## Learning Style Observations
- 已有广泛的碎片化知识，但缺乏系统框架——教学重点在于「串联」而非「灌输」
- 自发意识到四个学科的关联性——具有整合性思维倾向
- 追求「思想体系」而非实用技能——课程可以更理论化、更结构化

## Teaching Approach Notes
- 每个 lesson 应围绕一个「交叉节点」设计——一个四个学科汇聚的现象或问题
- 先给框架（思维脚手架），再填内容
- 螺旋式推进：同一主题在不同阶段以不同深度反复出现
- 控制每课的信息密度——working memory 是瓶颈
- 强调「可迁移的分析工具」而非事实记忆
