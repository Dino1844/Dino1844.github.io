1. 背包家族：所有 DP 的「母题」

背包问题是 DP 的母题——大量看似无关的题（零钱兑换、单词拆分、整数划分、股票交易次数受限）本质都是背包。掌握背包的两种核心变体（0-1 和完全），就掌握了 DP 的半壁江山。

变体物品数量典型问题
0-1 背包每件最多选一次分割等和子集、目标和
完全背包每件无限件可选零钱兑换、完全平方数、单词拆分
多重背包每件有固定数量按颜色选球（Hot 100 较少）
多维背包容量有多个维度一和零（0/1 个数双约束）

2. 0-1 背包：每件物品选或不选

经典 0-1 背包：n 件物品，第 i 件重量 w[i]、价值 v[i]。背包容量 W。每件最多选一次，求最大价值。

2.1 状态与转移

状态：dp[i][j] = 考虑前 i 件物品、容量为 j 时的最大价值。
转移：对第 i 件物品，选或不选：
  不选：dp[i][j] = dp[i-1][j]
  选（前提 j ≥ w[i]）：dp[i][j] = dp[i-1][j-w[i]] + v[i]
  取 max：dp[i][j] = max(dp[i-1][j], dp[i-1][j-w[i]] + v[i])
边界：dp[0][j] = 0（没有物品可选）。

2.2 二维实现

vector<vector<int>> dp(n + 1, vector<int>(W + 1, 0));
for (int i = 1; i <= n; i++)
    for (int j = 0; j <= W; j++) {
        dp[i][j] = dp[i-1][j];  // 不选第 i 件
        if (j >= w[i-1])
            dp[i][j] = max(dp[i][j], dp[i-1][j - w[i-1]] + v[i-1]);
    }
return dp[n][W];

2.3 空间优化：一维 + 倒序循环

dp[i][j] 只依赖 dp[i-1][...]，可压成一维。但容量循环必须倒序——这是 0-1 背包的灵魂。

vector<int> dp(W + 1, 0);
for (int i = 0; i < n; i++)
    for (int j = W; j >= w[i]; j--)  // ⚠️ 倒序！
        dp[j] = max(dp[j], dp[j - w[i]] + v[i]);
return dp[W];

📐 为什么必须倒序？

二维转一维时，dp[j] 在更新前存的是 dp[i-1][j]（上一行）。转移需要 dp[i-1][j-w[i]]，即上一行的更小容量。

如果正序循环 j：当我们算 dp[j] 时，dp[j-w[i]] 已经被本物品更新过（变成了 dp[i][j-w[i]]），相当于同一物品被选了两次——这恰好是完全背包的行为！

倒序循环 j：算 dp[j] 时，dp[j-w[i]] 还没被本物品更新（仍是 dp[i-1][j-w[i]]），保证每件物品只选一次。✅

3. 题 1：分割等和子集 — 0-1 背包判定

LeetCode 416. Partition Equal Subset Sum（Hot 100）
判断非空数组能否分成两个子集，使两者元素之和相等。
例：nums = [1,5,11,5] → true（[1,5,5] 和 [11]）

3.1 转化为 0-1 背包

设总和 sum。若 sum 为奇数，直接 false。否则目标 target = sum/2。问题变成：能否从 nums 中选若干个数，使和恰好为 target。这就是 0-1 背包的判定版（每件选或不选，问能否恰好装满容量 target）。

3.2 状态与转移

状态：dp[j] = 能否用若干已考虑的数凑出和 j（bool）。
转移：对每个数 x，倒序更新：dp[j] = dp[j] || dp[j-x]。
边界：dp[0] = true（空集和为 0）。

bool canPartition(vector<int>& nums) {
    int sum = accumulate(nums.begin(), nums.end(), 0);
    if (sum % 2) return false;
    int target = sum / 2;
    vector<bool> dp(target + 1, false);
    dp[0] = true;
    for (int x : nums)
        for (int j = target; j >= x; j--)  // 倒序，0-1 背包
            dp[j] = dp[j] || dp[j - x];
    return dp[target];
}

复杂度：O(n × target) 时间，O(target) 空间。

4. 完全背包：每件物品无限件

与 0-1 背包的唯一区别：每件物品可以选任意多次。这导致容量循环变成正序。

4.1 转移与循环

// 完全背包：容量正序循环
vector<int> dp(W + 1, 0);
for (int i = 0; i < n; i++)
    for (int j = w[i]; j <= W; j++)  // ⚠️ 正序！
        dp[j] = max(dp[j], dp[j - w[i]] + v[i]);

正序意味着算 dp[j] 时，dp[j-w[i]] 可能已经包含本物品——即本物品可以被重复选取，这正是完全背包要的。

5. 题 2：零钱兑换 — 完全背包最值

LeetCode 322. Coin Change（Hot 100）
给定硬币面额 coins 和金额 amount，每种硬币无限枚，求凑成 amount 的最少硬币数。
例：coins = [1,2,5], amount = 11 → 3（5+5+1）

5.1 识别为完全背包

「每种硬币无限枚」→ 完全背包。「最少硬币数」→ 求最小值。物品 = 硬币，重量 = 面额，价值 = 1（每枚硬币计 1），容量 = amount。

5.2 状态与转移

状态：dp[j] = 凑出金额 j 的最少硬币数。
转移：dp[j] = min(dp[j], dp[j - coin] + 1)（用一枚 coin）。
边界：dp[0] = 0（金额 0 不需要硬币），其余初始化为 ∞。

int coinChange(vector<int>& coins, int amount) {
    vector<int> dp(amount + 1, INT_MAX);
    dp[0] = 0;
    for (int coin : coins)
        for (int j = coin; j <= amount; j++)  // 正序，完全背包
            if (dp[j - coin] != INT_MAX)
                dp[j] = min(dp[j], dp[j - coin] + 1);
    return dp[amount] == INT_MAX ? -1 : dp[amount];
}
⚠️ INT_MAX + 1 溢出陷阱：dp[j-coin] 若为 INT_MAX，加 1 会溢出成负数，破坏 min。必须先判断 dp[j-coin] != INT_MAX。这是背包最值题的通用防御。

6. 题 3：完全平方数 — 完全背包计数

LeetCode 279. Perfect Squares（Hot 100）
给定正整数 n，求最少几个完全平方数（1,4,9,...）相加等于 n。
例：n = 12 → 3（4+4+4）

6.1 转化为完全背包

物品 = 所有 ≤ n 的完全平方数（1², 2², ..., ⌊√n⌋²），每个无限使用。容量 = n。求最少物品数。与零钱兑换结构完全相同，只是「硬币面额」变成了平方数。

int numSquares(int n) {
    vector<int> dp(n + 1, INT_MAX);
    dp[0] = 0;
    for (int i = 1; i * i <= n; i++) {       // 物品：i*i
        int sq = i * i;
        for (int j = sq; j <= n; j++)        // 正序，完全背包
            if (dp[j - sq] != INT_MAX)
                dp[j] = min(dp[j], dp[j - sq] + 1);
    }
    return dp[n];
}
同构识别：零钱兑换和完全平方数的代码几乎逐行对应。一旦识别出「完全背包最值」这个模式，两题就是一题。这种「模式识别」是 DP 高手的核心能力。

7. 0-1 vs 完全：循环顺序的致命差异

0-1 背包完全背包
物品循环外层外层
容量循环倒序 (j = W → w[i])正序 (j = w[i] → W)
每件物品最多选一次可选无限次
典型题分割等和子集、目标和零钱兑换、完全平方数、单词拆分
🧠 一句话记忆：
「倒序 = 每件只选一次（0-1）；正序 = 每件可选多次（完全）」
原因：正序时 dp[j-w[i]] 已含本物品 → 可重复选；倒序时 dp[j-w[i]] 还没含本物品 → 只选一次。

7.1 求组合数 vs 排列数（循环顺序的另一层含义）

当完全背包求方案数时，物品和容量的循环顺序还决定是组合还是排列：

// 求组合数（顺序无关）：物品在外，容量在内
for (int coin : coins)
    for (int j = coin; j <= amount; j++)
        dp[j] += dp[j - coin];

// 求排列数（顺序有关）：容量在外，物品在内
for (int j = 1; j <= amount; j++)
    for (int coin : coins)
        if (j >= coin) dp[j] += dp[j - coin];

这是 LeetCode 518（零钱兑换 II）和 377（组合总和 IV）的区别——两题代码几乎一样，只差循环顺序。

8. 题 4：一和零 — 多维背包

LeetCode 474. Ones and Zeroes
给定字符串数组 strs，以及整数 m 和 n。选出最多的字符串，使选中的字符串中 '0' 总数 ≤ m 且 '1' 总数 ≤ n。

8.1 识别为二维 0-1 背包

每个字符串是一件物品，有两个重量维度（'0' 的个数 zeros、'1' 的个数 ones）。背包有两个容量（m, n）。每件选或不选 → 0-1 背包。求最多物品数 → 价值全为 1。

8.2 状态与转移

状态：dp[j][k] = 用 ≤ j 个 '0' 和 ≤ k 个 '1' 能选的最多字符串数。
转移：对每个字符串（zeros, ones），两个维度都倒序：
  dp[j][k] = max(dp[j][k], dp[j-zeros][k-ones] + 1)

int findMaxForm(vector<string>& strs, int m, int n) {
    vector<vector<int>> dp(m + 1, vector<int>(n + 1, 0));
    for (auto& s : strs) {
        int zeros = count(s.begin(), s.end(), '0');
        int ones = s.size() - zeros;
        for (int j = m; j >= zeros; j--)           // 维度 1 倒序
            for (int k = n; k >= ones; k--)       // 维度 2 倒序
                dp[j][k] = max(dp[j][k], dp[j - zeros][k - ones] + 1);
    }
    return dp[m][n];
}

复杂度：O(L × m × n)，L 是字符串数。

多维背包的通用规则：每个容量维度都是一个循环。0-1 背包所有容量维度都倒序；完全背包都正序。维度的嵌套顺序不影响结果（只要每个维度内部方向正确）。

9. 背包问题识别指南

看到这些特征 → 想背包：
1. 有若干「物品」，每个有某种代价（重量/体积/时间）
2. 有一个或多个容量上限
3. 每个物品选或不选（0-1）或可重复选（完全）
4. 求最大价值 / 最小代价 / 方案数 / 可行性
题目特征背包类型容量循环
每件最多选一次0-1倒序
每件可无限选完全正序
每件有固定数量多重二进制拆分后按 0-1 处理
多个容量约束多维每维独立循环
求方案数且顺序无关完全（组合）物品外、容量内
求方案数且顺序有关完全（排列）容量外、物品内
