Phase 1: DNS 解析 —— 域名到 IP 地址的转换

DNS 缓存（浏览器 → OS → 路由器 → ISP） 递归查询 vs 迭代查询 根域名服务器 → TLD → 权威服务器 A 记录 / AAAA 记录 / CNAME DNS over HTTPS (DoH)
深入阅读： 📖 DNS 深度解析 📋 DNS 参考卡

Phase 2: TCP 连接 —— 可靠的传输管道

SYN / SYN-ACK / ACK 三次握手 序列号 (Sequence Number) 与确认号 (ACK) 拥塞控制 (慢启动、拥塞避免) 流量控制 (滑动窗口) TIME_WAIT 与四次挥手
深入阅读： 📖 TCP 深度解析 📋 TCP 参考卡

Phase 3: TLS 握手 —— 建立加密信道

ClientHello / ServerHello 证书链验证 (CA → 中间证书 → 服务器) 非对称加密交换密钥 → 对称加密传输数据 TLS 1.2 vs TLS 1.3 握手效率 HTTPS = HTTP over TLS
深入阅读： 📖 TLS 深度解析 📋 TLS 参考卡

Phase 4: HTTP 请求 —— 应用层协议

请求方法：GET / POST / PUT / DELETE 状态码：2xx / 3xx / 4xx / 5xx Header 字段（Host, User-Agent, Cookie…） HTTP/1.1 队头阻塞 → HTTP/2 多路复用 → HTTP/3 QUIC 缓存策略（ETag, Cache-Control）
深入阅读： 📖 HTTP 深度解析 📋 HTTP 参考卡

Phase 5: IP 路由 —— 网络层的逐跳转发

IP 地址（IPv4 / IPv6）与子网划分 (CIDR) 路由表 & 最长前缀匹配 BGP（域间路由） vs OSPF（域内路由） NAT 网络地址转换 TTL 与 traceroute
深入阅读： 📖 IP 路由深度解析 📋 IP 层参考卡

Phase 6: 链路层 —— 在同一网络内的帧传输

MAC 地址与 ARP（地址解析协议） 以太网帧结构 交换机 vs 集线器 vs 路由器 CSMA/CD（冲突检测） WiFi (802.11) 与有线网络的差异
深入阅读： 📖 链路层深度解析 📋 链路层参考卡

Phase 7: 浏览器渲染 —— 从 HTML 到像素

HTML 解析 → DOM 树 CSS 解析 → CSSOM 树 布局 (Layout) → 绘制 (Paint) → 合成 (Composite) JavaScript 执行与事件循环 关键渲染路径优化
深入阅读： 📖 浏览器渲染深度解析 （注：此阶段属于浏览器原理，非严格网络范畴）
