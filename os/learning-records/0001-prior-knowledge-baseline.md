# 先前知识基线

用户具备以下基础：
- **编程**：有 C 语言基础，能读懂系统级代码；有 Python 基础
- **计算机组成**：理解 CPU、内存、磁盘的基本角色；知道寄存器/cache/RAM/硬盘的速度差异；理解中断的基本概念
- **数据结构**：理解链表、哈希表、红黑树的基本操作
- **系统使用**：日常使用 Linux 命令行，理解进程（`ps`、`top`）、文件系统（`ls -l`、`df`）的用户视角

**待建立的知识**（课程目标）：
- 进程在 OS 内部如何表示、调度和切换
- 虚拟内存的完整机制和硬件支撑
- 并发编程的同步原语及其在 OS 内核中的实现
- 文件系统的内部结构和崩溃一致性保证
- I/O 子系统的完整软件栈
- 虚拟化与容器的隔离机制

**教学意义**：不需要从"什么是操作系统"讲起（用户已有基本用户视角），但需要从用户视角切换到内核视角。0001 直接建立 OS 的内部世界观——"三条幻象"作为理解所有后续机制的钥匙。
