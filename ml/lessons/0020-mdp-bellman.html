你有一个智能体，在一个未知环境里通过试错学习。它不知道状态转移规律，不知道奖励函数， 只能通过"做出动作 → 看到新状态和奖励 → 调整策略"来学习。 这就是强化学习（RL）——和 ML 的监督学习共享概率和优化的数学工具， 但核心问题完全不同。

RL 与监督学习的本质区别：监督学习有正确答案（标签 $y$），RL 只有奖励信号（reward）——正确的不是"这个动作对不对"，而是"长期来看做这些动作能拿多少奖励"。延迟反馈和探索-利用权衡是 RL 独有的困难。

激活已有知识

  1. 条件概率 $p(s'\mid s,a)$——给定当前状态和动作，下一状态的概率分布。
  2. 期望 $\mathbb{E}[X] = \sum_x p(x)x$——RL 里大量用期望，因为环境和策略都是随机的。
  3. 动态规划——把大问题拆成重叠子问题，Bellman 方程就是动态规划在 MDP 上的形式。

1. RL 与监督学习的本质区别

监督学习：给定 $(\mathbf{x}_n, y_n)$，学 $p(y\mid\mathbf{x})$ 或 $f(\mathbf{x})\approx y$。评价标准：预测误差。

强化学习：智能体在环境里做动作，环境反馈奖励。没有"正确答案"——只有"这个动作在这个状态下长期看有多好"。

监督学习强化学习
反馈形式标签 $y$（即时、完整）奖励 $r$（可能延迟、稀疏）
数据来源给定的固定数据集智能体与环境交互产生
核心困难过拟合、泛化延迟奖励 + 探索/利用权衡
数学框架概率建模 + 优化MDP + 动态规划 + 函数逼近
RL 的"打游戏"类比：你玩一个没见过的游戏，没人告诉你规则。你按了一个键 → 角色跳了一下 → 得分 +10。下一次，你会不会更愿意按那个键？按了之后，后续的事件会不会导致最终得分更高？这就是 RL 要回答的两个核心问题：(1) 这个动作在那时有多好？(2) 长远来看，怎么选动作序列使总奖励最大？

2. MDP：五元组形式化一切序贯决策

RL 基础

Markov 决策过程 · MDP

Markov Decision Process
数学本质：MDP = $(\mathcal{S}, \mathcal{A}, \mathcal{P}, \mathcal{R}, \gamma)$——五个组件精确描述了"智能体在随机环境里做序贯决策"的所有要素。

五元组

  • $\mathcal{S}$：状态空间（state space），环境所有可能状态的集合
  • $\mathcal{A}$：动作空间（action space），智能体在每个状态可执行的动作
  • $\mathcal{P}(s'\mid s,a)$：状态转移概率（transition dynamics），做完 $a$ 后从 $s$ 跳到 $s'$ 的概率
  • $\mathcal{R}(s,a,s')$：奖励函数（reward function），过渡到 $s'$ 时获得的即时期望奖励
  • $\gamma\in[0,1]$：折扣因子（discount factor），未来的奖励在今天值多少

Markov 性质

状态包含"所有相关历史"：$p(s_{t+1}\mid s_t,a_t,s_{t-1},a_{t-1},\ldots) = p(s_{t+1}\mid s_t,a_t)$。给定当前状态，未来与过去条件独立。这意味着决策只需要当前状态——不需要记住完整历史。

→ §2: MDP 定义 → 0021: 动态规划求解已知 MDP

MDP 的交互循环：

$$s_0 \xrightarrow{a_0} s_1, r_1 \xrightarrow{a_1} s_2, r_2 \xrightarrow{a_2} \cdots$$

每一步：智能体观测状态 $s_t$ → 选动作 $a_t$（根据策略 $\pi$）→ 环境采样 $s_{t+1}\sim\mathcal{P}(\cdot\mid s_t,a_t)$ 并给奖励 $r_{t+1}=\mathcal{R}(s_t,a_t,s_{t+1})$。

注意两个关键：转移概率 $\mathcal{P}$ 由环境决定，智能体不知道（model-free）或只知道部分（model-based）。奖励信号是唯一的学习信号——没有标签告诉你"正确动作是什么"。

3. 回报与价值函数：从"这步赚多少"到"长远看有多好"

RL 的目标不是最大化单步奖励，而是最大化累积奖励——用折扣因子 $\gamma$ 把未来奖励折现：

$$\boxed{\;G_t = r_{t+1} + \gamma r_{t+2} + \gamma^2 r_{t+3} + \cdots = \sum_{k=0}^{\infty} \gamma^k r_{t+k+1}\;}$$

$\gamma=0$：只看眼前（贪婪），$\gamma\to 1$：看长远。$\gamma<1$ 保证无穷序列的回报有限（只要奖励有界）。

范式 #21 · 价值函数 = 期望回报

回报 $G_t$ 是随机的（取决于未来的状态转移和动作选择）。价值函数取期望，消去随机性，变成状态的确定性函数——这就是 RL 里一切计算的起点。

状态价值函数 $V^\pi(s)$：从状态 $s$ 开始，一直按策略 $\pi$ 选动作，能拿到的期望回报。

$$V^\pi(s) = \mathbb{E}_\pi[G_t \mid S_t = s] = \mathbb{E}_\pi\!\left[\sum_{k=0}^{\infty} \gamma^k r_{t+k+1} \;\middle|\; S_t = s\right]$$

动作价值函数 $Q^\pi(s,a)$：从状态 $s$ 开始，做动作 $a$，之后一直按 $\pi$ 选动作，能拿到的期望回报。

$$Q^\pi(s,a) = \mathbb{E}_\pi[G_t \mid S_t = s, A_t = a]$$
$V$ 和 $Q$ 的关系：$V^\pi(s) = \mathbb{E}_{a\sim\pi(\cdot\mid s)}[Q^\pi(s,a)]$——状态的价值 = 按策略分布加权所有动作的 $Q$ 值。$V$ 告诉你在状态 $s$ 有多好，$Q$ 告诉你在状态 $s$ 做动作 $a$ 有多好。

4. Bellman 期望方程：把未来折叠到现在

价值函数的定义里有一个"未来求和"——看似需要知道无限远的奖励才能算。Bellman 方程的洞察是： 今天的价值 = 今天的期望奖励 + 明天价值的折扣。这就把无限和变成了一个递归关系。

推导 · $V^\pi$ 的 Bellman 方程

$V^\pi(s) = \mathbb{E}_\pi[G_t \mid S_t = s]$ 定义
$= \mathbb{E}_\pi[r_{t+1} + \gamma G_{t+1} \mid S_t = s]$ $G_t = r_{t+1} + \gamma G_{t+1}$（回报的递归定义）
$= \sum_a \pi(a\mid s) \sum_{s'} \mathcal{P}(s'\mid s,a) \big[\mathcal{R}(s,a,s') + \gamma\, \mathbb{E}_\pi[G_{t+1}\mid S_{t+1}=s']\big]$ 展开动作和状态转移的期望
$= \sum_a \pi(a\mid s) \sum_{s'} \mathcal{P}(s'\mid s,a) \big[\mathcal{R}(s,a,s') + \gamma\, V^\pi(s')\big]$ 最后一项就是 $V^\pi(s')$ —— 这就是递归！
$$\boxed{\;V^\pi(s) = \sum_a \pi(a\mid s) \sum_{s'} \mathcal{P}(s'\mid s,a)\big[\mathcal{R}(s,a,s') + \gamma V^\pi(s')\big]\;}$$

同理，$Q^\pi$ 的 Bellman 方程：

$$\boxed{\;Q^\pi(s,a) = \sum_{s'} \mathcal{P}(s'\mid s,a)\big[\mathcal{R}(s,a,s') + \gamma\sum_{a'} \pi(a'\mid s') Q^\pi(s',a')\big]\;}$$
Bellman 方程的本质：自洽性条件。它说"如果 $V^\pi$ 是正确的价值函数，那么对它自己的递归定义必须成立"。反过来，满足 Bellman 方程的函数就是 $V^\pi$。这给了我们一个检验和求解价值函数的方法：猜一个 $V$，看它是否满足方程 —— 这就是下一课动态规划的基础。

5. Bellman 最优方程：最优策略的充要条件

有多个策略时，怎么定义"最优"？偏序：$\pi \geq \pi'$ 当且仅当 $V^\pi(s) \geq V^{\pi'}(s)$ 对所有 $s$。 这个偏序下存在最优策略 $\pi^*$（在有限 MDP 中），且所有最优策略共享同一个最优价值函数 $V^*(s) = \max_\pi V^\pi(s)$。

最优策略不是最大化单步奖励——是选 $Q$ 值最大的动作：$\pi^*(s) = \arg\max_a Q^*(s,a)$。

推导 · Bellman 最优方程

$V^*(s) = \max_a Q^*(s,a)$ 最优策略选最好的动作，所以最优状态价值 = 最优动作价值的 max
$= \max_a \sum_{s'} \mathcal{P}(s'\mid s,a)\big[\mathcal{R}(s,a,s') + \gamma V^*(s')\big]$ 代入 $Q^*$ 的 Bellman 方程，且最优策略在 $s'$ 也用最优动作
$$\boxed{\;V^*(s) = \max_a \sum_{s'} \mathcal{P}(s'\mid s,a)\big[\mathcal{R}(s,a,s') + \gamma V^*(s')\big]\;}$$
$$\boxed{\;Q^*(s,a) = \sum_{s'} \mathcal{P}(s'\mid s,a)\big[\mathcal{R}(s,a,s') + \gamma \max_{a'} Q^*(s',a')\big]\;}$$
Bellman 最优方程与期望方程的关键区别：期望方程里是 $\sum_a\pi(a\mid s)$（按策略分布加权），最优方程里是 $\max_a$（选最好的动作）。max 让方程变成非线性的——无法用线性方程组求解。这就是 RL 需要迭代方法（值迭代、策略迭代、Q-learning）的根本原因。
方程形式求解方式解
Bellman 期望方程$V^\pi = \mathcal{T}^\pi V^\pi$（线性）解线性方程组 或 迭代$V^\pi$（给定策略）
Bellman 最优方程$V^* = \mathcal{T}^* V^*$（非线性，含 $\max$）值迭代、策略迭代、Q-learning$V^*$（最优）

5.5. 动态规划：已知模型，怎么求最优策略

Bellman 方程给了我们检验和定义价值函数的方式。但怎么算出来？ 如果 MDP 的 $\mathcal{P}$ 和 $\mathcal{R}$ 完全已知（白盒环境），动态规划（DP）用 Bellman 方程做迭代更新， 收敛到 $V^*$。

DP 的核心假设：已知环境模型（$\mathcal{P}$ 和 $\mathcal{R}$），且状态和动作空间有限（表格型，非函数逼近）。 这限制了 DP 的直接应用范围（大多数实际问题不知道 $\mathcal{P}$），但它是所有 RL 方法的理论基础—— model-free 方法本质上是在用采样近似 DP 的期望计算。

范式 #22 · 广义策略迭代（GPI）

几乎所有 RL 算法都可以理解为两个交替过程的交互： 策略评估（policy evaluation）：给定策略 $\pi$，算出 $V^\pi$（或 $Q^\pi$）；
策略改进（policy improvement）：给定 $Q^\pi$，构造一个更好的策略 $\pi'(s)=\arg\max_a Q^\pi(s,a)$。
两者轮流进行，直到策略不再变化 → 到达最优。DP、MC、TD、Actor-Critic 全是 GPI 的不同实现。

5.6. 策略迭代（Policy Iteration）

策略迭代在两个步骤间交替，直到收敛：

算法 · 策略迭代

① 策略评估（Policy Evaluation）
用 Bellman 期望方程迭代更新 $V$，直到收敛（或近似收敛）： $$V_{k+1}(s) \leftarrow \sum_a \pi(a\mid s) \sum_{s'} \mathcal{P}(s'\mid s,a)\big[\mathcal{R}(s,a,s') + \gamma V_k(s')\big]$$ Bellman 期望方程作为"赋值"操作——把右边算出来的值赋给左边。这叫迭代策略评估。
② 策略改进（Policy Improvement）
对每个状态 $s$，用当前 $V^\pi$ 算出 $Q^\pi(s,a)$，选最优动作： $$\pi'(s) \leftarrow \arg\max_a \sum_{s'} \mathcal{P}(s'\mid s,a)\big[\mathcal{R}(s,a,s') + \gamma V^\pi(s')\big]$$ 贪心改进：对当前价值函数做一步最优选择
③ 如果 $\pi' = \pi$（所有状态动作不变）→ 停止，已收敛到 $\pi^*$。否则回到①。 策略改进定理（L3 题）保证每轮严格不退化，有限 MDP 必收敛
策略迭代的代价：策略评估需要迭代到收敛——每轮评估都跑很多次 Bellman 更新。 对大状态空间这很贵。但工程上可以不等到完全收敛就做策略改进——这引出了值迭代。

5.7. 值迭代（Value Iteration）

策略迭代的瓶颈在策略评估——每轮都要把 $V^\pi$ 算到收敛。值迭代的洞察：策略评估做一步就够了。把 Bellman 最优方程直接当更新规则用：

$$\boxed{\;V_{k+1}(s) \leftarrow \max_a \sum_{s'} \mathcal{P}(s'\mid s,a)\big[\mathcal{R}(s,a,s') + \gamma V_k(s')\big]\;}$$

这就是值迭代——它等价于：策略评估只做一步 → 策略改进（取 $\max$）→ 重复。可以证明值迭代收敛到 $V^*$。

策略迭代值迭代
策略评估迭代到收敛（多步）只做一步 Bellman 更新
策略改进显式更新 $\pi(s)$（取 $\arg\max$）隐式——$\max$ 直接嵌在更新里
收敛策略不变时停止（有限步收敛）$V$ 变化小于阈值时停止（渐近收敛）
计算量/轮大（多步评估）小（一步更新）
适用动作空间不大的 MDP大多数表格型 MDP 的默认选择
DP 的两个根本局限：(1) 需要已知 $\mathcal{P}$ 和 $\mathcal{R}$——大多数实际问题不知道；(2) 需要对所有 $s\in\mathcal{S}$ 做全扫描——状态空间巨大时不可行。 这两个局限直接逼出了 model-free 方法（不需要 $\mathcal{P}$）和函数逼近（不枚举所有状态）——下一课的主题。

6. 推导与自测

L1 · Bellman 方程的手算验证 L1
一个 MDP 有两个状态 $\{s_1,s_2\}$，一个动作 $a$。$\mathcal{P}(s_1\mid s_1,a)=0.5$，$\mathcal{P}(s_2\mid s_1,a)=0.5$；$\mathcal{P}(s_2\mid s_2,a)=1$（$s_2$ 是吸收态）。$\mathcal{R}(s_1,a,s_1)=0$，$\mathcal{R}(s_1,a,s_2)=10$，$\mathcal{R}(s_2,a,s_2)=0$。$\gamma=0.9$。策略始终选 $a$。写出 $V(s_1)$ 和 $V(s_2)$ 的 Bellman 方程并求解。
展开推导
$V(s_2) = 1\cdot[0 + 0.9\cdot V(s_2)] \Rightarrow V(s_2) = 0.9V(s_2) \Rightarrow V(s_2)=0$吸收态，奖励为零，价值也为零
$V(s_1) = 0.5[0+0.9V(s_1)] + 0.5[10+0.9\cdot 0] = 0.45V(s_1) + 5$一半概率留在 $s_1$（奖励 0），一半去 $s_2$（奖励 10）
$V(s_1) - 0.45V(s_1) = 5 \Rightarrow V(s_1) = \frac{5}{0.55} \approx 9.09$解一元一次方程
$Q(s_1,a) = V(s_1) \approx 9.09$（只有一个动作）验证：从 $s_1$ 出发，期望回报约 9.09
L2 · 最优方程的 $\max$ 导致非线性 L2
在上述 MDP 的基础上，增加第二个动作 $b$：$\mathcal{P}(s_1\mid s_1,b)=0$，$\mathcal{P}(s_2\mid s_1,b)=1$，$\mathcal{R}(s_1,b,s_2)=5$。写出 Bellman 最优方程，求解 $V^*(s_1)$ 和最优动作。
展开推导
$V^*(s_2)=0$（吸收态，不变）
$Q^*(s_1,a) = 0.5[0+0.9V^*(s_1)] + 0.5[10+0] = 0.45V^*(s_1) + 5$
$Q^*(s_1,b) = 0\cdot[0+0.9V^*(s_1)] + 1\cdot[5+0] = 5$
$V^*(s_1) = \max(Q^*(s_1,a), Q^*(s_1,b)) = \max(0.45V^*(s_1)+5, 5)$这里 $\max$ 使方程非线性——需要判断哪个更大
如果 $V^*(s_1)=5$，则 $Q^*(s_1,a)=0.45\cdot 5+5=7.25 > 5$ → 矛盾！所以 $V^*(s_1)>5$，最优动作是 $a$。迭代才能找到不动点——这就是"值迭代"的雏形
$V^*(s_1) = 0.45V^*(s_1)+5 \Rightarrow V^*(s_1) = 5/0.55 \approx 9.09$，和之前一样。$a$ 仍然是更优的动作
L3 · 从 Bellman 方程到 "策略改进定理" L3
证明：若对所有 $s$，$Q^\pi(s,\pi'(s)) \geq V^\pi(s)$，则 $V^{\pi'}(s) \geq V^\pi(s)$（策略 $\pi'$ 至少和 $\pi$ 一样好）。这就是策略迭代的理论基础——贪心改进永远不降性能。
展开推导
对任意 $s$：$V^\pi(s) \leq Q^\pi(s,\pi'(s))$已知条件
$= \mathbb{E}[r + \gamma V^\pi(s') \mid s, \pi'(s)]$$Q^\pi$ 的 Bellman 方程
$\leq \mathbb{E}[r + \gamma Q^\pi(s',\pi'(s')) \mid s, \pi'(s)]$再次用已知条件，这次在 $s'$ 上
$= \mathbb{E}_{\pi'}[r + \gamma r' + \gamma^2 V^\pi(s'') \mid s]$展开一层
重复展开到无穷：$\leq \mathbb{E}_{\pi'}[\sum\gamma^k r_{t+k+1}\mid s] = V^{\pi'}(s)$右端正是按 $\pi'$ 走的期望回报
因此 $V^{\pi'} \geq V^\pi$——策略严格不退化。这就是策略改进定理，它保证了贪心策略迭代收敛到最优。整个 RL 的理论基石之一
关键带回：MDP 是 RL 的"概率模型"（相当于 ML 里的 $p(y\mid\mathbf{x})$）。Bellman 方程是"损失函数"——满足它就找到了价值函数。 期望方程（有 $\sum\pi$）→ 评估给定策略；最优方程（有 $\max$）→ 找最优策略。 $\max$ 带来的非线性是 RL 需要迭代算法的根源，也是下一课"动态规划"要解决的核心问题。
