核心职责

在同一段物理链路上，将数据从一个设备传到相邻设备。使用 MAC 地址寻址，每一跳重新封装帧。

以太网帧结构

┌──────────┬────────────┬──────────┬──────────┬────────────────┬──────┐
│ 前导码   │ 目的 MAC   │ 源 MAC   │ 类型     │ 数据           │ CRC  │
│ 8 bytes  │ 6 bytes    │ 6 bytes  │ 2 bytes  │ 46–1500 bytes  │ 4 B  │
└──────────┴────────────┴──────────┴──────────┴────────────────┴──────┘
字段大小说明
前导码8 B同步发送方和接收方的时钟，帧定界符
目的 MAC6 B接收方 MAC；全 F 为广播 (FF:FF:FF:FF:FF:FF)
源 MAC6 B发送方 MAC
类型2 B0x0800=IPv4, 0x0806=ARP, 0x86DD=IPv6
数据46–1500 BMTU=1500（常见）。不足46则padding
CRC4 B循环冗余校验，错误则丢弃

ARP 地址解析协议

作用：已知 IP，查 MAC。
过程：广播请求 → 目标单播响应 → 缓存（arp -a 查看）
安全：无认证，可被 ARP 欺骗攻击

交换机 vs 其它设备

设备工作层查什么表转发依据隔离什么
集线器 Hub物理层无无条件广播无
交换机 Switch链路层MAC 表目标 MAC冲突域
路由器 Router网络层路由表目标 IP广播域

交换机自学习

  1. 收到帧 → 记录 源 MAC → 端口 映射
  2. 查目标 MAC：已知端口 → 精确转发；未知 → 泛洪（除接收口外全发）
  3. 条目老化：通常 5 分钟无活动则删除

CSMA/CD vs CSMA/CA

CSMA/CD (以太网)CSMA/CA (WiFi)
策略冲突检测冲突避免
检测方式边说边听无法同时收发 → 使用退避+RTS/CTS
重传发生冲突后随机退避链路层 ACK + 重传
现状交换式以太网中几乎无冲突WiFi 中始终存在

常见 CLI 命令

命令作用
arp -a查看 ARP 缓存表（IP → MAC 映射）
ip link / ifconfig查看网络接口的 MAC 地址和状态
arping -I eth0 192.168.1.1手动发送 ARP 请求
tcpdump -i eth0 arp抓取 ARP 包
ip neigh查看邻居表（IPv6 NDP + IPv4 ARP）

关键数字

MAC 地址长度：48 位 (6 字节)
以太网 MTU：1500 字节 (标准) / 9000 字节 (Jumbo Frame)
最短帧：64 字节
MAC 表老化时间：~300 秒 (5 分钟，厂商可调)
ARP 缓存老化：~60–300 秒（OS 相关）
