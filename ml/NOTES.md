### 第七阶段 · 算法数学深处（原 aimath，合入 2026-06-19）
> 哲学：洞察优先于推导，每一步"有因可据"而非"神的灵机一动"。在 PRML 主干之后，沿六领域地图深入生成模型族与信息几何。
18. ✅ Score Function——统一生成模型的数学之眼（$Z$ 不可算 → score → Langevin → DDPM）

23. ✅ 散度家族——$f$-散度统一 KL/JS/χ² + Wasserstein 的几何直觉 + 为什么散度选择决定 GAN 的生与死

### 第八阶段 · 强化学习（2026-06-19 启动）
> RL 是 ML 的第三极——监督学习学映射，无监督学结构，RL 学序贯决策。压缩为 3 课高密度内容。
20. ✅ MDP → Bellman → 动态规划（MDP 五元组 → 价值函数 → Bellman 期望/最优方程 → 策略迭代 → 值迭代）
21. ▶ Model-free RL：MC → TD → Q-learning → SARSA（不知道转移概率时的预测与控制）
22. ▶ Deep RL：DQN → 策略梯度 → Actor-Critic → PPO（函数逼近 + 经验回放 + clipped surrogate）
