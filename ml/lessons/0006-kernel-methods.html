1. 基函数的困境：显式特征爆炸

核心技巧

核技巧 · Kernel Trick

隐式特征映射
数学本质：不显式构造特征 $\boldsymbol{\phi}(\mathbf{x})$，只通过核函数 $k(\mathbf{x},\mathbf{x}') = \boldsymbol{\phi}(\mathbf{x})^\top\boldsymbol{\phi}(\mathbf{x}')$ 计算内积。把 $\mathbf{w} = \boldsymbol{\Phi}^\top\boldsymbol{\alpha}$ 代入正规方程，所有 $\boldsymbol{\Phi}$ 项只以内积 $\mathbf{K}$ 的形式出现。

为什么有效

原始解：$\mathbf{w} = (\boldsymbol{\Phi}^\top\boldsymbol{\Phi})^{-1}\boldsymbol{\Phi}^\top\mathbf{y}$（需要 $M$ 维特征）

核化解：$\boldsymbol{\alpha} = (\mathbf{K}+\lambda\mathbf{I})^{-1}\mathbf{y}$（只需要 $N\times N$ 核矩阵）

预测：$f(\mathbf{x}_*) = \sum_n \alpha_n k(\mathbf{x}_*,\mathbf{x}_n)$——永不碰 $\boldsymbol{\phi}$

→ 0001 §4: 正规方程的核化版本 → 0007: SVM = 核化 + 最大间隔 → Mercer: 保证 $\mathbf{K}\succeq 0$

回顾 基石 0001 §1 的模型。取 $\phi_j(x) = x^j$（$j=0,\dots,M-1$），得到 $M$ 阶多项式回归。 输入是一维 $x\in\mathbb{R}$，特征向量 $\boldsymbol{\phi}(x) \in \mathbb{R}^M$。 如果输入是 $D$ 维 $\mathbf{x}\in\mathbb{R}^D$，取所有 $d$ 次单项式（monomials）做特征，特征数会爆炸：

$$M = \binom{D + d}{d} = \frac{(D+d)!}{D!\,d!}$$

例如 $D=100$ 维输入，$d=3$ 次多项式，$M = \binom{103}{3} = 176,\!851$——十七万个特征。 $d=4$ 则 $M \approx 4.6$ 百万。$d=5$ 则过亿。维度组合爆炸（combinatorial explosion）。

更糟的是，有些有用的特征映射是无穷维的。例如高斯基函数 $\phi_k(x) = \exp\big(-(x-\mu_k)^2/(2\sigma^2)\big)$ 在每个 $\mu_k$ 处放一个基函数——如果 $\mu_k$ 取遍所有实数，$\boldsymbol{\phi}(x)$ 就是无穷维的。我们不可能显式地构造和存储它。

问题不是"要不要用高维特征"，而是"怎么算高维特征的内积而不显式构造它们"。 答案藏在算法的输入里：很多算法——岭回归、PCA、SVM——只通过内积 $\boldsymbol{\phi}(\mathbf{x}_i)^\top\boldsymbol{\phi}(\mathbf{x}_j)$ 与数据交互。 如果我们能直接算这个内积，就不需要知道 $\boldsymbol{\phi}$ 的坐标。

2. 核技巧：只算内积，不显式算 $\phi$

定义核函数（kernel function）：

$$k(\mathbf{x}, \mathbf{x}') = \boldsymbol{\phi}(\mathbf{x})^\top\boldsymbol{\phi}(\mathbf{x}')$$

核函数接受两个原始输入，直接返回它们在特征空间中的内积。核技巧（kernel trick）就是：设计算法时，把一切出现 $\boldsymbol{\phi}(\mathbf{x}_i)^\top\boldsymbol{\phi}(\mathbf{x}_j)$ 的地方替换成 $k(\mathbf{x}_i,\mathbf{x}_j)$，从而完全避免显式构造 $\boldsymbol{\phi}$。

看一个具体的例子来说明核技巧的威力。考虑二维输入 $\mathbf{x}=(x_1,x_2)$ 和一个二次多项式特征映射：

$$\boldsymbol{\phi}(\mathbf{x}) = (1,\; \sqrt{2}x_1,\; \sqrt{2}x_2,\; x_1^2,\; x_2^2,\; \sqrt{2}x_1x_2)^\top \in \mathbb{R}^6$$

直接算两个特征向量的内积：

核技巧演示

$\boldsymbol{\phi}(\mathbf{x})^\top\boldsymbol{\phi}(\mathbf{x}') = 1 + 2x_1x_1' + 2x_2x_2' + x_1^2x_1'^2 + x_2^2x_2'^2 + 2x_1x_2x_1'x_2'$ 展开 6 项内积
$= (1 + x_1x_1' + x_2x_2')^2 = (1 + \mathbf{x}^\top\mathbf{x}')^2$ 因式分解！
$\therefore k(\mathbf{x},\mathbf{x}') = (1 + \mathbf{x}^\top\mathbf{x}')^2$，计算复杂度 $O(D)$ 而非 $O(M)=O(D^2)$。

这里 $M=6$ 已经比 $D=2$ 大了，但核的计算只需 $O(D)$ 而非 $O(D^2)$。 对 $D=100$、$d=3$ 的多项式，$M\approx 176,\!851$，但核 $(1+\mathbf{x}^\top\mathbf{x}')^3$ 仍是 $O(D)$。 节省是天文数字级别的。

核技巧的本质：把"构造高维特征"的计算成本，转化为"设计一个能高效计算内积的函数"的设计成本。 我们不再问"用什么 $\boldsymbol{\phi}$"，而是问"用什么 $k$"——后者通常便宜得多。

但并非所有算法都能核化。能核化的算法必须满足一个条件：算法只通过内积与数据交互。岭回归、PCA、SVM 满足；原始形式的神经网络不满足（因为权重直接作用于特征）。

3. Mercer 定理：什么函数是合法核

给定一个二元函数 $k(\mathbf{x},\mathbf{x}')$，怎么知道它对应某个特征映射 $\boldsymbol{\phi}$？ 换句话说，什么函数是合法核？

答案由 Mercer 定理（Mercer's theorem）给出。先定义 Gram 矩阵：

$$\mathbf{K}_{ij} = k(\mathbf{x}_i, \mathbf{x}_j) \quad \text{对数据集 } \{\mathbf{x}_n\}_{n=1}^N$$

Mercer 定理（核版本）： 一个对称连续函数 $k: \mathcal{X}\times\mathcal{X}\to\mathbb{R}$ 是合法核（即存在某个 Hilbert 空间 $\mathcal{H}$ 和特征映射 $\boldsymbol{\phi}: \mathcal{X}\to\mathcal{H}$ 使得 $k(\mathbf{x},\mathbf{x}') = \langle\boldsymbol{\phi}(\mathbf{x}), \boldsymbol{\phi}(\mathbf{x}')\rangle_{\mathcal{H}}$）当且仅当对任意有限点集 $\{\mathbf{x}_n\}_{n=1}^N$，Gram 矩阵 $\mathbf{K}$ 是对称半正定（positive semidefinite）的：

$$\mathbf{K} \succeq 0 \quad\Longleftrightarrow\quad \forall\,\mathbf{c}\in\mathbb{R}^N,\; \mathbf{c}^\top\mathbf{K}\mathbf{c} \geq 0$$
Mercer 定理说：核的合法性等价于 Gram 矩阵处处半正定。 这是一个可验证的条件——你不需要找到 $\boldsymbol{\phi}$，只需要检查所有可能的 Gram 矩阵是否半正定。 实践中我们通常从已知合法核构造新核，而不是从头验证。

从已知合法核构造新核的几个重要性质（证明见推导题）：

  • 和： 若 $k_1, k_2$ 是合法核，则 $k(\mathbf{x},\mathbf{x}') = k_1(\mathbf{x},\mathbf{x}') + k_2(\mathbf{x},\mathbf{x}')$ 是合法核。
  • 数乘： 若 $k$ 是合法核，$c\geq 0$，则 $c\,k$ 是合法核。
  • 积： 若 $k_1, k_2$ 是合法核，则 $k(\mathbf{x},\mathbf{x}') = k_1(\mathbf{x},\mathbf{x}')\,k_2(\mathbf{x},\mathbf{x}')$ 是合法核（Schur 积定理）。
  • 多项式： 若 $k$ 是合法核，$p(\cdot)$ 是非负系数多项式，则 $p(k)$ 是合法核。
  • 指数： 若 $k$ 是合法核，则 $\exp(k)$ 是合法核（由指数函数的幂级数展开和积的封闭性保证）。

这些性质让我们可以放心地构造复杂核，而不必每次都验证半正定性。

4. 常见核：多项式核、RBF 核与对应特征映射

4.1 多项式核

$$k(\mathbf{x},\mathbf{x}') = (\mathbf{x}^\top\mathbf{x}' + c)^d, \qquad c \geq 0,\; d \in \mathbb{N}$$

对应特征映射包含所有次数 $\leq d$ 的单项式（monomials），每个单项式带一个系数权重。 当 $c=0$ 时只含 $d$ 次单项式；$c>0$ 时包含 $0$ 到 $d$ 次的所有单项式。 特征空间维度 $M = \binom{D+d}{d}$，但核计算只需 $O(D)$。

4.2 RBF 核（高斯核）

$$k(\mathbf{x},\mathbf{x}') = \exp\!\left(-\frac{\|\mathbf{x}-\mathbf{x}'\|^2}{2\sigma^2}\right)$$

RBF 核（Radial Basis Function kernel）也叫高斯核。它对应无穷维特征映射。 为什么？把指数展开：

RBF 核的无穷级数展开

$k(\mathbf{x},\mathbf{x}') = \exp\!\left(-\frac{\|\mathbf{x}\|^2}{2\sigma^2}\right) \exp\!\left(\frac{\mathbf{x}^\top\mathbf{x}'}{\sigma^2}\right) \exp\!\left(-\frac{\|\mathbf{x}'\|^2}{2\sigma^2}\right)$ 展开平方 $\|\mathbf{x}-\mathbf{x}'\|^2 = \|\mathbf{x}\|^2 - 2\mathbf{x}^\top\mathbf{x}' + \|\mathbf{x}'\|^2$
$= \exp\!\left(-\frac{\|\mathbf{x}\|^2}{2\sigma^2}\right) \left(\sum_{m=0}^\infty \frac{(\mathbf{x}^\top\mathbf{x}'/\sigma^2)^m}{m!}\right) \exp\!\left(-\frac{\|\mathbf{x}'\|^2}{2\sigma^2}\right)$ $\exp(\cdot)$ 的泰勒展开
每一项 $(\mathbf{x}^\top\mathbf{x}')^m$ 是 $m$ 次多项式核，对应有限维特征。无穷项求和 $\Rightarrow$ 无穷维特征空间。

RBF 核有一个直观的性质：$k(\mathbf{x},\mathbf{x}')$ 只取决于两点间的欧氏距离 $\|\mathbf{x}-\mathbf{x}'\|$。 距离越近，核值越大（接近 1）；距离越远，核值趋近 0。 $\sigma$ 控制"多近算近"：$\sigma$ 小，核值随距离快速衰减（每个点只影响附近极小的区域）；$\sigma$ 大，影响范围广。

RBF 核的 $\sigma$ 是超参数中最重要的之一： $\sigma$ 太小 $\rightarrow$ 核矩阵接近单位阵 $\rightarrow$ 每个点只"看"到自己 $\rightarrow$ 严重过拟合； $\sigma$ 太大 $\rightarrow$ 核矩阵接近全 1 矩阵 $\rightarrow$ 所有点都"一样" $\rightarrow$ 严重欠拟合。 交叉验证选 $\sigma$ 是标准做法。

5. 表示定理：解在数据张成的子空间里

现在我们有核函数 $k$，但原始算法（如岭回归）的参数 $\mathbf{w}$ 仍在特征空间中。 如果特征空间是无穷维的，$\mathbf{w}$ 也是无穷维的——我们怎么表示它？

表示定理（representer theorem）给出答案：对一大类正则化风险最小化问题，最优解 $\mathbf{w}$ 可以写成训练数据的线性组合。

考虑正则化风险泛函：

$$\mathcal{R}(\mathbf{w}) = \sum_{n=1}^N L\big(y_n, \mathbf{w}^\top\boldsymbol{\phi}(\mathbf{x}_n)\big) + \lambda\, g(\|\mathbf{w}\|)$$

其中 $L$ 是损失函数，$g(\cdot)$ 是严格单调递增的正则化项（如 $g(t)=t^2$ 对应 L2 正则）。

表示定理： 上述风险泛函的最优解 $\mathbf{w}^*$ 可以表示为

$$\mathbf{w}^* = \sum_{n=1}^N \alpha_n \boldsymbol{\phi}(\mathbf{x}_n)$$

即 $\mathbf{w}^*$ 落在数据 $\{\boldsymbol{\phi}(\mathbf{x}_n)\}$ 张成的子空间里。

表示定理的意义： 即使特征空间是无穷维的，最优 $\mathbf{w}$ 也只在一个 $N$ 维子空间里。 我们只需要 $N$ 个系数 $\alpha_n$ 来描述它——把无穷维问题降到了 $N$ 维。 这是核方法能工作的根本保证。

证明思路（见推导题 5）：把 $\mathbf{w}$ 分解为平行于数据子空间的分量 $\mathbf{w}_\parallel$ 和垂直于它的分量 $\mathbf{w}_\perp$。 垂直分量不影响预测值（因为 $\boldsymbol{\phi}(\mathbf{x}_n)^\top\mathbf{w}_\perp = 0$），但增加 $\|\mathbf{w}\|$ 从而增加正则化项。 所以最优解必有 $\mathbf{w}_\perp = \mathbf{0}$。

🔗 推导范式 #7 · 表示定理——"正则化把解压进数据张成的子空间"

任何形如 $\min_\mathbf{w}\;\text{loss}(\langle\mathbf{w},\boldsymbol{\phi}(\mathbf{x}_n)\rangle,y_n)+\lambda\|\mathbf{w}\|^2$ 的问题，最优 $\mathbf{w}=\sum_n\alpha_n\boldsymbol{\phi}(\mathbf{x}_n)$。 证明骨架永远是：分解 $\mathbf{w}=\mathbf{w}_\parallel+\mathbf{w}_\perp$，垂直分量不进 loss（内积为 0）却进正则项（$\|\mathbf{w}\|^2$ 变大）→ 最优必 $\mathbf{w}_\perp=0$。 0007/0008 SVM 的对偶、0011 核 PCA、0015 高斯过程回归——全是这一招的对偶化。 它是"为什么核技巧合法"的根基：解只活在 $N$ 维，所以只需 $N\times N$ 核矩阵，无穷维特征空间永不显式出现。

6. 核岭回归：把岭回归核化

现在把基石 0001 §3 的岭回归核化，作为核方法的完整例子。

原始岭回归（在特征空间中）：

$$\min_{\mathbf{w}} \;\sum_{n=1}^N \big(y_n - \mathbf{w}^\top\boldsymbol{\phi}(\mathbf{x}_n)\big)^2 + \lambda \|\mathbf{w}\|^2$$

由表示定理，$\mathbf{w} = \sum_{n=1}^N \alpha_n \boldsymbol{\phi}(\mathbf{x}_n) = \boldsymbol{\Phi}^\top\boldsymbol{\alpha}$，其中 $\boldsymbol{\Phi}\in\mathbb{R}^{N\times M}$ 是设计矩阵，$\boldsymbol{\alpha}\in\mathbb{R}^N$。

代入目标函数：

核岭回归推导

$\mathbf{w}^\top\boldsymbol{\phi}(\mathbf{x}_n) = \big(\sum_m \alpha_m \boldsymbol{\phi}(\mathbf{x}_m)\big)^\top\boldsymbol{\phi}(\mathbf{x}_n) = \sum_m \alpha_m k(\mathbf{x}_m, \mathbf{x}_n) = \mathbf{K}_{n,:}\boldsymbol{\alpha}$ 用核代替内积
$\|\mathbf{w}\|^2 = \boldsymbol{\alpha}^\top\boldsymbol{\Phi}\boldsymbol{\Phi}^\top\boldsymbol{\alpha} = \boldsymbol{\alpha}^\top\mathbf{K}\boldsymbol{\alpha}$ $\|\boldsymbol{\Phi}^\top\boldsymbol{\alpha}\|^2 = \boldsymbol{\alpha}^\top\boldsymbol{\Phi}\boldsymbol{\Phi}^\top\boldsymbol{\alpha} = \boldsymbol{\alpha}^\top\mathbf{K}\boldsymbol{\alpha}$
目标函数：$\mathcal{J}(\boldsymbol{\alpha}) = \|\mathbf{y} - \mathbf{K}\boldsymbol{\alpha}\|^2 + \lambda \boldsymbol{\alpha}^\top\mathbf{K}\boldsymbol{\alpha}$ 预测向量是 $\mathbf{K}\boldsymbol{\alpha}$
对 $\boldsymbol{\alpha}$ 求梯度令为零：$-\mathbf{K}(\mathbf{y} - \mathbf{K}\boldsymbol{\alpha}) + \lambda\mathbf{K}\boldsymbol{\alpha} = \mathbf{0}$ $\nabla_{\boldsymbol{\alpha}}\|\mathbf{y}-\mathbf{K}\boldsymbol{\alpha}\|^2 = -2\mathbf{K}^\top(\mathbf{y}-\mathbf{K}\boldsymbol{\alpha})$
$\mathbf{K}(\mathbf{K} + \lambda\mathbf{I})\boldsymbol{\alpha} = \mathbf{K}\mathbf{y}$，两边左乘 $\mathbf{K}^{-1}$（假设 $\mathbf{K}$ 可逆）得 $\boxed{\;\boldsymbol{\alpha} = (\mathbf{K} + \lambda\mathbf{I})^{-1}\mathbf{y}\;}$ 核岭回归的闭式解

对新点 $\mathbf{x}_\ast$ 的预测：

$$f(\mathbf{x}_\ast) = \mathbf{w}^\top\boldsymbol{\phi}(\mathbf{x}_\ast) = \sum_{n=1}^N \alpha_n k(\mathbf{x}_n, \mathbf{x}_\ast) = \mathbf{k}_\ast^\top (\mathbf{K} + \lambda\mathbf{I})^{-1}\mathbf{y}$$

其中 $\mathbf{k}_\ast$ 是 $N$ 维向量，$(\mathbf{k}_\ast)_n = k(\mathbf{x}_n, \mathbf{x}_\ast)$。

对比原始岭回归和核岭回归：
原始：$\mathbf{w} = (\boldsymbol{\Phi}^\top\boldsymbol{\Phi} + \lambda\mathbf{I})^{-1}\boldsymbol{\Phi}^\top\mathbf{y}$，复杂度 $O(M^3 + M^2N)$。
核化：$\boldsymbol{\alpha} = (\mathbf{K} + \lambda\mathbf{I})^{-1}\mathbf{y}$，复杂度 $O(N^3)$。
当 $M \gg N$（高维特征、少样本）时，核版本从 $O(M^3)$ 降到 $O(N^3)$——巨大节省。
当 $N \gg M$（多样本、低维特征）时，原始版本更优。选择取决于 $M$ 和 $N$ 的相对大小。

7. 推导与演算

下面 6 道题，难度递增。先自己做，做不出再看提示，做完再对解答。

题 1 · RBF 核的无穷级数展开 L1 · 基础
证明 RBF 核 $k(\mathbf{x},\mathbf{x}') = \exp(-\|\mathbf{x}-\mathbf{x}'\|^2/(2\sigma^2))$ 可以展开为无穷级数，其中每一项是多项式核的常数倍。由此说明 RBF 核对应无穷维特征映射。
提示
展开 $\|\mathbf{x}-\mathbf{x}'\|^2 = \|\mathbf{x}\|^2 - 2\mathbf{x}^\top\mathbf{x}' + \|\mathbf{x}'\|^2$，分离出与 $\mathbf{x}$ 和 $\mathbf{x}'$ 分别相关的因子，然后对 $\exp(\mathbf{x}^\top\mathbf{x}'/\sigma^2)$ 做泰勒展开。
解答
$k(\mathbf{x},\mathbf{x}') = \exp\!\left(-\frac{\|\mathbf{x}\|^2}{2\sigma^2}\right) \exp\!\left(\frac{\mathbf{x}^\top\mathbf{x}'}{\sigma^2}\right) \exp\!\left(-\frac{\|\mathbf{x}'\|^2}{2\sigma^2}\right)$
对中间项泰勒展开：$\exp\!\left(\frac{\mathbf{x}^\top\mathbf{x}'}{\sigma^2}\right) = \sum_{m=0}^\infty \frac{(\mathbf{x}^\top\mathbf{x}')^m}{m!\,\sigma^{2m}}$
所以 $k(\mathbf{x},\mathbf{x}') = \sum_{m=0}^\infty \frac{1}{m!\,\sigma^{2m}} \exp\!\left(-\frac{\|\mathbf{x}\|^2}{2\sigma^2}\right) (\mathbf{x}^\top\mathbf{x}')^m \exp\!\left(-\frac{\|\mathbf{x}'\|^2}{2\sigma^2}\right)$
令 $\psi_m(\mathbf{x}) = \frac{1}{\sqrt{m!}\,\sigma^m} \exp\!\left(-\frac{\|\mathbf{x}\|^2}{2\sigma^2}\right) \mathbf{x}^{\otimes m}$（其中 $\mathbf{x}^{\otimes m}$ 是 $m$ 阶张量积，包含所有 $m$ 次单项式），则 $k(\mathbf{x},\mathbf{x}') = \sum_{m=0}^\infty \psi_m(\mathbf{x})^\top \psi_m(\mathbf{x}')$。
这是无穷个特征函数的和，每个 $\psi_m$ 对应 $m$ 次多项式核的特征映射。因此 RBF 核对应无穷维特征空间。$\square$
题 2 · 核的和保持半正定性 L1 · 基础
设 $k_1$ 和 $k_2$ 是合法核（即对任意有限点集，对应的 Gram 矩阵半正定）。证明 $k(\mathbf{x},\mathbf{x}') = k_1(\mathbf{x},\mathbf{x}') + k_2(\mathbf{x},\mathbf{x}')$ 也是合法核。
提示
对任意 $\mathbf{c}\in\mathbb{R}^N$，写出 $\mathbf{c}^\top\mathbf{K}\mathbf{c}$ 并拆成两项之和。
解答
对任意数据集 $\{\mathbf{x}_n\}_{n=1}^N$，设 $\mathbf{K}_1$ 和 $\mathbf{K}_2$ 分别是 $k_1$ 和 $k_2$ 的 Gram 矩阵，$\mathbf{K} = \mathbf{K}_1 + \mathbf{K}_2$。
对任意 $\mathbf{c}\in\mathbb{R}^N$：$\mathbf{c}^\top\mathbf{K}\mathbf{c} = \mathbf{c}^\top(\mathbf{K}_1 + \mathbf{K}_2)\mathbf{c} = \mathbf{c}^\top\mathbf{K}_1\mathbf{c} + \mathbf{c}^\top\mathbf{K}_2\mathbf{c}$。
因为 $k_1, k_2$ 是合法核，$\mathbf{K}_1 \succeq 0$ 且 $\mathbf{K}_2 \succeq 0$，所以 $\mathbf{c}^\top\mathbf{K}_1\mathbf{c} \geq 0$ 且 $\mathbf{c}^\top\mathbf{K}_2\mathbf{c} \geq 0$。
因此 $\mathbf{c}^\top\mathbf{K}\mathbf{c} \geq 0$ 对任意 $\mathbf{c}$ 成立，即 $\mathbf{K} \succeq 0$。由 Mercer 定理，$k$ 是合法核。$\square$
题 3 · 核的逐点积保持半正定性（Schur 积定理） L2 · 理解
设 $k_1$ 和 $k_2$ 是合法核。证明 $k(\mathbf{x},\mathbf{x}') = k_1(\mathbf{x},\mathbf{x}')\,k_2(\mathbf{x},\mathbf{x}')$ 也是合法核。
提示：利用 Schur 积定理（Hadamard 积定理）：若 $\mathbf{A}, \mathbf{B} \succeq 0$，则它们的逐元素积 $\mathbf{A} \odot \mathbf{B}$ 也 $\succeq 0$。再结合核的 Gram 矩阵定义。
提示
$k$ 的 Gram 矩阵 $\mathbf{K}$ 满足 $\mathbf{K}_{ij} = (\mathbf{K}_1)_{ij}(\mathbf{K}_2)_{ij}$，即 $\mathbf{K} = \mathbf{K}_1 \odot \mathbf{K}_2$。Schur 积定理保证半正定矩阵的 Hadamard 积仍半正定。
解答
对任意数据集 $\{\mathbf{x}_n\}$，记 $\mathbf{K}_1, \mathbf{K}_2$ 为 $k_1, k_2$ 的 Gram 矩阵。$k$ 的 Gram 矩阵 $\mathbf{K}_{ij} = k_1(\mathbf{x}_i,\mathbf{x}_j) k_2(\mathbf{x}_i,\mathbf{x}_j) = (\mathbf{K}_1)_{ij}(\mathbf{K}_2)_{ij}$，即 $\mathbf{K} = \mathbf{K}_1 \odot \mathbf{K}_2$（Hadamard 积）。
因为 $k_1, k_2$ 是合法核，$\mathbf{K}_1 \succeq 0$ 且 $\mathbf{K}_2 \succeq 0$。
Schur 积定理：对任意半正定矩阵 $\mathbf{A}, \mathbf{B}$，它们的 Hadamard 积 $\mathbf{A} \odot \mathbf{B}$ 也半正定。
证明思路（不要求掌握全部细节）：半正定矩阵 $\mathbf{A}$ 可写为 $\mathbf{A} = \sum_i \mathbf{a}_i \mathbf{a}_i^\top$（特征分解）。则 $(\mathbf{A} \odot \mathbf{B})_{ij} = A_{ij}B_{ij} = \sum_{p,q} (\mathbf{a}_p)_i(\mathbf{a}_p)_j (\mathbf{b}_q)_i(\mathbf{b}_q)_j$。令 $\mathbf{c}_{pq}$ 为 $(\mathbf{c}_{pq})_i = (\mathbf{a}_p)_i(\mathbf{b}_q)_i$，则 $\mathbf{A} \odot \mathbf{B} = \sum_{p,q} \mathbf{c}_{pq}\mathbf{c}_{pq}^\top$，是半正定矩阵的和，故半正定。
因此 $\mathbf{K} = \mathbf{K}_1 \odot \mathbf{K}_2 \succeq 0$，$k$ 是合法核。$\square$
题 4 · 核岭回归解的推导 L2 · 理解
从岭回归目标 $\min_{\mathbf{w}} \sum_{n=1}^N (y_n - \mathbf{w}^\top\boldsymbol{\phi}(\mathbf{x}_n))^2 + \lambda\|\mathbf{w}\|^2$ 出发，利用表示定理 $\mathbf{w} = \boldsymbol{\Phi}^\top\boldsymbol{\alpha}$，完整推导核岭回归的解 $\boldsymbol{\alpha} = (\mathbf{K} + \lambda\mathbf{I})^{-1}\mathbf{y}$ 和预测 $f(\mathbf{x}_\ast) = \sum_n \alpha_n k(\mathbf{x}_n, \mathbf{x}_\ast)$。
提示
先写出 $\mathbf{w}^\top\boldsymbol{\phi}(\mathbf{x}_n)$ 用 $\boldsymbol{\alpha}$ 和核表示，再写出 $\|\mathbf{w}\|^2$ 用 $\boldsymbol{\alpha}$ 和 $\mathbf{K}$ 表示。对 $\boldsymbol{\alpha}$ 求梯度时注意 $\mathbf{K}$ 是对称的。
解答
设 $\mathbf{w} = \boldsymbol{\Phi}^\top\boldsymbol{\alpha}$，其中 $\boldsymbol{\Phi} \in \mathbb{R}^{N\times M}$ 第 $n$ 行为 $\boldsymbol{\phi}(\mathbf{x}_n)^\top$。
预测向量：$\boldsymbol{\Phi}\mathbf{w} = \boldsymbol{\Phi}\boldsymbol{\Phi}^\top\boldsymbol{\alpha} = \mathbf{K}\boldsymbol{\alpha}$。
正则项：$\|\mathbf{w}\|^2 = \boldsymbol{\alpha}^\top\boldsymbol{\Phi}\boldsymbol{\Phi}^\top\boldsymbol{\alpha} = \boldsymbol{\alpha}^\top\mathbf{K}\boldsymbol{\alpha}$。
目标：$\mathcal{J}(\boldsymbol{\alpha}) = \|\mathbf{y} - \mathbf{K}\boldsymbol{\alpha}\|^2 + \lambda \boldsymbol{\alpha}^\top\mathbf{K}\boldsymbol{\alpha}$
$= \mathbf{y}^\top\mathbf{y} - 2\boldsymbol{\alpha}^\top\mathbf{K}\mathbf{y} + \boldsymbol{\alpha}^\top\mathbf{K}^2\boldsymbol{\alpha} + \lambda \boldsymbol{\alpha}^\top\mathbf{K}\boldsymbol{\alpha}$
对 $\boldsymbol{\alpha}$ 求梯度：$\nabla_{\boldsymbol{\alpha}}\mathcal{J} = -2\mathbf{K}\mathbf{y} + 2\mathbf{K}^2\boldsymbol{\alpha} + 2\lambda\mathbf{K}\boldsymbol{\alpha}$
令为零：$\mathbf{K}^2\boldsymbol{\alpha} + \lambda\mathbf{K}\boldsymbol{\alpha} = \mathbf{K}\mathbf{y}$，即 $\mathbf{K}(\mathbf{K} + \lambda\mathbf{I})\boldsymbol{\alpha} = \mathbf{K}\mathbf{y}$
假设 $\mathbf{K}$ 可逆（$\lambda>0$ 时 $\mathbf{K}+\lambda\mathbf{I}$ 总是可逆），左乘 $\mathbf{K}^{-1}$：$(\mathbf{K} + \lambda\mathbf{I})\boldsymbol{\alpha} = \mathbf{y}$
$\therefore \boldsymbol{\alpha} = (\mathbf{K} + \lambda\mathbf{I})^{-1}\mathbf{y}$
预测：$f(\mathbf{x}_\ast) = \mathbf{w}^\top\boldsymbol{\phi}(\mathbf{x}_\ast) = \boldsymbol{\alpha}^\top\boldsymbol{\Phi}\boldsymbol{\phi}(\mathbf{x}_\ast) = \sum_{n=1}^N \alpha_n k(\mathbf{x}_n, \mathbf{x}_\ast)$。$\square$
题 5 · 表示定理的证明 L3 · 进阶
考虑正则化风险泛函 $\mathcal{R}(\mathbf{w}) = \sum_{n=1}^N L(y_n, \mathbf{w}^\top\boldsymbol{\phi}(\mathbf{x}_n)) + \lambda\, g(\|\mathbf{w}\|)$，其中 $g(\cdot)$ 是严格单调递增函数。证明最优解 $\mathbf{w}^*$ 可以表示为 $\mathbf{w}^* = \sum_{n=1}^N \alpha_n \boldsymbol{\phi}(\mathbf{x}_n)$。
提示：将 $\mathbf{w}$ 分解为 $\mathbf{w} = \mathbf{w}_\parallel + \mathbf{w}_\perp$，其中 $\mathbf{w}_\parallel$ 在 $\{\boldsymbol{\phi}(\mathbf{x}_n)\}$ 张成的子空间中，$\mathbf{w}_\perp$ 正交于该子空间。比较 $\mathcal{R}(\mathbf{w})$ 和 $\mathcal{R}(\mathbf{w}_\parallel)$。
提示
对任意 $\mathbf{w}$，$\mathbf{w}_\perp^\top\boldsymbol{\phi}(\mathbf{x}_n)=0$ 对所有 $n$ 成立（因为 $\mathbf{w}_\perp$ 正交于所有 $\boldsymbol{\phi}(\mathbf{x}_n)$）。所以 $\mathbf{w}^\top\boldsymbol{\phi}(\mathbf{x}_n) = \mathbf{w}_\parallel^\top\boldsymbol{\phi}(\mathbf{x}_n)$——预测值不变。但 $\|\mathbf{w}\|^2 = \|\mathbf{w}_\parallel\|^2 + \|\mathbf{w}_\perp\|^2 \geq \|\mathbf{w}_\parallel\|^2$，所以 $\mathcal{R}(\mathbf{w}) \geq \mathcal{R}(\mathbf{w}_\parallel)$，等号仅当 $\mathbf{w}_\perp = \mathbf{0}$。
解答
令 $S = \operatorname{span}\{\boldsymbol{\phi}(\mathbf{x}_1), \dots, \boldsymbol{\phi}(\mathbf{x}_N)\}$ 为数据张成的子空间。对任意 $\mathbf{w}$，做正交分解 $\mathbf{w} = \mathbf{w}_\parallel + \mathbf{w}_\perp$，其中 $\mathbf{w}_\parallel \in S$，$\mathbf{w}_\perp \perp S$。
预测值不变：因为 $\mathbf{w}_\perp \perp S$，所以 $\mathbf{w}_\perp^\top\boldsymbol{\phi}(\mathbf{x}_n) = 0$ 对所有 $n$ 成立。因此 $\mathbf{w}^\top\boldsymbol{\phi}(\mathbf{x}_n) = \mathbf{w}_\parallel^\top\boldsymbol{\phi}(\mathbf{x}_n)$。损失项 $L$ 不变。
正则项增大：$\|\mathbf{w}\|^2 = \|\mathbf{w}_\parallel\|^2 + \|\mathbf{w}_\perp\|^2 \geq \|\mathbf{w}_\parallel\|^2$，等号仅当 $\mathbf{w}_\perp = \mathbf{0}$。因为 $g$ 严格单调递增，$g(\|\mathbf{w}\|) \geq g(\|\mathbf{w}_\parallel\|)$。
因此 $\mathcal{R}(\mathbf{w}) = \sum_n L(y_n, \mathbf{w}_\parallel^\top\boldsymbol{\phi}(\mathbf{x}_n)) + \lambda g(\|\mathbf{w}\|) \geq \sum_n L(y_n, \mathbf{w}_\parallel^\top\boldsymbol{\phi}(\mathbf{x}_n)) + \lambda g(\|\mathbf{w}_\parallel\|) = \mathcal{R}(\mathbf{w}_\parallel)$。
等号成立当且仅当 $\mathbf{w}_\perp = \mathbf{0}$，即 $\mathbf{w} = \mathbf{w}_\parallel \in S$。所以最优解 $\mathbf{w}^*$ 必在 $S$ 中，可表示为 $\mathbf{w}^* = \sum_{n=1}^N \alpha_n \boldsymbol{\phi}(\mathbf{x}_n)$。$\square$
关键洞察：垂直分量 $\mathbf{w}_\perp$ 对拟合数据毫无贡献（预测值不变），却要承受正则化惩罚——所以最优解一定把它设为零。这就是"表示定理"的几何本质。
题 6 · 多项式核的显式特征映射 L3 · 进阶
考虑二维输入 $\mathbf{x} = (x_1, x_2) \in \mathbb{R}^2$ 和二次多项式核 $k(\mathbf{x},\mathbf{x}') = (\mathbf{x}^\top\mathbf{x}')^2$。写出对应的特征映射 $\boldsymbol{\phi}(\mathbf{x})$（显式列出所有分量），数出特征维度，并说明当输入维度 $D$ 和次数 $d$ 增大时维度如何组合爆炸。
提示
展开 $(\mathbf{x}^\top\mathbf{x}')^2 = (x_1x_1' + x_2x_2')^2 = x_1^2x_1'^2 + 2x_1x_2x_1'x_2' + x_2^2x_2'^2$。每个乘积项对应一个特征分量。注意系数 $\sqrt{2}$ 的来历：$2x_1x_2x_1'x_2' = (\sqrt{2}x_1x_2)(\sqrt{2}x_1'x_2')$。
解答
展开：$(\mathbf{x}^\top\mathbf{x}')^2 = (x_1x_1' + x_2x_2')^2 = x_1^2x_1'^2 + 2x_1x_2x_1'x_2' + x_2^2x_2'^2$
写成内积形式 $\boldsymbol{\phi}(\mathbf{x})^\top\boldsymbol{\phi}(\mathbf{x}')$：
$\boldsymbol{\phi}(\mathbf{x}) = (x_1^2,\; \sqrt{2}\,x_1x_2,\; x_2^2)^\top \in \mathbb{R}^3$
验证：$\boldsymbol{\phi}(\mathbf{x})^\top\boldsymbol{\phi}(\mathbf{x}') = x_1^2x_1'^2 + 2x_1x_2x_1'x_2' + x_2^2x_2'^2 = (\mathbf{x}^\top\mathbf{x}')^2$ ✓
维度：二维输入、二次核的特征维度是 $3 = \binom{2+2}{2} - 1$（不含常数项）。一般地，$D$ 维输入、$d$ 次多项式核 $(\mathbf{x}^\top\mathbf{x}')^d$ 的特征维度是 $\binom{D+d}{d}$（含常数项时 $\binom{D+d}{d}$，不含时 $\binom{D+d}{d} - 1$）。
数值例子：$D=100$，$d=3$ 时 $\binom{103}{3} = 176,\!851$；$d=4$ 时 $\binom{104}{4} \approx 4.6\times 10^6$；$d=5$ 时 $\binom{105}{5} \approx 9.6\times 10^7$。这就是组合爆炸。核技巧 $(1+\mathbf{x}^\top\mathbf{x}')^d$ 的计算始终是 $O(D)$，与 $d$ 无关（忽略常数因子）。

8. 自测

Q1 · 核技巧的核心思想是什么？
答案
核技巧的核心是：很多算法只需要特征空间中数据点之间的内积 $\boldsymbol{\phi}(\mathbf{x}_i)^\top\boldsymbol{\phi}(\mathbf{x}_j)$，而不需要特征向量 $\boldsymbol{\phi}(\mathbf{x})$ 本身的坐标。通过定义核函数 $k(\mathbf{x}_i,\mathbf{x}_j) = \boldsymbol{\phi}(\mathbf{x}_i)^\top\boldsymbol{\phi}(\mathbf{x}_j)$ 并直接计算它，可以避免显式构造高维（甚至无穷维）特征映射，大幅降低计算复杂度。
Q2 · Mercer 定理说一个函数是合法核的充要条件是什么？
答案
对称连续函数 $k$ 是合法核当且仅当对任意有限点集，其 Gram 矩阵 $\mathbf{K}_{ij}=k(\mathbf{x}_i,\mathbf{x}_j)$ 是半正定的（$\mathbf{c}^\top\mathbf{K}\mathbf{c} \geq 0$ 对所有 $\mathbf{c}\in\mathbb{R}^N$ 成立）。等价地，$k$ 对应某个特征空间中的内积。
Q3 · 表示定理为什么重要？它如何把无穷维问题降到有限维？
答案
表示定理说：对一大类正则化风险最小化问题，最优解 $\mathbf{w}^*$ 落在训练数据 $\{\boldsymbol{\phi}(\mathbf{x}_n)\}$ 张成的子空间里。即使特征空间是无穷维的，这个子空间最多 $N$ 维（$N$ 是样本数）。因此我们只需要 $N$ 个系数 $\alpha_n$ 来描述 $\mathbf{w}^* = \sum_n \alpha_n \boldsymbol{\phi}(\mathbf{x}_n)$，把无穷维优化问题降到了 $N$ 维。证明的关键：$\mathbf{w}$ 的垂直分量不影响预测但增加正则惩罚，故最优时必为零。
Q4 · 核岭回归 $\boldsymbol{\alpha} = (\mathbf{K} + \lambda\mathbf{I})^{-1}\mathbf{y}$ 中，$\lambda$ 的作用是什么？和原始岭回归的 $\lambda$ 有何对应关系？
答案
$\lambda$ 控制正则化强度。在核岭回归中，$\lambda$ 加在 Gram 矩阵 $\mathbf{K}$ 的对角线上，保证 $\mathbf{K}+\lambda\mathbf{I}$ 可逆（即使 $\mathbf{K}$ 本身奇异）。这和原始岭回归中 $\lambda$ 加在 $\boldsymbol{\Phi}^\top\boldsymbol{\Phi}$ 对角线上完全对应——两者都是对权重 $\mathbf{w}$ 的 L2 惩罚。$\lambda$ 越大，解越"平滑"（系数 $\boldsymbol{\alpha}$ 的范数越小）；$\lambda$ 越小，解越"贴合"训练数据。当 $\lambda \to 0$ 且 $\mathbf{K}$ 可逆时，$\boldsymbol{\alpha} = \mathbf{K}^{-1}\mathbf{y}$ 给出零训练误差的插值解。
