1. 故事的起点：一个生成假设

给定数据 $\{(\mathbf{x}_n, y_n)\}_{n=1}^N$，$\mathbf{x}_n \in \mathbb{R}^D$，$y_n \in \mathbb{R}$。 我们想用模型预测 $y$。整条逻辑链的起点不是"最小化误差"，而是一个关于数据是怎么来的假设：

$$y = \mathbf{w}^\top\boldsymbol{\phi}(\mathbf{x}) + \varepsilon, \qquad \varepsilon \sim \mathcal{N}(0, \sigma^2)$$

即：真实世界有一个确定性规律 $\mathbf{w}^\top\boldsymbol{\phi}(\mathbf{x})$，我们观测到的是它加上一个高斯噪声。 这里 $\boldsymbol{\phi}(\mathbf{x})$ 是基函数向量，$\phi_0(\mathbf{x})=1$ 吸收偏置项。 取 $\boldsymbol{\phi}(\mathbf{x})=\mathbf{x}$ 就是普通线性回归；取 $\phi_j(x)=x^j$ 就是多项式回归； 取高斯基函数就是 RBF 回归。"线性回归"指的是对参数 $\mathbf{w}$ 线性，输入可以任意非线性变换—— 这一点记牢，后面核方法、GLM、神经网络都靠它。

为什么噪声取高斯？不只是"好算"。两个深层理由：

  1. 中心极限定理。噪声通常是大量独立微小扰动（测量误差、未建模因素……）的叠加。CLT 说这种和趋向高斯——高斯是"许多小扰动之和"的吸引子。
  2. 最大熵原理。只给定均值和方差时，高斯是熵最大的分布，假设得最少。用高斯等于声明："除了知道噪声均值 0、方差 $\sigma^2$，我对它一无所知。"

这两点让高斯成为缺省假设而非任意选择。当然它会失效——金融收益的厚尾就是反例，那时该换 Student-t 或拉普拉斯。换噪声分布就换一切，这是后面反复出现的主题。

等价地把假设写成条件分布：

$$p(y\mid\mathbf{x},\mathbf{w},\sigma^2) = \mathcal{N}(y\mid \mathbf{w}^\top\boldsymbol{\phi}(\mathbf{x}),\, \sigma^2)$$

2. 假设推出损失：为什么是平方

MLE

最大似然估计 · Maximum Likelihood Estimation

频率派 · Fisher
数学本质：参数 $\theta$ 是固定未知量（不是随机变量），在所有候选 $\theta$ 里挑让已观测数据出现概率最大的那个——"既然这份数据出现了，那它出现的概率应该不小"。

核心公式

$$\hat\theta_{\text{MLE}}=\arg\max_\theta\ p(\mathcal{D}\mid\theta)\;=\;\arg\max_\theta\ \log p(\mathcal{D}\mid\theta)$$

取 $\log$ 不改极值点，只把乘积 $\prod_n$ 变求和 $\sum_n$，好求导。似然 $p(\mathcal{D}\mid\theta)$ 是数据的概率看成 $\theta$ 的函数，不是"$\theta$ 的概率"。

三步流程

  • 建模型：写出 $p(\mathcal{D}\mid\theta)$（本课即假设高斯噪声）
  • 取对数：$\ell(\theta)=\log p(\mathcal{D}\mid\theta)$
  • 求极值：$\partial\ell/\partial\theta=0$ 解 $\hat\theta$
→ MAP：加先验 $p(\theta)$ 取众数 → 贝叶斯：求整个后验 $p(\theta\mid\mathcal{D})$ → 本课 §6：MLE ⟺ 最小化 KL 散度

假设数据 i.i.d.。把所有数据点的条件概率乘起来，得到似然函数—— 它是参数 $\mathbf{w}$ 的函数（数据固定），表达"如果参数是 $\mathbf{w}$，观察到这份数据的概率有多大"：

$$p(\mathbf{y}\mid\mathbf{X},\mathbf{w},\sigma^2) = \prod_{n=1}^N \mathcal{N}(y_n\mid \mathbf{w}^\top\boldsymbol{\phi}(\mathbf{x}_n),\, \sigma^2)$$

最大似然的原则是：选让数据概率最大的 $\mathbf{w}$。直接最大化这个乘积不好算—— $N$ 个小概率相乘会数值下溢，求导要用乘积法则反复展开。 取对数一举两得：单调变换不改变极值点，乘积变求和，求导变线性。

对数似然

$\displaystyle \log p = \sum_{n=1}^N \log \mathcal{N}(y_n\mid \mathbf{w}^\top\boldsymbol{\phi}(\mathbf{x}_n), \sigma^2)$ log 把 ∏ 变 ∑
$\displaystyle = -\frac{N}{2}\log(2\pi\sigma^2) - \frac{1}{2\sigma^2}\sum_{n=1}^N (y_n - \mathbf{w}^\top\boldsymbol{\phi}(\mathbf{x}_n))^2$ 代入高斯密度，拆出与 $\mathbf{w}$ 无关的常数项

关于 $\mathbf{w}$ 最大化。第一项与 $\mathbf{w}$ 无关，第二项前有负号，于是：

$$\arg\max_{\mathbf{w}}\; \log p \;=\; \arg\min_{\mathbf{w}}\; \sum_{n=1}^N (y_n - \mathbf{w}^\top\boldsymbol{\phi}(\mathbf{x}_n))^2$$
最小二乘不是设计出来的，是从高斯噪声假设里推出来的。 "平方"是高斯密度里那个 $(y-\mu)^2$ 的直接后果。 换噪声分布就换损失：拉普拉斯噪声 $\Rightarrow$ 绝对值损失（L1）；均匀噪声 $\Rightarrow$ 最大偏差型损失。 损失函数是噪声假设的影子。

注意一个细节：$\sigma^2$ 在整个推导里只是损失前面的一个正系数 $\frac{1}{2\sigma^2}$，不影响 $\mathbf{w}$ 的极值点位置。所以 $\mathbf{w}$ 的解与 $\sigma^2$ 无关——这点后面 GLM 还会用到。

3. 损失推出解：正规方程

范式

正规方程 · Normal Equation

闭式解 · 最小二乘解
数学本质：损失函数是 $\mathbf{w}$ 的二次型，梯度为零给出线性方程组——二次损失 + 线性模型 = 闭式解。

核心公式

$$\boxed{\;\mathbf{w}_{\text{ML}} = (\boldsymbol{\Phi}^\top\!\boldsymbol{\Phi})^{-1}\boldsymbol{\Phi}^\top\mathbf{y}\;}$$

$\boldsymbol{\Phi}^\top\!\boldsymbol{\Phi}$ 是 $M\times M$ Hessian，$\boldsymbol{\Phi}^\top\mathbf{y}$ 是参数-输出相关性向量。

三步推导

  1. 写损失：$\mathcal{L}=\frac{1}{2\sigma^2}\|\mathbf{y}-\boldsymbol{\Phi}\mathbf{w}\|^2$
  2. 求梯度：$\nabla_{\mathbf{w}}\mathcal{L} = -\frac{1}{\sigma^2}\boldsymbol{\Phi}^\top(\mathbf{y}-\boldsymbol{\Phi}\mathbf{w}) = \mathbf{0}$
  3. 解方程：$\boldsymbol{\Phi}^\top\boldsymbol{\Phi}\mathbf{w} = \boldsymbol{\Phi}^\top\mathbf{y}$
→ §4: 解即投影 → 0006: 核化 $\mathbf{w}=\boldsymbol{\Phi}^\top\boldsymbol{\alpha}$ → 0004(指数族): MLE 即矩匹配

把设计矩阵记作 $\boldsymbol{\Phi}\in\mathbb{R}^{N\times M}$（第 $n$ 行是 $\boldsymbol{\phi}(\mathbf{x}_n)^\top$），负对数似然写成矩阵形式：

$$\mathcal{L}(\mathbf{w}) = \frac{1}{2\sigma^2}\|\mathbf{y}-\boldsymbol{\Phi}\mathbf{w}\|^2 = \frac{1}{2\sigma^2}(\mathbf{y}-\boldsymbol{\Phi}\mathbf{w})^\top(\mathbf{y}-\boldsymbol{\Phi}\mathbf{w})$$

这是 $\mathbf{w}$ 的二次函数，求梯度令为零：

正规方程的推导

$\displaystyle \nabla_{\mathbf{w}}\mathcal{L} = \frac{1}{2\sigma^2}\nabla_{\mathbf{w}}\big(\mathbf{y}^\top\mathbf{y} - 2\mathbf{y}^\top\boldsymbol{\Phi}\mathbf{w} + \mathbf{w}^\top\boldsymbol{\Phi}^\top\boldsymbol{\Phi}\mathbf{w}\big)$ 展开平方，用 $\mathbf{a}^\top\mathbf{b}=\mathbf{b}^\top\mathbf{a}$
$\displaystyle = \frac{1}{\sigma^2}(-\boldsymbol{\Phi}^\top\mathbf{y} + \boldsymbol{\Phi}^\top\boldsymbol{\Phi}\mathbf{w})$ 用 $\nabla \mathbf{b}^\top\mathbf{x}=\mathbf{b}$，$\nabla \mathbf{x}^\top\mathbf{A}\mathbf{x}=2\mathbf{A}\mathbf{x}$（$\mathbf{A}$ 对称）
令其为 $\mathbf{0}$，得 正规方程 $\;\boldsymbol{\Phi}^\top\boldsymbol{\Phi}\,\mathbf{w} = \boldsymbol{\Phi}^\top\mathbf{y}$，解出 $\boxed{\;\mathbf{w}_{\text{ML}} = (\boldsymbol{\Phi}^\top\boldsymbol{\Phi})^{-1}\boldsymbol{\Phi}^\top\mathbf{y}\;}$

几个要点串起来：

  • 唯一全局最小。Hessian $\nabla^2_{\mathbf{w}}\mathcal{L}=\boldsymbol{\Phi}^\top\boldsymbol{\Phi}$ 半正定，列满秩时正定——所以这是凸优化，没有局部极值。线性回归"好算"的根源在此。
  • 可逆条件。$\boldsymbol{\Phi}^\top\boldsymbol{\Phi}$ 可逆要求 $\operatorname{rk}(\boldsymbol{\Phi})=M$，即 $N\geq M$ 且特征线性无关。多重共线性或 $M>N$ 时矩阵奇异，解不唯一——这正是过拟合的信号，也是正则化登场的时机。
  • 伪逆。$(\boldsymbol{\Phi}^\top\boldsymbol{\Phi})^{-1}\boldsymbol{\Phi}^\top$ 是 Moore–Penrose 伪逆在列满秩时的特例，把"逆"推广到非方阵。
  • 偏置的解。若显式写出偏置 $w_0$，令 $\partial\mathcal{L}/\partial w_0=0$ 得 $w_0 = \bar{y} - \sum_{j\geq1} w_j\bar{\phi}_j$——偏置补偿目标均值与基函数加权均值之差，所以回归线总穿过数据中心。
  • 数值实现别直接求逆。$(\boldsymbol{\Phi}^\top\boldsymbol{\Phi})^{-1}$ 条件数被平方，数值不稳定。工程上用 SVD 或 QR 分解。理解原理时写逆没问题，实现时别这么写。

4. 解的几何：正交投影

几何

正交投影 · Orthogonal Projection

Hat Matrix · 投影矩阵
正交投影：观测向量 y 被投影到设计矩阵 Φ 的列空间上。残差 y−ŷ 与列空间正交。
数学本质：$\hat{\mathbf{y}} = \mathbf{P}\mathbf{y}$，其中 $\mathbf{P} = \boldsymbol{\Phi}(\boldsymbol{\Phi}^\top\!\boldsymbol{\Phi})^{-1}\boldsymbol{\Phi}^\top$ 是到 $\boldsymbol{\Phi}$ 列空间的正交投影。$\mathbf{P}^2=\mathbf{P}$（幂等），残差与拟合值正交。

核心性质

  • $\operatorname{tr}(\mathbf{P}) = M$（投影到的维度 = 参数个数）
  • $\operatorname{tr}(\mathbf{I}-\mathbf{P}) = N-M$（→ 这就是 §5 $\sigma^2$ 偏差中 $N-M$ 的来源）
  • $\hat{\mathbf{y}} = \mathbf{P}\mathbf{y}$，残差 $\mathbf{y}-\hat{\mathbf{y}} = (\mathbf{I}-\mathbf{P})\mathbf{y}$
→ §5: $\mathbb{E}[\hat\sigma^2]=\frac{N-M}{N}\sigma^2$ → 0003: 边缘似然 = 贝叶斯版投影 → 0011: PCA = 低秩投影

正规方程 $\boldsymbol{\Phi}^\top(\mathbf{y}-\boldsymbol{\Phi}\mathbf{w})=\mathbf{0}$ 有一个一眼能看穿的几何含义。 把 $N$ 个目标值 $y_1,\dots,y_N$ 看成 $\mathbb{R}^N$ 里的向量 $\mathbf{y}$。 每个基函数在 $N$ 个数据点上的取值也是 $\mathbb{R}^N$ 里的向量，记作 $\boldsymbol{\varphi}_j$（即 $\boldsymbol{\Phi}$ 的第 $j$ 列）。 $M$ 个 $\boldsymbol{\varphi}_j$ 张成一个 $M$ 维子空间 $S$（当 $M

预测向量 $\boldsymbol{\Phi}\mathbf{w}$ 永远落在 $S$ 里。残差 $\mathbf{r}=\mathbf{y}-\boldsymbol{\Phi}\mathbf{w}$。 正规方程说的正是 $\boldsymbol{\Phi}^\top\mathbf{r}=\mathbf{0}$，即残差正交于 $S$ 的每一列。 而一个向量到子空间距离最近的点，恰是它在该子空间上的正交投影——这是欧氏几何的基本事实。

最小二乘解 = $\mathbf{y}$ 在列空间 $S=\operatorname{col}(\boldsymbol{\Phi})$ 上的正交投影。 $\mathbf{w}_{\text{ML}}$ 是这个投影在基 $\{\boldsymbol{\varphi}_j\}$ 下的坐标； 投影矩阵是 $\boldsymbol{\Phi}(\boldsymbol{\Phi}^\top\boldsymbol{\Phi})^{-1}\boldsymbol{\Phi}^\top$。 "最小化平方距离"和"正交投影"是同一件事的两个说法。

一个漂亮的推论：若基函数正交归一（$\boldsymbol{\Phi}^\top\boldsymbol{\Phi}=\mathbf{I}$，如 Fourier 基、小波基），投影退化为 $\sum_k \boldsymbol{\varphi}_k\boldsymbol{\varphi}_k^\top\mathbf{y}$——各特征完全解耦，每个系数独立计算。这是信号处理偏爱正交基的原因：没有"特征间耦合"，加一个基函数不影响已有系数。

非正交基时，$\boldsymbol{\Phi}^\top\boldsymbol{\Phi}$ 那个矩阵就是在处理基函数之间的耦合——它把"在斜基下求坐标"修正成"在正交意义下求投影"。Gram–Schmidt 可以把任意线性无关基正交化，本质上就是在消这个耦合。

5. 解的代价：σ² 被低估，过拟合

$\sigma^2$ 也能用 MLE 估。对对数似然求 $\partial/\partial\sigma^2$ 令为零，得 $\widehat{\sigma^2}_{\text{ML}} = \frac{1}{N}\|\mathbf{y}-\boldsymbol{\Phi}\mathbf{w}_{\text{ML}}\|^2$——残差平方的均值。 看起来自然，但它系统性低估真实 $\sigma^2$：

$$\mathbb{E}\big[\widehat{\sigma^2}_{\text{ML}}\big] = \frac{N-M}{N}\,\sigma^2 \;<\; \sigma^2$$

原因很具体：$\mathbf{w}_{\text{ML}}$ 是用同一份数据拟合出来的，它会"贴着"数据走，使残差比真实噪声小。 模型用掉 $M$ 个参数去解释数据，残差里只剩 $N-M$ 个独立信息——自由度从 $N$ 降到 $N-M$。 无偏修正版除以 $N-M$ 而非 $N$。

▸ 展开 · $\mathbb{E}[\widehat{\sigma^2}_{\text{ML}}]=\tfrac{N-M}{N}\sigma^2$ 的完整推导

设真模型 $\mathbf{y}=\boldsymbol{\Phi}\mathbf{w}_*+\boldsymbol\varepsilon$，$\boldsymbol\varepsilon\sim\mathcal{N}(\mathbf{0},\sigma^2\mathbf{I})$，$\boldsymbol\Phi\in\mathbb{R}^{N\times M}$ 列满秩。要证 $\mathbb{E}\!\left[\tfrac{1}{N}\|\mathbf{y}-\boldsymbol{\Phi}\mathbf{w}_{\text{ML}}\|^2\right]=\tfrac{N-M}{N}\sigma^2$。

① 残差 = 噪声在正交补上的投影。拟合值 $\hat{\mathbf{y}}=P\mathbf{y}$，$P=\boldsymbol{\Phi}(\boldsymbol{\Phi}^\top\boldsymbol{\Phi})^{-1}\boldsymbol{\Phi}^\top$ 为正交投影（$P^2=P,\ P^\top=P$）。残差 $\mathbf{r}=(I-P)\mathbf{y}$。
② 确定部分被投影消掉。代入 $\mathbf{y}=\boldsymbol{\Phi}\mathbf{w}_*+\boldsymbol\varepsilon$： $\mathbf{r}=(I-P)\boldsymbol{\Phi}\mathbf{w}_*+(I-P)\boldsymbol\varepsilon$。因 $P\boldsymbol{\Phi}=\boldsymbol{\Phi}$，$(I-P)\boldsymbol{\Phi}=\mathbf{0}$，第一项消失： $$\mathbf{r}=(I-P)\boldsymbol\varepsilon$$ 残差只含噪声，与真值 $\mathbf{w}_*$ 无关——几何把信号投影掉了。
③ 残差平方 = 噪声的二次型。用 $(I-P)^2=I-P$： $$\|\mathbf{r}\|^2=\boldsymbol\varepsilon^\top(I-P)\boldsymbol\varepsilon$$
④ 高斯二次型期望。对 $\boldsymbol\varepsilon\sim\mathcal{N}(\mathbf{0},\sigma^2\mathbf{I})$，$\mathbb{E}[\boldsymbol\varepsilon^\top A\boldsymbol\varepsilon]=\sigma^2\,\text{tr}(A)$： $$\mathbb{E}[\|\mathbf{r}\|^2]=\sigma^2\,\text{tr}(I-P)$$
⑤ 投影矩阵的迹 = 子空间维数。用 $\text{tr}(AB)=\text{tr}(BA)$： $$\text{tr}(P)=\text{tr}\!\big((\boldsymbol{\Phi}^\top\boldsymbol{\Phi})^{-1}\boldsymbol{\Phi}^\top\boldsymbol{\Phi}\big)=\text{tr}(I_M)=M$$ 故 $\text{tr}(I-P)=N-M$。
⑥ 合起来。 $$\mathbb{E}[\widehat{\sigma^2}_{\text{ML}}]=\tfrac{1}{N}\sigma^2(N-M)=\tfrac{N-M}{N}\sigma^2<\sigma^2\quad\square$$

三个关键点：(i) $\mathbf{r}=(I-P)\boldsymbol\varepsilon$ 把信号消掉只剩噪声；(ii) $\text{tr}(I-P)=N-M$ 即残差空间维数，模型消耗了 $M$ 个自由度；(iii) 二次型期望公式把"平方的期望"化成"迹 × 方差"。除以 $N$ 把 $N-M$ 份噪声摊到 $N$ 份 → 低估；除以 $N-M$ 才无偏。

这是过拟合的微观体现：用数据估参数，再用同一数据估噪声，必然乐观偏误。 把它放大就是宏观现象——用 $M$ 阶多项式拟合 $N$ 个点，$M$ 增大时 $\mathbf{w}_{\text{ML}}$ 让训练残差趋零， 但系数绝对值爆炸、曲线剧烈震荡，测试点预测灾难性偏离。 根子是同一个：MLE 把模型贴到带噪的有限样本上，把噪声也当信号学了。

这个病不是线性回归独有，是点估计 + 高容量模型的通病。它直接逼出三条出路：

思路做法概率视角
正则化损失加 $\lambda\|\mathbf{w}\|_2^2$（Ridge）或 $\lambda\|\mathbf{w}\|_1$（Lasso）给 $\mathbf{w}$ 加先验：高斯先验 $\Rightarrow$ L2，拉普拉斯先验 $\Rightarrow$ L1。即 MAP 估计
模型选择交叉验证选 $M$；或 AIC/BIC在似然里罚模型复杂度
贝叶斯方法不取点，对 $\mathbf{w}$ 积分求预测分布完整后验 $p(\mathbf{w}\mid\mathcal{D})\propto p(\mathcal{D}\mid\mathbf{w})p(\mathbf{w})$，自带不确定性

正则化只是贝叶斯的"贫民版"——它取后验的众数（MAP），丢掉了后验的形状（不确定性）。Ridge 让 $\boldsymbol{\Phi}^\top\boldsymbol{\Phi}+\lambda\mathbf{I}$ 强制可逆，几何上把投影"收缩"向原点；Lasso 在 $\lambda$ 足大时让某些系数恰好为零，产生稀疏模型——稀疏性来自 L1 球的角点与等高线相切，是约束区域几何形状的后果，不是概率假设的直接推论。下一课就做完整的贝叶斯线性回归，看不确定性如何被显式表达。

6. 解的意义：MLE 即最小化 KL 散度

KL

KL 散度 · Kullback–Leibler Divergence

相对熵 · 信息论
数学本质：用分布 $q$ 去近似 $p$ 时，多付出的"额外惊讶"——$\mathrm{KL}(p\|q)$ 衡量两个分布的差距，是用 $q$ 编码来自 $p$ 的样本时比最优多用的比特数。

核心公式

$$\mathrm{KL}(p\,\|\,q)=\mathbb{E}_{p}\!\left[\log\frac{p(x)}{q(x)}\right]=\int p(x)\log\frac{p(x)}{q(x)}\,dx\;\geq\;0$$

非负（Gibbs 不等式），当且仅当 $p=q$ 处处成立时为 0。不对称：$\mathrm{KL}(p\|q)\neq\mathrm{KL}(q\|p)$，方向 matters。

拆成交叉熵 − 熵

$$\mathrm{KL}(p\|q)=\underbrace{\mathbb{E}_p[-\log q(x)]}_{\text{交叉熵 }H(p,q)}-\underbrace{H(p)}_{\text{与 }q\text{ 无关}}$$

对 $q$ 最小化 KL ⟺ 最小化交叉熵（$H(p)$ 固定）。这就是为什么分类用交叉熵损失。

方向选择

  • 前向 $\mathrm{KL}(p\|q)$（mean-seeking）：$p$ 大处 $q$ 必须大，否则被重罚。MLE 用此方向，$p=\widehat{p}_{\text{data}}$。
  • 反向 $\mathrm{KL}(q\|p)$（mode-seeking）：$q$ 只在 $p$ 高概率区有支撑，常用于变分推断（0015）。
→ 本节：MLE ⟺ 最小化 $\mathrm{KL}(\widehat{p}_{\text{data}}\|p_{\mathbf{w}})$ → 0010/0015：ELBO = $\log p - \mathrm{KL}$ → 深度学习交叉熵损失 = 同一物

前面把 MLE 当成"让数据概率最大"。还有一个更深的视角，把它和信息论接上。 定义经验分布 $\widehat{p}_{\text{data}}$ 为数据集上的均匀分布（每个样本权重 $1/N$）， 模型分布 $p_{\mathbf{w}}$。模型与数据之间的 KL 散度：

$$\mathrm{KL}(\widehat{p}_{\text{data}} \,\|\, p_{\mathbf{w}}) = \underbrace{\mathbb{E}_{\widehat{p}_{\text{data}}}[-\log p_{\mathbf{w}}(\mathbf{x},y)]}_{\text{交叉熵}} \;-\; \underbrace{H(\widehat{p}_{\text{data}})}_{\text{与 }\mathbf{w}\text{ 无关}}$$

第二项是经验分布的熵，与 $\mathbf{w}$ 无关。第一项正是负对数似然的样本均值。所以：

$$\arg\min_{\mathbf{w}}\; \mathrm{KL}(\widehat{p}_{\text{data}} \,\|\, p_{\mathbf{w}}) \;=\; \arg\max_{\mathbf{w}}\; \frac{1}{N}\sum_n \log p_{\mathbf{w}}(\mathbf{x}_n,y_n) \;=\; \mathbf{w}_{\text{ML}}$$
最大似然 = 最小化 KL 散度 = 最小化交叉熵，三位一体。 这把"最大似然"从一个人为的量，提升为"让模型分布尽量贴近数据分布"这一基本原则。 深度学习里的交叉熵损失不是另起炉灶，就是这同一个东西。

方向不能反：是 $\mathrm{KL}(\widehat{p}_{\text{data}}\|p_{\mathbf{w}})$，不是 $\mathrm{KL}(p_{\mathbf{w}}\|\widehat{p}_{\text{data}})$。反向要求 $\widehat{p}_{\text{data}}$ 处处非零，但经验分布是离散的、对连续数据无意义。这就是为什么分类用前向 KL（交叉熵）而非反向——前向 KL 对"模型没给数据足够概率"施重罚，正是我们想要的。

7. 推广：指数族与 GLM——一个假设统一所有损失

到此为止只讲了一种噪声：高斯。但回头看 §1 那句"换噪声分布就换一切"—— 它指向一个更大的结构。把高斯、Bernoulli、Poisson、指数、Gamma……这些看似不相干的分布 写成同一种形式，损失、激活函数、方差就全部从这一个形式里掉出来。 这就是指数族（exponential family），而"广义线性模型"（GLM）是它配上线性自然参数假设的产物。

指数族

指数族 · Exponential Family

统一参数化 · 自然参数
数学本质：能写成 $p(y\mid\eta)=h(y)\exp\!\big(\eta\,T(y)-A(\eta)\big)$ 的分布构成一个族。 $\eta$ 叫自然参数，$T(y)$ 叫充分统计量，$A(\eta)$ 叫对数配分函数（保证归一化）。

三个成员对照

分布自然参数 $\eta$$A(\eta)$均值 $\mu=A'(\eta)$
高斯（$\sigma^2$ 固定）$w/\sigma^2$$\eta^2\sigma^2/2$$\eta\sigma^2$
Bernoulli$\log\frac{\phi}{1-\phi}$$\log(1+e^\eta)$$\sigma(\eta)$（sigmoid）
Poisson$\log\lambda$$e^\eta$$e^\eta$

为什么这个形式重要

  • 均值 = $A'(\eta)$，方差 = $A''(\eta)$。对 $A$ 求导就拿到均值和方差——一个函数编码了分布的矩。
  • MLE 即矩匹配。令 $\eta$ 线性依赖输入 $\eta=\mathbf{w}^\top\boldsymbol\phi(\mathbf{x})$，对数似然对 $\mathbf{w}$ 求梯度令为零，得 $\boldsymbol\Phi^\top\boldsymbol\mu(\mathbf{w})=\boldsymbol\Phi^\top\mathbf{y}$——模型充分统计量的期望匹配数据的充分统计量。高斯时这就是正规方程。
  • 充分统计量维度固定 → 共轭先验存在。这是 0009 指数族与共轭先验的入口。
→ §3: 高斯时退化为正规方程 → 0004: 逻辑回归 = Bernoulli + 线性 $\eta$ → 0009: 指数族 + 共轭先验讲到底

把 Bernoulli 代进指数族看一遍——这是 Q6 考察的推导，也是逻辑回归的真正起源：

从 Bernoulli 到 sigmoid

$p(y\mid\phi)=\phi^y(1-\phi)^{1-y}=\exp\!\big(y\log\phi+(1-y)\log(1-\phi)\big)$ Bernoulli 写成指数形式
$=\exp\!\Big(y\underbrace{\log\frac{\phi}{1-\phi}}_{\eta}+\log(1-\phi)\Big)$ 凑出自然参数 $\eta=\log(\phi/(1-\phi))$（logit）
反解 $\phi$：$\eta=\log\frac{\phi}{1-\phi}\Rightarrow\phi=\frac{1}{1+e^{-\eta}}=\sigma(\eta)$ logit 的反函数就是 sigmoid
配上 GLM 假设 $\eta=\mathbf{w}^\top\boldsymbol\phi(\mathbf{x})$，得 $\mathbb{E}[y\mid\mathbf{x}]=\phi=\sigma(\mathbf{w}^\top\boldsymbol\phi(\mathbf{x}))$ sigmoid 不是设计的，是 Bernoulli + 线性自然参数的必然
平方损失来自高斯，交叉熵来自 Bernoulli，Poisson 回归来自 Poisson——它们都是同一个模板的实例。 模板就是指数族 + $\eta=\mathbf{w}^\top\boldsymbol\phi(\mathbf{x})$。换分布只换三样东西：损失（$-A(\eta)+\eta T(y)$）、激活函数（$A'(\eta)$ 的反函数）、方差函数（$A''(\eta)$）。 这就是 GLM 的"配方"。0004 逻辑回归会把这个配方完整跑一遍（含 IRLS——非线性时的"正规方程"）。

本课到此为止。指数族的完整理论（共轭先验、充分统计量、信息几何里 $A(\eta)$ 是势函数、Fisher 度量 $=A''(\eta)$）留给 0009；这里只建立直觉：你已经在 §1–§6 见过这个统一结构的第一个成员（高斯），其余成员是同构的。

8. 推导与自测

L1 · 从拉普拉斯噪声推出 L1 损失 L1
拉普拉斯分布 $p(\varepsilon)=\frac{1}{2b}\exp(-|\varepsilon|/b)$。写出对数似然，证明高斯噪声换拉普拉斯后，MLE 等价于最小化 $\sum_n|y_n-\mathbf{w}^\top\boldsymbol{\phi}(\mathbf{x}_n)|$。为什么 L1 比 L2 对异常值更鲁棒？
展开推导
$p(y_n|\mathbf{x}_n,\mathbf{w}) = \frac{1}{2b}\exp\!\big(-\frac{|y_n-\mathbf{w}^\top\boldsymbol{\phi}(\mathbf{x}_n)|}{b}\big)$噪声服从拉普拉斯 → 条件分布也是拉普拉斯（位置参数平移）
对数似然：$\log p = -N\log(2b) - \frac{1}{b}\sum_n|y_n-\mathbf{w}^\top\boldsymbol{\phi}(\mathbf{x}_n)|$取 log 把指数消掉，$|·|$ 留在分子
最大化 → 最小化 $\sum_n|y_n-\mathbf{w}^\top\boldsymbol{\phi}(\mathbf{x}_n)|$（L1 损失）第一项与 $\mathbf{w}$ 无关，$1/b>0$ 只是正系数
鲁棒性：高斯尾部 $\propto e^{-x^2}$（轻尾），拉普拉斯尾部 $\propto e^{-|x|}$（重尾）。大偏差在拉普拉斯下不那么"意外" → L1 不会被异常值主导。这是"损失是噪声的影子"的直接例证
L2 · 投影矩阵的幂等性证明 L2
$\mathbf{P}=\boldsymbol{\Phi}(\boldsymbol{\Phi}^\top\boldsymbol{\Phi})^{-1}\boldsymbol{\Phi}^\top$。证明：(1) $\mathbf{P}^2=\mathbf{P}$（幂等）；(2) $\mathbf{P}^\top=\mathbf{P}$（对称）；(3) $\mathbf{I}-\mathbf{P}$ 也是幂等对称的；(4) $\operatorname{tr}(\mathbf{P})=M$。
展开推导
(1) $\mathbf{P}^2 = \boldsymbol{\Phi}(\boldsymbol{\Phi}^\top\boldsymbol{\Phi})^{-1}\boldsymbol{\Phi}^\top \cdot \boldsymbol{\Phi}(\boldsymbol{\Phi}^\top\boldsymbol{\Phi})^{-1}\boldsymbol{\Phi}^\top = \boldsymbol{\Phi}(\boldsymbol{\Phi}^\top\boldsymbol{\Phi})^{-1}(\boldsymbol{\Phi}^\top\boldsymbol{\Phi})(\boldsymbol{\Phi}^\top\boldsymbol{\Phi})^{-1}\boldsymbol{\Phi}^\top = \boldsymbol{\Phi}(\boldsymbol{\Phi}^\top\boldsymbol{\Phi})^{-1}\boldsymbol{\Phi}^\top = \mathbf{P}$中间 $(\boldsymbol{\Phi}^\top\boldsymbol{\Phi})^{-1}(\boldsymbol{\Phi}^\top\boldsymbol{\Phi})=\mathbf{I}_M$
(2) $\mathbf{P}^\top = (\boldsymbol{\Phi}(\boldsymbol{\Phi}^\top\boldsymbol{\Phi})^{-1}\boldsymbol{\Phi}^\top)^\top = \boldsymbol{\Phi}((\boldsymbol{\Phi}^\top\boldsymbol{\Phi})^{-1})^\top\boldsymbol{\Phi}^\top = \boldsymbol{\Phi}(\boldsymbol{\Phi}^\top\boldsymbol{\Phi})^{-1}\boldsymbol{\Phi}^\top = \mathbf{P}$$(\boldsymbol{\Phi}^\top\boldsymbol{\Phi})^{-1}$ 对称，因为它是对称矩阵的逆
(3) $(\mathbf{I}-\mathbf{P})^2 = \mathbf{I} - 2\mathbf{P} + \mathbf{P}^2 = \mathbf{I} - 2\mathbf{P} + \mathbf{P} = \mathbf{I} - \mathbf{P}$幂等性直接用 $\mathbf{P}^2=\mathbf{P}$
(4) $\operatorname{tr}(\mathbf{P}) = \operatorname{tr}(\boldsymbol{\Phi}(\boldsymbol{\Phi}^\top\boldsymbol{\Phi})^{-1}\boldsymbol{\Phi}^\top) = \operatorname{tr}((\boldsymbol{\Phi}^\top\boldsymbol{\Phi})^{-1}\boldsymbol{\Phi}^\top\boldsymbol{\Phi}) = \operatorname{tr}(\mathbf{I}_M) = M$迹的循环性质：$\operatorname{tr}(AB)=\operatorname{tr}(BA)$
L3 · 信息论视角：MLE = min KL 的完整推导 L3
经验分布 $\widehat{p}_{\text{data}}(\mathbf{x},y)=\frac1N\sum_n\delta(\mathbf{x}-\mathbf{x}_n)\delta(y-y_n)$。证明：(1) $\mathrm{KL}(\widehat{p}_{\text{data}}\|p_{\mathbf{w}}) = -\frac1N\log p(\mathcal{D}|\mathbf{w}) + \text{const}$；(2) 因此最大化似然等价于最小化这个 KL；(3) 为什么用 $\mathrm{KL}(\widehat{p}_{\text{data}}\|p_{\mathbf{w}})$ 而非 $\mathrm{KL}(p_{\mathbf{w}}\|\widehat{p}_{\text{data}})$？
展开推导
(1) $\mathrm{KL}(\widehat{p}\|p_{\mathbf{w}}) = \mathbb{E}_{\widehat{p}}[\log\widehat{p}] - \mathbb{E}_{\widehat{p}}[\log p_{\mathbf{w}}]$。第一项与 $\mathbf{w}$ 无关 = const。KL = 交叉熵 − 熵
$\mathbb{E}_{\widehat{p}}[\log p_{\mathbf{w}}] = \frac1N\sum_n\log p_{\mathbf{w}}(\mathbf{x}_n,y_n) = \frac1N\log p(\mathcal{D}|\mathbf{w})$（假设 i.i.d.）经验期望 = 样本均值
所以 $\mathrm{KL} = \text{const} - \frac1N\log p(\mathcal{D}|\mathbf{w})$。min KL ⇔ max $\log p$。这就是为什么 MLE 的深层含义是"让模型分布尽可能接近数据的经验分布"
(3) $\mathrm{KL}(p_{\mathbf{w}}\|\widehat{p})$ 需要 $\widehat{p}$ 处处非零，但经验分布是 Dirac 脉冲——在没数据的点 $\widehat{p}=0$，$p_{\mathbf{w}}$ 若给正概率 → KL 无穷大。$\mathrm{KL}(\widehat{p}\|p_{\mathbf{w}})$ 只要求 $p_{\mathbf{w}}$ 在数据点非零，合理。方向不是任选的——数据分布的性质决定了哪个方向有定义

Q1 · 假设噪声服从拉普拉斯分布 $p(\varepsilon)\propto\exp(-|\varepsilon|/b)$，MLE 导出哪种损失？

拉普拉斯对数密度正比于 $-|y-\mu|/b$，MLE ⟺ 最小 $\sum|y_n-\mathbf{w}^\top\boldsymbol{\phi}(\mathbf{x}_n)|$。L1 对异常值更鲁棒，因为拉普拉斯尾部比高斯厚，大偏差不那么"意外"。这正是"损失是噪声假设的影子"。

Q2 · $\widehat{\sigma^2}_{\text{ML}} = \frac{1}{N}\|\mathbf{y}-\boldsymbol{\Phi}\mathbf{w}_{\text{ML}}\|^2$ 的期望是？

$\mathbb{E}[\widehat{\sigma^2}_{\text{ML}}]=\frac{N-M}{N}\sigma^2$。模型用 $M$ 个参数消耗了 $M$ 个自由度，残差只剩 $N-M$ 个独立信息，故系统性低估。无偏修正除以 $N-M$ 而非 $N$。这是过拟合的微观体现。

Q3 · 从信息论看，MLE 等价于最小化哪个量？

$\mathrm{KL}(\widehat{p}_{\text{data}}\|p_{\mathbf{w}}) = \mathbb{E}_{\widehat{p}}[-\log p_{\mathbf{w}}] - H(\widehat{p})$。第二项与 $\mathbf{w}$ 无关，第一项即负对数似然。方向不能反：$\mathrm{KL}(p_{\mathbf{w}}\|\widehat{p})$ 要求 $\widehat{p}$ 处处非零，对连续数据无意义。

Q4 · Ridge 回归 $\min\|\mathbf{y}-\boldsymbol{\Phi}\mathbf{w}\|^2+\lambda\|\mathbf{w}\|^2$ 在概率上等价于？

高斯先验 $\log p(\mathbf{w})\propto-\|\mathbf{w}\|^2/(2\tau^2)$，MAP 最大化 $\log p(\mathcal{D}|\mathbf{w})+\log p(\mathbf{w})$ 即得 Ridge，$\lambda=\sigma^2/\tau^2$。拉普拉斯先验给 L1（Lasso）。MAP 是后验众数，不是完整贝叶斯——丢掉了不确定性。

Q5 · 当 $M>N$（特征多于样本），$\boldsymbol{\Phi}^\top\boldsymbol{\Phi}$ 必然奇异，MLE 会怎样？

$M>N$ 时 $\operatorname{col}(\boldsymbol{\Phi})$ 维度 $\leq N$，$\mathbf{y}$ 几乎总在列空间内，存在 $\mathbf{w}$ 使 $\boldsymbol{\Phi}\mathbf{w}=\mathbf{y}$（零残差）。但解空间是 $M-N$ 维仿射子空间，不唯一，且范数极大的解对应剧烈震荡的预测。这正是高维场景必须正则的原因。

Q6 · 把 Bernoulli 写成指数族后，自然参数 $\eta=\log(\phi/(1-\phi))$，反解 $\phi$ 得到 sigmoid。这说明了什么？

Sigmoid 不是拍脑袋选的——它是 Bernoulli 在指数族下，自然参数与输入线性相关（$\eta=\mathbf{w}^\top\mathbf{x}$）时，预测 $\mathbb{E}[y\mid\mathbf{x}]=\phi=\sigma(\eta)$ 的必然结果。和"平方损失来自高斯"是同一类事：激活函数来自输出分布的假设。

Q7 · 正规方程 $\boldsymbol{\Phi}^\top\boldsymbol{\Phi}\mathbf{w}=\boldsymbol{\Phi}^\top\mathbf{y}$ 的几何含义是？

$\boldsymbol{\Phi}^\top(\mathbf{y}-\boldsymbol{\Phi}\mathbf{w})=\mathbf{0}$ 即残差正交于 $\boldsymbol{\Phi}$ 的每一列，也就是正交于整个列空间。向量到子空间距离最近的点恰是正交投影——所以最小二乘解就是 $\mathbf{y}$ 在 $\operatorname{col}(\boldsymbol{\Phi})$ 上的正交投影，$\mathbf{w}_{\text{ML}}$ 是投影坐标。
