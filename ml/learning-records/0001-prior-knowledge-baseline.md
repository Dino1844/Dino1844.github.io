# 先前知识基线

用户具备以下基础：
- **数学**：微积分、线性代数、概率统计有一定基础，足以理解推导过程；若遇到不熟悉的数学工具会主动提出
- **ML 概念**：理解 SVM 的基本思想（最大间隔分类），但不熟悉推导细节；对其他 ML 算法的了解程度待进一步确认
- **编程**：有 Python 基础，可以用 AI 辅助写代码
- **资源**：手头有 MML（Mathematics for ML）和 PRML（模式识别与机器学习）两本教材

**教学意义**：不需要从数学基础开始；每节课可以直接进入 ML 主题，数学推导作为课程的组成部分而非前置条件。首课可从概率视角下的线性回归开始——这是连接概率论和 ML 建模的桥梁，也是 PRML 第三章的核心内容。
