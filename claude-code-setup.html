从零开始：nvm → npm → Claude Code → DeepSeek API → Teach Skill

nvm → Node.js → npm → Claude Code → DeepSeek API → Teach Skill → GitHub Pages → 🎓 使用

1. 安装 nvm（Node Version Manager）

nvm 让你在同一台机器上管理多个 Node.js 版本。它解决的核心问题是：不同项目可能需要不同的 Node 版本，而系统包管理器通常只能装一个。

安装命令

curl -o- https://raw.githubusercontent.com/nvm-sh/nvm/v0.40.1/install.sh | bash

安装完成后，重启终端或执行：

source ~/.bashrc   # 或 source ~/.zshrc

验证安装

nvm --version
💡 提示 如果命令未找到，检查 ~/.bashrc 或 ~/.zshrc 中是否被正确添加了 nvm 初始化脚本。通常安装脚本会自动追加，但某些系统需要手动确认。

2. 安装 Node.js 与 npm

nvm 安装好之后，用 nvm 来安装 Node.js，npm 会随 Node.js 自动安装。

安装 LTS 版本（推荐）

nvm install --lts
nvm use --lts
nvm alias default 'lts/*'
📌 这三条命令的含义 install --lts — 下载最新的长期支持版本
use --lts — 在当前 shell 中切换到该版本
alias default 'lts/*' — 设置默认版本，新终端自动使用此版本

验证安装

node --version   # 例如 v22.11.0
npm --version    # 例如 10.9.0

3. 安装 Claude Code

Claude Code 是 Anthropic 提供的命令行 AI 编程助手。通过 npm 全局安装：

npm install -g @anthropic-ai/claude-code
⚠️ 权限问题 如果遇到 EACCES 权限错误，不要用 sudo。nvm 管理的 Node.js 不需要 sudo。请确认 nvm use --lts 已执行且 npm 的全局路径在用户目录下：
npm config get prefix 应输出类似 /home/用户名/.nvm/versions/node/v22.11.0 的路径。

验证安装

claude --version

4. 配置 DeepSeek API

Claude Code 默认使用 Anthropic API。要改用 DeepSeek 模型(可以开发票)，请参照官方指南设置环境变量或配置文件：

📖 接入 Claude Code — DeepSeek API 官方文档

核心步骤：在 platform.deepseek.com 获取 API Key，然后设置 ANTHROPIC_BASE_URL 和 ANTHROPIC_AUTH_TOKEN 两个环境变量即可。详细参数请直接参阅上方官方文档。

5. 安装 Teach Skill

Teach Skill 是 Claude Code 的结构化教学扩展模块。安装与使用详见：

📖 Learn Anything with My Teach Skill — aihero.dev

6. 部署到 GitHub Pages

把 Teach Skill 产出的课程文件部署到 GitHub Pages，就能在任何地方通过浏览器访问你的学习笔记。

📖 GitHub Pages 快速入门 — 官方文档

一句话总结：创建一个名为 你的用户名.github.io 的公开仓库，把 HTML 文件推上去，等几秒即可在 https://你的用户名.github.io 访问。如果需要自定义域名或绑定 HTTPS，详见上方官方文档。

7. 使用 Teach Skill

Teach skill 围绕三个核心概念组织学习：

知识 · 技能 · 智慧

📖 知识

来自高质量、高信任度的资源

🛠 技能

通过交互式练习获得的实战能力

🧠 智慧

在社区和实践中验证的真知灼见

基础工作流

# 1. 明确学习任务
/teach 帮我学习量化金融的基础概念

# 2. Agent 会询问你的学习目标，填入 MISSION.md

# 3. Agent 产出课程（HTML 文件）到 lessons/ 目录

# 4. 在浏览器中打开课程文件学习

# 5. 遇到问题随时回来追问：
/teach 上一课中关于期权定价的部分我没理解

关键文件结构

~/.claude/skills/teach/
├── MISSION.md              # 你的学习目标
├── NOTES.md                # 学习偏好记录
├── RESOURCES.md            # 高质量资源列表
├── lessons/                # HTML 课程文件
│   └── 0001-xxx.html
├── learning-records/       # 学习记录
│   └── 0001-xxx.md
└── reference/              # 参考卡片（速查表）
💡 最佳实践
  • 每次只学一个紧密相关的话题
  • 在浏览器中打开 HTML 课程，边看边实操
  • 用 /teach 追问直到真正理解
  • 定期回顾 learning-records/ 巩固记忆

📋 快速检查清单

  • nvm --version — nvm 已安装且可用
  • node --version — Node.js LTS 已安装
  • npm --version — npm 已就绪
  • claude --version — Claude Code 已全局安装
  • ~/.claude/settings.json — DeepSeek API 已配置
  • /teach 可用 — Teach skill 已安装
  • https://你的用户名.github.io — GitHub Pages 已部署
  • 浏览器打开课程 — 开始学习
