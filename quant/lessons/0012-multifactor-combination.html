多因子组合与因子择时

Lesson 0012（重写·深度版）· 第三阶段收官 · 预计 40-50 分钟

🔁 衔接

0010-0011 给了你一堆因子。但单因子都有长失效期（动量崩溃、价值 5 年跑输、carry unwinding），单用任何一个多数人扛不住。这节讲怎么组合：每个因子单独生成信号 → 标准化 → 加权合成 → 得到一个比任何单因子都稳的综合信号。这是从"有一堆因子"到"有一个策略"的跨越。

一、为什么要组合——数学上为什么有效

组合夏普比单因子高，不只是"分散"的直觉，有严格数学。两个因子组合的夏普：

$$\text{Sharpe}_{\text{组合}}^2 = \frac{(w_1 \mu_1 + w_2 \mu_2)^2}{w_1^2 \sigma_1^2 + w_2^2 \sigma_2^2 + 2 w_1 w_2 \rho \sigma_1 \sigma_2}$$

关键在分母的 $\rho$（因子相关系数）：

  • $\rho = 1$（完全相关）：组合没好处，等价于单因子
  • $\rho = 0$（不相关）：组合夏普平方 = 单因子夏普平方之和（夏普提升显著）
  • $\rho < 0$（负相关，如动量-价值）：组合夏普比任一单因子都高得多——负相关意味着一方的回撤被另一方对冲

⚡ 这就是为什么 0010 强调动量-价值负相关

负相关不是"碰巧好"——它是组合夏普提升的最大来源。设计多因子策略的核心问题不是"加哪个因子"，而是"加哪个和现有组合负相关的因子"。一个本身很好但和组合高度相关的因子，加进去几乎不提升夏普。

二、信号标准化——组合的前提

不同因子的量纲差异巨大（动量是 %、费率是 bp、MVRV 是比值），不能直接相加。必须先标准化到同一尺度。

横截面 z-score（最常用）

在每个时点 $t$，对所有资产 $i$，把因子值转成横截面 z-score：

$$z_{i,t} = \frac{f_{i,t} - \text{median}(f_{\cdot,t})}{\text{IQR}(f_{\cdot,t})}$$

用中位数和 IQR（而非均值/标准差）是因为因子分布常有肥尾和异常值——均值/std 会被极端值带偏。z-score 后每个因子都是均值 0、尺度 1 的量，可以相加。

时间序列 rank（更稳健）

不用 z-score，用横截面排名百分位（0 到 1）。对肥尾和异常值完全免疫。代价是损失一点信息（线性变 rank）。实务中 rank 比 z-score 更常用，因为更稳健。

三、组合方法——从简单到复杂

3.1 等权 Equal Weight

$$S_i = \frac{1}{K} \sum_{k=1}^{K} z_{i}^{(k)}$$

每个因子权重 $1/K$。优点：无参数、不过拟合、鲁棒。缺点：忽略因子强弱和相关结构。实务中往往是最好的起点——DeMiguel et al. (2009) 证明等权经常胜过复杂优化，因为优化对估计误差敏感。

3.2 风险加权 Inverse Volatility Weighting

$$w_k = \frac{1/\sigma_k}{\sum_j 1/\sigma_j}$$

波动大的因子少配。比等权合理，且不需要预测因子收益（只需波动率，好估）。这是从等权往上走一步的安全选择。

3.3 IC 加权 Information Coefficient Weighting

IC = 因子值与未来收益的相关系数，衡量因子预测能力。用历史 IC 作权重：

$$w_k \propto \overline{\text{IC}_k} \quad (\text{IC 高的因子多配})$$

⚠️ 陷阱

IC 本身不稳定——历史 IC 高的因子未来未必高。直接用 IC 加权容易过拟合（追近期表现好的因子）。改进：用滚动 IC 的 shrinkage 估计，或 IC 的 t 统计量（显著性）而非 IC 值本身作权重。

3.4 优化加权（因子层面 Markowitz）

在因子层面做均值-方差优化，输入因子收益均值和协方差矩阵。

⚠️ 和资产层面 Markowitz 一样的病

error maximization——对因子收益均值估计误差敏感。第七课讲的问题在因子层面同样存在。实务中慎用，或加强约束（权重 ∈ [0, 0.4]、和为 1）。

实务建议（按优先级）

  1. 从等权开始，作为基准。这步就能拿到大部分夏普提升
  2. 试风险加权，看是否稳定提升
  3. IC 加权和优化加权谨慎用，必须样本外验证，且加强约束
  4. 因子数量 3-7 个为宜。太多过拟合，太少不分散
  5. 每加一个因子，检查它和现有组合的相关系数——>0.7 几乎不提升夏普，不值得加

四、因子正交化——避免重复暴露

因子之间往往相关（动量和低波动负相关、价值和质量正相关）。直接组合会有隐式重复加权——某个风险被多个因子同时表达，组合对该风险过度暴露。

方法：回归正交化

把因子按顺序加入，每个新因子对已有因子回归，取残差作为"纯因子"：

$$f_k^{\perp} = f_k - \sum_{j

残差 $f_k^{\perp}$ 是 $f_k$ 中已有因子解释不了的部分——它捕捉独立的风险来源。组合时用正交化后的因子，每个权重对应独立的 risk premium。

注意：正交化顺序影响结果（先入为主）——通常按因子稳健性排序（最稳健的先入）。

PCA 正交化

对因子协方差矩阵做 PCA，得主成分作为正交因子。优点：不依赖人为排序。缺点：主成分没有经济含义（是因子的线性组合），解释性差。

五、从综合得分到仓位

组合后得到每个资产的综合得分 $S_i$。怎么转成仓位？

常用映射

  • 线性：$w_i \propto S_i$，得分正做多负做空
  • 分位数：只对得分最高/最低的 N% 开仓，中间不开——减少弱信号噪声
  • sigmoid：$w_i \propto \tanh(S_i)$，限制极端仓位——得分再大仓位也有上限
  • 风险调整：$w_i \propto S_i / \sigma_i$，得分除以波动率——波动大的资产降仓（波动率目标思想）

最后总仓位按组合波动率目标缩放（如目标年化 20%），并加单资产上限（如 ≤30%）和总杠杆上限。

六、因子择时 Factor Timing

更激进：不固定权重，动态调整——某些时期多配动量，某些多配价值。

⚠️ 因子择时极难

学术共识（Asness 等）：因子择时几乎和选股一样难。因子的相对表现极难预测。大多数择时模型样本外失效。原因：因子收益的噪声远大于信号，择时信号被噪声淹没。业内主流：做因子配置（静态权重）可以，做因子择时（动态权重）要非常谨慎。

少数可行的体制性择时

不是短期择时，是体制识别——只在极端状态调整：

  • 动量崩溃预警：市场急速反转 + 动量估值极贵时，降动量权重。Daniel-Moskowitz 提出的条件偏度信号
  • 价值-动量价差：价值相对动量极便宜时（spread 在历史低分位），加价值权重——Asness 等 (2017)
  • 波动率体制：高波动体制下降低所有因子暴露（波动率目标的全局版）
  • 趋势过滤：市场-wide 趋势明确时多配时序动量，震荡时多配横截面/反转

共同点：只在极端体制调整，不频繁交易。频繁择时 = 过拟合。

七、因子衰减与监控

因子不是永生的。生命周期：发现 → 发表 → 拥挤 → 失效。

监控指标

指标含义警报
滚动 IC因子值与未来收益的滚动相关持续下降或转负
滚动夏普因子组合的滚动夏普持续下降
因子估值因子多空组合的估值（如 P/E of 多头-空头）极贵→拥挤→将反转
因子相关性和其他因子的相关相关性上升→失去分散价值

⚡ 实操

每月跟踪每个因子的滚动 IC 和夏普。IC 持续下降 = 因子在衰减。一旦某因子 IC 长期为零或负，从组合剔除或降权。币圈因子衰减更快——市场参与者学习快、容量小、新因子很快被复制。链上因子 2018 时 alpha 厚，2024 已衰减不少。持续寻找新因子是币圈量化的常态。

八、币圈多因子策略骨架（完整示例）

🔗 一个可落地的币圈多因子策略

选因子（按 0011 适用性）：动量、费率方向、MVRV、稳定币流量。

流程：

  1. 每个因子单独算信号 → 横截面 rank 标准化（0-1）
  2. 正交化（动量先入，其他对动量回归取残差）
  3. 等权合成（先从等权开始）：$S_i = \frac{1}{4}(\text{rank}_{\text{动量}} + \text{rank}_{\text{费率}} + \text{rank}_{\text{MVRV}} + \text{rank}_{\text{稳定币}})$
  4. 得分 → 仓位：$w_i \propto S_i / \sigma_i$（风险调整），单资产 ≤30%，总杠杆 ≤200%
  5. 组合波动率目标 20% 年化，动态缩放
  6. 每月再平衡，每次检查因子滚动 IC，衰减的降权

权重示例（起步）：动量 40%、费率方向 20%、MVRV 20%、稳定币 20%。动量多配因为币圈动量最稳健、alpha 最厚。

回测必须（第八课）：含已归零币（幸存者偏差）、扣费率+滑点、walk-forward、波动率目标验证崩溃保护。

测验

1. 为什么负相关因子组合夏普提升最大？

负相关因子收益更高 组合方差分母里 ρ 为负，方差变小；且一方回撤被另一方对冲 负相关意味着独立 负相关因子没有风险

2. 为什么信号组合前要先标准化（z-score 或 rank）？

不标准化算不出来 不同因子量纲不同（动量是%、费率是 bp），不标准化直接相加会被量纲大的因子主导 标准化提升精度 监管要求

3. 因子正交化的目的是？

减少因子数量 避免对同一风险重复暴露——每个正交因子捕捉独立的风险来源 提升单因子收益 简化计算

4. 因子择时为什么难？什么择时相对可行？

数据不够；高频择时可行 因子相对收益噪声大、择时信号被淹没；只有体制性择时（极端状态如动量崩溃预警）相对可行 择时不可行 择时很简单

5. 一个因子滚动 IC 持续下降到零，应该？

加大权重 因子在衰减，从组合剔除或降权，并寻找替代因子 保持不变 反向使用
