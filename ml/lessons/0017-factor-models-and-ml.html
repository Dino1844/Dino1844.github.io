1. 因子模型的数学起源：无套利 → 线性定价

范式 #19 · 无套利 → 线性定价

金融市场不允许"空手套白狼"——无套利条件强制资产的期望收益与其因子暴露之间必须存在线性关系。这不是经验规律，是数学定理。

考虑 $K$ 个因子的线性模型：$r_i = \alpha_i + \boldsymbol{\beta}_i^\top\mathbf{f} + \varepsilon_i$。 其中 $\boldsymbol{\beta}_i$ 是资产 $i$ 对 $K$ 个因子的暴露（loading）。

无套利条件要求：如果两个资产有完全相同的因子暴露 $\boldsymbol{\beta}$，它们必须有相同的期望收益。 否则买入高收益的 + 卖出低收益的 → 零净暴露 + 正收益 → 套利。

推导 · APT 定价方程

假设 $\mathbf{r} = \boldsymbol{\alpha} + \mathbf{B}\mathbf{f} + \boldsymbol{\varepsilon}$，$\mathbb{E}[\boldsymbol{\varepsilon}\mid\mathbf{f}] = 0$。 线性因子模型的基本设定
无套利 ⇒ $\exists \boldsymbol{\lambda}\in\mathbb{R}^K$ 使得 $\mathbb{E}[\mathbf{r}] \approx \mathbf{r}_f + \mathbf{B}\boldsymbol{\lambda}$ $\boldsymbol{\lambda}$ = 因子风险溢价向量——承担因子风险应得的补偿
$\boldsymbol{\alpha} = \mathbb{E}[\mathbf{r}] - \mathbf{r}_f - \mathbf{B}\boldsymbol{\lambda} = 0$（无 $\alpha$） 任何非零 $\alpha$ 都是套利机会——买入正 $\alpha$，卖空负 $\alpha$

2. APT：多因子无套利定价

APT（Arbitrage Pricing Theory, Ross 1976）是 CAPM 的多因子推广：

$$\boxed{\;\mathbb{E}[r_i] = r_f + \beta_{i1}\lambda_1 + \beta_{i2}\lambda_2 + \cdots + \beta_{iK}\lambda_K\;}$$
CAPM vs APT：CAPM 说"市场因子就够了"（$K=1$）；APT 说"有几个系统性风险源就有几个因子"（$K$ 由数据定）。 APT 不告诉你因子是什么——这正是统计因子模型存在的理由：让数据自己找出因子。

3. 统计因子模型：PCA 在金融里的化身

给定 $N$ 个资产在 $T$ 期的收益矩阵 $\mathbf{R}\in\mathbb{R}^{T\times N}$，PCA 对协方差矩阵 $\frac{1}{T}\mathbf{R}^\top\mathbf{R}$ 做特征分解。 前 $K$ 个特征向量就是统计因子——它们是数据中方差最大的 $K$ 个方向。

$$\mathbf{R}^\top\mathbf{R} = \mathbf{V}\mathbf{\Lambda}\mathbf{V}^\top, \quad \mathbf{F} = \mathbf{R}\mathbf{V}_{[:,:K]}$$

$\mathbf{F}\in\mathbb{R}^{T\times K}$ 是 $K$ 个统计因子的时间序列。每个因子是各资产的线性组合，权重由特征向量给出。

统计因子 ≠ 可解释因子。PCA 找到的第一个主成分通常就是"市场因子"（各资产等权组合的近似）， 但第二个、第三个可能没有简单的金融解释。它们捕获的是数据中的统计结构，不一定是"规模"或"价值"。

4. Fama–French 与基本面因子

Fama–French 三因子模型（1993）用基本面特征构造因子：

因子构造方式经济直觉
市场（MKT）$r_m - r_f$承担系统性风险应得的回报
规模（SMB）小市值 − 大市值小公司风险更高 → 期望收益更高
价值（HML）高 B/M − 低 B/M价值股（便宜）vs 成长股（贵）

后续扩展：五因子（+ 盈利 RMW + 投资 CMA）、动量因子（Carhart 四因子）。

基本面因子 vs 统计因子：Fama–French 是"用经济直觉选因子"；PCA 是"让数据选因子"。 ML 时代的主流做法是把两者结合：用基本面特征 + ML 模型（GBDT/NN）预测收益， 然后用统计因子做中性化消除不想要的风险暴露。

5. 因子中性化：正交投影的量化版

范式 #17（回接）· 中性化 = $\mathbf{I}-\mathbf{P}$

给定因子矩阵 $\mathbf{X}$，组合收益 $\mathbf{r}$ 中性化：$\mathbf{r}_\perp = (\mathbf{I} - \mathbf{X}(\mathbf{X}^\top\mathbf{X})^{-1}\mathbf{X}^\top)\mathbf{r}$。 结果 $\mathbf{r}_\perp$ 与所有因子的协方差为零——纯 $\alpha$，因子免疫。

正交投影在 0001 §4 里是几何直观，在 0017 里是风控工具： 把策略收益投影到因子空间上，取残差——残差部分不承担因子风险，alpha 归因干净。

6. GBDT 选股：函数空间梯度下降

范式 #20 · Boosting = 函数空间梯度下降

0013 的 AdaBoost 在函数空间做梯度下降。GBDT 推广到任意可微损失：第 $m$ 步拟合负梯度 $-\partial L/\partial f$。 在选股里，$f(\mathbf{x})$ = 预期收益率，$L$ = MSE 或排序损失。

GBDT 的数学本质

设当前模型 $F_{m-1}(\mathbf{x})$。计算每个样本上的负梯度： $g_{im} = -\left.\frac{\partial L(y_i, F(\mathbf{x}_i))}{\partial F(\mathbf{x}_i)}\right|_{F=F_{m-1}}$ 负梯度方向 = 损失下降最快的方向（在函数空间）
训练一棵回归树 $h_m(\mathbf{x})$ 拟合 $\{(\mathbf{x}_i, g_{im})\}$，更新 $F_m = F_{m-1} + \eta \cdot h_m$ $\eta$ = 学习率/shrinkage，每步只走一小步避免过拟合

在量化选股里的典型用法：特征 = 基本面因子值（PE、PB、动量……）；预测目标 = 下期收益率或排序；模型 = LightGBM/XGBoost。

8. 推导与演算

L1 · APT 定价验证 L1
已知两个因子，无风险利率 $r_f=2\%$，因子风险溢价 $\lambda_1=5\%, \lambda_2=3\%$。资产 A 的因子暴露 $\boldsymbol{\beta}_A=(1.2, 0.8)$。用 APT 给出它的期望收益。如果市场上它的期望收益是 10%，有无套利机会？
展开推导
APT 定价：$\mathbb{E}[r_A] = 2\% + 1.2\times 5\% + 0.8\times 3\% = 2\% + 6\% + 2.4\% = 10.4\%$$\alpha_A = 10\% - 10.4\% = -0.4\%$（实际收益低于定价）→ 卖出 A
L2 · 中性化与纯 alpha 分解 L2
一个选股策略的月收益 $\mathbf{r}$（$T\times 1$）对 Fama–French 三因子 $\mathbf{X}$（$T\times 3$）回归得到残差 $\mathbf{r}_\perp$。证明 $\operatorname{Cov}(\mathbf{r}_\perp, \mathbf{X}_k) = 0$ 对所有 $k$。
展开推导
$\mathbf{r}_\perp = \mathbf{r} - \mathbf{X}\hat{\mathbf{b}} = \mathbf{r} - \mathbf{X}(\mathbf{X}^\top\mathbf{X})^{-1}\mathbf{X}^\top\mathbf{r} = (\mathbf{I}-\mathbf{P})\mathbf{r}$$\hat{\mathbf{b}}$ 是 OLS 系数
$\mathbf{X}^\top\mathbf{r}_\perp = \mathbf{X}^\top(\mathbf{I}-\mathbf{P})\mathbf{r} = (\mathbf{X}^\top - \mathbf{X}^\top\mathbf{P})\mathbf{r}$$\mathbf{P} = \mathbf{X}(\mathbf{X}^\top\mathbf{X})^{-1}\mathbf{X}^\top$
$\mathbf{X}^\top\mathbf{P} = \mathbf{X}^\top\mathbf{X}(\mathbf{X}^\top\mathbf{X})^{-1}\mathbf{X}^\top = \mathbf{X}^\top$ ⇒ $\mathbf{X}^\top\mathbf{r}_\perp = 0$回归残差与自变量正交——OLS 的固有性质
L3 · GBDT 与 Newton 步的关系 L3
证明：GBDT 使用平方损失时，每一步等价于拟合残差。如果使用 Hessian（二阶信息），GBDT 的更新与 Newton 法有什么关系？
展开推导
MSE 损失：$L = \frac{1}{2}(y-F)^2$，$-\partial L/\partial F = y-F$（残差）GBDT 拟合残差 = 函数空间的梯度下降
Newton 步：$\Delta F = -(\partial^2 L/\partial F^2)^{-1}(\partial L/\partial F) = 1^{-1}(y-F) = y-F$平方损失的 Hessian = 1 → Newton = 梯度
对一般损失，Newton 步 = $-g_i/h_i$。XGBoost 用 $h_i$（二阶梯度）做加权——这就是为什么它比普通 GBDT 快。二阶信息 = 自适应步长
