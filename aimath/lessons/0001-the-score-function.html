1. 概率密度与配分函数：为什么生成模型这么难

1.1 什么是概率密度函数？

先回顾最基本的概念。一个在 $d$ 维空间上的概率密度函数（probability density function, PDF）$p(\mathbf{x})$ 需要满足两条性质：

  1. 非负性：$p(\mathbf{x}) \geq 0$ 对所有 $\mathbf{x} \in \mathbb{R}^d$ 成立
  2. 归一化：$\int_{\mathbb{R}^d} p(\mathbf{x})\, d\mathbf{x} = 1$（全空间的总体积分为 1）

第二条是最关键的——翻译成人话就是：「所有可能发生的事件的概率加起来必须恰好等于 1」。这看起来只是一个记账要求，但它恰恰是生成模型一切困难的根源。

🌰 具体例子：一维高斯分布

标准一维高斯分布 $\mathcal{N}(\mu, \sigma^2)$ 的密度函数：

$$p(x) = \frac{1}{\sqrt{2\pi\sigma^2}} \exp\left(-\frac{(x - \mu)^2}{2\sigma^2}\right)$$

前面的系数 $\frac{1}{\sqrt{2\pi\sigma^2}}$ 是精心挑选的——它保证了 $\int_{-\infty}^{\infty} p(x)\, dx = 1$。 这个系数就是归一化常数（normalizing constant）。

如果我们只写 $p(x) \propto \exp(-(x-\mu)^2/(2\sigma^2))$——也就是「正比于某个函数」—— 那我们确实知道 $p(x)$ 的形状（一个钟形曲线），但我们不知道它的高度。 归一化常数就是那个确定高度的因子。

1.2 配分函数 $Z$：为什么它不可计算

把上面的例子推广到一般情况。假设我们想建模一个概率分布，我们写出：

$$p_\theta(\mathbf{x}) = \frac{\tilde{p}_\theta(\mathbf{x})}{Z(\theta)}, \quad Z(\theta) = \int \tilde{p}_\theta(\mathbf{x})\, d\mathbf{x}$$

其中 $\tilde{p}_\theta(\mathbf{x})$ 是未归一化密度（unnormalized density）——它可以是一个神经网络输出的任意正数，比如 $\tilde{p}_\theta(\mathbf{x}) = \exp(-E_\theta(\mathbf{x}))$（这叫能量模型，$E_\theta$ 是神经网络）。$Z(\theta)$ 叫配分函数（partition function），它确保密度积分到 1。

问题来了：$Z(\theta)$ 需要对整个 $\mathbb{R}^d$ 做积分。 对于一张 $256 \times 256$ 的 RGB 图片，$d = 256 \times 256 \times 3 \approx 200{,}000$ 维。 在这个空间里做数值积分——用一个 $d$ 维网格，每个维度切 $N$ 个点——需要 $N^{200{,}000}$ 个网格点。 即使用蒙特卡洛方法，在高维空间中有效采样也需要指数级的样本量（这是维度灾难的核心含义）。
📍 停下来想一想：假设你有一个非常简单的模型，$\tilde{p}(\mathbf{x})$ 是神经网络输出的任意正数。 你能写出 $\tilde{p}(\mathbf{x})$，但你不知道 $p(\mathbf{x})$ 的实际数值——因为除以 $Z$ 之前，你不知道这个正数在整个空间中占多大比例。 就像你知道一个物体的相对形状但不知道它的绝对尺度。

1.3 所有生成模型都在绕开 $Z$

这就是为什么几乎每一种生成模型本质上都是在用不同的数学技巧逃避 $Z$ 的计算：

  • GAN —— 最极端的逃避：根本不写 $p(\mathbf{x})$，用对抗游戏隐式地学到怎么采样。判别器只判断「这是真的还是假的」，不计算概率密度。
  • VAE —— 引入隐变量 $\mathbf{z}$，把问题变成优化一个下界 (ELBO)。这个下界恰好不需要对 $\mathbf{z}$ 做积分——通过变分推断绕开了。
  • Normalizing Flow —— 唯一不绕的方法：使用可逆神经网络，配合变量替换公式 $\det(\partial f / \partial \mathbf{z})$，解析地计算 $Z$。代价是网络结构受到严重限制（必须可逆、Jacobian 必须好算）。
  • Energy-Based Model (EBM) —— 建模 $p_\theta(\mathbf{x}) \propto e^{-E_\theta(\mathbf{x})}$，坦然接受 $Z$ 不可算。训练时通过 MCMC 采样（如 Langevin 动力学）来估计涉及 $Z$ 的梯度项。

📇 不熟悉以上算法？先看 算法知识卡片，每张卡片用 3 分钟讲清楚一个算法的数学本质。

关键观察：上面的每个方法——无论是隐式采样、变分下界、可逆变换还是 MCMC——都在做一件很「迂回」的事。 有没有一个数学对象，天然地不依赖 $Z$，让你不需要绕路就能处理未归一化的概率模型？

2. Score Function：神奇地绕过配分函数

2.1 定义和直观含义

定义概率密度 $p(\mathbf{x})$ 的 score function（得分函数）：

$$\boxed{\mathbf{s}(\mathbf{x}) = \nabla_{\mathbf{x}} \log p(\mathbf{x})}$$

这里 $\nabla_{\mathbf{x}}$ 表示对数据 $\mathbf{x}$ 的梯度（不是对参数的梯度——这是关键区别）。 $\log$ 是自然对数。这个量告诉你：

在数据空间的任意一点 $\mathbf{x}$，往哪个方向走能让概率密度增长最快？

Score function 是一个向量场（vector field）——输入是空间中的点 $\mathbf{x}$，输出是一个 $d$ 维向量， 指向「概率更高的区域」。想象你在一个地形图上，概率密度就是海拔，score 就是最陡上坡方向。

2.2 核心性质：配分函数消失了

现在看最关键的推导——我们把 $p(\mathbf{x}) = \tilde{p}(\mathbf{x}) / Z$ 代入 score 的定义：

$\mathbf{s}(\mathbf{x}) = \nabla_{\mathbf{x}} \log p(\mathbf{x})$
$= \nabla_{\mathbf{x}} \log \left( \frac{\tilde{p}(\mathbf{x})}{Z} \right)$ // 代入 $p = \tilde{p} / Z$
$= \nabla_{\mathbf{x}} \bigl( \log \tilde{p}(\mathbf{x}) - \log Z \bigr)$ // $\log(a/b) = \log a - \log b$
$= \nabla_{\mathbf{x}} \log \tilde{p}(\mathbf{x}) - \nabla_{\mathbf{x}} \log Z$ // 梯度算子是线性的
$= \nabla_{\mathbf{x}} \log \tilde{p}(\mathbf{x}) - \mathbf{0}$ // $\log Z$ 不依赖于 $\mathbf{x}$！$Z$ 是对全空间积分的结果，是一个常数
$Z$ 消失了。因为 $Z$ 是对整个空间的积分——它不依赖于任何一个具体的 $\mathbf{x}$。 所以 $\log Z$ 是一个常数（相对于 $\mathbf{x}$），对 $\mathbf{x}$ 求梯度后恒为零。

这就是 score function 最核心的性质，也是后续一切展开的根源。 无论 $\tilde{p}$ 的绝对值有多大、$Z$ 有多不可计算，score 只关心 $\tilde{p}$ 的相对变化。

2.3 手算一个具体例子

🌰 一维高斯分布的 score

取标准一维高斯 $p(x) = \frac{1}{\sqrt{2\pi}\sigma} \exp\left(-\frac{(x-\mu)^2}{2\sigma^2}\right)$。让我们一步一步手算它的 score：

Step 1：取对数
$\log p(x) = -\frac{1}{2}\log(2\pi\sigma^2) - \frac{(x-\mu)^2}{2\sigma^2}$
Step 2：对 $x$ 求导
$s(x) = \frac{d}{dx} \log p(x) = 0 - \frac{2(x-\mu)}{2\sigma^2} = -\frac{x-\mu}{\sigma^2}$ // 注意 $-\frac{1}{2}\log(2\pi\sigma^2)$ 对 $x$ 求导为零（它就是这个分布的 $\log Z$）

观察：

  • $s(x) = -\frac{x-\mu}{\sigma^2}$ —— score 是一条直线！它指向均值 $\mu$。
  • 在 $x = \mu$ 处（概率最高点），$s(\mu) = 0$（梯度为零）。
  • 离 $\mu$ 越远，score 的绝对值越大——它在「用力」把你拉回来。
  • $\frac{1}{\sqrt{2\pi}\sigma}$（归一化常数）在求导后完全消失了。

2.4 Score 函数的一个重要恒等式

使用链式法则，score 也可以写成：

$$\mathbf{s}(\mathbf{x}) = \nabla_{\mathbf{x}} \log p(\mathbf{x}) = \frac{\nabla_{\mathbf{x}} p(\mathbf{x})}{p(\mathbf{x})}$$

这个形式清楚展示了为什么 score 在 $p(\mathbf{x})$ 很小的地方可能会很大—— 分母很小而分子不一定很小，score 可能爆炸。这是后续「为什么需要加噪」的关键原因。

Score 的概念有两层历史：

Fisher score（参数 score）：$\nabla_\theta \log p(x|\theta)$——对参数求导，费舍尔 1925 年提出，用于最大似然估计。

Stein score / Hyvärinen score（数据 score）：$\nabla_x \log p(x)$——对数据求导，是本文的主角。

别搞混：前者是 $\mathbb{R}^{\text{\#params}}$ 中的向量，后者是 $\mathbb{R}^d$（数据空间）中的向量。
📍 停下来想一想：假设 $p$ 是一个均匀分布 $p(x) = C$（常数），它的 score 是什么？答案是 $\mathbf{0}$——因为概率处处相等，没有任何方向是「更大概率的方向」。Score 关心的是变化，不是绝对值。

3. Langevin 动力学：有 score 就能采样

3.1 从布朗运动讲起

如果一个粒子只受随机扰动，没有外力——这就是布朗运动（Brownian motion）。在连续时间下，它的位置 $\mathbf{x}(t)$ 满足：

$$d\mathbf{x} = \sqrt{2\varepsilon}\, d\mathbf{w}(t)$$

其中 $\mathbf{w}(t)$ 是标准维纳过程（Wiener process）——你可以把它理解为「无穷小的独立高斯噪声」。$\varepsilon > 0$ 控制噪声强度。 如果粒子只做布朗运动，它的分布会逐渐扩散成一个越来越宽的高斯分布——没有什么方向性。

3.2 加上漂移：Langevin 方程

现在给粒子加一个确定性外力——让它偏向于往某个方向运动。这就是 Langevin 动力学（Langevin dynamics）：

$$d\mathbf{x} = \underbrace{\frac{\varepsilon}{2} \nabla_{\mathbf{x}} \log p(\mathbf{x})\, dt}_{\text{漂移项：往高概率方向走}} + \underbrace{\sqrt{2\varepsilon}\, d\mathbf{w}(t)}_{\text{扩散项：随机扰动}}$$

为什么漂移项是 $\frac{\varepsilon}{2} \nabla \log p$？这个系数不是随便选的。它是由一个叫 Fokker-Planck 方程的定理保证的：当漂移项取这个值时，$\mathbf{x}(t)$ 在 $t \to \infty$ 时的稳态分布 （stationary distribution）恰好是 $p(\mathbf{x})$。换一个系数，稳态分布就会变成别的分布。

3.3 离散化：可用于计算机的形式

把连续时间的 SDE 离散化（用 Euler-Maruyama 方法），得到迭代公式：

$$\boxed{\mathbf{x}_{t+1} = \mathbf{x}_t + \frac{\varepsilon}{2} \cdot \mathbf{s}(\mathbf{x}_t) + \sqrt{\varepsilon} \cdot \boldsymbol{\eta}_t, \quad \boldsymbol{\eta}_t \sim \mathcal{N}(\mathbf{0}, \mathbf{I})}$$

这个公式由两部分组成：

  1. 漂移项 $\frac{\varepsilon}{2} \mathbf{s}(\mathbf{x}_t)$ —— 沿 score 方向走半步。因为 $\mathbf{s}$ 指向概率上升最快的方向，所以这一步是梯度上升（不是下降——我们要最大化概率）。步长 $\varepsilon/2$ 控制每次移动的幅度。
  2. 扩散项 $\sqrt{\varepsilon} \cdot \boldsymbol{\eta}_t$ —— 独立的高斯噪声，每个维度独立，标准差为 $\sqrt{\varepsilon}$。注意 $\varepsilon$ 在漂移项中是一阶小量（$\varepsilon/2$）， 在扩散项中是 $\sqrt{\varepsilon}$——这意味着当 $\varepsilon$ 很小时，噪声主导了漂移。这不是 bug，这是 feature——噪声是探索分布的关键。
为什么必须加噪声？如果去掉扩散项，Langevin 动力学退化成了确定性的梯度上升： $\mathbf{x}_{t+1} = \mathbf{x}_t + \frac{\varepsilon}{2} \mathbf{s}(\mathbf{x}_t)$。 这个迭代最终会停在最近的局部极大值（一个 mode），再也出不来。

噪声有两个作用：① 让粒子有可能逃离局部陷阱，探索其他 modes； ② 让粒子的稳态分布恰好是 $p(\mathbf{x})$ 而不是某个 delta 函数。 没有噪声，你就不是在采样，而是在做优化。

4. Score Matching：不知道分布也能学 score

4.1 问题设定

上节讲了：有 score 就能采样。现在我们面对另一个问题：我们只有一堆数据样本 $\{\mathbf{x}^{(i)}\}_{i=1}^N \sim p_{\text{data}}(\mathbf{x})$，不知道 $p_{\text{data}}$ 的具体形式。 怎么学到一个近似的 score function $\mathbf{s}_\theta(\mathbf{x}) \approx \nabla_{\mathbf{x}} \log p_{\text{data}}(\mathbf{x})$？

4.2 朴素想法（以及它为什么行不通）

最直接的想法：最小化预测 score 和真实 score 之间的均方误差（MSE）：

$$\mathcal{L}_{\text{naive}}(\theta) = \mathbb{E}_{p_{\text{data}}(\mathbf{x})} \left[ \frac{1}{2} \left\| \mathbf{s}_\theta(\mathbf{x}) - \nabla_{\mathbf{x}} \log p_{\text{data}}(\mathbf{x}) \right\|^2 \right]$$
问题是 $\nabla_{\mathbf{x}} \log p_{\text{data}}(\mathbf{x})$ 是未知的——我们本来就不知道 $p_{\text{data}}$ 的解析形式！ 如果知道它，我们就不需要学 score 了。

4.3 Hyvärinen 的技巧：分部积分

Hyvärinen (2005) 的洞见是：展开上面的平方项，然后对包含 $\nabla \log p_{\text{data}}$ 的项做分部积分（integration by parts），把它转化成只涉及 $\mathbf{s}_\theta$ 的导数的形式。让我一步步推导：

展开 MSE：

$\frac{1}{2}\|\mathbf{s}_\theta - \nabla\log p\|^2 = \underbrace{\frac{1}{2}\|\mathbf{s}_\theta\|^2}_{\text{term A}} - \underbrace{\mathbf{s}_\theta^\top \nabla\log p}_{\text{term B}} + \underbrace{\frac{1}{2}\|\nabla\log p\|^2}_{\text{term C}}$

Term C 不依赖于 $\theta$ —— 它是常数，优化时忽略。
Term B 包含未知的 $\nabla\log p$。但注意到：

$\mathbb{E}_p[\mathbf{s}_\theta^\top \nabla\log p] = \int p(\mathbf{x})\, \mathbf{s}_\theta(\mathbf{x})^\top \nabla\log p(\mathbf{x})\, d\mathbf{x}$
$= \int p(\mathbf{x})\, \mathbf{s}_\theta(\mathbf{x})^\top \frac{\nabla p(\mathbf{x})}{p(\mathbf{x})}\, d\mathbf{x} = \int \mathbf{s}_\theta(\mathbf{x})^\top \nabla p(\mathbf{x})\, d\mathbf{x}$

现在用分部积分。在一维情况就是 $\int_a^b u\, dv = uv|_a^b - \int_a^b v\, du$。 在高维是 $\int f \cdot \nabla g = -\int g \cdot \nabla \cdot f$（假设 $p(\mathbf{x}) \to 0$ 当 $\|\mathbf{x}\| \to \infty$，边界项消失）：

$\int \mathbf{s}_\theta^\top \nabla p = -\int p(\mathbf{x})\, \operatorname{tr}\bigl(\nabla_{\mathbf{x}} \mathbf{s}_\theta(\mathbf{x})\bigr)\, d\mathbf{x} = -\mathbb{E}_p\bigl[\operatorname{tr}(\nabla_{\mathbf{x}} \mathbf{s}_\theta)\bigr]$

其中 $\operatorname{tr}(\nabla_{\mathbf{x}} \mathbf{s}_\theta)$ 是 $\mathbf{s}_\theta$ 的 Jacobian 矩阵的迹（对角线元素之和）， 也叫 $\mathbf{s}_\theta$ 的散度（divergence）。

拼起来，去掉常数项，得到 Hyvärinen score matching 损失：

$$\boxed{J_{\text{SM}}(\theta) = \mathbb{E}_{p_{\text{data}}(\mathbf{x})} \left[ \frac{1}{2} \|\mathbf{s}_\theta(\mathbf{x})\|^2 + \operatorname{tr}\bigl(\nabla_{\mathbf{x}} \mathbf{s}_\theta(\mathbf{x})\bigr) \right]}$$
奇迹发生了：这个损失函数不包含任何对 $p_{\text{data}}$ 的直接引用—— 只有期望 $\mathbb{E}_{p_{\text{data}}}$（用数据样本估计即可），以及 $\mathbf{s}_\theta$ 本身的范数和 Jacobian 迹。 我们不再需要知道真实分布的解析形式。

4.4 直觉：两项各自在做什么

  • $\frac{1}{2}\|\mathbf{s}_\theta(\mathbf{x})\|^2$：惩罚 score 向量在数据点处的长度。 因为在高概率区域（mode 附近），score 应该接近零（梯度为零），所以这一项让 score 在数据簇附近缩小。
  • $\operatorname{tr}(\nabla_{\mathbf{x}} \mathbf{s}_\theta(\mathbf{x}))$：惩罚 Jacobian 的迹。 在 mode 附近，score 向量指向 mode（汇聚），散度为负——这一项鼓励 score 场在数据附近汇聚而不是发散。 如果这一项不约束，score 网络可以 trivial 地输出零向量来满足第一项——但那样就不是真正的梯度场了。
📍 关键理解：Score matching 的优雅之处在于——它通过分部积分，把「和未知的真实 score 做比较」转化为了「检查预测 score 自己的结构」。梯度场的散度（迹）充当了「自我监督信号」。

5. 加噪的必要性：为什么不能直接用 score matching

5.1 低数据密度区域的问题

理论上，上一节的 score matching 可以直接在原始数据上训练。实践中有一个致命问题：

真实数据（比如自然图片）分布在一个低维流形上——$200{,}000$ 维空间中，只有极少一部分区域有数据。 在数据流形之外（也就是绝大部分空间），$p_{\text{data}}(\mathbf{x}) \approx 0$，因此：

$$\mathbf{s}(\mathbf{x}) = \frac{\nabla p(\mathbf{x})}{p(\mathbf{x})} \approx \frac{\text{有限值}}{\approx 0} \to \text{发散}$$

而且因为数据流形外几乎没有训练样本，score matching 损失在这些区域的期望 $\mathbb{E}_{p_{\text{data}}}$ 贡献为零——模型在这些区域完全没有监督信号，score 估计会非常不准确。

这就是为什么需要加噪。给数据加上高斯噪声 $\mathcal{N}(0, \sigma^2)$，相当于把 $p_{\text{data}}$ 和一个高斯核做卷积： $p_\sigma(\mathbf{x}) = (p_{\text{data}} * \mathcal{N}(0, \sigma^2))(\mathbf{x})$。加噪后的分布被「涂抹」到全空间——原本概率为零的区域现在也有了非零概率。 此时 score 处处有定义且光滑，模型在所有区域都能收到有效的训练信号。

5.2 Denoising Score Matching

实践中更常用的变体是 Denoising Score Matching (DSM)（Vincent, 2011）。它不是对 $p_{\text{data}}$ 做 score matching， 而是对加噪后的条件分布做：

$$\mathcal{L}_{\text{DSM}}(\theta) = \mathbb{E}_{\mathbf{x} \sim p_{\text{data}}} \mathbb{E}_{\tilde{\mathbf{x}} \sim \mathcal{N}(\mathbf{x}, \sigma^2 \mathbf{I})} \left[ \left\| \mathbf{s}_\theta(\tilde{\mathbf{x}}) - \nabla_{\tilde{\mathbf{x}}} \log q_\sigma(\tilde{\mathbf{x}} | \mathbf{x}) \right\|^2 \right]$$

关键：$q_\sigma(\tilde{\mathbf{x}} | \mathbf{x})$ 是我们手动加的高斯噪声——它的 score 是已知的！对于高斯噪声 $\tilde{\mathbf{x}} = \mathbf{x} + \sigma \boldsymbol{\epsilon}$：

$$\nabla_{\tilde{\mathbf{x}}} \log q_\sigma(\tilde{\mathbf{x}} | \mathbf{x}) = -\frac{\tilde{\mathbf{x}} - \mathbf{x}}{\sigma^2} = -\frac{\boldsymbol{\epsilon}}{\sigma}$$

所以 DSM 的损失变成：

$$\mathcal{L}_{\text{DSM}}(\theta) = \mathbb{E}_{\mathbf{x}, \boldsymbol{\epsilon}} \left[ \left\| \mathbf{s}_\theta(\mathbf{x} + \sigma \boldsymbol{\epsilon}) + \frac{\boldsymbol{\epsilon}}{\sigma} \right\|^2 \right]$$

这等价于训练一个网络，输入一张加噪图片，输出「去噪方向」。去噪 = 学 score。

5.3 多尺度噪声：从粗到细

不同 $\sigma$ 的噪声提供了不同分辨率的 score。$\sigma$ 很大时，score 只看到分布的大致轮廓（粗粒度）； $\sigma$ 很小时，score 能捕捉细节（细粒度）。Song & Ermon (2019) 提出用多个噪声尺度 $\sigma_1 > \sigma_2 > \cdots > \sigma_L$，采样时从大 $\sigma$ 开始（先确定大轮廓），逐渐减小 $\sigma$ （细化细节）——这就是退火 Langevin 动力学（annealed Langevin dynamics）。

这个「多尺度 + 退火」结构，也是后来 SDE 统一框架的离散前身——连续极限下，不同的噪声尺度变成了连续的时间 $t$， 而 sampling 变成了逆向 SDE 的求解。

6. 统一视角：从 EBM 到 Diffusion，都是同一件事

6.1 统一关系表

方法家族 建模对象 和 Score 的关系 关键等价
Energy-Based Model $E_\theta(\mathbf{x})$
$p_\theta \propto e^{-E_\theta}$		 $\mathbf{s}_\theta = -\nabla_\mathbf{x} E_\theta$ Score 就是负的能量梯度。学能量函数 = 学 score。
Score-Based Model $\mathbf{s}_\theta(\mathbf{x})$ 直接 本身就是 score 最直接的方式——不绕任何弯。
Diffusion Model (DDPM) $\boldsymbol{\epsilon}_\theta(\mathbf{x}_t, t)$
（噪声预测网络）		 $\mathbf{s}_\theta(\mathbf{x}_t, t) = -\frac{\boldsymbol{\epsilon}_\theta(\mathbf{x}_t, t)}{\sigma_t}$ 预测噪声 = 估计 score。DDPM 的损失函数就是 DSM 的加权版。

6.2 DDPM 损失 = Score Matching：显式证明

DDPM (Ho et al., 2020) 的简化训练损失是：

$$\mathcal{L}_{\text{DDPM}}^{\text{simple}} = \mathbb{E}_{t, \mathbf{x}_0, \boldsymbol{\epsilon}} \left[ \left\| \boldsymbol{\epsilon} - \boldsymbol{\epsilon}_\theta(\sqrt{\bar{\alpha}_t} \mathbf{x}_0 + \sqrt{1-\bar{\alpha}_t} \boldsymbol{\epsilon}, t) \right\|^2 \right]$$

现在看 DSM 损失（上一节）：

$$\mathcal{L}_{\text{DSM}} = \mathbb{E}_{\mathbf{x}, \tilde{\mathbf{x}}} \left[ \left\| \mathbf{s}_\theta(\tilde{\mathbf{x}}) - \nabla_{\tilde{\mathbf{x}}} \log q_\sigma(\tilde{\mathbf{x}} | \mathbf{x}) \right\|^2 \right]$$

令 $\tilde{\mathbf{x}} = \sqrt{\bar{\alpha}_t} \mathbf{x}_0 + \sqrt{1-\bar{\alpha}_t} \boldsymbol{\epsilon}$（DDPM 的前向加噪过程）。 则 $q(\tilde{\mathbf{x}} | \mathbf{x}_0) = \mathcal{N}(\sqrt{\bar{\alpha}_t} \mathbf{x}_0, (1-\bar{\alpha}_t)\mathbf{I})$， 且 $\nabla_{\tilde{\mathbf{x}}} \log q(\tilde{\mathbf{x}} | \mathbf{x}_0) = -\frac{\boldsymbol{\epsilon}}{\sqrt{1-\bar{\alpha}_t}}$。

代入 DSM 损失：

$$\left\| \mathbf{s}_\theta(\tilde{\mathbf{x}}, t) + \frac{\boldsymbol{\epsilon}}{\sqrt{1-\bar{\alpha}_t}} \right\|^2 = \frac{1}{1-\bar{\alpha}_t} \left\| \sqrt{1-\bar{\alpha}_t} \cdot \mathbf{s}_\theta(\tilde{\mathbf{x}}, t) + \boldsymbol{\epsilon} \right\|^2$$

定义 $\boldsymbol{\epsilon}_\theta = -\sqrt{1-\bar{\alpha}_t} \cdot \mathbf{s}_\theta$（即噪声预测 = 负的 scale 后的 score），则：

$$\mathcal{L}_{\text{DSM}} \propto \mathbb{E} \left[ \left\| \boldsymbol{\epsilon} - \boldsymbol{\epsilon}_\theta(\tilde{\mathbf{x}}, t) \right\|^2 \right] = \mathcal{L}_{\text{DDPM}}^{\text{simple}}$$
DDPM 不是灵机一动。它只是在加噪数据上做 denoising score matching， 只是换了个变量名（$\boldsymbol{\epsilon}_\theta$ 替代 $\mathbf{s}_\theta$）。噪声调度（线性方差 schedule） 是「多尺度」的一种具体选择。整个 DDPM 框架，从损失函数到采样过程， 都可以从「score matching + Langevin 动力学」这个视角必然地推导出来。

6.3 大局观

把整节课串起来：

  1. $Z$ 不可算 → 需要找一个不受 $Z$ 影响的数学对象来描述概率分布。
  2. Score $\nabla \log p$ → 这个对象天然存在——对数据求梯度，$\log Z$ 消失。
  3. Score matching → 不需要知道 $p$ 就能学 score（Hyvärinen, 2005）。
  4. Langevin 动力学 → 学到 score 就能采样（Fokker-Planck 保证稳态分布是 $p$）。
  5. 加噪 → 解决低密度区域的 score 估计问题，让模型在全空间有监督信号。
  6. 多尺度加噪 + 退火 Langevin → Score-based generative model（Song & Ermon, 2019）。
  7. 换个变量名 → DDPM（Ho et al., 2020）。它是同一件事的不同表述。
  8. 连续极限 → SDE 统一框架（Song et al., 2021），连接扩散模型和 score-based 模型。

这条逻辑链中的每一步都是有因可据的——不是因为某个人「灵机一动」想到了一个巧妙的损失函数， 而是因为每一步都是在回答一个很自然的问题：「上一步遇到了什么困难？什么数学工具能解决它？」

8. 这节课的核心 takeaway

  1. $Z$ 问题是生成模型的根源困难。所有方法本质上都是在绕它。
  2. Score function $\nabla_{\mathbf{x}} \log p(\mathbf{x})$ 天然免疫 $Z$。因为 $\log Z$ 对 $\mathbf{x}$ 是常数。
  3. 有 score → Langevin 动力学能采样。漂移 + 噪声 → 稳态分布就是 $p$。
  4. 没有 $p$ → Score matching 也能学 score。通过分部积分消除对真实 score 的依赖。
  5. 加噪是必要的。让 score 在全空间有定义和有监督信号。
  6. DDPM = 加噪数据上的 denoising score matching。不是灵机一动，是必然推导。
