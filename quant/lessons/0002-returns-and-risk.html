收益与风险

一、收益：你赚了多少

价格在变化，但价格本身没法直接比较。BTC 从 $60,000 涨到 $63,000 和 ETH 从 $1,800 涨到 $1,890——绝对涨了 $3,000 vs $90，但哪个涨得更多？收益率把价格变化标准化为百分比，让你可以在不同资产之间做公平比较。

简单收益率

Rt = (Pt − Pt−1) / Pt−1

最简单的形式：本期价格比上期涨（或跌）了百分之几。

日期BTC 价格简单收益率
周一$62,000—
周二$65,100+5.0%
周三$61,845−5.0%
周四$64,937+5.0%

注意一个细节：先涨 5% 再跌 5%，你不会回到原点——$62,000 × 1.05 × 0.95 = $61,845，比起点少了 $155。这个不对称性在量化建模中很重要。

对数收益率

rt = ln(Pt / Pt−1) = ln(Pt) − ln(Pt−1)

量化中更常用对数收益率（log return）。为什么？三个原因：

  1. 可加性——简单收益率乘起来麻烦，对数收益率直接相加。周一+周二的总收益 = r周一 + r周二
  2. 对称性——涨 5% 再跌 5%，在 log return 世界里正好抵消：ln(1.05) + ln(0.95) = −0.00125（几乎为零）
  3. 正态性假设——很多金融模型（Black-Scholes 期权定价等）假设收益率服从正态分布，log return 比 simple return 更接近这个假设

在实际应用中，小幅度变化时两者几乎一样（±4% 以内差异 < 0.1%）。量化分析中默认用 log return，除非有特殊理由。

二、风险：你冒了多大险

收益告诉你赚了多少。但两个策略可能赚得一样多，风险却天差地别——这才是量化选策略的关键。

波动率：风险的第一定义

σ = std(r1, r2, …, rn)

波动率 = 收益率的标准差。 这是金融中对"风险"最基础的量化定义：收益率波动越大，不确定性越大。

为什么用标准差衡量风险？

假设你有两个策略，过去 100 天的日收益均值都是 +0.1%：

策略日收益范围年化波动率直觉
A−0.5% ~ +0.7%~10%稳，像债券
B−5% ~ +5%~60%猛，像山寨币

同样的平均回报，A 让你睡得着，B 让你失眠。波动率量化了这个差异。

年化波动率

日收益率的标准差 × √365（币圈用 365，因为 24/7 交易；股票用 √252 个交易日）。

🔗 币圈对照

资产年化波动率（约）
标普 50015–20%
黄金15–18%
BTC50–80%
ETH70–100%
山寨币100–200%+

币圈的风险是传统资产的 3–10 倍。这意味着同样的收益率数字背后，币圈策略承担了高得多的风险。在币圈做量化，波动率管理是第一优先级。

三、收益与风险的统一：夏普比率

如果只看收益，高杠杆的山寨币策略可能年化 +200%，但这忽略了你可能一夜归零的风险。夏普比率把收益和风险放在一起比较。

Sharpe = (R策略 − R无风险) / σ策略

分子：你比无风险利率多赚了多少（超额收益）
分母：你为此冒了多大波动
含义：每承担一单位风险，你获得多少超额回报

直觉例子

策略年化收益年化波动无风险利率夏普比率
X+30%60%5%0.42
Y+15%12%5%0.83

X 赚得多，但每冒 1% 的波动才赚 0.42% 的超额收益。
Y 赚得少，但稳——夏普几乎是 X 的两倍。Y 是更好的策略。

夏普比率 > 1 算不错，> 2 算优秀，> 3 几乎没人能持续做到。现实中很多币圈策略夏普 < 1。

🔗 币圈的无风险利率

传统金融用国债利率（~5%）。币圈常用稳定币借贷利率（如 Aave 上 USDC 存款利率，~5–15% 不等）。但币圈的无风险利率本身波动大，不是真正的"无风险"——这是算币圈夏普时的一个常见争议。

四、另一个重要的风险视角：最大回撤

波动率衡量的是"颠簸"，但很多交易者更关心另一个问题：最惨的时候，我从顶到底亏了多少？

Max Drawdown = (峰顶 − 谷底) / 峰顶

如果你的净值从 $100,000 涨到 $150,000，然后跌到 $90,000——
最大回撤 = (150,000 − 90,000) / 150,000 = 40%。

最大回撤直接对应一个心理事实：你能承受多大的账户缩水而不割肉离场？很多策略历史夏普很好，但最大回撤 60%——真人根本拿不住。

测验

1. 量化分析中默认使用对数收益率的一个核心原因是？

计算更简单，不需要除法 多期收益率可以直接相加，且更接近正态分布 数值总是比简单收益率大 交易所规定的标准格式

2. 策略 A 年化收益 +20%，年化波动 15%；策略 B 年化收益 +50%，年化波动 60%。无风险利率 5%。哪个策略的夏普比率更高？

策略 A（夏普 = 1.0） 策略 B（夏普 = 0.75） 两个一样 夏普不考虑无风险利率

3. （回顾·上节课）你要在 CEX 上立即卖出 BTC，成交价对应什么？

Bid——买方愿意支付的最高价 Ask——卖方愿意接受的最低价 Last Price——最近成交价 Spread 的中点

4. 你的净值从 $100K 涨到 $200K，再跌到 $80K。最大回撤是多少？

20% 50% 60% 80%
